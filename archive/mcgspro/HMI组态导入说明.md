# HMI组态导入说明

**项目**：药液配置与加注控制系统 — HMI组态前期准备
**适用范围**：8套缸单元集中HMI（待选型，初步方向昆仑通态MCGS 12寸，型号代号AQEX-24）
**本目录交付物**：4份通用素材，HMI选型确认后直接导入组态软件
**配套文档**：HMI-PLC变量地址表 v1.0、HMI画面架构规划文档 v9.3、Story1.6报警详细规格书 v1.0

## 一、交付物清单与使用方法

本目录（`/workspace/AQUA-EXPO/docs/hmi_preparation/`）共4份文件，分工如下：

| 序号 | 文件名 | 类型 | 用途 | 使用阶段 |
|---|---|---|---|---|
| 1 | HMI变量导入CSV模板.csv | CSV | 91个PLC变量的批量导入模板，含变量名/数据类型/PLC地址/读写/断电保持/注释/画面编号 | 组态软件变量表批量导入 |
| 2 | 报警字32位解析映射表.md | MD | 32位报警字逐位映射（位地址/符号/优先级/报警码/颜色/文本/触发复位条件） | 报警指示灯阵列、报警文本库、确认逻辑组态 |
| 3 | 画面变量绑定清单.md | MD | 8画面共253个UI元素与PLC变量的逐项绑定 | 画面组态阶段逐元素绑定 |
| 4 | HMI组态导入说明.md | MD | 本文件，导入方法/选型适配/命名规范/颜色规范/多PLC连接配置 | 组态全程参考 |

### 1.1 CSV变量模板使用方法

1. **导入前**：用Excel或文本编辑器打开 `HMI变量导入CSV模板.csv`，确认表头7列：`变量名,数据类型,PLC地址,读写属性,断电保持,注释,画面编号`。
2. **单元前缀处理**：CSV中变量名为"通用名"（如 `VW2_StateMachine`）。导入前需按本说明第三章命名规范，为8套单元各生成一份带前缀的变量表（如 `U1_VW2_StateMachine` ~ `U8_VW2_StateMachine`），或由组态软件的"连接+变量地址"机制自动区分（推荐，见第五章）。
3. **导入操作**：
   - **MCGS**：组态软件→变量表→导入CSV（或Excel）；导入时指定"连接名"列对应PLC_01~PLC_08。若MCGS模板列名不一致，按其模板调整表头后导入。
   - **WinCC**：变量管理→新建变量→导入CSV（AS对应PLC地址）；WinCC需先建8个S7连接，再按连接导入对应变量。
   - **研华/其他**：按厂商CSV模板字段映射，本表字段为通用超集，按需裁剪。
4. **数据类型映射**：CSV中 BOOL/INT/WORD/DWORD/REAL/DT 需映射到具体HMI驱动类型。S7-200 SMART V区：BOOL=位，VW=INT/WORD(16位有符号/无符号)，VD=DWORD/REAL(32位)，DT=日期时间(8字节BCD)。
5. **断电保持列**：仅供HMI侧参考，实际断电保持由PLC系统块配置（见变量表附录A），HMI无需配置。

### 1.2 报警映射表使用方法

1. **报警指示灯阵列**：画面5按 `V300.0~V303.7` 顺序建32个指示灯，逐位绑定BOOL变量，颜色按"显示颜色"列配置。
2. **报警文本库**：将"报警码VW6值→HMI显示文本"导入HMI报警文本库，VW6大字显示时按码查表显示中文。
3. **触发/复位条件列**：用于HMI侧报警详情页提示信息（如"复位条件：V0.7高权限确认+I1.2反馈正常"），帮助操作员判断如何消缺。
4. **优先级颜色**：按"显示颜色"列直接配置，或用脚本按VW6值区间统一着色（见第四章）。

### 1.3 画面绑定清单使用方法

1. **逐画面组态**：按画面1~8顺序，对照清单逐UI元素绑定PLC变量。
2. **单元前缀**：清单中"绑定PLC变量"列为通用名，组态时按当前选中单元套前缀（见第三章）。
3. **二次确认标记**：清单"读写"列标 RW 且注释含"二次确认"的按钮，组态时配置弹窗或长按确认。
4. **待确认项**：清单中标注"待PLC支持/待确认"的元素，待PLC侧补充后绑定。

## 二、不同HMI选型的导入差异与适配建议

本项目HMI待选型（代号AQEX-24），初步方向昆仑通态MCGS。以下给出主流HMI的导入差异与适配建议，选型确认后按对应方式执行。

### 2.1 昆仑通态 MCGS（初步方向）

| 项 | 说明 |
|---|---|
| 通讯协议 | 原生支持S7-200 SMART以太网驱动（S7协议，推荐），免PLC侧额外编程 |
| 多PLC连接 | 支持单工程多连接，建议建8个连接 PLC_01~PLC_08 |
| 变量导入 | 组态软件变量表支持CSV/Excel导入；需注意MCGS变量地址格式（如 `VW2` 对应 S7-200 SMART V区） |
| 报警功能 | 支持报警组、报警文本库、报警颜色分级；32位报警字建议用"位变量"逐位组态或用脚本解析 |
| 趋势曲线 | 支持实时/历史趋势曲线，多曲线叠加 |
| 控件可见性脚本 | 中端以上型号支持（v9.3画面架构第九章三态显示必需），采购前确认 |
| 适配建议 | CSV导入前按MCGS变量表模板字段调整表头；8套变量用"连接名+地址"机制区分，无需复制8份变量表 |

### 2.2 西门子 WinCC (含 WinCC Unified / WinCC Flexible)

| 项 | 说明 |
|---|---|
| 通讯协议 | 原生支持S7-200 SMART（需安装相应通信包），S7协议 |
| 多PLC连接 | 变量管理下建8个S7连接，每连接对应1台PLC |
| 变量导入 | 支持CSV导入变量；WinCC变量地址用 `VW2` / `V0.0` / `VD10` 格式 |
| 报警功能 | 报警系统强大，支持离散量报警（位报警）和模拟量报警；32位报警字适合用"离散量报警"逐位配置 |
| 适配建议 | CSV表头改为WinCC字段（名称/数据类型/地址/采集周期等）；断电保持列删除（WinCC无此概念）；画面编号列可保留为注释 |

### 2.3 威纶通 cMT / 步科 / 研华等

| 项 | 说明 |
|---|---|
| 通讯协议 | 主流品牌均支持S7-200 SMART驱动（S7协议） |
| 多PLC连接 | 支持多连接，建8个连接 |
| 变量导入 | 多支持CSV导入；字段名各异，按厂商模板映射本CSV字段 |
| 适配建议 | 本CSV为通用超集，导入前按厂商模板裁剪字段；研华Advantech WebAccess等支持脚本可见性的型号方可实现三态显示 |

### 2.4 通用适配原则

1. **协议优先S7**：S7-200 SMART CPU本体以太网口原生支持S7协议，减少PLC侧编程（Modbus TCP需PLC侧额外编程配置Modbus服务器）。选型确认后若HMI不支持S7协议，再考虑Modbus TCP。
2. **变量表复用**：8套PLC程序完全相同、变量地址一致，组态软件应利用"连接+地址"机制，1套变量定义×8连接复用，避免维护8份重复变量表。若组态软件不支持连接复用（需变量名全局唯一），则按第三章命名规范生成8份带前缀变量表。
3. **CSV字段映射**：本CSV 7字段为通用超集，导入各HMI时按需映射/裁剪：

   | 本CSV字段 | MCGS | WinCC | 威纶通 |
   |---|---|---|---|
   | 变量名 | 变量名 | 变量名称 | 标签名 |
   | 数据类型 | 数据类型 | 数据类型 | 数据类型 |
   | PLC地址 | 寄存器地址 | 地址 | 地址 |
   | 读写属性 | 读写属性(读/写/读写) | 访问权限 | 读写 |
   | 断电保持 | (参考,不导入) | (删除) | (参考,不导入) |
   | 注释 | 注释 | 注释 | 注释 |
   | 画面编号 | (参考,可入注释) | (参考) | (参考) |

## 三、变量命名规范

### 3.1 单元前缀规则

8套PLC变量地址完全一致，HMI侧通过"单元号前缀+变量名"区分。统一前缀格式：

```
U{单元号}_{变量名}
```

- `U1_VW2_StateMachine` = 1号单元的状态机（绑定PLC_01连接的VW2）
- `U3_VW6_AlarmCode` = 3号单元的当前报警码（绑定PLC_03连接的VW6）
- `U8_VD_C_Set` = 8号单元的目标浓度（绑定PLC_08连接的VD10）
- `U1_M_Alarm_SafetyRelay` = 1号单元的安全继电器故障位（绑定PLC_01连接的V300.5）

### 3.2 变量名命名规则（沿用变量表v1.0符号）

| 变量类别 | 前缀 | 示例 | 说明 |
|---|---|---|---|
| 系统命令位 | CMD_ | CMD_Start, CMD_AckAlarm | HMI→PLC命令，V0.x |
| 系统状态位 | STA_ | STA_StartAck, STA_TankA_State | PLC→HMI状态，V1.x |
| 状态机/字 | VW_ | VW2_StateMachine, VW6_AlarmCode | VW区字变量 |
| 浮点参数/实测 | VD_ | VD_C_Set, VD_S1_Actual | VD区REAL/DWORD |
| 报警位 | M_Alarm_ | M_Alarm_Overflow_AHigh | V300.x~V303.x报警位 |
| Modbus缓冲 | MB_ | MB_Pump_Reset, MB_Pump_Aspirate | VW200~VW228映射 |
| 系统标志 | M_ | M_InitDone, M_AlarmAckMode | V304.0, V200.0 |
| 时间戳 | DT_ | DT_TankB_FullTime | DT10 |
| HMI内部 | (无PLC前缀) | Unit1_Enabled, SelectedUnit | HMI本地变量,不下发PLC |

### 3.3 命名注意事项

1. **8套复用**：HMI工程变量表按8套×91变量=728个PLC变量点组态（满配），变量点授权按8套满配核算（见画面架构文档5.1节第10条）。
2. **全局唯一**：变量名在HMI工程内全局唯一，单元前缀保证不冲突。
3. **大小写**：建议统一用大小写混合（驼峰），避免HMI不支持中文/特殊字符。
4. **HMI内部变量**：单元使能 `Unit1_Enabled`~`Unit8_Enabled`、选中单元号 `SelectedUnit`、连接状态 `PLC_01_Online`~`PLC_08_Online` 等存HMI断电保持/内存区，命名不加U前缀。

## 四、报警分级颜色规范

### 4.1 颜色定义

| 优先级 | VW6编码段 | HMI显示颜色 | RGB参考 | 视觉效果 | 强制人工确认 |
|---|---|---|---|---|---|
| 最高级 | 99 | 红色闪烁 | #FF0000 | 1Hz闪烁+背景反白，最高警示 | 是（HMI二次确认+高权限） |
| 漫溢级 | 10~14 | 红色 | #FF0000 | 常亮红色 | 是 |
| 节奏级 | 20 | 橙色 | #FF8C00 | 常亮橙色 | 是 |
| 一般级 | 21, 30~66 | 黄色 | #FFD700 | 常亮黄色 | 按M_AlarmAckMode (V200.0) |
| 无报警 | 0 | 绿色 | #00B050 | 常亮绿色 | — |

### 4.2 着色实现建议

1. **VW6大字显示**：用脚本按VW6值区间着色（推荐，避免逐位判断）：
   ```
   若 VW6 = 99       → 红色闪烁
   若 10 ≤ VW6 ≤ 14  → 红色
   若 VW6 = 20       → 橙色
   若 VW6 = 21 或 30 ≤ VW6 ≤ 66 → 黄色
   若 VW6 = 0        → 绿色
   ```
2. **32位报警指示灯阵列**：逐位绑定BOOL，颜色按报警映射表"显示颜色"列静态配置（每位固定颜色），活动位(=1)点亮、非活动位(=0)熄灭。
3. **全局报警横幅**：取8套单元VW6最高优先级，按上述区间着色，显示"X号单元:报警文本"。
4. **报警声音**：Q0.7（DO_Alarm_Sound）由PLC管理，HMI仅显示声音状态；新报警重鸣由PLC逻辑保证（FC3 NETWORK2/3）。

### 4.3 状态指示灯通用配色

| 状态 | 颜色 | RGB |
|---|---|---|
| 正常/ON/在线 | 绿色 | #00B050 |
| 故障/OFF/离线 | 红色或黄色(按严重度) | #FF0000 / #FFD700 |
| 警戒/通讯中断 | 黄色 | #FFD700 |
| 未使能/占位 | 灰色 | #BFBFBF |
| 满缸(上/下缸) | 蓝色 | #0070C0 |
| 空缸 | 灰色 | #BFBFBF |

## 五、多PLC连接配置说明

### 5.1 网络拓扑

```
本地集中HMI (192.168.2.10)
   │ 工业以太网交换机 (9口及以上)
   ├─ PLC#1 (192.168.2.101) ─ 1号缸单元
   ├─ PLC#2 (192.168.2.102) ─ 2号缸单元
   ├─ PLC#3 (192.168.2.103) ─ 3号缸单元
   ├─ PLC#4 (192.168.2.104) ─ 4号缸单元
   ├─ PLC#5 (192.168.2.105) ─ 5号缸单元
   ├─ PLC#6 (192.168.2.106) ─ 6号缸单元
   ├─ PLC#7 (192.168.2.107) ─ 7号缸单元
   └─ PLC#8 (192.168.2.108) ─ 8号缸单元
```

子网掩码：255.255.255.0（C类，现场网络环境确认后定型）。

### 5.2 HMI工程8连接配置

HMI工程中配置8个PLC连接（站点），每连接对应1台PLC：

| HMI连接名 | 目标IP | 单元编号 | 单元使能(HMI内部变量) | 首期状态 |
|---|---|---|---|---|
| PLC_01 | 192.168.2.101 | 1 | Unit1_Enabled | TRUE(首期启用) |
| PLC_02 | 192.168.2.102 | 2 | Unit2_Enabled | FALSE |
| PLC_03 | 192.168.2.103 | 3 | Unit3_Enabled | FALSE |
| PLC_04 | 192.168.2.104 | 4 | Unit4_Enabled | FALSE |
| PLC_05 | 192.168.2.105 | 5 | Unit5_Enabled | FALSE |
| PLC_06 | 192.168.2.106 | 6 | Unit6_Enabled | FALSE |
| PLC_07 | 192.168.2.107 | 7 | Unit7_Enabled | FALSE |
| PLC_08 | 192.168.2.108 | 8 | Unit8_Enabled | FALSE |

### 5.3 连接配置要点

1. **协议**：优先S7协议（S7-200 SMART原生支持，免PLC侧编程）；选型确认若HMI不支持S7，则用Modbus TCP（PLC侧需额外编程配置Modbus服务器，工作量较大）。
2. **连接名**：统一用 `PLC_01`~`PLC_08`，与单元编号一一对应，便于变量绑定与维护。
3. **变量绑定到连接**：组态软件支持"变量指定所属连接"的，1套变量定义×8连接复用（推荐）；不支持的，按第三章生成8份带 `U1_`~`U8_` 前缀的变量表，各变量指定对应连接。
4. **单元使能变量**：`Unit1_Enabled`~`Unit8_Enabled` 存HMI断电保持区，**不写入PLC**（使能是HMI侧管理概念，PLC程序8套完全相同不感知自身使能状态）。
5. **通讯在线检测**：由HMI通讯驱动自动完成，表现为内部"连接状态"变量（如 `PLC_01_Online`），无需PLC侧额外编程。
6. **三态显示驱动**：画面1卡片三态由"单元使能 × 通讯在线"组合判定（见画面架构文档第九章）：
   - 使能=TRUE 且 在线=TRUE → 彩色正常显示
   - 使能=TRUE 且 在线=FALSE → 黄色"通讯中断"占位
   - 使能=FALSE → 灰色"未接入"占位
7. **资源核算**：变量点数按8套满配（728点）核算，连接数按8核算，即使首期仅启用1套，也按满配采购，避免扩展时资源不足。

### 5.4 首期交付配置

- 仅 `Unit1_Enabled`=TRUE，2~8号=FALSE
- PLC_01 (192.168.2.101) 通讯正常，PLC_02~08 离线
- 画面1：1号彩色正常，2~8号灰色"未接入"
- 画面5：仅监控1号单元报警
- 画面7：1号PLC+其2个485从站正常，2~8号显示"未使能"
- 扩展时无需重新下装HMI工程，仅需画面8勾选新单元使能开关

## 七、待确认事项（选型后闭环）

以下事项需HMI选型（AQEX-24）确认后闭环，届时更新本目录素材：

1. **通讯协议**：S7协议或Modbus TCP（推荐S7）
2. **HMI具体型号**：是否支持8连接、728变量点、控件可见性脚本、报警/历史/趋势容量
3. **屏幕尺寸**：12寸是否足够8套总览信息密度，否则升15寸
4. **CSV导入字段**：按选型HMI的CSV模板调整 `HMI变量导入CSV模板.csv` 表头
5. **报警码编码**：本素材以Story1.6细编码（30~66）为准，若PLC编程采用变量表概要编码（50~53阀C/60~61泵/70注射泵/80 RTC/90流量开关），需同步更新《报警字32位解析映射表》第5列
6. **阀/泵手动命令位**：变量表v1.0未定义阀A/B/C手动开关、泵启停的HMI命令位（V0区已满），需PLC侧扩展后补充《画面变量绑定清单》画面3绑定
7. **注射泵速度参数映射**：VD132/136/140与Modbus 40009/40010/40011对应关系待确认
