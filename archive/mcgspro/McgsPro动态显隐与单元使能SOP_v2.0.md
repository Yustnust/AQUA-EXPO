# 第一部分:动态显隐机制SOP(AQEX-13)

## 1. 三态显示判定逻辑(使能+在线双条件)

### 1.1 判定矩阵

每个单元的显示状态由`U{n}_Enable`(使能)和`U{n}_Online`(在线)两个变量组合判定,派生出`U{n}_State`(显示状态):

| U{n}_Enable | U{n}_Online | U{n}_State | 显示状态 | 卡片颜色 | 可点击 | 数据刷新 |
|---|---|---|---|---|---|---|
| 0 | — | 0 | 未接入 | 灰色(&H808080) | 否 | 否 |
| 1 | 1 | 1 | 正常运行 | 彩色(&H00CC66绿) | 是 | 是 |
| 1 | 0 | 2 | 通讯中断 | 黄色(&H00FFFF) | 是(提示) | 否 |

### 1.2 在线判定依据

**在线判定变量**: `U{n}_VW2`(PLC状态机字,只读,来自Modbus/S7通讯)

**判定规则**:
- `U{n}_VW2 >= 0` → 在线(PLC正常响应,状态机有有效值)
- `U{n}_VW2 < 0` → 离线(通讯失败,驱动写入哨兵值-1)

**通讯失败哨兵值配置**(在设备窗口→通讯驱动属性中设置):
- 操作位置:设备窗口→双击Modbus/S7驱动→通道属性
- 字段:"通信失败时的值"
- 值:`-1`
- 确认:断开PLC后,VW2变量值自动变为-1

### 1.3 三态显示ASCII示意

```
  正常运行(State=1)         通讯中断(State=2)         未接入(State=0)
  ┌────────────────┐        ┌────────────────┐        ┌────────────────┐
  │  ▓▓▓▓▓▓▓▓▓▓▓  │        │  ░░░░░░░░░░░  │        │  ▒▒▒▒▒▒▒▒▒▒▒  │
  │  1号单元       │        │  3号单元       │        │  5号单元       │
  │  ████████████  │        │  ████ 黄 ████  │        │  ███ 灰 ███   │
  │  S4_运行中     │        │  通讯中断      │        │  未接入        │
  │  流量: 2.3L    │        │  数据: —       │        │  数据: —       │
```

## 3. 循环策略脚本(500ms周期更新Online和State)

### 3.1 创建循环策略

**操作位置**:McgsPro组态环境→左侧工作台→运行策略

| 步骤 | 操作位置 | 字段 | 值 | 确认 |
|---|---|---|---|---|
| 1 | 运行策略窗口→"新建策略"按钮 | 策略类型 | 循环策略 | 弹出新建对话框 |
| 2 | 新建对话框 | 策略名称 | `UnitStateRefresh` | 名称填入 |
| 3 | 新建对话框 | 策略内容注释 | `周期更新8单元Online和State变量` | 注释填入 |
| 4 | 点击"确定" | — | — | 策略列表出现UnitStateRefresh |
| 5 | 双击UnitStateRefresh→策略属性 | 策略执行方式 | 定时循环 | 选中 |
| 6 | 策略属性 | 循环时间(ms) | `500` | 500ms周期 |
| 7 | 点击"确定" | — | — | 属性保存 |

### 3.2 循环策略脚本内容

**操作位置**:双击UnitStateRefresh策略→进入脚本编辑器→策略行脚本

```basic
' ============================================
' 策略名: UnitStateRefresh
' 周期: 500ms
' 功能: 根据U{n}_Enable和U{n}_VW2更新U{n}_Online和U{n}_State
' 语法: McgsPro类Basic(While/EndWhile,无For/Next)
' ============================================
DIM i AS integer
DIM enName AS string
DIM vw2Name AS string
DIM onName AS string
DIM stName AS string
DIM enableVal AS integer
DIM vw2Val AS integer

i = 1
While i <= 8
    ' 动态构造变量名
    enName = "U" & i & "_Enable"
    vw2Name = "U" & i & "_VW2"
    onName = "U" & i & "_Online"
    stName = "U" & i & "_State"

    ' 读取使能标志和PLC状态机字
    !DataGetInt(enName, enableVal)
    !DataGetInt(vw2Name, vw2Val)

    If enableVal = 0 Then
        ' 未使能: State=0(未接入), Online=0
        !DataSetInt(onName, 0)
        !DataSetInt(stName, 0)
    Else
        ' 已使能: 根据VW2判断在线性
        If vw2Val >= 0 Then
            ' VW2有效, 在线
            !DataSetInt(onName, 1)
            !DataSetInt(stName, 1)
        Else
            ' VW2无效(哨兵值-1), 离线
            !DataSetInt(onName, 0)
            !DataSetInt(stName, 2)
        EndIf
    EndIf

    i = i + 1
EndWhile
```

### 3.3 脚本组态录入操作

| 步骤 | 操作位置 | 字段 | 值 | 确认 |
|---|---|---|---|---|
| 1 | UnitStateRefresh策略→双击策略行 | 脚本类型 | 脚本程序 | 进入脚本编辑器 |
| 2 | 脚本编辑器 | 粘贴§3.2脚本内容 | — | 脚本填入编辑器 |
| 3 | 菜单→"检查"→"组态查错" | — | — | 提示"脚本无错误" |
| 4 | 点击"确定"保存 | — | — | 脚本保存生效 |

### 3.4 周期性能说明

- 循环策略最小周期100ms,500ms满足实时性且CPU负载低
- 每周期执行8次`!DataGetInt`+2次`!DataSetInt`=24次数据对象操作,耗时<50ms
- 循环策略在独立线程执行,不阻塞画面刷新

## 4. 构件可见性配置(以1号单元卡片为例)

### 4.1 设计思路:三图层叠加+可见性表达式

1号单元卡片由3个叠加的标签构件组成,每个对应一种状态,通过可见度表达式控制显隐:

```
  卡片1结构(三层叠加,同一坐标位置):
  ┌──────────────────────┐
  │ Card1_Normal (彩色)   │ ← 可见度: U1_State == 1
  ├──────────────────────┤
  │ Card1_CommErr (黄色)  │ ← 可见度: U1_State == 2
```

# 第二部分:单元使能配置SOP(AQEX-14)

## 1. 单元使能存储设计(U1_Enable~U8_Enable永久存盘)

### 1.1 存储机制选型

McgsPro 3.3.6提供两种数据持久化方式,针对单元使能标志(单整数变量)选用**初值存盘**:

| 持久化方式 | 适用对象 | 是否适用Enable变量 | 选型 |
|---|---|---|---|
| 历史数据存盘(§4.4.1) | 仅组对象 | 不适用(Enable是单整数非组对象) | ✗ |
| 初值数据存盘(§4.4.3) | 整数/浮点数/字符串 | 适用 | ✓(选用) |

**初值存盘原理**(参考McgsPro 4.4.3):
- 工程启动时,数据对象加载组态时设置的初值
- 运行中调用`!SaveSingleDataInit(变量名)`将当前值保存为新初值
- 调用`!FlushDataInitValueToDisk()`将初值刷盘到磁盘文件(32K大小)
- 下次启动时,变量恢复为上次保存的初值(断电不丢失)

### 1.2 存储设计

```
  使能配置存储流程:
  ┌─────────────┐    画面8开关组态     ┌─────────────┐
  │ 运维人员操作 │ ──────────────────→ │ U1~U8_Enable │
  │ (管理员权限) │                     │ 变量值更新   │
  └─────────────┘                     └──────┬──────┘
                                             │
                              !SaveSingleDataInit
                                             ▼
                                      ┌─────────────┐
                                      │ 内存初值缓存 │
                                      └──────┬──────┘
                                             │
                              !FlushDataInitValueToDisk
                                             ▼
                                      ┌─────────────┐
                                      │ 磁盘初值文件 │ ← 断电不丢失
                                      │  (32K大小)  │
                                      └──────┬──────┘
                                             │
                                       下次启动加载
                                             ▼
                                      ┌─────────────┐
                                      │ U1~U8_Enable │
                                      │ 恢复上次值   │
                                      └─────────────┘
```

### 1.3 永久存盘两种实现方式

| 方式 | 配置位置 | 触发时机 | 刷盘延迟 | 推荐场景 |
|---|---|---|---|---|
| A.自动保存(基本属性勾选) | 实时数据库→基本属性→"变化时自动保存初值" | 变量值变化时自动触发 | 60秒后刷盘 | 日常运行(容忍60秒丢失) |
| B.脚本主动存盘 | 使能开关脚本中调用`!SaveSingleDataInit`+`!FlushDataInitValueToDisk` | 保存按钮点击时立即触发 | 立即刷盘 | 推荐采用(确保配置即时落盘) |

**本SOP采用方式B为主、方式A为辅**:基本属性勾选"变化时自动保存初值"作兜底,脚本主动存盘确保即时落盘。

## 4. 使能开关脚本(切换+存盘+日志,需管理员组权限)

### 4.1 ToggleEnable1用户策略(单单元使能切换)

**操作位置**:运行策略→新建策略→用户策略→命名`ToggleEnable1`

```basic
' ============================================
' 策略名: ToggleEnable1
' 功能: 切换1号单元使能状态(0↔1),立即存盘,更新按钮文本
' 权限: 标准按钮安全属性已限制管理员组,此处二次校验
' 语法: McgsPro类Basic(无For/Next/MsgBox)
' ============================================
DIM curVal AS integer
DIM newVal AS integer
DIM permChk AS float

' 二次校验管理员组权限(防御性)
permChk = !CheckUserGroup("管理员组")
If permChk <> 0 Then
    ' 非管理员,更新提示标签后退出
    !DataSetString("EnableTipText", "权限不足,需管理员组")
    Exit
EndIf

' 读取当前使能值
!DataGetInt("U1_Enable", curVal)

' 翻转(0→1, 1→0)
If curVal = 0 Then
    newVal = 1
Else
    newVal = 0
EndIf

' 写入新值
!DataSetInt("U1_Enable", newVal)

' 立即初值存盘(永久保存,断电不丢失)
!SaveSingleDataInit("U1_Enable")
!FlushDataInitValueToDisk()

' 更新按钮文本(通过策略行后续动作或画面脚本,此处仅更新提示)
If newVal = 1 Then
    !DataSetString("EnableTipText", "1号单元已使能,配置已保存")
Else
    !DataSetString("EnableTipText", "1号单元已禁用,配置已保存")
EndIf

' 记录操作日志(写入操作日志变量,由系统操作日志功能存盘)
' McgsPro操作日志通过!SaveData保存到MCGS_OPERATION_LOG组对象
```

### 4.3 SaveEnableConfig策略(批量保存配置)

**操作位置**:运行策略→新建策略→用户策略→命名`SaveEnableConfig`

```basic
' ============================================
' 策略名: SaveEnableConfig
' 功能: 批量保存U1~U8_Enable初值到磁盘
' 触发: BtnSave按钮(已弹窗确认)
' ============================================
DIM i AS integer
DIM enName AS string

i = 1
While i <= 8
    enName = "U" & i & "_Enable"
    ' 逐个保存初值
    !SaveSingleDataInit(enName)
    i = i + 1
EndWhile

' 统一刷盘(一次刷盘,减少TPC磁盘写入,延长寿命)
!FlushDataInitValueToDisk()

' 更新提示
!DataSetString("EnableTipText", "全部使能配置已保存并落盘")
```

**注意**:`!FlushDataInitValueToDisk()`不频繁调用(参考McgsPro 4.4.3注意事项),仅在保存按钮点击时调用一次,批量SaveSingleDataInit后统一刷盘。

### 4.4 RestoreDefaultEnable策略(恢复默认)

**操作位置**:运行策略→新建策略→用户策略→命名`RestoreDefaultEnable`

```basic
    !DataSetInt("U1_Enable", 1)

    !DataSetInt("U3_Enable", 0)

    !DataSetInt("U5_Enable", 0)
    !DataSetInt("U6_Enable", 0)
    !DataSetInt("U7_Enable", 0)
```

## 附录B:McgsPro脚本语法速查(v2.0合规)

### B.1 允许的语法

```basic
' 变量声明
DIM i AS integer
DIM name AS string
DIM val AS float

' 赋值
i = 1
name = "U" & i & "_Enable"

' 条件(只有If/Then/Else/EndIf,无ElseIf)
If x = 0 Then
    ' 语句
Else
    If x = 1 Then
        ' 语句
    Else
        ' 语句
    EndIf
EndIf

' 循环(只有While/EndWhile,无For/Next)
i = 1
While i <= 8
    ' 语句
    i = i + 1
EndWhile

' 跳出循环
Break

' 退出脚本
Exit

' 数据对象读写
!DataGetInt("U1_Enable", val)
!DataSetInt("U1_Enable", 1)

' 初值存盘
!SaveSingleDataInit("U1_Enable")
!FlushDataInitValueToDisk()

' 权限检查
perm = !CheckUserGroup("管理员组")

' 窗口操作
!OpenWindow("画面2_单元详情")
```

### B.2 禁止的语法(v1.0遗留,已废弃)

```basic
' ✗ 禁止: For/Next循环
For i = 1 To 8
Next

' ✗ 禁止: MsgBox弹窗
!MsgBox("提示", 0, "标题")

' ✗ 禁止: ElseIf
If x = 0 Then
ElseIf x = 1 Then
EndIf

' ✗ 禁止: Exit Sub / Exit Function
Exit Sub

' ✗ 禁止: VBScript式Dim(无类型)
Dim x

' ✗ 禁止: GetValue/SetValue(VBScript函数)
GetValue("U1_Enable")
```

### B.3 替代方案对照

| v1.0(VBScript,废弃) | v2.0(McgsPro类Basic) |
|---|---|
| `For i=1 To 8 ... Next` | `i=1: While i<=8 ... i=i+1 EndWhile` |
| `ElseIf` | 嵌套`If...Else...If...Else...EndIf EndIf` |
| `!MsgBox(...)` | 标准按钮"弹窗确认"安全属性 / 标签可见性提示 |
| `Exit Sub` | `Exit` |
| `Dim x` | `DIM x AS integer` |
| `GetValue("U1_Enable")` | `!DataGetInt("U1_Enable", val)` |
| `Execute("U1_Enable = 1")` | `!DataSetInt("U1_Enable", 1)` |
