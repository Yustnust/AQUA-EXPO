## 第一章 总则

### 1.1 组态环境准备

**1.1.1 软硬件环境**

| 项目 | 规格 | 说明 |
|---|---|---|
| 组态软件 | 昆仑通态MCGSE组态环境 McgseSet v6.98及以上 | 厂商官网下载，激活授权 |
| 运行环境 | Windows 7/10 64位 | 开发机+触摸屏一体 |
| 触摸屏型号 | TPC12寸（1280×800）建议 | 与线框图分辨率匹配 |
| PLC通讯 | S7-200 SMART CPU ST40/SR40 | 以太网S7协议 |
| 网络 | 工业以太网交换机（9口以上） | HMI+8台PLC |
| 字体文件 | 微软雅黑 msyh.ttc / 黑体 simhei.ttf | 中文字体，需安装到组态机 |

**1.1.2 准备工作清单**

1. 在组态机安装MCGSE组态软件，启动后激活授权（默认15天试用，正式工程需正版授权）
2. 将中文字体文件 `msyh.ttc`、`simhei.ttf` 复制到 `C:\Windows\Fonts\` 目录
3. 将配套交付物拷入组态机工作目录：
   - `HMI变量导入CSV模板.csv`（变量批量导入）
   - `MCGS变量导入_8连接版.csv`（8连接版变量表）
   - `MCGS组态脚本代码_v1.0.md`（脚本源代码）
4. 检查网络连通：组态机IP设为 `192.168.2.10`（与PLC同网段），ping `192.168.2.101` 通即配置正确
5. 关闭防火墙或开放S7通讯端口（TCP 102）

```vbscript
' 见MCGS组态脚本代码v1.0第8.1节
Dim unit, alarmCode
unit = SelectedUnit
alarmCode = GetValue("U" & unit & "_VW6_AlarmCode")

If alarmCode = 0 Then
    !MsgBox("当前无报警", 0, "提示")
    Exit Sub
End If

Dim needLevel
If alarmCode = 99 Or (alarmCode >= 10 And alarmCode <= 14) Then
    needLevel = 2  ' 最高级/漫溢级需L2+
ElseIf alarmCode >= 20 And alarmCode <= 21 Then
    needLevel = 2  ' 节奏级需L2+
Else
    needLevel = 1  ' 一般级L1+即可
End If

If LoginLevel < needLevel Then
    !MsgBox("权限不足!此报警需L" & needLevel & "权限确认", 0, "权限提示")
    Exit Sub
End If

Dim result
result = !MsgBox("确认报警?报警码:" & alarmCode, 1, "报警确认")
If result = 1 Then
    Execute("U" & unit & "_CMD_AckAlarm = 1")
    LoginTime = CStr(Now())
End If
```

### 11.1 无硬件仿真验证

MCGS提供"模拟运行"功能，无需连接PLC即可验证组态。

**步骤1：进入模拟运行**
- MCGSE → 工具 → 模拟运行（或F5快捷键）
- 选择"模拟设备"代替真实PLC驱动

**步骤2：模拟设备配置**

## 第十二章 常见问题

### 12.1 组态过程问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 变量导入CSV失败 | CSV表头与MCGS模板字段不一致 | 按MCGS变量表模板字段调整表头后重新导入 |
| 变量名重复 | 8套单元变量未加U前缀 | 按 `U{X}_变量名` 规则重命名，确保全局唯一 |
| 中文显示乱码 | 字体未加载 | 工具→字体管理→添加微软雅黑/黑体→重新打开工程 |
| 控件可见性脚本不生效 | MCGS版本不支持 | 升级MCGSE到v6.98以上；或改用脚本动态修改"Visible"属性 |
| 8连接通讯不上 | IP配置错误/防火墙 | 核对IP与子网，关闭防火墙或开放TCP 102 |
| 卡片三态颜色不变化 | 周期脚本未配置 | 主控窗口→循环策略→添加每1秒周期脚本，粘贴第4.4节脚本 |
| 单元选择器切换无效 | SelectedUnit变量未定义 | 数据对象→新建SelectedUnit(INT,断电保持,初值1) |
| 状态机文本不刷新 | 脚本未绑定到画面 | 画面2 OnLoad→添加状态机映射脚本(第5.3节) |

### 12.2 报警阵列问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 32位指示灯全亮 | BOOL变量绑定错误 | 检查V300.0~V303.7逐位绑定，不能整体绑定VW300 |
| V301.7/V303.7位显示异常 | 误绑定预留位 | 这两位不绑定变量，文本标注"预留" |
| 报警颜色不分级 | 颜色配置在指示灯上 | 颜色由脚本按VW6值区间统一着色（第8.2节脚本） |
| 报警确认后不消光 | PLC侧复位条件未满足 | 检查报警映射表"复位条件"列，确认DI信号已恢复 |
| 继电器报警无法清除 | 缺少I1.2反馈 | 现场修复后I1.2=ON，再点击V0.7确认按钮 |

### 12.3 权限问题

| 问题 | 原因 | 解决 |
|---|---|---|
| L1可进入手动画面 | OnLoad权限检查脚本未配置 | 画面3 OnLoad添加第6.1节脚本 |
| 登录后立即注销 | LoginTime未刷新 | 每次操作后 `LoginTime = CStr(Now())` |
| 15分钟超时不生效 | 周期脚本未配置 | 主控窗口→循环策略→添加第3.2节脚本 |
| 浓度参数L2可编辑 | 控件ReadOnly属性未绑定 | 浓度组3个输入框ReadOnly绑定 `Not (LoginLevel>=3)` |
| 继电器按钮L2可点击 | 按钮Enabled属性未绑定 | 按钮Enabled绑定 `LoginLevel=3` |

### 12.4 趋势曲线问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 曲线不显示 | 历史数据组态未启用 | MCGSE→历史数据→启用历史记录→添加变量 |
| 曲线只显示当前值 | TimeRange属性配置错误 | 通过第9.2节脚本设置TimeRange=3600/86400等 |
| 多曲线重叠看不清 | Y轴量程差异大 | 启用"双Y轴"或单独缩放各曲线 |
| X轴不显示轮次 | X轴变量绑定错误 | X轴绑定U{X}_VW8_RoundCount，整数刻度 |

### 12.5 通讯问题

| 问题 | 原因 | 解决 |
|---|---|---|
| PLC连接全部离线 | 网线/IP/防火墙 | HMI ping PLC IP确认网络通；关闭防火墙 |
| 部分变量读不到 | 变量地址错误 | 核对变量表地址（VW2/VW6/VD10等）与PLC程序一致 |
| 注射泵状态异常 | Modbus从站未配置 | PLC侧配置Modbus主站，VW4/VW200~228映射正确 |
| 流量计数值不更新 | 485通讯失败 | 检查485接线/波特率/站号；PLC侧Modbus轮询正常 |
| 时间同步失败 | PLC不支持RTC写入 | S7-200 SMART通过S7协议SetRTC功能，确认PLC固件支持 |

### 12.6 性能问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 画面切换卡顿 | 周期脚本执行过频 | 通讯/超时脚本间隔≥1秒，避免0.1秒级 |
| 8卡片刷新慢 | For循环8次正常 | 不应卡顿；检查是否有其他高耗时脚本 |
| 仿真运行慢 | 模拟设备数据量大 | 减少模拟设备变量数；正式运行连接真实PLC即可 |
| 报警日志表格慢 | 历史数据量大 | 配置日志保留时长90天，超出自动清理 |
