# PLC程序设计规格书 — Story 1.2 状态机S0-S7骨架

**配套文档**：《药液配置加注控制系统_PLC设计文档》v9.3、《HMI-PLC变量地址表》v1.0
**Jira Issue**：AQEX-6
**程序架构**：西门子 S7-200 SMART，OB1主循环 + FC功能块
**本规格书范围**：状态机骨架（状态调度 + S0~S7各状态基本动作 + 状态转移条件）
**不含**：阀门诊断(Story 1.3)、节奏纠偏(Story 1.4)、急停详细逻辑(Story 1.5)、报警详细逻辑(Story 1.6)、断电恢复详细逻辑(Story 1.7)——这些在各状态FC中预留调用接口，后续Story填充
**v1.1 变更**：S4(FC15)增加"下缸已排空"互锁(V1.7=0),节拍保持并行,详见 2.6 节

## 一、程序总体架构

### 1.1 程序组织块(POU)清单

| POU | 类型 | 名称 | 调用方式 | 功能 |
|---|---|---|---|---|
| OB1 | 主循环 | MAIN | 系统自动 | 主循环，调用各FC |
| FC0 | 功能块 | SysInit | 首次扫描(SM0.1) | 系统初始化 |
| FC1 | 功能块 | StateDispatcher | 每周期 | 状态机调度，根据VW2调用对应状态FC |
| FC10 | 功能块 | State_S0_Init | VW2=0时 | S0初始化状态 |
| FC11 | 功能块 | State_S1_Inlet | VW2=1时 | S1上缸进水 |
| FC12 | 功能块 | State_S2_PreMix | VW2=2时 | S2预循环搅拌 |
| FC13 | 功能块 | State_S3_Dosing | VW2=3时 | S3加药 |
| FC14 | 功能块 | State_S35_Rest | VW2=4时 | S3.5静止等候 |
| FC15 | 功能块 | State_S4_Transfer | VW2=5时 | S4上→下转移 |
| FC16 | 功能块 | State_S5_Run | VW2=6时 | S5实验运行中 |
| FC17 | 功能块 | State_S6_Drain | VW2=7时 | S6下缸排水 |
| FC18 | 功能块 | State_S7_End | VW2=8时 | S7实验结束 |
| FC19 | 功能块 | State_Error | VW2=99时 | 故障锁定 |
| FC2 | 功能块 | EStopHandling | 每周期 | 急停与安全处理（骨架预留） |
| FC3 | 功能块 | AlarmHandling | 每周期 | 报警处理（骨架预留） |
| FC4 | 功能块 | ModbusPolling | 每周期 | Modbus通讯轮询（骨架预留） |

### 1.2 OB1主循环结构

```
OB1 MAIN:
  // 首次扫描初始化
  IF SM0.1 THEN
    CALL FC0(SysInit)
  END_IF

  // 每周期调用：安全与通讯（优先级最高，任何状态都执行）
  CALL FC2(EStopHandling)    // 急停处理（可强制转移至S_ERROR）
  CALL FC4(ModbusPolling)    // Modbus轮询
  CALL FC3(AlarmHandling)    // 报警处理

  // 状态机调度（急停触发时FC2会强制VW2=99，跳过正常状态调度）
  CALL FC1(StateDispatcher)

  // 每周期刷新HMI握手状态等
  CALL FC99(HmiRefresh)      // HMI状态刷新（可选，骨架预留）
```

### 1.3 状态调度器FC1逻辑

```
FC1 StateDispatcher:
  // 根据VW2当前状态值调用对应FC
  CASE VW2 OF
    0:   CALL FC10(State_S0_Init)
    1:   CALL FC11(State_S1_Inlet)
    2:   CALL FC12(State_S2_PreMix)
    3:   CALL FC13(State_S3_Dosing)
    4:   CALL FC14(State_S35_Rest)
    5:   CALL FC15(State_S4_Transfer)
    6:   CALL FC16(State_S5_Run)
    7:   CALL FC17(State_S6_Drain)
    8:   CALL FC18(State_S7_End)
    99:  CALL FC19(State_Error)
    ELSE: VW2 := 0   // 非法状态值，强制回S0
  END_CASE
```

## 二、各状态FC规格

### 2.1 FC10 — S0初始化 (VW2=0)

**功能**：系统上电/复位后的初始状态，清空状态标志，复位所有输出，等待启动命令。

**进入条件**：
- 首次扫描(SM0.1)经FC0设置
- 急停解除后系统复位(I2.3按下)
- S7实验结束后HMI确认重启(CMD_Start)

**动作**：
| 动作 | 说明 |
|---|---|
| 复位上下缸状态 | V1.6=0(上缸空), V1.7=0(下缸空) |
| 复位所有DO | Q0.0~Q1.0全部=0（潜水泵停、阀门关、报警停） |
| 复位急停锁存 | M_EStop_Latch(V300.4)=0 |
| 复位报警标志 | VB300~VB303清零, VW6=0 |
| 清除命令握手 | V1.0~V1.5=0（响应已完成的命令确认位） |

**转移条件**：
| 条件 | 目标状态 | 说明 |
|---|---|---|
| CMD_Start(V0.0)上升沿 AND 无活动报警 | →S1(VW2=1) | HMI下发启动命令 |
| 急停触发(I1.1=OFF) | →S_ERROR(VW2=99) | FC2强制转移 |

**退出动作**：置V1.0=1(启动命令已接收握手)

### 2.2 FC11 — S1上缸进水 (VW2=1)

**功能**：打开阀A向上缸进水，用差值法计量进水量，达到目标进水量后关闭阀A并验证。

**进入条件**：从S0接收CMD_Start

**进入动作**：
| 动作 | 变量 | 说明 |
|---|---|---|
| 记录流量计快照 | VD_FlowMeter_Snapshot(VD82) = MB_Flow_Total | 差值法基准 |
| 开启阀A | Q0.2=1 | 电动球阀A打开 |
| 启动S1实测计时 | T37开始计时 | 记录VD_S1_Actual |
| 置上缸状态 | V1.6=0(空) | 进水开始，仍为空 |

**周期动作**：
| 动作 | 说明 |
|---|---|
| 计算当前进水量 | VD_Current_InletVolume(VD90) = MB_Flow_Total − VD_FlowMeter_Snapshot |
| 漫溢保护检测 | 若I0.5(液位计A高位)=ON → 触发M_Alarm_Overflow_AHigh + NC电磁阀上缸(Q0.5)动作 → 转S_ERROR |
| 阀A开到位超时检测 | 若开启后VD_Timeout_ValveA时间内I1.3未ON → 报警 |
| 流量开关A检测 | 阀A开到位后I0.0应ON，否则报警 |

**转移条件**：
| 条件 | 目标状态 | 说明 |
|---|---|---|
| VD_Current_InletVolume ≥ 目标进水量 | →S2(VW2=2) | 进水达标（目标进水量待定义，暂用VD_Vol_Target或单独定义VD_Inlet_Target） |
| 阀A关闭超时/故障报警 | →S_ERROR | 故障锁定 |
| 急停触发 | →S_ERROR | FC2强制 |

**退出动作**：
| 动作 | 说明 |
|---|---|
| 关闭阀A | Q0.2=0 |
| 延时验证(VD_Delay_ValveA_Verify) | 验证流量开关A=OFF且流量计差值不再增长 |
| 记录VD_S1_Actual | T37当前值存入VD70 |
| 【预留】二次校正接口 | S1完成后触发纠偏二次校正(Story 1.4填充) |

**【骨架阶段简化】**：目标进水量暂用固定值或HMI设定，差值法计量逻辑实现，漫溢保护和延时验证实现，但阀门详细诊断(内漏/四态)留接口给Story 1.3。

### 2.4 FC13 — S3加药 (VW2=3)

**功能**：根据目标浓度和进水量计算加药步数，控制注射泵抽液和排液。

**进入条件**：从S2预循环完成

**进入动作**：
| 动作 | 变量 | 说明 |
|---|---|---|
| 计算目标体积 | VD_Vol_Target(VD98) = VD_C_Set × VD_Current_InletVolume / VD_C_Stock | µL |
| 计算目标步数 | VD_Dose_Steps(VD102) = VD_Vol_Target / VD_StepResolution | 步 |
| 下发注射泵抽液指令 | MB_Pump_Aspirate(VW204) = VD_Dose_Steps | 写入40006 |
| 下发注射泵排液指令 | MB_Pump_Dispense(VW206) = VD_Dose_Steps | 写入40007 |
| 置泵工作标志 | 内部标志位 | 等待注射泵完成 |

**周期动作**：
| 动作 | 说明 |
|---|---|
| 轮询注射泵状态码 | VW4(映射自41001)，0=完成，1=运行中，2=抽液，3=排液，其他=错误 |
| 注射泵超时检测 | 长时间无响应或状态码报错 → 报警 |

**转移条件**：
| 条件 | 目标状态 | 说明 |
|---|---|---|
| VW4=0(注射泵完成) | →S3.5(VW2=4) | 加药完成 |
| 注射泵故障报警 | →S_ERROR | 故障锁定 |
| 急停触发 | →S_ERROR | FC2强制 |

**退出动作**：无（注射泵自动停止）

### 2.6 FC15 — S4上→下转移 (VW2=5)

**功能**：打开阀B将上缸溶液转移至下缸。**v1.1起增加"下缸已排空"互锁:下缸未空时静默等待,直到S6排空完成后自动开阀,期间不报错、不停机。**

**进入条件**：从S3.5静止等候完成(VW2=5)

**进入动作**：见下表(每周期检测,见 v1.1 互锁逻辑)

**v1.1 互锁逻辑(关键变更)**：

> **业务约束**:S4启动前必须确认下缸已排空(V1.7=0)。否则**静默等待**(不报错、不停机、不进S_ERROR),S5的预规划已转S1~S3.5进行上缸配液,本FC每周期重新检测V1.7,**下缸一空立即开阀B转液**。

| 检测项 | 条件 | 动作 |
|---|---|---|
| 状态=S4 | `AW= VW2, 5` | 必备前置条件 |
| 下缸排空检查 | `AN V1.7` | V1.7=1(下缸满)→屏蔽本FC所有S/R/计时/赋值指令 |
| 互锁放行 | V1.7=0 | 进入动作分支:开阀B、启动计时、置上缸空、启动阀B诊断 |

> **实现要点**:
> - 触发条件用 `LD SM0.0 + AW= VW2, 5`,**不用 M10.4 EU**,避免首周期 V1.7=1 时错过启动
> - 用 `LPS` 嵌套 + `AN V1.7` 在同 NETWORK 内实现动态屏蔽,符合 S7-200 SMART 的 JMP/LBL 同 NETWORK 约束
> - FC31 阀B诊断的 NETWORK 1 漫溢保护(液位 B 高位)仍每周期无条件执行——下缸真高位时强制转 S_ERROR,这是该有的安全兜底
> - 当 Diag_State_B(VW262)=0(未启动)时,FC31 走子状态 0 空转,不会误报

**进入动作**(互锁放行后执行)：
| 动作 | 变量 | 说明 |
|---|---|---|
| 开启阀B | Q0.3=1 | 电动球阀B打开 |
| 开启下缸NC球阀 | Q0.6=1 | 与阀B串联,需得电导通 |
| 启动S4计时 | T40计时 | 记录VD_S4_Actual(VD74) |
| 置上缸状态 | V1.6=0(空) | 开始转移,上缸排空 |
| 启动阀B诊断 | VB262=1 | 置诊断子状态=1(等开到位) |
| 清诊断结果 | VW268=0 | 清空上次诊断结果 |

**周期动作**：
| 动作 | 说明 |
|---|---|
| **v1.1互锁轮询** | 每周期重新检测 V1.7,下缸一空立即开阀(无需 M10.4 EU) |
| 漫溢保护检测 | 若I0.7(液位计B高位)=ON → 触发M_Alarm_Overflow_BHigh + NC电磁阀下缸(Q0.6)动作 → 转S_ERROR |
| 阀B四态诊断 | 【Story 1.3填充】流量开关B + 液位计A低位组合判断 |
| 阀B超时检测 | VD_Timeout_ValveB时间内流量开关B未ON → 报警 |
| 上缸排空检测 | I0.6(液位计A低位)=ON → 上缸已排空 |

**转移条件**：
| 条件 | 目标状态 | 说明 |
|---|---|---|
| 互锁放行 + I0.6(液位计A低位)=ON AND 流量开关B(I0.1)=OFF | →S5(VW2=6) | 转移完成（上缸空+无流量） |
| **v1.1新增** 互锁等待(V1.7=1) | 保持S4 | 静默等待下缸排空,不报错、不停机 |
| 阀B故障报警 | →S_ERROR | 故障锁定 |
| 急停触发 | →S_ERROR | FC2强制 |

**时序示意**：

```
S5 (下缸跑)  ──┬─→ 换水周期到 ──→ S6 排水 (与上缸配液并行)
              │
              └─→ Available 触发 ──→ S1 → S2 → S3 → S3.5 (上缸配液)
                                          │
                                          ↓ 进入 S4
                                          ↓
                                    ┌─ V1.7=0(下缸空) ──→ 开阀B → 转S5
                                    │
                                    └─ V1.7=1(下缸满) ──→ 静默等待,每周期轮询
                                                       (直到 S6 排空完成)
```

**退出动作**：
| 动作 | 说明 |
|---|---|
| 关闭阀B | Q0.3=0 |
| 记录VD_S4_Actual | T40当前值存入VD74 |
| 置下缸状态 | V1.7=1(满) | 转移完成，下缸满 |
| 【关键】记录DT_TankB_FullTime | 当前RTC时间写入DT10 | 用于换水周期计算 |

### 2.7 FC16 — S5实验运行中 (VW2=6)

**功能**：实验主体运行阶段，按换水周期循环执行S1→S6，累计实验时长，触发节奏纠偏预规划。

**进入条件**：从S4转移完成（首次进入）

**进入动作**：
| 动作 | 变量 | 说明 |
|---|---|---|
| S5上升沿触发预规划 | 【Story 1.4填充】计算本轮S2/S3.5目标时长 | 纠偏算法 |
| 启动换水周期计时 | T41计时 | 周期=VD_CycleSetpoint(VD20) |
| 启动实验时长累加 | VD_ExperimentDuration_Accum(VD96)开始累加 | 仅下缸=满期间 |

**周期动作**：
| 动作 | 说明 |
|---|---|
| 换水周期到达检测 | T41 ≥ VD_CycleSetpoint → 启动新一轮S1 |
| 实验时长检测 | VD_ExperimentDuration_Accum ≥ VD_ExperimentTarget → 实验结束转S7 |
| 实验时长累加 | 每周期VW8(轮次)+1 |

**转移条件**：
| 条件 | 目标状态 | 说明 |
|---|---|---|
| 换水周期到达(T41≥VD_CycleSetpoint) AND 上缸状态=空 | →S1(VW2=1) | 新一轮换水 |
| 换水周期到达 AND 上缸状态≠空 | →S_ERROR | 异常（上缸未排空，比节奏滞后更严重） |
| VD_ExperimentDuration_Accum ≥ VD_ExperimentTarget | →S7(VW2=8) | 实验时长达标,结束 |
| CMD_Stop(V0.2)上升沿 | →S7(VW2=8) | HMI手动停止 |
| 急停触发 | →S_ERROR | FC2强制 |

> **v1.1 配套说明**:S5 的"换水周期到达 → S1" 预规划触发**不**检查下缸是否已排空——S1~S3.5 的上缸配液流程可以在下缸排水期间并行进行。仅 S4 入口增加 V1.7 互锁。详细见 2.6 节。

**退出动作**：
| 动作 | 说明 |
|---|---|
| 停止换水周期计时 | T41复位 |
| 【若转S1】保持实验时长累加 | S5返回S1时累加继续 |
| 【若转S7】停止实验时长累加 | 实验结束 |

### 2.8 FC17 — S6下缸排水 (VW2=7)

**功能**：实验结束后排空下缸溶液。

**进入条件**：从S5实验运行中（换水周期内）或S7实验结束

**进入动作**：
| 动作 | 变量 | 说明 |
|---|---|---|
| 开启阀C | Q0.4=1 | 电动球阀C打开 |
| 启动S6计时 | T42计时 | 记录VD_S6_Actual(VD78) |

**周期动作**：
| 动作 | 说明 |
|---|---|

| 记录VD_S6_Actual | T42当前值存入VD78 |
| 更新VD_S6_Rolling | 滚动更新S6排水时长 |
| 置下缸状态 | V1.7=0(空) | 排空完成 |

### 2.9 FC18 — S7实验结束 (VW2=8)

**功能**：实验全部完成，状态机锁定，等待人工HMI确认。

**进入条件**：实验时长达标或HMI手动停止

**进入动作**：
| 动作 | 说明 |
|---|---|
| 复位所有DO | 潜水泵停、阀门关、报警停 |
| 停止实验时长累加 | VD_ExperimentDuration_Accum锁定最终值 |
| 置实验结束标志 | 内部标志位 |

**周期动作**：仅等待HMI确认

**转移条件**：
| 条件 | 目标状态 | 说明 |
|---|---|---|
| CMD_Start(V0.0)上升沿 | →S0(VW2=0) | HMI确认重启，回S0初始化 |
| 急停触发 | →S_ERROR | FC2强制 |

**退出动作**：无（S0会重新初始化）

### 2.10 FC19 — S_ERROR故障锁定 (VW2=99)

**功能**：急停或最高级报警触发后的故障锁定状态，所有输出强制安全状态。

**进入条件**：急停触发(I1.1=OFF)或安全继电器故障或漫溢报警

**进入动作**：
| 动作 | 说明 |
|---|---|
| 复位所有DO（安全状态） | 潜水泵停、电动球阀关、报警声音/灯光开 |
| NC电磁阀保持失电(关闭) | Q0.5=0, Q0.6=0（常闭型，失电=关闭=安全） |
| 置急停锁存 | M_EStop_Latch(V300.4)=1 |
| 置故障状态标志 | 供HMI显示 |

**周期动作**：
| 动作 | 说明 |
|---|---|
| 等待急停解除 | I1.1=ON(急停按钮恢复) |
| 等待系统复位 | I2.3(系统复位按钮)按下 |

**转移条件**：
| 条件 | 目标状态 | 说明 |
|---|---|---|
| I1.1=ON(急停解除) AND I2.3上升沿(系统复位) | →S0(VW2=0) | 急停解除并系统复位，回S0 |
| 安全继电器故障未消除 | 保持S_ERROR | 不允许离开故障态 |

**退出动作**：清除M_EStop_Latch（由S0执行）
