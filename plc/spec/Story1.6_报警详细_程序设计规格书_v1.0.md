## 一、概述与设计决策闭环

### 1.1 范围

实现 PLC 设计文档第八章定义的报警完整功能:
- **8.1 报警分级**:漫溢风险级/节奏滞后级/一般故障级/最高级(继电器故障)的优先级与处理方式
- **8.2 消音/消光独立处理**:I2.1就地消音+V0.4 HMI消音 → 只关声音;V0.3 HMI报警确认 → 根本原因消失后才消光+清锁存
- **8.3 报警日志**:时间戳+单元编号+报警类型+动作(触发/消音/已知晓/复位),写入断电保持区
- **9.3 报警确认模式**:M_AlarmAckMode(0=自动恢复/1=人工确认),漫溢/节奏滞后/继电器故障不受此模式影响

### 1.2 设计决策闭环(10项)

| # | 决策项 | 结论 | 依据 |
|---|---|---|---|
| 1 | FC3职责边界 | **FC3负责报警码计算VW6+消音消光输出管理+确认命令处理+日志记录**;不负责报警位的置位(由各FC置位)、不负责状态机锁定(由FC2/FC19) | FC3是报警"汇总+输出+确认"中枢,各报警源独立置位 |
| 2 | 优先级链实现方式 | **用LPS/LPP+AW=比较+条件跳转**,非纯JMP链 | S7-200 SMART STL的JMP是栈顶条件跳转,需先LD压栈;骨架原写法语法不严谨,重写为规范的"比较→跳转"结构 |
| 3 | 报警码细分编码 | **十位=类别,个位=细分序号**(如阀A关到位超时=32);VW6保存最高优先级未确认报警码 | 变量表9.2已定义编码规则;细分编码让HMI能精确定位报警类型 |
| 4 | 消音触发源 | **I2.1就地按钮(上升沿) OR V0.4 HMI命令(上升沿)**,两者都关Q0.7 | 第八章8.2"就地按钮或HMI命令";新报警重新鸣响(消音不锁存) |
| 5 | 消光(报警确认)条件 | **V0.3上升沿 AND 报警根本原因已消失(VW6=0 OR 对应报警位=0)**;高优先级需HMI二次确认(HMI侧实现,PLC只收V0.3) | 8.2"根本原因消失后确认才消光";8.2说明高优先级二次确认由HMI实现 |
| 6 | M_AlarmAckMode编址 | **改用V200.0**(独立位),弃用变量表建议的V124.0 | V124.0与VD124(VD_RestTime_Target,Story1.4用)冲突;V200.0独立无冲突 |
| 7 | CMD_SafetyRelayAck编址 | **改用V0.7**(Story1.5误用V0.5,与变量表CMD_ForceTankA_Empty冲突) | 变量表V0.5=CMD_ForceTankA_Empty,V0.6=CMD_ForceTankA_Full;V0.7原预留,继电器故障确认属安全关键,优先占用 |
| 8 | 自动恢复模式处理 | **M_AlarmAckMode=0时,一般故障级报警位在条件消失后自动R复位**;漫溢/节奏滞后/继电器故障不受此模式影响,保持锁存 | 8.1"自动恢复模式→条件消失后自动清除";仅一般故障级适用 |
| 9 | 报警日志存储 | **VB500~VB599环形缓冲区,16字节/条,最多6条**;新报警触发时写入,满则覆盖最旧 | 8.3要求记录;S7-200 SMART V区有限,6条够HMI轮询读取;详细历史由HMI侧存储 |
| 10 | 报警输出Q0.7/Q1.0管理权 | **FC3统一管理Q1.0灯光;Q0.7声音由FC2(急停)/FC19(故障态)置位+FC3管理消音** | 避免多FC双写;FC3每周期根据VW6管理Q1.0,FC2/FC19只置Q0.7不碰Q1.0 |

## 四、FC3 报警处理规格

### 4.1 NETWORK结构

| NETWORK | 功能 |
|---|---|
| 1 | 优先级链计算VW6(最高优先级未确认报警码) |
| 2 | 报警输出管理:有报警→灯光Q1.0常亮;新报警→声音Q1.0重新鸣响 |
| 3 | 消音处理(I2.1 OR V0.4 → 关声音,置M_Sound_Latched) |
| 4 | 报警确认处理(V0.3 → 根本原因消失才消光+清锁存) |
| 5 | 自动恢复模式(M_AlarmAckMode=0时,一般故障级条件消失自动R复位) |
| 6 | 新报警检测+日志写入(优先级链变化且新报警→写日志) |

### 4.2 NETWORK 1: 优先级链计算VW6

```
// 优先级: 99(继电器故障) > 10~14(漫溢/急停) > 20(节奏滞后严重) > 21(节奏滞后提示)
//         > 30~39(阀A) > 40~44(阀B) > 50~53(阀C) > 60~61(泵) > 70(注射泵) > 80(RTC) > 90(流量开关)
// 用LPS压栈+条件跳转实现,跳转到nAlarmCodeDone

// 最高级: 安全继电器故障
LD     V300.5
JMP    nCode99

// 漫溢级
LD     V300.0                        // 上缸漫溢
JMP    nCode10
LD     V300.1                        // 下缸漫溢
JMP    nCode11
LD     V300.2                        // NC阀上缸动作
JMP    nCode12
LD     V300.3                        // NC阀下缸动作
JMP    nCode13
LD     V300.4                        // 急停锁存
JMP    nCode14

// 节奏滞后级
LD     V300.6                        // 严重滞后
JMP    nCode20
LD     V300.7                        // 滞后提示
JMP    nCode21

// 阀A类(30~36)
LD     V301.0                        // 关后仍有流
JMP    nCode30
LD     V301.1                        // 内漏
JMP    nCode31
... (V301.2~V301.6 → 32~36)

// 阀B/C/泵类(40~47)
LD     V302.0                        // 阀B诊断异常
JMP    nCode40
... (V302.1~V302.7 → 41~47)

// 其他(60~66)
LD     V303.0                        // 阀C关到位超时
JMP    nCode60
... (V303.1~V303.6 → 61~66)

// 无报警
LD     SM0.0
MOVW   0, VW6
JMP    nAlarmCodeDone

// 报警码赋值标签
nCode99:  MOVW 99, VW6   JMP nAlarmCodeDone
nCode10:  MOVW 10, VW6   JMP nAlarmCodeDone
... (依次类推)

nAlarmCodeDone:
```

### 4.3 NETWORK 2: 报警输出管理

```
// 有活动报警(VW6≠0) → 灯光Q1.0常亮
// 新报警(VW6由0变非0) → 清M_Sound_Latched,声音重新鸣响
LD     VW6
LPS
AW<>   VW6, 0
S      Q1.0, 1                        // 灯光常亮
LPP

// 新报警检测: VW6上升沿(0→非0) → 清消音标志,声音重鸣
LD     VW6
EU                                  // 上升沿(注意:VW6是字,EU按位检测,改用比较)
// 改用: 上一周期VW6=0 且 本周期VW6≠0
// 用M11.2保存上一周期VW6状态
LD     M11.2                        // 上一周期有报警
AN     M11.2                        // 本逻辑需调整,见STL实现
// 简化: 本周期VW6≠0且M_Sound_Latched=0 → 声音开
LD     VW6
AW<>   VW6, 0
AN     M11.1                        // 未消音
S      Q0.7, 1                       // 声音开
// 更新上一周期标志
LD     VW6
AW<>   VW6, 0
=      M11.2                        // 记录本周期有报警
```

### 4.4 NETWORK 3: 消音处理

```
// 消音源: I2.1就地按钮(上升沿) OR V0.4 HMI命令(上升沿)
LD     I2.1
EU
O      V0.4
EU
R      Q0.7, 1                       // 关声音
S      M11.1, 1                      // 置消音标志(新报警时清)
S      V1.4, 1                       // STA_MuteDone握手
R      V0.4, 1                       // 清HMI消音命令
// 注: 消音只关声音,灯光Q1.0和报警锁存保持;新报警(VW6变化)时M11.1清,声音重鸣
```

### 4.5 NETWORK 4: 报警确认处理(消光)

```
// V0.3上升沿 = HMI报警确认命令
// 确认规则:
//   1. 高优先级(漫溢/节奏滞后/继电器故障):HMI侧二次确认,PLC只收V0.3,根本原因消失后才消光+清锁存
//   2. 一般故障级:M_AlarmAckMode=1(人工)时需V0.3确认;M_AlarmAckMode=0(自动)时条件消失自动清(见NETWORK5)
LD     V0.3
EU
S      V1.3, 1                       // STA_AlarmAckDone握手
R      V0.3, 1                       // 清确认命令
// 检查根本原因是否消失: VW6=0(所有报警位已清)才允许消光
LD     VW6
AW=    VW6, 0
R      Q1.0, 1                       // 根本原因消失,关灯光
// 注: 根本原因未消失(VW6≠0)时,确认只记录"已知晓",灯光保持
```

### 4.6 NETWORK 5: 自动恢复模式

```
// M_AlarmAckMode=0(自动恢复)时,一般故障级报警位条件消失自动R复位
// 漫溢/节奏滞后/继电器故障不受此模式影响,保持锁存
LD     V200.0                        // M_AlarmAckMode=0(自动)
NOT                                     // 取反:=0时执行
// 阀A类一般故障自动复位(条件:对应DI恢复正常)
// 例如V301.0(阀A关后仍有流): 阀A已关到位且流量开关A=OFF时复位
LD     V301.0                        // 阀A关后仍有流报警
AN     I0.0                          // 流量开关A已OFF(条件消失)
R      V301.0, 1                     // 自动复位
// ... 其他一般故障级同理,按各自条件复位
// 注: 漫溢(V300.0~V300.3)/急停(V300.4)/继电器故障(V300.5)/节奏滞后(V300.6/7)不在此处理
```

### 4.7 NETWORK 6: 新报警检测+日志写入

```
// VW6由0变非0(新报警触发) → 写日志
LD     M11.2                        // 上一周期VW6=0(无报警)
AN     M11.2                        // (逻辑调整,见STL)
// 简化: VW6≠0且M11.3(上一周期无报警)=1 → 新报警
LD     VW6
AW<>   VW6, 0
A      M11.3                        // 上一周期无报警
EU                                  // 上升沿
// 写日志: READ_RTC → VB500+索引×16
CALL   FC50:V AlarmLog              // 日志写入子程序(可选,或内联)
// 简化内联: 索引VW202 × 16 + VB500 = 起始地址
// 实际STL用指针AR1实现
```

> **注**: NETWORK 6 的日志写入涉及间接寻址(指针),STL实现较复杂。本Story给出规格,STL实现用简化版(固定地址+索引比较),完整环形缓冲区可在后续优化。

## 六、消音/消光/确认完整时序

### 6.1 消音时序

```
T0: 报警触发,VW6=30(阀A故障),Q0.7=1(声音),Q1.0=1(灯光),M11.1=0
T1: 操作员按I2.1(就地消音) 或 HMI下发V0.4=1
  → FC3 NETWORK3: R Q0.7(关声音), S M11.1(消音标志), S V1.4(握手)
  → 灯光Q1.0保持,报警位V301.0保持,VW6=30保持
T2: 新报警触发(VW6变化,如新增V301.1)
  → FC3 NETWORK2: M11.1被清(新报警重鸣逻辑),Q0.7=1(声音重鸣)
  → 操作员需再次消音
```

### 6.2 消光(报警确认)时序

```
场景A: 一般故障级,M_AlarmAckMode=1(人工确认)
T0: 阀A故障V301.0置位,VW6=30,Q1.0=1
```
