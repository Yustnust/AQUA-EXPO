# Story 1.2 状态机骨架 — LAD梯形图说明

**配套**：STL代码文件见 plc/stl/ 目录
**说明**：因纯文本无法绘制梯形图图形，本文档用文字描述每个网络的梯形图结构，工程师可据此在STEP 7-Micro/WIN SMART中绘制LAD。每个网络的STL代码在对应.stl文件中。

## 一、OB1主循环梯形图

### Network 1: 首次扫描初始化
```
[SM0.1]──┬──(CALL FC0 SysInit)
```
SM0.1仅在首次扫描ON，调用FC0初始化。

### Network 2~5: 每周期调用（SM0.0常ON）
```
[SM0.0]──┬──(CALL FC2 EStopHandling)    // 急停处理(优先)
[SM0.0]──┬──(CALL FC4 ModbusPolling)    // Modbus轮询
[SM0.0]──┬──(CALL FC3 AlarmHandling)    // 报警处理
[SM0.0]──┬──(CALL FC1 StateDispatcher)  // 状态机调度
```

## 二、FC1状态调度器梯形图

用比较指令+跳转线圈实现多分支：

### Network 1: 状态比较与跳转
```
// 每个比较网络结构相同，以S0为例：
[VW2 <= 0]──(JMP nStateS0)
[VW2 == 1]──(JMP nStateS1)
[VW2 == 2]──(JMP nStateS2)
... (S3/S3.5/S4/S5/S6/S7/S_ERROR)
[VW2 >= 100]──(JMP nStateInvalid)  // 非法值
```

### Network 2~12: 各状态入口LBL+CALL
```
LBL nStateS0
  └──(CALL FC10 State_S0_Init)
  └──(JMP nDispatchEnd)

LBL nStateS1
  └──(CALL FC11 State_S1_Inlet)
  └──(JMP nDispatchEnd)
... (以此类推)
```

## 三、FC10 S0初始化梯形图

### Network 1: 安全待命输出
```
[SM0.0]──┬──(MOV 0→QB0)      // 所有DO=0
         └──(R Q0.7, 1)      // 报警声音关
```

### Network 2: 启动命令检测与状态转移
```
         [VW6 == 0]
[V0.0]──┤P├──────────┬──(MOV 1→VW2)      // S0→S1
                       ├──(S V1.0, 1)      // 握手确认
                       └──(R V0.0, 1)      // 清命令位
```
V0.0上升沿(P) AND 无报警(VW6=0) → 转S1。

## 四、FC11 S1上缸进水梯形图

### Network 1: 进入动作
```
[SM0.0]──┬──(MOV VD86→VD82)   // 流量计快照
         ├──(S Q0.2, 1)       // 阀A开
         ├──(R T37, 1)        // 复位计时器
         ├──(TON T37, 32767)  // 启动S1计时
         └──(R V1.6, 1)       // 上缸=空
```

### Network 2: 计算当前进水量
```
[SM0.0]──(SUB VD86-VD82→VD90)  // 当前进水量=当前值-快照
```

### Network 3: 漫溢保护
```
[I0.5]──┬──(S V300.0, 1)       // 漫溢报警标志
        ├──(S Q0.5, 1)         // NC电磁阀上缸动作
        ├──(MOV 99→VW2)        // 转S_ERROR
        └──(MOV 0→VB3)
```

### Network 4: 进水达标转移
```
[VD90 >= VD250]──┬──(R Q0.2, 1)    // 关阀A
                 ├──(MOV 2→VW2)    // 转S2
                 ├──(MOV 0→VB3)
                 └──(MOV T37→VD70) // 记录S1实测
```

## 六、FC13 S3加药梯形图

### Network 1: 计算加药步数
```
[SM0.0]──(VD10×VD90÷VD14→VD98)   // 目标体积
       ──(VD98÷VD18→VD102)        // 目标步数
```

### Network 2: 下发注射泵指令
```
[SM0.0]──┬──(ROUND VD102→VW204)   // 抽液步数
         ├──(MOV VW204→VW206)     // 排液步数
         └──(S M10.3, 1)          // 待下发标志
```

### Network 3: 等待注射泵完成
```
[VW4 == 0]──┬──(MOV 4→VW2)        // 转S3.5
            ├──(MOV 0→VB3)
            └──(R M10.3, 1)       // 清标志

[VW4 >= 4]──┬──(S V303.4, 1)      // 注射泵故障报警
            ├──(MOV 99→VW2)       // 转S_ERROR
            └──(MOV 0→VB3)
```

## 九、FC16 S5实验运行梯形图

### Network 1: 首次进入预规划+周期计时
```
[SM0.0]──[AN M10.5]──┬──(S M10.5, 1)    // S5已进入标志
                     └──(CALL FC30预留)  // 纠偏预规划

[SM0.0]──(TON T41, VW256)                // 换水周期计时
```

### Network 3: 换水周期到达转S1
```
         [AN V1.6]    // 上缸=空(正常)
[T41]──┤          ├──┬──(R T41, 1)
                       ├──(R M10.5, 1)
                       ├──(MOV 1→VW2)    // 转S1
                       ├──(MOV 0→VB3)
                       └──(INCB VB8)     // 轮次+1

[T41]──[A V1.6]──┬──(S V301.6, 1)       // 上缸未排空异常
                 ├──(MOV 99→VW2)         // 转S_ERROR
                 └──(MOV 0→VB3)
```

### Network 4: 实验时长达标转S7
```
[VD96 >= VD24]──┬──(R T41, 1)
                ├──(R M10.5, 1)
                ├──(MOV 8→VW2)    // 转S7
                └──(MOV 0→VB3)
```

## 十二、FC19 S_ERROR梯形图

### Network 1: 故障态安全输出
```
[SM0.0]──┬──(MOV 0→QB0)       // 泵停阀关
         ├──(S Q0.7, 1)       // 声音报警
         └──(S Q1.0, 1)       // 灯光报警
```

### Network 2: 急停解除+系统复位
```
                                  [A I1.2]
[I1.1]──[A I2.3]──┤P├──────┤        ├──┬──(R V300.4, 1)  // 清急停锁存
                                        ├──(R V300.5, 1)  // 清继电器报警
                                        ├──(MOV 0→VW2)    // 转S0
                                        └──(MOV 0→VB3)
```
I1.1=ON(急停解除) AND I2.3上升沿(复位按钮) AND I1.2=ON(继电器正常) → 回S0。

## LAD绘制要点

1. **跳转指令**：LAD中用跳转线圈(JMP)和标号(LBL)实现，对应STL的JMP/LBL
2. **上升沿检测**：LAD中用P(上升沿)触点，对应STL的EU
3. **比较指令**：LAD中用比较触点(如 `|VW2 == 1|`)，对应STL的LDW=
4. **MOVE指令**：LAD中用MOV方框指令，对应STL的MOVB/MOVW/MOVD
5. **定时器**：LAD中直接用TON方框，PT输入接预设值
6. **CALL指令**：LAD中用CALL方框调用子程序FC

**导入建议**：先在STEP 7-Micro/WIN SMART中建立符号表(对应变量地址表)，再逐个新建FC/OB，可参考STL代码用LAD视图编辑(软件支持STL/LAD自动转换部分指令)。
