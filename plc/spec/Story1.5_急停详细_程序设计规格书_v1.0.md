## 一、概述与设计决策闭环

### 1.1 范围

实现 PLC 设计文档第九章定义的急停逻辑完整功能:
- **9.1 双触点分离接线**的软件体现(I1.1 PLC监测回路,硬件回路不经过PLC本规格不涉及)
- **9.2 安全继电器强制导向反馈确认**(I1.2,主触点粘连检测)
- **9.3 急停触发与解除流程**(硬件切断+软件锁存+系统复位按钮)
- **9.4 继电器故障最高级报警**(延时校验I1.2,禁止自动恢复)

### 1.2 设计决策闭环(8项)

| # | 决策项 | 结论 | 依据 |
|---|---|---|---|
| 1 | FC2与FC19职责划分 | **FC2负责急停检测与锁存触发**(每周期扫描);**FC19负责故障锁定态的等待复位**(VW2=99时调用) | FC2在OB1 NETWORK2优先调用,任何状态都能捕获急停;FC19只在S_ERROR态运行,处理复位 |
| 2 | 急停触发判据 | **I1.1下降沿**(常闭触点由ON→OFF瞬间)触发,非电平触发 | 9.3"急停触发"明确"按下瞬间"动作;用EU上升沿(NOT后)避免重复触发 |
| 3 | 安全继电器反馈延时 | **2秒**(T35,PT=20×100ms),I1.1已OFF且2秒后I1.2仍未反馈→继电器故障 | 9.2"延时一定时间";2秒兼顾继电器机械动作时间与故障捕获灵敏度 |
| 4 | 输出强制安全时机 | **FC2 NETWORK3每周期执行**,只要V300.4(M_EStop_Latch)=1就强制QB0=0 | 9.3"强制所有阀门/泵内部输出线圈复位";每周期覆盖,防止状态FC误写 |
| 5 | 报警输出归属 | **FC2只置Q0.7(声音),灯光Q1.0由FC3报警处理统一管理** | 避免FC2与FC3对Q1.0双写冲突;FC3按报警优先级管理灯光(急停=漫溢级常亮) |
| 6 | 系统复位按钮判据 | **I1.1=ON(急停已释放) AND I2.3上升沿 AND V300.5=0(无继电器故障) AND I1.2=ON(反馈正常)** | 9.3"释放后仍需按系统复位";9.4"继电器故障不允许任何自动恢复"→V300.5=0是必要条件 |
| 7 | 继电器故障清除方式 | **V300.5由HMI高权限确认后通过V0.5(CMD_SafetyRelayAck)清除,非系统复位按钮清除** | 9.4"需更高权限或更明确的二次确认";复位按钮只清V300.4急停锁存,不清V300.5 |
| 8 | 急停触发时VW2处理 | **FC2检测到急停立即MOVB 99,VB2(转S_ERROR),下一周期FC1调度进FC19** | 状态机集中管理,FC19接管故障态输出安全+等待复位 |

### 1.3 待确认项(0项)

本Story所有逻辑依据第九章规格,无新增待确认项。

## 三、FC2 急停处理规格

### 3.1 NETWORK结构

| NETWORK | 功能 |
|---|---|
| 1 | 急停触发检测(I1.1下降沿) + 锁存 + 转S_ERROR |
| 2 | 安全继电器反馈延时校验(V300.4=1且2秒后I1.2仍OFF→V300.5) |
| 3 | 急停锁存时输出强制安全(QB0=0,Q0.7声音开) |
| 4 | 急停触发写报警码(VW6=10,继电器故障VW6=99优先) |

### 3.2 NETWORK 1: 急停触发检测

```
// I1.1常闭:ON=正常,OFF=急停触发
// NOT后:急停按下=ON,用EU上升沿检测"按下瞬间"
LD     I1.1
NOT
EU
S      V300.4, 1                  // M_EStop_Latch锁存
MOVB   99, VB2                    // 转S_ERROR
MOVB   0, VB3
// 清预规划标志(防止S5残留)
R      M10.7, 1
```

### 3.3 NETWORK 2: 安全继电器反馈延时校验

```
// 急停锁存后,2秒内I1.2应反馈"动力回路已断开"
// I1.2定义:ON=动力回路已断开确认(辅助触点反馈)
// 若2秒后I1.2仍OFF → 主触点可能粘连,继电器故障
LD     V300.4                      // 急停已锁存
AN     I1.2                        // 且反馈未到位
TON    T35, 20                     // 2秒延时

LD     T35                         // 延时到达
EU
S      V300.5, 1                   // M_Alarm_SafetyRelay(最高级报警)
```

### 3.4 NETWORK 3: 输出强制安全

```
// 急停锁存时,每周期强制QB0=0(泵停/阀关/NC电磁阀失电=安全)
// Q0.7报警声音开(急停立即报警)
// Q1.0灯光不在此处理,由FC3按报警优先级统一管理
LD     V300.4
MOVB   0, QB0
S      Q0.7, 1                     // 报警声音开
```

### 3.5 NETWORK 4: 报警码写入

```
// 优先级:继电器故障(99) > 急停(10)
// FC3报警处理会综合所有报警字算VW6,此处仅保证急停态VW6非0
LD     V300.5                      // 继电器故障(最高级)
MOVB   99, VB6                    // VW6=99
MOVB   0, VB7
JMP    nFC2End

LD     V300.4                      // 急停(无继电器故障)
AN     V300.5
MOVB   10, VB6                    // VW6=10
MOVB   0, VB7

nFC2End:
```

## 四、FC19 故障锁定规格

### 4.1 NETWORK结构

| NETWORK | 功能 |
|---|---|
| 1 | 故障态输出强制安全(与FC2 NETWORK3协同,双保险) |
| 2 | 继电器故障禁止复位检测(V300.5=1时锁定) |
| 3 | 等待急停释放+系统复位按钮 → 回S0 |
| 4 | 继电器故障HMI高权限确认清除(V0.5) |

### 4.2 NETWORK 1: 故障态输出强制安全

```
// S_ERROR态双保险:即使FC2未执行,QB0也强制安全
LD     SM0.0
MOVB   0, QB0
S      Q0.7, 1                     // 声音(FC3管理消音)
// Q1.0灯光由FC3按报警优先级管理(急停/继电器故障=常亮)
```

### 4.3 NETWORK 2: 继电器故障禁止复位

```
// 9.4: 继电器故障不允许任何自动恢复,必须人工检修
// V300.5=1时,即使I1.1恢复+I2.3按下,也不允许回S0
LD     V300.5
JMP    nFC19NoReset                // 继电器故障 → 跳过复位
```

### 4.4 NETWORK 3: 急停解除+系统复位

```
// 复位条件(全部满足):
//   I1.1=ON(急停按钮已释放,常闭触点恢复)
//   I2.3上升沿(系统复位按钮按下)
//   V300.5=0(无继电器故障,NETWORK2已跳过)
LD     I1.1                        // 急停已释放
A      I2.3                        // 系统复位按钮
EU                                 // 上升沿(按下瞬间)
// 清急停锁存
R      V300.4, 1                  // M_EStop_Latch=0
// 强制上下缸状态置空(9.3:复位后上下缸状态强制置"空")
R      V1.6, 1                    // 上缸=空
R      V1.7, 1                    // 下缸=空
// 转S0初始化(9.3:回到S0重新开始,不支持从中断点继续)
MOVB   0, VB2                     // VW2=0(S0)
MOVB   0, VB3
// 清报警码
MOVB   0, VB6
MOVB   0, VB7
// 停报警声音(灯光由FC3按确认流程管理)
R      Q0.7, 1

nFC19NoReset:
LBL    nFC19NoReset
```

### 4.5 NETWORK 4: 继电器故障HMI高权限确认

```
// 9.4: 继电器故障确认需更高权限/二次确认,通过HMI下发V0.5命令
// V0.5=1表示HMI高权限确认"继电器已检修,动力回路已验证正常"
// 此时要求I1.2=ON(反馈确实正常)才允许清除V300.5
LD     V0.5                        // HMI高权限确认命令
EU
A      I1.2                        // 且安全继电器反馈确实正常(已检修)
R      V300.5, 1                  // 清除继电器故障报警
R      V0.5, 1                    // 清确认命令
// 注: 清除V300.5后,下一周期NETWORK3才允许系统复位按钮回S0
```

## 五、OB1调度顺序确认

### 5.1 当前调度顺序(已正确,无需修改)

```
NETWORK 1: SM0.1首次扫描 → FC0 SysInit
NETWORK 2: SM0.0每周期   → FC2 EStopHandling  ← 急停最高优先级
NETWORK 3: SM0.0每周期   → FC4 ModbusPolling
NETWORK 4: SM0.0每周期   → FC3 AlarmHandling
NETWORK 5: SM0.0每周期   → FC1 StateDispatcher ← 状态调度在急停之后
NETWORK 6: 实验轮次(预留)
```

### 5.2 优先级保证

- FC2在FC1之前:急停触发时FC2立即写VW2=99,同一周期FC1调度进FC19
- FC2在FC3之前:急停锁存V300.4先置位,FC3报警处理能读到完整报警字
- FC2每周期执行:即使VW2=99(S_ERROR态),FC2仍持续监测I1.2反馈(继电器故障检测不依赖FC19)

## 六、急停触发与解除完整时序

### 6.1 急停触发时序

```
T0: 操作员按下急停按钮
  → 硬件:安全继电器线圈失电,主触点断开,切断动力电(不经过PLC)
  → 软件:I1.1由ON变OFF

T0(同周期):
  → FC2 NETWORK1: I1.1 NOT EU → S V300.4(锁存) + MOVB 99,VB2(转S_ERROR)
  → FC2 NETWORK3: V300.4=1 → QB0=0 + Q0.7=1(声音)

T0+1周期:
  → FC1调度VW2=99 → FC19 NETWORK1: QB0=0(双保险)
  → FC3报警处理:读V300.4 → Q1.0灯光常亮(漫溢级)

T0~T0+2秒:
  → FC2 NETWORK2: V300.4=1, I1.2应反馈ON(动力回路已断开)
  → 若I1.2正常: T35计时中,2秒内I1.2变ON → T35复位,不触发V300.5
  → 若I1.2异常(粘连): T35计时到达 → S V300.5(继电器故障最高级报警)

T0+2秒(若继电器故障):
  → FC2 NETWORK4: VW6=99
  → FC3: V300.5=1 → 最高级报警,HMI提示"立即人工检修"
```

### 6.2 急停解除时序(无继电器故障)

```
T1: 操作员旋转/拔起急停按钮
  → 硬件:急停按钮常闭触点恢复闭合,安全继电器线圈重新得电(动力回路待复位)
  → 软件:I1.1由OFF变ON

T1(同周期):
  → FC2 NETWORK1: I1.1=ON,NOT后=OFF,EU无上升沿 → 不动作
  → V300.4保持锁存,VW2保持99(FC19继续运行)

T1~T2: 系统保持S_ERROR态,HMI显示"急停已释放,等待系统复位"

T2: 操作员按下系统复位按钮(I2.3)
  → FC19 NETWORK2: V300.5=0(无继电器故障) → 不跳过
  → FC19 NETWORK3: I1.1=ON + I2.3 EU → 清V300.4 + 上下缸置空 + VW2=0(回S0)
  → 系统从S0重新开始(不支持从中断点继续)
```

### 6.3 急停解除时序(有继电器故障)

```
T1: 操作员释放急停按钮,I1.1=ON
  → 但V300.5=1(继电器故障)
  → FC19 NETWORK2: V300.5=1 → JMP nFC19NoReset(跳过复位)
  → 即使按下I2.3,NETWORK3不执行,系统无法回S0

T2: 人工检修继电器/接触器,排除主触点粘连
  → I1.2恢复ON(动力回路已断开确认)

T3: HMI高权限操作员确认检修完成,下发V0.5=1
  → FC19 NETWORK4: V0.5 EU + I1.2=ON → R V300.5(清除继电器故障)

T4: 操作员按下系统复位按钮(I2.3)
  → FC19 NETWORK2: V300.5=0 → 不跳过
  → FC19 NETWORK3: 复位回S0
```

## 七、与报警系统交互

### 7.1 报警分级(第八章8.1)

| 报警 | 优先级 | 强制人工确认 | 确认方式 |
|---|---|---|---|
| V300.4 M_EStop_Latch | 漫溢风险级 | 是 | 系统复位按钮(I2.3) |
| V300.5 M_Alarm_SafetyRelay | **最高级**(高于漫溢) | 是 | HMI高权限确认(V0.5)+ I1.2正常 |

### 7.2 报警码VW6(第八章9.2)

| 状态 | VW6 |
|---|---|
| 继电器故障(V300.5=1) | 99 |
| 急停(V300.4=1,V300.5=0) | 10 |
| 复位后 | 0 |

### 7.3 报警输出Q0.7/Q1.0管理

| 输出 | 管理者 | 急停态行为 |
|---|---|---|
| Q0.7 报警声音 | FC2置位,FC3管理消音 | 急停触发立即ON,可消音(I2.1) |
| Q1.0 报警灯光 | FC3统一管理(按VW6优先级) | 急停/继电器故障=常亮,需报警确认后消光 |

### 7.4 FC3 AlarmHandling 协同点(FC3详细由Story 1.6实现)

- FC3读取V300.4/V300.5,按优先级计算VW6
- FC3管理Q1.0灯光:急停(10)/继电器故障(99)→常亮,需HMI报警确认(V0.3/V0.4)后消光
- FC3管理消音:I2.1按下或HMI消音命令 → R Q0.7
- 本Story的FC2/FC19不直接操作Q1.0,避免与FC3冲突

## 八、验证要点

1. **急停触发**:I1.1由ON→OFF,V300.4立即置位,VW2=99,QB0=0,Q0.7=1
2. **反馈正常**:急停后2秒内I1.2变ON,T35复位,V300.5不置位
3. **继电器故障**:急停后2秒I1.2仍OFF,V300.5置位,VW6=99
4. **急停释放**:I1.1恢复ON,V300.4保持锁存(不自动复位)
5. **系统复位(无故障)**:I1.1=ON + I2.3上升沿 + V300.5=0 → V300.4清除,VW2=0
6. **系统复位(有故障)**:V300.5=1 → I2.3无效,必须先V0.5+I1.2清除V300.5
7. **继电器故障清除**:V0.5上升沿 + I1.2=ON → V300.5清除,之后I2.3才能复位
8. **输出双保险**:FC2 NETWORK3(每周期) + FC19 NETWORK1(S_ERROR态)双重强制QB0=0
