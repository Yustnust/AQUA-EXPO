# v2.5 注射泵引擎化合并设计方案 v1.0

**日期**:2026-10-08
**前置版本**:v2.4.1(FC21 已重构,手动泵协议与 FC13 对齐)
**状态**:已实施(2026-10-08,feature/v2.5-pump-engine),待仿真验证
**影响面**:FC13 / FC21 / FC13A(不变) / 新增 FC23 / OB1(1处) / FC1A(不变) / HMI(零改动)

---

## 1. 背景与目标

### 1.1 问题

注射泵控制逻辑目前分布在两个 FC 中,同一条泵协议(写指令→等运动→强停→等就绪)被完整实现了两遍:

| 文件 | 行数 | 说明 |
|------|------|------|
| FC13_State_S3_Dosing.stl | 373 | 自动加药(上缸 S2 子流程,VW226 子状态机) |
| FC13A_PumpErrExit.stl | 36 | FC13 公共错误退出 |
| FC21_ManualSyringePump.stl | ~630 | 手动控制(v2.4.1 重构后与 FC13 协议同款) |
| **合计** | **~1040** | 大量结构重复的指令 |

历史教训:v2.4.1 之前 FC21 与 FC13 实现不一致(缺强停、缺运动检测),直接导致"手动开只能吸液"的现场故障。**两条链路各写一遍,必然再次漂移。**

### 1.2 目标

1. **单一事实源**:泵协议只写一遍,自动/手动只是同一引擎的两种模式;
2. **减体积**:缓解 ST20 程序存储器 12 KB 上限(警告 830),v2.4.1 后 FC21 体积上升,需要本方案回收;
3. **行为保持**:自动路径(FC13 现状,现场验证过)语义逐字节等价;手动路径保持 v2.4.1 行为;HMI 地址零变化。

### 1.3 非目标

- 不修改泵的 Modbus 协议、步数计算口径、6000 步上限;
- 不修改 FC1A 的搅拌泵生命周期与 VW226=9 完成闩锁消费逻辑;
- 不处理 HMI"抽液/排液/复位"三直连按钮无效问题(地址表 v1.10 注6 已登记,另行排期)。

## 2. 可行性依据(已核实)

| # | 依据 | 核实结果 |
|---|------|---------|
| 1 | **调用互斥** | FC13 仅经 FC1A 在 VW418=2(自动 S2)执行;FC21 仅在 VW2=0(S0)执行(OB1 调度保证)。两者永不同扫描周期运行,**子状态寄存器 VW226、握手位 M11.6/11.7/M12.0~12.2、定时器 T102/T104 可全套共用** |
| 2 | **模式位空闲** | M17.0~M17.7 全程序零引用,取 **M17.0 = PumpEngine_ManualMode** |
| 3 | **冷启动清理** | SBR25 已清 VW226/M12.1~12.2/M13.5~13.7;FC1A 在 S2 入口清 VW226 并初始化 VD372/VD440 |
| 4 | **完成闩锁消费** | FC1A 判定"VW226=9 且 T38 到点"→ VW418=3,下轮 S2 由 FC1A 首次进入复位 VW226——引擎保持 9=完成闩锁语义即可,FC1A **零改动** |
| 5 | **错误出口** | 自动错误走 FC13A PumpErrExit(转 S_ERROR,现场验证);手动错误只需置 99 自恢复,二者可在引擎内按模式分流,FC13A 保留不动 |

## 3. 总体架构

```
┌─────────────────┐   CALL    ┌──────────────────────────────┐
│ FC13 (自动壳)    │ ────────→ │                              │
│ ~30行:          │           │                              │
│  模式=自动       │           │      FC23 注射泵引擎          │
│  搅拌泵再断言     │           │  (VW226 子状态机,纯泵协议)    │
│  CALL引擎        │           │  0 init → 1写抽液 → 2等运动 → │
└─────────────────┘           │  3强停 → 4等就绪 → 5写排液 →  │
┌─────────────────┐           │  6等运动 → 7强停 → 8结算 →    │
│ FC21 (手动壳)    │ ────────→ │  9完成闩锁(自动) /            │
│ ~55行:          │           │  30回零 → 40冷却(手动) /      │
│  模式=手动       │           │  99错误自恢复                 │
│  HMI镜像        │           │                              │
│  启/停命令检测    │           │  错误分流: 自动→CALL          │
│  CALL引擎        │           │  PumpErrExit / 手动→99        │
└─────────────────┘           └──────────────────────────────┘
```

**核心原则**:引擎只认识"泵",不认识"自动/手动工艺"。工艺相关的东西全部留在壳里:
- 搅拌泵 Q0.0/Q0.1 → FC13 壳(FC1A 仍握有完整生命周期)
- HMI 命令/显示镜像 → FC21 壳
- 目标/累计寄存器差异 → 引擎按模式位选地址(见 §5)

## 4. 引擎状态机(FC23,子状态寄存器 VW226)

| 状态 | 名称 | 动作 | 转移 |
|------|------|------|------|
| 0 | 初始化 | 清握手(M12.0×3/M11.6×2/T102);模式自动: VD372=VD584(VD440 不清,跨轮累计);模式手动: VD372=VD452、VD440=0 | →1 |
| 1 | 写抽液 | 步数=VD372/VD350,上限6000;≤0 步:自动→9 / 手动→30;否则写 9C46(门控 VW4=0),同步 VW204 | 写失败→错误;写成功→2 |
| 2 | 等抽液运动 | M12.1 开始检测 + T102(30s);完成或超时→3(超时走强停恢复不报错) | →3 |
| 3 | 强停1 | 写 9C42=1(无需就绪门控) | 写失败→错误;成功→4 |
| 4 | 等就绪1 | 等 VW4=0;**停止请求 M13.7(仅手动会出现)→30**,否则→5 | →5 / →30 |
| 5 | 写排液 | 写 9C47(门控 VW4=0),同步 VW206 | 写失败→错误;成功→6 |
| 6 | 等排液运动 | M12.2 + T102,同状态2 | →7 |
| 7 | 强停2 | 写 9C42=1 | 写失败→错误;成功→8 |
| 8 | 等就绪2+结算 | 等 VW4=0;**单次扫描内**:VD440+=VD102×VD350,VD372-=同值;然后分支:自动: VD440≥VD584→9,未完成→1;手动: M13.7→30;VW388=0(单次)→30;VD440≥VD452→30;循环未完成→1 | 见左 |
| 9 | 完成闩锁(**仅自动**) | 清握手+T102;保持闩锁供 FC1A 消费(9+T38→VW418=3,语义与现 FC13 完全一致) | FC1A 转出后由 FC1A 清 VW226 |
| 30 | 回零(仅手动) | T102 看门狗(卡非 0 态 30s→99);写 9C43=1(门控 VW4=0 且 VW510=0,或 T104 冷却到) | →40 |
| 40 | 回零冷却 | T104(5s,VW510>0 时允许重试);写失败→99;成功→清 M13.7/握手→**0** | →0 |
| 99 | 错误 | 1 扫描后自恢复→0(手动语义,同 v2.4.1);自动路径不进 99(直接 PumpErrExit) | →0 |

NET1 非法值回收:合法集 {0~9, 30, 40, 99},其余→0+全清(同 v2.4.1 语义)。

### 关键简化(相对 v2.4.1 FC21)

- v2.4.1 把"等运动"折叠在写状态内(M13.5/13.6 保护标志),引擎回归 FC13 的独立状态 2/6——**M13.5/M13.6 整个取消**,M13.7(停止请求)保留为手动与引擎之间唯一接口位;
- 停止请求 M13.7 只能由手动壳置位(OB1 离 S0 即清),引擎内**无需模式门控**停止检查,天然安全。

## 5. 模式位与寄存器映射

### 5.1 模式位 M17.0(PumpEngine_ManualMode)

- 壳每层扫描调用引擎前无条件刷新:FC13 壳 `R M17.0,1`,FC21 壳 `S M17.0,1`;
- 引擎只在被壳调用的扫描内读它——**不存在跨扫描持久化问题,冷启动无需专门清零**;
- OB1"非S0清除"NET 追加:`LD M17.0 → MOVW 0, VW226 + R M17.0,1`——手动流程中途切自动时清残留子状态(自动运行期间 FC13 已把 M17.0 刷成 0,该清除天然不误伤自动加药)。

### 5.2 寄存器映射(引擎单一工作集)

| 引擎内部 | 自动语义 | 手动语义 | HMI 显示 |
|----------|---------|---------|---------|
| VD372(剩余) | =VD584 目标(FC1A 也初始化) | =VD452 目标 | FC21 壳每扫描镜像 →VD396 |
| VD440(累计) | S2 内跨轮累计(FC1A 入口清零) | 启动时清零 | FC21 壳每扫描镜像 →VD392 |
| VD584 | 目标(HMI 设定) | — | 不变 |
| VD452 | — | 目标(HMI 设定) | 不变 |
| VW226 | 子状态(9=完成闩锁) | 同左(9 不使用) | FC21 壳镜像 →VW390 |
| VD102/VW204/VW206 | 步数/调试缓冲 | 同左(共用) | 不变 |

**HMI 侧 VD392/VD396/VW390 地址与变量名全部不变**,只是数值来源从"FC21 自算"变成"引擎计算+壳镜像"(每扫描 2~3 条 MOVR,仅 S0 态执行)。

### 5.3 错误分流(引擎内每个错误点)

```
检测到错误(V303.4 或 VW4≥4 或 写失败)
 ├─ M17.0=0(自动) → CALL PumpErrExit (FC13A 不动: 停搅拌泵+S_ERROR+清握手)
 └─ M17.0=1(手动) → MOVW 99, VW226 + 清握手(M12.0×3/M11.6×2/T102)
```

1. **分支**:`feature/v2.5-pump-engine` 从 `feature/v2.3.1-plc-defect-fixes` 拉出;
