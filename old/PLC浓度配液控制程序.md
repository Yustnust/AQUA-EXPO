# PLC 浓度配液控制程序（梯形图逻辑设计）

## 一、控制目标

通过注射泵（加药泵）向水流中定量加注母液，配合流量计实测水流量，
按比例前馈方式控制容器内溶液浓度；同时通过电磁阀控制进/排水，
并实时采集温度、pH数据用于监控与报警。

> 说明：本设计不限定PLC品牌，采用通用梯形图（LAD）表达方式。
> 待你确定PLC型号（西门子/三菱/AB等）后，我可以帮你转换为
> 具体平台的指令（如西门子 SCALE/NORM_X/SCL，三菱 D寄存器等）。

## 二、I/O 地址分配表

### 数字量输入 (DI)

| 地址   | 名称           | 说明                     |
|--------|----------------|--------------------------|
| I0.0   | 启动按钮       | 常开，按下ON             |
| I0.1   | 停止按钮       | 常开，按下ON             |
| I0.2   | 急停按钮       | 常闭接入，动作后OFF      |
| I0.3   | 液位低开关     | 液位低于下限时ON         |
| I0.4   | 液位高开关     | 液位高于上限时ON         |
| I0.5   | 手动/自动选择  | ON=自动，OFF=手动        |
| I0.6   | 加药泵故障反馈 | 变频器/泵体故障触点      |

### 数字量输出 (DO)

| 地址   | 名称           | 说明                     |
|--------|----------------|--------------------------|
| Q0.0   | 进水电磁阀     | 进水                     |
| Q0.1   | 排水电磁阀     | 排空/换液                |
| Q0.2   | 加药泵启动     | 泵运行使能               |
| Q0.3   | 运行指示灯     |                          |
| Q0.4   | 报警指示/蜂鸣器|                          |

### 模拟量输入 (AI，均为4~20mA，需标定量程)

| 地址   | 名称       | 量程示例        | 工程量  |
|--------|-----------|----------------|---------|
| AI0    | 流量计     | 0 ~ 50 L/min   | 水流量  |
| AI1    | 温度计     | 0 ~ 100 ℃      | 温度    |
| AI2    | pH计       | 0 ~ 14 pH      | pH值    |

### 模拟量输出 (AO)

| 地址   | 名称           | 说明                          |
|--------|----------------|-------------------------------|
| AO0    | 加药泵调速信号 | 0~10V 或 4~20mA，对应泵冲程/转速 |

## 三、关键内部变量（数据块/中间继电器）

| 符号            | 类型  | 说明                             |
|-----------------|-------|----------------------------------|
| M0.0            | Bool  | 系统运行状态（启动后置位）        |
| M0.1            | Bool  | 报警总标志                        |
| M0.2            | Bool  | 液位控制完成（自动进水结束）      |
| C_set           | Real  | 目标浓度设定值（HMI输入，如 5%） |
| C_stock         | Real  | 母液浓度（HMI输入，如 20%）      |
| Q_flow          | Real  | 实测流量（AI0标定后，L/min）     |
| Q_dose_SP       | Real  | 加药泵目标流量 = Q_flow×C_set/C_stock |
| AO0_out         | Real  | 加药泵输出信号（Q_dose_SP标定后）|
| T_val           | Real  | 温度实测值                        |
| PH_val          | Real  | pH实测值                          |

## 四、梯形图逻辑（按功能分Rung说明）

### Rung 1 — 急停与安全联锁（最高优先级）

```
  I0.2(急停,常闭接线->PLC内为常开逻辑判断)
   ----| |-------------------------------( M0.0 )   系统运行状态
        |
        + I0.6(泵故障) --|/|--
```
逻辑：急停触发或加药泵故障，立即复位 M0.0，所有输出（Q0.0~Q0.2）强制OFF。

### Rung 2 — 启动/停止（自锁）

```
  I0.0        I0.1       M0.0(泵故障/急停联锁,常闭)
--| |----+---|/|----------|/|-----------------( M0.0 )
   M0.0  |
  --| |--+
```
按启动置位、按停止或联锁触发复位，标准启保停结构。

### Rung 3 — 自动模式：液位控制进水阀

```
   M0.0    I0.5(自动)   I0.3(液位低)  I0.4(液位高,常闭)
  --| |------| |-----------| |------------|/|--------( Q0.0 )  进水阀
```
液位低于下限且未到上限时，自动开进水阀；到高限后自动关闭。

### Rung 4 — 流量信号标定（模拟量转工程量）

```
Q_flow := NORM_X(AI0, 0, 27648, 0.0, 50.0)   // 视平台用SCALE/NORM_X等价指令
```
即将 4~20mA 对应的原始AD值线性转换为 0~50 L/min 的实际流量。

### Rung 5 — 加药目标流量计算（比例前馈）

```
条件： M0.0=ON  AND  I0.5(自动)=ON  AND  Q_flow > 0.5 (最小流量阈值，防止无水时误加药)

  Q_dose_SP := Q_flow * C_set / C_stock
```
即：加药泵流量 = 水流量 × (目标浓度 / 母液浓度)。
> 例：目标5%浓度，母液20%，水流量10L/min → 加药流量 = 10×5/20 = 2.5 L/min

### Rung 6 — 加药泵启停与输出

```
   M0.0     I0.5    Q_flow>0.5   I0.6(故障,常闭)
  --| |------| |--------| |------------|/|----------( Q0.2 )  加药泵启动

  AO0_out := SCALE(Q_dose_SP, 0, 量程上限, 0, 27648)   // 输出给AO0
```

### Rung 7 — 温度、pH 数据采集与报警

```
T_val  := NORM_X(AI1, 0, 27648, 0.0, 100.0)
PH_val := NORM_X(AI2, 0, 27648, 0.0, 14.0)

条件：T_val > T_HighLimit  OR  T_val < T_LowLimit
      PH_val > PH_HighLimit  OR  PH_val < PH_LowLimit
      -----------------------------------------------( M0.1 )  报警总标志
                                                       ( Q0.4 )  报警指示/蜂鸣器
```
建议报警限值可放在HMI可调参数区，例如 T: 15~35℃，pH: 6~9（按你的工艺实际设定）。

### Rung 8 — 排水/换液（手动或自动触发）

```
  I0.5(手动) OR (M0.0=OFF AND 换液指令ON)
  ------------------------------------------( Q0.1 )  排水阀
```

### Rung 9 — 运行指示

```
  M0.0
--| |----------------------------------------( Q0.3 )
```

## 五、控制流程说明（自动模式）

1. 按下启动 → M0.0置位 → 系统进入运行状态
2. 液位低于下限 → 自动开进水阀，到高限自动关闭
3. 流量计实时监测水流量 Q_flow
4. 当 Q_flow > 最小阈值时，按比例前馈公式计算加药泵目标流量 Q_dose_SP，
   驱动加药泵输出 AO0
5. 温度、pH持续采集，超限触发报警（不停机，仅提示，除非你需要联锁停机）
6. 急停或加药泵故障 → 立即停止全部输出
7. 停止按钮 → 正常顺序停止（先停泵，后关阀）

## 六、需要你确认/补充的点

1. **报警是否需要联锁停机**（例如pH超限是否要自动停加药泵）？
2. **温度、pH是否需要闭环控制**（目前只做采集报警，若需要自动调节请告知调节对象，例如加热棒/加酸碱泵）
3. **加药泵是模拟量调速（0~10V/4~20mA）还是脉冲计量泵**？我按模拟量做的，脉冲型需改用高速输出指令
4. **母液浓度 C_stock 是固定值还是也需要在线检测**？
