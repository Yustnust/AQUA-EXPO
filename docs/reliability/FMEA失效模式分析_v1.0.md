## 一、评分标准与等级定义

### 1.1 严重度 S（Severity，失效对系统/人员的影响）

| S值 | 等级 | 定义 |
|---|---|---|
| 9~10 | 灾难性 | 人身伤害 / 液体溢出造成环境污染 / 设备永久损坏 |
| 7~8 | 严重 | 漫溢风险 / 实验中断不可恢复 / 需长时间检修 |
| 5~6 | 中等 | 单周期实验失败 / 需人工介入但可恢复 |
| 3~4 | 轻微 | 短时停机 / 自动恢复 / 仅提示报警 |
| 1~2 | 可忽略 | 无实质影响 |

### 1.2 发生度 O（Occurrence，失效发生概率）

| O值 | 等级 | 定义 |
|---|---|---|
| 8~10 | 高 | 工业现场常见（机械磨损/水垢/接线松动） |
| 5~7 | 中 | 偶发（特定工况/维护周期相关） |
| 3~4 | 低 | 较少发生 |
| 1~2 | 极低 | 罕见 |

### 1.3 探测度 D（Detection，现有诊断能否发现）

| D值 | 等级 | 定义 |
|---|---|---|
| 9~10 | 几乎不可探测 | 无任何诊断 / 诊断未实现（STL骨架阶段） |
| 7~8 | 差 | 仅间接推断 / 无定位到具体设备 |
| 5~6 | 中 | 有诊断但可能误报/漏报 |
| 3~4 | 好 | 有交叉诊断（双信号源验证） |
| 1~2 | 极好 | 多重独立诊断 + 限位反馈 |

### 1.4 RPN 风险优先数判定

| RPN区间 | 风险等级 | 处置要求 |
|---|---|---|
| ≥150 | 高风险 | 必须改进，优先实施 |
| 80~149 | 中风险 | 应改进，列入计划 |
| <80 | 低风险 | 可接受，持续监控 |
