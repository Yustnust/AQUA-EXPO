## 一、设计目标

本次调整解决三个核心问题：

1. **取消独立预循环环节**：S1 上缸注水结束后，直接进入 **S2 搅拌 + 加药** 合并阶段；S2 时间到达后进入 **S3 配完等待转移**；接到下缸排空信号后进入 S4 上下缸转移。
2. **实现上下缸并行工作**：新增上缸配液子流程状态字 **VW304**。下缸实验（S4~~S6）与上缸配液（S1~~S3）并行。
3. **引入 24h 换水次数硬约束**：用户设定 24h 内下缸必须完成的换水次数 `VD414`。通过**双倒计时器**严格保证单轮换水周期。

## 二、状态机重新定义

### 2.1 VW2（下缸主状态机）

| 值  | 状态       | 说明                  |
| -- | -------- | ------------------- |
| 0  | S0 初始化   | 待机、等待启动             |
| 5  | S4 转移    | 上缸 → 下缸转移（交汇点）      |
| 6  | S5 实验运行  | 下缸内有液或正在转移/排水，实验计时中 |
| 7  | S6 下缸排水  | 下缸排空                |
| 8  | S7 实验结束  | 全部结束                |
| 99 | S\_ERROR | 报警停机                |

### 2.2 VW304（上缸配液子流程）

| 值 | 状态         | 说明            |
| - | ---------- | ------------- |
| 0 | 空闲         | 上缸无配液任务       |
| 1 | S1 上缸进水    | 阀A开，流量计累计     |
| 2 | S2 搅拌 + 加药 | 潜水泵运行，同时注射泵加药 |
| 3 | S3 配完等待转移  | 已完成，等下缸排空     |
| 4 | 已转移        | 本轮完成，准备下一轮触发  |

### 2.3 双倒计时器时序

使用 **TimerA / TimerB** 两个倒计时器，**交替分配给连续轮次**。每个计时器跟踪一个完整换水周期：从该轮 **S1 开始**，到该轮 **S6 结束**。

```
时间轴 ─────────────────────────────────────────────────────────────────→

轮次N:    S1 → S2 → S3 → S4 → S5 → S6
          ↑_________________________↑
               TimerA 倒计时

轮次N+1:                  S1 → S2 → S3 → S4 → S5 → S6
                            ↑_________________________↑
                                 TimerB 倒计时

轮次N+2:                                          S1 → S2 → S3 → S4 → S5 → S6
                                                      ↑_________________________↑
                                                           TimerA 复用
```

### 2.4 关键规则

- **TimerA/B 每个都从 S1 开始，到 S6 结束**。

- **倒计时初始值** = `T_single - VD426 - VD430`。

- **S4 转移是唯一的上下缸交汇点**：必须同时满足“下缸排空（V1.7=0）”和“上缸已配完（VW304=3）”。

- **S6 触发条件**：当前计时器剩余 ≤ `S6_actual`。

- **下一轮 S1 触发条件**：当前计时器剩余 ≤ `S1_actual + VD28 + VD430`。

- **S6 结束后上缸未配完**：直接报警“24h换水次数无法保证”，不进 S5 空等。

- **搅拌时间严格固定**：VD28 为 HMI 设定参数，不可压缩。

- **结束条件**：总换水次数 ≥ VD414 **且** 总实验时间 ≥ VD\_ExperimentTarget，同时满足才进 S7。

## 四、关键算法

### 4.1 单轮换水周期计算

```
T_single = 86400.0 / VD414          // 单次目标周期（秒）
T_cycle = T_single - VD426 - VD430  // 实际倒计时总时长
```

### 4.2 计时器启动

采用 **TON 定时器**（100ms 时基），每轮 S1 开始时根据当前轮次分配 TimerA 或 TimerB。

```
IF M16.0 = 1 THEN
    VW286 = T_cycle * 10            // TimerA 的 PT 值（100ms时基）
    TON   T46, VW286                // 启动 TimerA
ELSE
    VW288 = T_cycle * 10            // TimerB 的 PT 值
    TON   T48, VW288                // 启动 TimerB
END_IF
```

> 注：T\_A/T\_B 为两个 TON 定时器（如 T38/T121，具体地址需确认）。Timer 当前值 PV 可直接用于比较。

### 4.3 S6 触发条件

```
S6_actual = VD116                   // 首轮时实际为S4实测，由FC15存入
IF VW306 = 0 THEN
    S6_actual = VD108               // 首轮无实测值用默认值
END_IF

// TON当前值PV为100ms时基，需与S6_actual*10比较
IF Timer_Current_PV <= S6_actual * 10 AND VW2 = 6 THEN
    MOVW 7, VW2                     // 转S6排水
END_IF
```

### 4.4 下一轮 S1 触发条件

触发下一轮 S1 时，当前轮的 S1 已经完成，VD70 已有实测值，无需默认值。

```
Prep_Needed = (VD70 + VD28 + VD430) * 10    // 转换为100ms时基

IF Timer_Current_PV <= Prep_Needed AND VW304 = 0 AND VW6 = 0 THEN
    S M16.1, 1                      // 触发下一轮S1
END_IF
```

### 4.5 S6 结束后逻辑

```
IF 下缸排空 THEN
    IF VW304 = 3 THEN               // 上缸已配完
        IF 结束条件满足 THEN
            MOVW 8, VW2             // 进S7
        ELSE
            MOVW 5, VW2             // 转S4转移
            INCW VW306              // 换水次数+1
            // 切换计时器标记
            M16.0 = NOT M16.0
        END_IF
    ELSE
        // 上缸未配完：保持等待，不报警
        // 下缸已排空但无上缸液体可转移，系统等待上缸配完
        // 此情况会导致24h换水次数延迟，但不触发报警停机
    END_IF
END_IF
```

### 4.6 结束条件

```
结束条件（同时满足）:
    VW306 >= VD414
    AND VD366 >= VD24                 // VD366=实验时间累计(min), VD24=实验目标时间(min)
```

## 九、已确认事项

1. **TON 定时器地址**：TimerA=T46，TimerB=T48，S2 搅拌=T38，S4 实测=T49。
2. **S1 已开始标志位**：M16.2，S1 开始时置1，S1 完成后清0。
3. **VD442/VD446 显示值**：每周期把当前活动 TON 的 PV 除10后存入对应 VD。
4. **周期超时报警位**：V303.6（原流量开关瞬时异常位，已删除，可复用）。
5. **T_cycle <= 0 处理**：报警 V303.6 并禁止启动。
