## 一、设计目标

本次调整解决三个核心问题：

1. **取消独立预循环环节**：S1 上缸注水结束后，直接进入 **S2 搅拌 + 加药** 合并阶段；S2 时间到达后进入 **S3 配完等待转移**；接到下缸排空信号后进入 S4 上下缸转移。
2. **实现上下缸并行工作**：新增上缸配液子流程状态字 **VW304**。下缸实验（S4~~S6）与上缸配液（S1~~S3）并行。
3. **引入 24h 换水次数硬约束**：用户设定 24h 内下缸必须完成的换水次数 `VD414`。通过**双倒计时器**严格保证单轮换水周期。

### 2.2 VW304（上缸配液子流程）

| 值 | 状态         | 说明            |
| - | ---------- | ------------- |
| 0 | 空闲         | 上缸无配液任务       |
| 1 | S1 上缸进水    | 阀A开，流量计累计     |
| 2 | S2 搅拌 + 加药 | 潜水泵运行，同时注射泵加药 |

### 2.3 双倒计时器时序（v2.3 修订：软件秒计数器方案）

使用 **TimerA / TimerB** 两个倒计时器，**交替分配给连续轮次**。每个计时器跟踪一个完整换水周期：从该轮 **S1 开始**，到该轮 **S6 结束**。

```
时间轴 ─────────────────────────────────────────────────────────────────→

轮次N:    S1 → S2 → S3 → S4 → S5 → S6
          ↑_________________________↑
               TimerA 计时

轮次N+1:                  S1 → S2 → S3 → S4 → S5 → S6
                            ↑_________________________↑
                                 TimerB 计时

轮次N+2:                                          S1 → S2 → S3 → S4 → S5 → S6
                                                      ↑_________________________↑
                                                           TimerA 复用
```

**实现机制（v2.3 修订，替代原 T46/T48 TON 方案）**：

- **VD248 / VD252**：TimerA / TimerB 的 32 位 REAL 秒计数器（Elapsed，已运行秒数），每轮 S1 首次进入时由 FC11 将对应计数器清零。
- **T63**：1 秒脉冲发生器（TON，PT=10，100ms 时基），由 FC40 每周期驱动。
- **累加规则**：仅在 `VW304=1`（上缸 S1 期间）且 1s 脉冲到达时，给当前活动计数器 `+1.0`。
- **采用本方案的原因**：TON 定时器 PV 为 16 位 INT，100ms 时基上限 32767（约 54.6 分钟），无法覆盖 T_cycle（VD414=6 时约 14370 秒）；32 位 REAL 秒计数器无此限制（原"TON PT 16 位 INT 溢出"问题随之消除）。
- **显示值**：VD256 / VD244（DINT，秒）由 FC40 每周期将对应 Elapsed 取整写入，供 HMI 读取。

### 2.4 关键规则

- **TimerA/B 每个都从 S1 开始计时，到 S6 结束**：每轮 S1 首次进入时清零对应计数器，S6 完成时切换 M16.0（**全程序仅此一处切换**，见 §5.6）。

- **周期比较基准**：`T_cycle = 86400/VD414 − VD426 − VD430`（秒），由 FC40 每周期计算（VD186）。

- **S4 转移是唯一的上下缸交汇点**：必须同时满足"下缸排空（V1.7=0）"和"上缸已配完（VW304=3）"。

- **S6 触发条件**：当前计时器剩余时间 ≤ `S6_actual`，即 `Elapsed ≥ T_cycle − VD116`。`VD116` 为 S6 滚动实测时长（首轮为 S4 实测值，由 FC15 写入；后续轮次为 S6 实测值，由 FC17 写入）。

- **下一轮 S1 触发条件**：当前计时器剩余 ≤ `S1_actual + VD28 + VD430`，即 `Elapsed ≥ T_cycle − (VD70 + VD28 + VD430)`。此时上缸必须处于"已转移"（VW304=4）状态。

- **S6 结束后上缸未配完**：直接报警"24h换水次数无法保证"，不进 S5 空等。

- **搅拌时间严格固定**：VD28 为 HMI 设定参数，不可压缩。

- **结束条件**：总换水次数 ≥ VD414 **且** 总实验时间 ≥ VD_ExperimentTarget，同时满足才进 S7。

## 四、关键算法

### 4.1 单轮换水周期计算

```
T_single = 86400.0 / VD414          // 单次目标周期（秒）
T_cycle  = T_single - VD426 - VD430 // 实际倒计时总时长（秒）
```

### 4.2 计时器启动（v2.3 修订：软件秒计数器方案）

不再使用 TON 双倒计时器。改为 **FC11 在 S1 首次进入时清零对应 Elapsed 计数器**，FC40 用 T63 产生的 1s 脉冲在 S1 期间累加：

```
// FC11（NETWORK：S1 首次进入）
IF VW304=1 AND M16.2=0 THEN
    S M16.2, 1                      // 置 S1 已开始标志（防重复清零）
    IF M16.0=1 THEN VD248 = 0.0     // 清零 TimerA_Elapsed
    ELSE           VD252 = 0.0     // 清零 TimerB_Elapsed
    R T37, 1                        // 复位 S1 实测计时
    TON T37, 32767                  // 启动 S1 实测计时（PT 取最大值，完成时读当前值）
END_IF

// FC40（NETWORK 2/3）
TON T63, 10                         // 1s 脉冲发生器（100ms 时基）
IF T63 上升沿 AND VW304=1 AND M16.0=1 THEN VD248 += 1.0 END_IF
IF T63 上升沿 AND VW304=1 AND M16.0=0 THEN VD252 += 1.0 END_IF
```

> 注：Elapsed 为"已运行秒数"，**比较方向与"剩余时间"相反**，使用时应按 §4.3/§4.4 的换算关系书写。

### 4.3 S6 触发条件（v2.3 修订）

```
S6_actual = VD116                   // 首轮为S4实测（FC15写入），后续为S6滚动实测（FC17写入）
IF VW400 = 0 THEN S6_actual = VD108 END_IF   // 首轮无实测值用默认值

// "剩余 ≤ S6_actual" ⇔ "Elapsed ≥ T_cycle − S6_actual"
IF Elapsed >= T_cycle - S6_actual AND VW2 = 6 AND VW6 = 0 THEN
    MOVW 7, VW2                     // 转S6排水
    S    M10.7, 1                   // 置S6首次进入脉冲（供FC17消费，见 §5.6）
END_IF
```

### 4.4 下一轮 S1 触发条件（v2.3 修订）

触发下一轮 S1 时，当前轮的 S1 已经完成，VD70 已有实测值，无需默认值。

```
Prep_Needed = VD70 + VD28 + VD430   // S1实测 + S2固定 + 上缸安全余量（秒）

// "剩余 ≤ Prep_Needed" ⇔ "Elapsed ≥ T_cycle − Prep_Needed"
IF Elapsed >= T_cycle - Prep_Needed AND VW304 = 4 AND VW6 = 0 THEN
    S M16.1, 1                      // 触发下一轮S1脉冲
END_IF

// M16.1 消费方（OB1 新增，FC40 之后、上缸子流程调度之前）：
IF M16.1 = 1 THEN
    MOVW 1, VW304                   // 上缸进入下一轮 S1
    R    M16.1, 1                   // 清脉冲
END_IF
```

> 注：VW304=4（已转移）是上缸可启动下一轮的唯一合法入口状态；首轮由 FC10 直接置 VW304=1（不经 M16.1，见 §5.8）。

### 4.5 S6 结束后逻辑

```
IF 下缸排空 THEN
    IF VW304 = 3 THEN               // 上缸已配完
        IF 结束条件满足 THEN
            MOVW 8, VW2             // 进S7
        ELSE
            MOVW 5, VW2             // 转S4转移
            INCW VW400              // 换水次数+1
        END_IF
    ELSE
        // 上缸未配完：保持等待，不报警
        // 下缸已排空但无上缸液体可转移，系统等待上缸配完
        // 此情况会导致24h换水次数延迟，但不触发报警停机
    END_IF
END_IF
```

> 注：**M16.0 切换不在此处**。S6 完成转移（含切 M16.0、VW304 置 4 的后续流转）统一由 FC17 处理（见 §5.6），全程序仅此一处切换计时器。

### 4.6 结束条件

```
结束条件（同时满足）:
    VW400 >= VD414
    AND VD366 >= VD24                 // VD366=实验时间累计(min), VD24=实验目标时间(min)
```

## 五、逐FC改动清单

### 5.1 FC40\_RhythmCorrection.stl — 功能重构

**删除原功能**：三层纠偏。

**新增功能**：双倒计时器（软件秒计数器）管理与触发。由 OB1 每周期调用（FC22 之后、FC1 之前）。

```stl
NETWORK 1: 计算单轮周期
  LD     SM0.0
  MOVR   86400.0, VD186
  /R     VD414, VD186               // T_single
  -R     VD426, VD186               // - Transfer_Margin
  -R     VD430, VD186               // - Safety_Margin = T_cycle
  // T_cycle <= 0 → 报警 V303.6 并跳过本周期其余计算（跳到本FC末尾）

NETWORK 2: 1秒脉冲发生器
  LD     SM0.0
  R      T63, 1
  TON    T63, 10                    // PT=10(100ms时基)=1s
  LD     T63
```
