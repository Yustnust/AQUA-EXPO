# S2-S4 流程重构与 24h 换水次数硬约束设计方案 v1.0

> **配套文档**：《药液配置加注控制系统_PLC设计文档》v9.x、《HMI-PLC变量地址表_v1.8+》、《PLC_完整寄存器映射表_v1.1》  
> **适用范围**：8套缸单元（S7-200 SMART CPU ST20 + EM DT16/DR16），1台本地集中HMI  
> **文档性质**：设计调整方案，待用户确认后实施（先改文档，再改代码）  

---

## 一、设计目标

本次调整要解决三个核心问题：

1. **取消独立预循环环节**：S1 上缸注水结束后，直接进入“搅拌 + 加药”合并阶段，搅拌时间到达后进入 S4 上下缸转移。  
2. **实现上下缸并行工作**：在单 VW2 状态机下无法真正并行，新增上缸配液子流程状态字 **VW100** + 触发标志 **M10.3**，实现“下缸实验（S5/S6）”与“上缸配液（S1/S3）”并行。  
3. **引入 24h 换水次数硬约束**：用户设定 24h 内下缸必须完成的换水次数 `VD_24h_Target`。第一轮后的所有循环必须严格满足该次数；搅拌时间严格固定；S5 实验时间作为弹性量，通过自动调整来适应 24h 周期。

## 二、新流程总览

### 2.1 状态机重新定义

| 状态字 | 值 | 含义 | 说明 |
|---|---|---|---|
| **VW2（下缸主状态机）** | 0 | S0 初始化 | 待机、等待启动 |
|  | 5 | S4 转移 | 上缸 → 下缸转移（交汇点） |
|  | 6 | S5 实验运行 | 下缸内有液，实验计时 |
|  | 7 | S6 下缸排水 | 下缸排空 |
|  | 8 | S7 实验结束 | 全部结束 |
|  | 99 | S_ERROR | 报警停机 |
| **VW100（上缸配液子流程）** | 0 | 空闲 | 上缸无配液任务 |
|  | 1 | S1 上缸进水 | 阀A开，流量计累计 |
|  | 3 | S3 搅拌 + 加药 | 潜水泵运行，同时注射泵加药 |
|  | 4 | 配完等待转移 | 已完成，等下缸到位 |
|  | 5 | 已转移 | 本轮完成，下一轮触发后清零 |

> 注：VW100 中跳过 2，保留与原 S2 的编号区分，避免文档混淆。

### 2.2 正常时序

```
时间轴 ──────────────────────────────────────────────────────────────→

VW2  │S0│   S5实验运行（弹性）   │S6│S4│S5│S6│S4│ ... │S7│
     └──┘                      └──┘──┘  └──┘──┘
     ↑ 启动                    ↑        ↑
     下缸空等上缸配完           下缸排空  上缸已配完→转移

VW100│0│  1(进水)→3(搅拌+加药)→4(等)              1→3→4  ...
     ──┘                          ↑                ↑
                                  │                └── S4完成瞬间触发新一轮
                                  └── 搅拌到且加药完
```

### 2.3 关键规则

- **S4 转移是唯一的上下缸交汇点**：必须同时满足“下缸排空（V1.7=0）”和“上缸已配完（VW100=4）”。
- **S4 完成后立即触发新一轮上缸配液**：下缸变满的同时，上缸开始下一轮进水。
- **S5 结束条件**：S5 目标实验时间到（VD_S5_Elapsed ≥ VD_S5_Elapsed_Target）**且** 上缸已配完（VW100=4，防止下缸排空后无液可换）。若上缸未配完，下缸继续实验（适当延长 S5），等待上缸配完。
- **搅拌时间严格固定**：VD_PreMixTime 为 HMI 设定参数，不可压缩。
- **24h 换水次数硬约束**：由 VD_24h_Target 反算单次目标周期，S5 实验时间 = 单次周期 - 上缸配液固定时间 - S6/S4 估算时间 - 余量。

## 四、关键算法

### 4.1 单次周期与 S5 目标时长计算

每轮 **S4 完成瞬间**（下缸刚变满，进入 S5）执行一次：

```
T_single = 86400.0 / VD_24h_Target          // 单次目标周期（秒）

S1_est = VD70
IF S1_est < 1.0 THEN S1_est = 20.0          // 首轮无实测值时用默认值

Stir_fixed = VD_PreMixTime                  // 严格固定

S6_est = VD116
IF S6_est < 1.0 THEN S6_est = VD_S6_Default // 首轮无滚动值时用默认值

Transfer_margin = 30.0                      // S4转移+安全余量（秒）

VD_S5_Elapsed_Target = T_single - S1_est - Stir_fixed - S6_est - Transfer_margin

IF VD_S5_Elapsed_Target < VD_S5_MinSafe THEN
    报警 V303.6 = 24h换水次数设置过激进
    VD_S5_Elapsed_Target = VD_S5_MinSafe     // 安全兜底
END_IF
```

### 4.2 S5 结束条件

```
S5结束条件（全部满足）:
    VW2 = 6
    VD_S5_Elapsed >= VD_S5_Elapsed_Target
    VW100 = 4      // 上缸已配完，确保转移后有液可换
    VW6 = 0

满足后:
    MOVW 7, VW2    // 转S6排水
    // 不清VD_S5_Elapsed，S6完成后由FC15清
```

若 `VD_S5_Elapsed >= VD_S5_Elapsed_Target` 但 `VW100 ≠ 4`：
- 下缸继续实验（S5 自然延长）
- 若超过 `VD_S4WaitTimeout` 仍未等到 VW100=4，则报“上缸配液超时”（复用或新增报警码）

### 4.3 24h 窗口结束判定

新增一个“24h 周期开始时间戳”**DT_24h_Start**（建议占用 DT12 = VB18~VB25，需确认VB18~VB25是否空闲）：

- 首轮 S4 完成瞬间，记录 DT_24h_Start = 当前 RTC
- 后续每完成一次换水（S6 完成），VW_CycleCount + 1
- 当 `当前RTC - DT_24h_Start >= 24h` 时：
  - 若 `VW_CycleCount < VD_24h_Target` → 报警“24h换水次数不足”
  - 无论是否达标，本周期结束，进入 S7

> 备选简化方案：不增加DT12，仍沿用 `VD_ExperimentTarget`（总实验分钟数）作为总时长控制，24h/N次通过S5弹性时长自然保证。但无法检测“实际未达标”的报警。

## 五、逐FC改动清单

### 5.1 删除 FC40_RhythmCorrection.stl

原三层纠偏算法完全废弃，删除该文件并在 FC1/OB1 中移除对其调用。

### 5.2 新建 FC1A_State_S3_Prepare.stl

由 **FC12 + FC13 合并**而来，实现“搅拌 + 加药同时进行”。

**NETWORK 1：首次进入**
```stl
LDW=   VW100, 3
AN     M10.4                    // 首次进入标志（新分配，如M10.4）
S      M10.4, 1
S      Q0.0, 1                  // 开潜水泵1
S      Q0.1, 1                  // 开潜水泵2
MOVR   VD28, VD336              // 复用VD336运算中间变量
*R     10.0, VD336
ROUND  VD336, AC0
MOVW   AC0, VW252               // PT值（与FC12原用法兼容）
TON    T120, VW252              // 搅拌总时长
// 加药子状态机初始化
MOVW   0, VW226
R      V303.4, 1
MOVR   VD584, VD372             // 剩余量=目标量
MOVR   0.0, VD440               // 累计加药量清零（每轮S3清零）
```

**NETWORK 2~N：加药子状态机**
复用 FC13 全部状态机逻辑（VW226 0~9），仅做以下调整：
- 不再在 NETWORK 1 中开潜水泵（已上移）
- 不再在 NETWORK 15 转 S3.5，改为检测搅拌完成 + 加药完成

**NETWORK X：完成判定**
```stl
LD     T120                     // 搅拌时间到
A      VW226.9                  // 加药完成（VW226=9的完成位，需确认表达）
A      V303.4                   // 无加药错误（取反逻辑按实际PLC语法）
// 实际实现建议：LDW= VW226, 9 + AN V303.4
R      Q0.0, 1
R      Q0.1, 1
R      T120, 1
MOVW   4, VW100                 // 上缸配完，等转移
S      M10.2, 1                 // 保留原S1首次进入标志清位逻辑，需调整位置
```

**NETWORK X+1：搅拌到但加药未完成**
```stl
LD     T120
AN     VW226.9                  // 加药未完成
// 报警：加药超时（搅拌时间内未完成）
S      V303.5, 1                // 或新增报警位
```

### 5.3 FC11_State_S1_Inlet.stl

**删除**：
- NETWORK 7 二次校正 FC40 调用

### 5.8 FC10_State_S0_Init.stl

## 九、待确认事项

1. **DT_24h_Start 是否新增？** 如需严格检测“24h内未达标”，建议新增 DT12（VB18~VB25）；如仅通过 S5 弹性时长保证，可不新增。
2. **M10.4 首次进入标志是否可用？** 当前M10.2/M10.3/M10.6/M10.7均已定义，M10.4/M10.5需确认空闲。
3. **加药超时报警位**：复用 V303.x 中未用位，或新增 V303.7？
4. **S5空等是否计入24h窗口？** 建议计入，使24h/N次成为真正硬约束。
5. **首轮下缸是否直接进S5空等？** 当前方案如此，可简化启动逻辑；如希望首轮也先S4转移一次再进S5，需调整。
