## 一、风险评级标准

### 1.1 概率等级(Probability)

| 等级 | 描述 | 判定依据 |
|---|---|---|
| 高 | 极可能发生 | 已有缺陷确证/现场工况常见/采购周期已超期 |
| 中 | 可能发生 | 偶发工况/特定条件触发/依赖外部决策 |
| 低 | 较少发生 | 罕见工况/多重保护存在/已制定缓解措施 |

### 1.2 影响程度(Impact)

| 等级 | 描述 | 判定依据 |
|---|---|---|
| 严重 | 人身/漫溢/安全功能失效/项目里程碑无法达成 | S=9~10 / 阻塞验收 / 安全联锁失效 |
| 高 | 单元停机/实验失败/采购关键路径延误 | S=7~8 / 需长时间检修 |
| 中 | 单周期失败/需人工介入可恢复/进度小幅滑移 | S=5~6 |
| 低 | 短时停机/仅提示/自动恢复 | S=3~4 |
