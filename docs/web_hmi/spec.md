# AQUA-EXPO Web HMI 技术规格书

**项目**：药液配置与加注控制系统（AQUA-EXPO）  
**文档用途**：替代昆仑通态 McgsPro 触摸屏方案，采用触屏电脑 + Web HMI 实现 8 套缸单元集中监控  
**版本**：v1.1  
**编制日期**：2026-07-30  
**更新日期**：2026-07-31  
**关联 JIRA**：AQEX-49（Epic: Web HMI 替代 McgsPro 触屏方案）  
**状态**：全部开发任务已完成

## 1. 概述

### 1.1 背景

原 McgsPro 方案已完成变量表、CSV 导入文件、画面绑定清单、脚本代码等设计，但在实际导入过程中遇到 McgsPro 西门子_Smart200 驱动对 8 位无符号数据类型支持不完整、画面组态依赖专用组态软件、后续扩展远程访问困难等问题。McgsPro 专用文件已归档至 `archive/mcgspro/`，本方案替代 McgsPro 作为正式 HMI 实现。

### 1.2 新方案目标

采用**触屏电脑 + Web HMI** 方案，实现：

- 8 套缸单元集中监控
- 实时报警 + 声光提示 + 强制弹窗
- 参数写入 + 手动控制（带二次确认）
- 历史数据记录与趋势曲线
- 操作员/管理员两级权限
- 跨平台（Windows/Android、x86/ARM）
- PLC 通过交换机/网线直连/WiFi 与触屏电脑通信

### 1.3 复用基础

本方案直接复用以下已有成果：

- `docs/HMI-PLC变量地址表_v1.0.md`：变量命名与地址分配权威来源
- `docs/hmi_preparation/画面变量绑定清单.md`：8 画面 253 个 UI 元素绑定关系
- `docs/hmi_preparation/McgsPro脚本代码_54个_v2.0.md`：业务逻辑（启动/停止/手动/参数/报警/权限）
- `docs/hmi_preparation/报警字32位解析映射表.md`：报警字按位解析规则
- `docs/hmi_preparation/HMI用户权限矩阵_v1.0.md`：权限控制逻辑（合并为两级）

## 2. 技术架构

### 2.1 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                     触屏电脑（工业一体机/平板）               │
│  ┌─────────────────────┐      ┌──────────────────────────┐  │
│  │   前端：React SPA     │      │   后端：FastAPI + Python  │  │
│  │   (浏览器全屏/PWA)    │◄────►│   pymodbus + SQLite      │  │
│  │                     │      │                          │  │
│  │   - 总览/详情/手动   │      │   - Modbus TCP 主站轮询   │  │
│  │   - 参数/报警/趋势   │      │   - 历史数据归档          │  │
│  │   - 通讯/设置        │      │   - 报警判断与推送        │  │
│  └─────────────────────┘      │   - 用户权限校验          │  │
│                               └──────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
                              │
                           网线/WiFi/交换机
                              │
┌─────────────────────────────────────────────────────────────┐
│              8 × S7-200 SMART PLC（192.168.2.101~108）       │
│                  Modbus TCP Server（端口 502）               │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 技术栈选型

| 层级 | 技术 | 说明 |
|---|---|---|
| 前端框架 | React 18 + TypeScript | 组件化、类型安全 |
| UI 组件 | Tailwind CSS + shadcn/ui | 可直接生成现代工业风格界面 |
| 状态管理 | Zustand | 轻量，适合实时数据、权限、报警状态 |
| 图表库 | Recharts / Tremor | 历史趋势曲线 |
| 后端框架 | FastAPI | 异步、自动生成 API 文档 |
| PLC 通信 | pymodbus (TCP Master) | 支持 S7-200 SMART Modbus TCP |
| 历史数据库 | SQLite | 单机零配置，满足本地记录需求 |
| 进程管理 | Windows 任务计划/nssm 或 pm2 | 后端开机自启 |
| 部署 | 触屏电脑本地运行 | 浏览器访问 `http://localhost:8000` |

### 2.3 部署方式

- **后端**：随触屏电脑开机自启动，监听 `0.0.0.0:8000`
- **前端**：由 FastAPI 静态文件服务托管，或单独由 nginx/Node 服务
- **浏览器**：触屏电脑开机自动全屏打开 `http://localhost:8000`
- **建议 OS**：Windows 10/11 IoT 或 Windows 嵌入式版（x86/x64），便于部署 Python 环境
- **远程访问（当前版本）**：不提供公网访问；触屏电脑与 PLC 在同一局域网内运行。将来若需远程监控，通过 VPN 或反向代理 + 认证层扩展，不在本期实现

#### 3.1.1 响应式与总览页设计

**响应式设计**

- 前端采用响应式布局，优先适配触屏电脑主流分辨率（1280×800、1920×1080、1024×768）。
- 控制面板设置最小宽度 1024px；低于该宽度时提示"请使用平板或触屏电脑操作"，避免手机上误操作。
- 手机/平板可应急查看数据和报警，但手动控制、参数修改等关键操作不推荐在小屏设备上执行。

**总览页设计：卡片式**

总览页采用 **8 单元卡片式** 布局，而非 8 套单元的组合 P&ID 流程图：

| 方案 | 优点 | 缺点 |
|---|---|---|
| 卡片式 | 报警定位快、信息密度高、适配各种屏幕、开发和维护成本低 | 缺少流程图直观感 |
| 流程图小图 | 流程直观 | 8 套单元挤在一张图里拥挤、报警定位慢、小屏适配差、开发和维护成本高 |

点击总览页卡片后，进入该单元的**单元详情页**，显示完整单套 P&ID 流程图与动画。

### 3.3 业务逻辑复用

复用 `McgsPro脚本代码_54个_v2.0.md` 中的业务逻辑，转换为前端/后端代码：

| 原 McgsPro 脚本 | Web HMI 实现位置 | 说明 |
|---|---|---|
| 启动/停止/报警确认/消音 | 后端 API + 前端按钮 | 后端写 PLC 后自动清零（模拟上升沿） |

### 3.4 动画效果设计

采用 **2D 工程图风格 + SVG + CSS 动画**，不使用粒子效果，保证在 x86/ARM、Windows/Android 触屏设备上流畅运行。

#### 动画技术选型

| 技术 | 使用场景 | 是否采用 |
|---|---|---|
| SVG + CSS 动画 | 水缸液位、阀门开关、泵叶轮、流量计指针、水流虚线 | 是 |
| CSS keyframes | 报警闪烁、按钮呼吸灯、状态过渡 | 是 |
| Canvas 2D | 简单辅助效果（如趋势曲线） | 部分使用 |
| WebGL/Three.js | 3D 效果 | 否 |
| 粒子效果 | 水流喷溅、气泡等 | 否 |

> **不用粒子效果的原因**：
> - 性能开销大，8 单元同时运行时累积消耗明显；
> - 工业监控强调状态清晰，粒子容易造成视觉干扰；
> - SVG 虚线流动已能清晰表达"介质在流动"。

#### 各元素动画实现

| 元素 | 动画效果 | 实现方式 | 绑定数据 |
|---|---|---|---|
| 上缸/下缸 | 液位升降 | SVG 矩形高度变化 + `clip-path` | `tank_a_state`、`tank_b_state`、过程量 |
| 阀 A/B/C | 开关状态 | SVG 阀体旋转/平移 + 颜色变化 | 阀反馈 I 点、手动命令 |
| 潜水泵 1/2 | 运行/停止 | SVG 叶轮旋转动画 | 泵运行 DO |
| 注射泵 | 运行/停止 | SVG 活塞往复或指针摆动 | `MB_Pump_Position` |
| 流量计 | 瞬时流量指针 | SVG 指针 `rotate` 变换 | `VD_FlowRate_Instant` |
| 管道 | 水流状态 | SVG `stroke-dasharray` 虚线流动 | 状态机、泵运行 |
| 报警状态 | 红色/黄色闪烁 | CSS keyframes | `alarm_byte_0~3`、`alarm_code` |

#### 动画性能约束

- 动画帧率目标：30fps；
- 只有数据变化时才重绘，避免无意义的全屏刷新；
- 总览页 8 单元卡片使用简化动画，单元详情页使用完整 P&ID 动画；
- 报警闪烁使用 CSS 硬件加速，降低 CPU 占用。

## 4. 数据模型

### 4.1 实时数据结构

后端为每个单元维护一个实时数据对象，按 500ms~1s 轮询更新：

```json
{
  "unit_id": 1,
  "online": true,
  "enabled": true,
  "state_machine": 2,
  "tank_a_state": true,
  "tank_b_state": false,
  "alarm_code": 0,
  "alarm_byte_0": 0,
  "alarm_byte_1": 0,
  "alarm_byte_2": 0,
  "alarm_byte_3": 0,
  "do_alarm_sound": false,
  "do_alarm_light": false,
  "c_set": 5.0,
  "c_stock": 100.0,
  "flow_meter_current": 123.45,
  "flow_rate_instant": 2.5,
  ...
}
```

### 4.2 历史数据表（SQLite）

```sql
CREATE TABLE history_data (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    unit_id INTEGER NOT NULL,
    tag_name TEXT NOT NULL,        -- 变量名，如 c_set, flow_rate
    value REAL NOT NULL,
    timestamp DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_unit_tag_time (unit_id, tag_name, timestamp)
);

CREATE TABLE alarms (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    unit_id INTEGER NOT NULL,
    alarm_code INTEGER NOT NULL,
    alarm_text TEXT,
    bit_index INTEGER,             -- 0~31，对应 V300.0~V303.7
    level TEXT,                    -- red/orange/yellow
    action TEXT,                   -- trigger/ack/mute/reset
    timestamp DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE user_settings (
    key TEXT PRIMARY KEY,
    value TEXT
);
```

### 4.3 变量采样周期配置

支持按变量分组配置采样周期（客户可在系统设置中调整）：

| 变量组 | 默认周期 | 示例变量 |
|---|---|---|
| 快速过程量 | 500ms | 状态机、流量、报警码 |
| 一般模拟量 | 1s | 浓度、液位、压力 |
| 慢变参数 | 10s | 实验时长累加、轮次计数 |
| 趋势归档 | 1s~10s 可调 | 用于历史曲线 |
| 长期归档 | 1min | 设备运行统计 |

## 5. 通信协议

### 5.1 Modbus TCP 配置

| 项 | 值 |
|---|---|
| 协议 | Modbus TCP |
| PLC 角色 | Server（Slave） |
| HMI 角色 | Client（Master） |
| 端口 | 502 |
| PLC IP | 192.168.2.101 ~ 192.168.2.108 |
| 读取方式 | 按单元批量读取保持寄存器（功能码 03） |
| 写入方式 | 单寄存器（功能码 06）/ 多寄存器（功能码 16） |

### 5.2 读取地址映射

直接沿用 HMI-PLC 变量地址表中的 V 区地址，通过 Modbus 保持寄存器读取：

| 数据类型 | PLC 地址 | Modbus 地址 | 长度 | 说明 |
|---|---|---|---|---|
| WORD | VW2 | 40003 | 1 | 状态机 |
| REAL | VD10 | 40006 | 2 | 目标浓度 |
| BOOL | V0.0 | 按位打包到 WORD 中读取 | — | 命令位 |
| BYTE | VB300 | 400301 | 1 | 报警字节 0（经 VW300 拆分） |
| BYTE | VB301 | 400302 | 1 | 报警字节 1（经 VW300 拆分） |
| BYTE | VB302 | 400303 | 1 | 报警字节 2（经 VW302 拆分） |
| BYTE | VB303 | 400304 | 1 | 报警字节 3（经 VW302 拆分） |

> 注：
> - BOOL 量在后端通过读取字节/字后按位解析，再映射为布尔字段。
> - 报警字节 VB300~VB303 物理存储于 VW300/VW302，后端按字读取后拆分为 4 个字节供前端使用。

### 5.3 命令写入逻辑

- 前端发送命令请求 → 后端写入 PLC 对应地址
- 后端写入成功后，在下一个轮询周期自动清零命令位（模拟上升沿/脉冲）
- 所有写入类操作记录到操作日志表

## 6. 历史数据与曲线

### 6.1 历史数据记录

- 后端根据采样周期配置，将指定变量写入 SQLite
- 默认记录的变量：
  - 实验时长累加 VD366
  - 实测 T 总时长 VD112
  - 实测 S6 排水时长 VD116
  - S1/S4/S6 实测时长 VD70/VD74/VD78
  - 本次进水量 VD90
  - 瞬时流速 VD94
  - 报警码 VW6

### 6.2 历史数据保留策略

- 客户可在系统设置中配置保留时长：7 天 / 30 天 / 90 天 / 自定义
- 后台定时任务清理超期数据
- 默认保留 30 天

### 6.3 趋势曲线

- 支持按单元、按变量组、按时间范围查询
- 默认时间范围：最近 1 小时 / 8 小时 / 24 小时 / 7 天
- X 轴：时间；Y 轴：多曲线叠加
- 支持显示报警阈值参考线
- **变量自选**：客户可在趋势页面勾选任意历史变量，后台动态查询并叠加显示；默认提供常用变量快捷组合（浓度、流量、状态机、液位相关）

## 7. 报警策略

### 7.1 报警来源

| 来源 | 说明 |
|---|---|
| VW6_AlarmCode | PLC 当前最高优先级报警码 |
| VB300~VB303 | 32 位报警字节，按位解析 V300.0~V303.7 |
| 通讯中断 | 后端轮询超时判定 |

### 7.2 报警提示与声光联动

| 提示/执行器 | 驱动来源 | Web HMI 行为 |
|---|---|---|
| 页面红色/闪烁 | 报警状态（VW6 + VB300~VB303） | 顶部全局报警横幅 + 单元卡片报警色 |
| 触屏扬声器蜂鸣 | 报警状态 | 与现场声音报警器 Q0.7 同步鸣响 |
| 现场声音报警器 Q0.7 | PLC 报警处理 FC3 输出 | PLC 直接驱动蜂鸣器 |
| 现场灯光报警器 Q2.0 | PLC 报警处理 FC3 输出 | PLC 直接驱动报警灯；Web HMI 显示其实际状态 |

- **强制弹窗**：新报警出现时强制弹出报警确认窗口（操作员可确认）
- **报警确认**：操作员点击确认后，后端向 PLC 写入 CMD_AckAlarm
- **消音联动**：
  - 就地物理消音按钮 I0.4 按下后，PLC 将 Q0.7 置 OFF
  - Web HMI 消音按钮写入 V0.4 后，PLC 同样将 Q0.7 置 OFF
  - Web HMI 检测到 Q0.7=OFF 或 STA_MuteDone(V1.4)=1 后，立即停止触屏扬声器
  - **一处消音，两处声音同时停止**

### 7.3 报警记录

- 报警触发、确认、消音、复位均记录到 `alarms` 表
- 报警日志页面支持按单元、按级别、按时间筛选

## 8. 权限模型

### 8.1 用户角色

按用户要求简化为**两级授权**：

| 角色 | 权限 |
|---|---|
| 操作员 | 查看所有画面、确认/消音报警、查看趋势、启动/停止/急停（需二次确认） |
| 管理员 | 操作员全部权限 + 手动控制 + 参数修改 + 单元使能 + 用户管理 |

### 8.2 默认账户

| 用户名 | 密码 | 角色 |
|---|---|---|
| operator | Op1234 | 操作员 |
| admin | Ad1234 | 管理员 |

> 首次部署后必须修改默认密码。

### 8.3 控制权限

- 手动控制按钮（阀/泵/注射泵）：仅管理员可见/可操作，需二次确认
- 参数输入框：仅管理员可编辑
- 启动/停止/急停：操作员和管理员均可操作，均需二次确认
- 报警确认/消音：操作员可操作

## 9. 关键设计点确认

| 设计点 | 用户确认 |

| 后端部署 | 触屏电脑自己跑后端 |
| PLC 通信 | Modbus TCP |

## 11. 风险与依赖

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| S7-200 SMART Modbus TCP 同时连接数限制 | 8 台 PLC 并发读取性能 | 后端异步轮询，单连接超时 1s |
| 触屏电脑性能不足 | Android/ARM 运行 React + Python | 优先推荐 x86 Windows 工控机 |
| 网络不稳定 | 通讯中断误报警 | 增加心跳检测 + 离线判定延时 |
| 历史数据量过大 | SQLite 查询变慢 | 按时间分区 + 定期清理 |
| 浏览器全屏被退出 | 现场误操作 | 使用 Kiosk 模式/PWA 锁定 |

## 13. 已确认事项

1. **响应式布局**：优先适配触屏电脑（1280×800、1920×1080、1024×768），最小宽度 1024px；手机仅应急查看，不推荐操作。
2. **总览页**：采用 8 单元卡片式布局，点击进入单元详情页查看完整 P&ID 流程图。
3. **历史曲线**：允许客户自选变量，默认提供常用变量快捷组合。
4. **远程访问**：当前版本仅本地/局域网访问，远程监控作为将来扩展，不在本期实现。
