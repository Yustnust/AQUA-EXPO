## 第一章 测试总则

### 1.1 FAT 与 SAT 区别与范围界定

| 项目 | FAT（Factory Acceptance Test，工厂验收） | SAT（Site Acceptance Test，现场验收） |
|---|---|---|
| 执行地点 | 设备制造厂内（PLC厂内测试台） | 客户现场（缸体设备就位后） |
| 执行时机 | 设备出厂前 | 现场安装接线完成后 |
| 负载情况 | **无真实负载**，DI用信号发生器/短接线/状态图表强制模拟，DO用万用表/继电器指示灯监测 | **带真实负载**，阀门/泵/流量计/注射泵/液位计全部接入 |
| 测试重点 | PLC程序逻辑正确性、I/O映射、状态机、报警/急停/断电恢复逻辑 | 现场设备动作正确性、Modbus通讯、长时稳定性、真实工艺流程 |
| Modbus从站 | 可用模拟从站软件（Modbus Slave）替代 | 真实注射泵+流量计 |
| 通过判据 | 全部【必测】项通过 + 严重问题0个 | 全部【必测】项通过 + 严重问题0个 |
| 备注 | FAT通过的必测项在SAT可标记为【回归】复测 | SAT新增现场设备联动测试 |

### 1.2 测试通过判据

1. **必测项全通过**：所有标记为【必测】的用例必须全部通过，任一不通过即拒收。
2. **严重问题0个**：测试中发现的严重问题（导致安全功能失效、状态机死锁、急停失效等）数量为0。
3. **选测项记录**：【选测】项不通过不影响交付，但需记录在测试报告中，后续版本修复。
4. **回归项说明**：【回归】项为FAT已在厂内通过、SAT现场复测的用例，确保现场环境无回归。
5. **单项通过判定**：用例期望结果中列出的所有VW/Q/I/V变量值均与实测一致，方判定该用例通过；任一不符即判失败。
