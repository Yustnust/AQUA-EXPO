**2.3.4 单元选择器动态显隐机制（过滤未使能单元）**

McgsPro 通过"安全属性→使能控制→表达式为0构件失效→构件不可见"实现按钮动态显隐：
- 每个单元按钮 `btnUnit_N` 的"使能控制"表达式设为 `Unit{N}_Enabled`
- 当 `Unit{N}_Enabled=0` 时按钮自动隐藏，运行时未使能单元不显示在选择器中
- 这种方式比脚本控制Visible属性更稳定，且不依赖循环策略刷新

**2.3.5 当前选中单元高亮处理**

在画面"窗口加载事件"和每个 `btnUnit_N` 抬起脚本末尾追加：

    If i = SelectedUnit Then
        Call SetUnitBtnColor(i, RGB(52,152,219))   ' 蓝

### 2.4 报警字位运算显示模板（画面2/5共用）

**位运算方法说明**：McgsPro 标签"显示输出"的表达式支持位运算，可将字节变量按位拆解后以开关量形式显示。

例如，报警字1（VB300）的第0位（V300.0，上缸漫溢）单独显示，使用标签构件的"显示输出"绑定表达式 `VB300 \ 1 % 2`（取整除后取模2）；第3位（V300.3）使用 `VB300 \ 8 % 2`。一般化公式：

```
位N的值 = (字节变量 \ (2 ^ N)) % 2
```

McgsPro 实时数据库中VB300~VB303按字节定义变量，定义为整数类型，按位运算表达式可在标签显示输出中直接使用。

**示例：V300.0（上缸漫溢）指示灯标签**

| 属性页 | 字段 | 取值 |
|---|---|---|
| 基本属性 | 填充颜色 | #95A5A6（默认灰） |
| 动画连接 → 颜色动画连接 → 填充颜色 | 表达式 | (VB300 \ 1) % 2 |
| 动画连接 → 填充颜色 | 分段点0 | 值=0，颜色=#95A5A6（灰，无报警） |
| 动画连接 → 填充颜色 | 分段点1 | 值=1，颜色=#E74C3C（红，漫溢级） |
| 动画连接 → 闪烁效果 | 表达式 | (VB300 \ 1) % 2 |
| 动画连接 → 闪烁效果 | 闪烁速度 | 快速（仅最高级99使用快速，漫溢级关闭闪烁） |
| 扩展属性 | 文本内容 | 上缸漫溢(10) |

> 说明：本SOP为每个报警位采用"标签构件+填充颜色动画+文本内容"实现"指示灯+报警文本"一体化，节省元件数量并保证32位报警阵列的统一性。

### 12.1 工程编译

**步骤1**：McgsPro → 工具 → 组态查错（检查脚本语法、变量绑定、构件引用完整性）

**步骤3**：常见编译问题排查

| 问题 | 原因 | 解决 |
|---|---|---|
| 变量未定义 | CSV导入遗漏或变量名拼写错误 | 实时数据→数据对象→新建 |
| 构件引用变量不存在 | 复制画面后未修改变量前缀 | 双击构件→显示输出→表达式重新绑定 |
| 脚本语法错误 | 中英文标点混用 | 将中文括号改为英文括号 |
| 报警浏览构件无数据 | 报警对象未在报警设置中启用 | 实时数据→数据对象→报警属性→启用报警 |
