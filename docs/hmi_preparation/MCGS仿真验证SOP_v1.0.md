## 七、常见问题与解决

### 7.1 仿真器问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 仿真器无法启动 | 端口被占用 | 检查102端口,kill占用进程 |
| MCGS连接失败 | IP/端口/TSAP配置错误 | 核对MCGS通讯配置SOP |
| 变量读取失败 | 变量地址错误 | 核对变量地址表v1.0 |
| 数据类型错位 | Int/Float映射错误 | 检查MCGS变量类型 |

### 7.2 MCGS问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 脚本语法错误 | VBScript语法不规范 | 用MCGS脚本编辑器调试 |
| 画面卡顿 | 周期脚本过频 | 调整周期为2秒 |
| 变量不刷新 | 连接断开 | 检查通讯状态 |
| 权限不生效 | LoginTime未刷新 | 每次操作后刷新LoginTime |
| 报警颜色错 | 颜色常量错误 | 用MCGS颜色选择器确认 |

### 7.3 通讯问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 8连接限制 | MCGS标准版限制 | 切换Modbus TCP方案 |
| 通讯延迟大 | 变量过多 | 分组轮询,降低采样率 |
| 数据跳变 | 通讯中断后恢复 | 启用降级模式(FC4) |
| 变量错位 | V区/寄存器映射错误 | 核对Modbus映射规则 |
