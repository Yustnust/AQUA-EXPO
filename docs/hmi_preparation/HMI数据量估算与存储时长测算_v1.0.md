# 药液配置加注控制系统 — HMI数据量估算与存储时长测算 v1.0

**项目**: 药液配置加注控制系统
**适用HMI**: 昆仑通态MCGS 12寸触摸屏(初步选型)
**用途**: 回答供应商"本地可保存条数时长由程序数据量决定"的回复,精确测算本项目数据量与存储时长,作为选型容量确认依据
**日期**: 2026-07-15

---

## 一、供应商回复分析

供应商回复:"这些功能都能实现,本地可保存的条数时长,由您的程序数据量决定。"

**问题**: 供应商将"存储时长"问题转回给项目方,需项目方先明确"程序数据量",供应商才能确认硬件配置是否满足。本测算即回答此问题。

## 二、本项目数据量分类估算

### 2.1 报警历史记录

**数据来源**: 8套单元×32位报警字,每次报警触发/确认/消除均记录一条

| 参数 | 值 | 说明 |
|---|---|---|
| 报警源 | 8单元×32位=256个报警点 | 全系统报警位总数 |
| 单条记录字段 | 时间戳(8B)+单元号(1B)+报警码(2B)+描述(30B)+状态(1B)+操作员(8B) | 约50字节/条 |
| 触发频率(估) | 平均每单元每天20条报警事件(含触发/确认/消除) | 保守估计 |
| 日数据量 | 8单元×20条×50B = 8KB/天 | |
| 年数据量 | 8KB×365 = 2.9MB/年 | |

### 2.2 趋势曲线数据(关键变量)

**数据来源**: 7条趋势曲线×8单元,采样间隔是决定数据量的核心变量

| 曲线 | 变量 | 采样建议间隔 |
|---|---|---|
| 1 | VD96 实验时长累加 | 1分钟 |
| 2 | VD112 T滚动 | 1分钟 |
| 3 | VD116 S6滚动 | 1分钟 |
| 4 | VD70 S1实测 | 1分钟 |
| 5 | VD74 S4实测 | 1分钟 |
| 6 | VD78 S6实测 | 1分钟 |
| 7 | VD90 本次进水量 | 1分钟 |

**单条采样点**: 时间戳(4B)+数值(4B) = 8字节

**不同采样间隔下的日/年数据量**:

| 采样间隔 | 单单元日数据量 | 8单元日数据量 | 8单元年数据量 |
|---|---|---|---|
| 1秒 | 7曲线×8B×86400秒 = 4.8MB | 38.6MB/天 | 14.1GB/年 |
| 10秒 | 0.48MB | 3.86MB/天 | 1.41GB/年 |
| **1分钟(推荐)** | **0.08MB** | **0.65MB/天** | **237MB/年** |
| 5分钟 | 0.016MB | 0.13MB/天 | 47MB/年 |
| 1小时 | 0.0027MB | 0.022MB/天 | 7.9MB/年 |

**推荐采样间隔: 1分钟**(换水周期30分钟,1分钟采样足够反映趋势,数据量适中)

### 2.3 审计日志(操作记录)

**数据来源**: L2/L3权限操作记录

| 参数 | 值 |
|---|---|
| 单条记录 | 时间戳(8B)+用户(8B)+权限(1B)+单元(1B)+操作类型(2B)+内容(50B)+结果(1B) ≈ 70字节 |
| 操作频率(估) | 每天50条操作(含参数修改/手动操作/权限登录等) |
| 日数据量 | 50×70B = 3.5KB/天 |
| 年数据量 | 1.25MB/年 |

### 2.4 配方/参数存储

**数据来源**: HMI设定参数(VD10~VD140)+报警模式+单元使能配置

| 参数 | 值 |
|---|---|
| 参数总量 | 约30个REAL参数×4B + 配置标志 = 约200字节/单元 |
| 8单元总参数 | 1.6KB(静态,不增长) |
| 配方版本数 | 保留10组配方 = 16KB |

### 2.5 数据量汇总

| 数据类型 | 日数据量 | 年数据量(推荐1分钟采样) |
|---|---|---|
| 报警历史 | 8KB | 2.9MB |
| 趋势曲线(1分钟采样) | 650KB | 237MB |
| 审计日志 | 3.5KB | 1.25MB |
| 配方/参数(静态) | — | 16KB |
| **合计** | **约0.66MB/天** | **约241MB/年** |

## 三、昆仑通态MCGS典型存储配置

### 3.1 昆仑通态TPC1211系列典型硬件

| 型号 | Flash存储 | RAM | 说明 |
|---|---|---|---|
| TPC1211-T12CE(经济型) | 4GB | 256MB | 入门12寸 |
| TPC1262Hi(高配型) | 8GB | 512MB | 增强12寸 |
| TPC1211-T12CE(新批次) | 8GB | 512MB | 需确认具体批次 |

**注**: 具体型号待供应商二轮确认,此处按典型配置估算。

### 3.2 存储分配建议(以4GB Flash为例)

| 区域 | 容量 | 用途 |
|---|---|---|
| 系统及组态软件 | 约1.5GB | Windows CE/MCGS运行环境+工程文件 |
| 历史数据区(建议) | 约2GB | 报警/趋势/审计 |
| U盘导出缓冲 | 约0.5GB | 临时导出文件 |

### 3.3 存储时长测算(核心结论)

**基于本项目数据量(241MB/年)与不同采样间隔**:

| 采样间隔 | 年数据量 | 2GB可存时长 | 8GB可存时长(全盘) |
|---|---|---|---|
| 1秒 | 14.1GB | 52天 | 208天 |
| 10秒 | 1.41GB | 1.4年 | 5.7年 |
| **1分钟(推荐)** | **241MB** | **8.3年** | **33年** |
| 5分钟 | 47MB | 42年 | 170年 |
| 1小时 | 7.9MB | 253年 | — |

### 3.4 容量结论

**本项目采用1分钟采样间隔(推荐)时**:
- 4GB Flash(分配2GB历史区): 可存储约**8.3年**,完全满足需求
- 8GB Flash: 可存储约**33年**,远超需求
- 即使采样间隔提高到10秒,4GB仍可存1.4年,满足年度需求

**结论: 昆仑通态TPC1211经济型(4GB)即可满足本项目8单元×7曲线×1分钟采样的存储需求,存储时长≥8年。**

## 五、项目存储配置建议

### 5.1 推荐配置

| 配置项 | 推荐值 | 理由 |
|---|---|---|
| 趋势采样间隔 | 1分钟 | 换水周期30分钟,1分钟足够;数据量适中(241MB/年) |
| 报警记录保留 | 全部保留(循环覆盖) | 8KB/天数据量小,可长期保存 |
| 审计日志保留 | 全部保留 | 1.25MB/年数据量小 |
| U盘导出周期 | 每月1次 | 防止数据丢失,定期备份 |
| 配方版本 | 10组 | 满足不同浓度实验切换 |

### 5.2 数据导出与备份策略

| 周期 | 操作 | 说明 |
|---|---|---|
| 每月 | U盘导出历史数据 | CSV格式,按月归档 |
| 每季度 | U盘导出审计日志 | 合规要求 |
| 每年 | U盘全量备份 | 含工程文件+历史数据 |
| 重大变更前 | 工程文件备份 | 参数/逻辑修改前导出工程 |

## 六、风险与缓解

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 供应商推荐型号Flash仅2GB | 低 | 存储时长减半(4年) | 仍满足年度需求,可接受 |
| 趋势采样需1秒级 | 中 | 数据量增60倍 | 采用10秒采样(1.4年/4GB)或选8GB型号 |
| MCGS数据不压缩 | 中 | 实际占用大于测算 | 选8GB型号预留余量 |
| U盘导出失败 | 低 | 数据无法备份 | 定期检查+SD卡双备份(若支持) |
