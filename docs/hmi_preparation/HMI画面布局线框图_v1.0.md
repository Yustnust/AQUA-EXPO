# 药液配置加注控制系统 — HMI画面布局线框图 v1.0

**项目**：药液配置与加注控制系统
**配套文档**：HMI画面架构规划文档v9.3、画面变量绑定清单v1.0、HMI-PLC变量地址表v1.0
**用途**：HMI组态阶段8画面的空间布局参考，明确每个UI元素的位置/尺寸/颜色/层级。组态工程师按本线框图直接摆位，无需自行设计布局。
**适用范围**：12寸触摸屏（分辨率1280×800建议），8套缸单元通用
**选型无关性**：本文档不依赖具体HMI厂商，线框图为通用布局，组态时按实际控件库映射

---

## 布局总则

### 1.1 全局布局规范

| 项目 | 规范 | 说明 |
|---|---|---|
| 分辨率 | 1280×800（横向） | 12寸工业触摸屏主流分辨率 |
| 配色 | 深灰底(#2C3E50)+白字主调 | 工业HMI通用，降低视觉疲劳 |
| 字体 | 微软雅黑/黑体 16pt(正文)/24pt(标题)/32pt(数值) | 中文显示清晰 |
| 导航栏 | 顶部80px高，8画面切换按钮 | 全局固定，当前页高亮 |
| 状态栏 | 底部60px高，全局报警横幅+时间+权限 | 全局固定 |
| 单元选择器 | 导航栏下方40px，1~8号单元按钮+当前选中高亮 | 画面2~7共用 |
| 操作安全 | 写入类按钮需二次确认弹窗；高权限操作需先登录 | 防误操作 |

## 组态实施建议

### 9.1 开发顺序建议

| 顺序 | 画面 | 优先级 | 说明 |
|---|---|---|---|
| 1 | 画面2 单元详情 | 高 | 核心监控页，验证8连接+变量绑定 |
| 2 | 画面5 报警与日志 | 高 | 安全关键，验证32位报警阵列 |
| 3 | 画面1 总览首页 | 高 | 基于2的卡片简化版 |
| 4 | 画面4 参数设置 | 中 | 验证写入类操作+权限 |
| 5 | 画面8 系统设置 | 中 | 验证单元使能+RTC校时 |
| 6 | 画面3 手动控制 | 中 | 验证手动命令位+联锁 |
| 7 | 画面6 趋势曲线 | 低 | 验证历史数据+曲线控件 |
| 8 | 画面7 通讯维护 | 低 | 调试用，最后开发 |

### 9.2 首期1套验证策略

首期仅1号单元使能，组态时：
1. 画面1仅1号卡片彩色，2~8号灰色"未接入"
2. 画面5报警阵列32位全部绑定1号单元
3. 画面6趋势曲线仅1号单元数据
4. 画面8仅1号使能开关可操作
5. 后续扩展时仅需画面8勾选新单元使能，其余画面自动显示

### 9.3 选型确认后映射步骤

1. 按本线框图8画面在HMI组态软件中建画面
2. 按"画面变量绑定清单v1.0"逐元素绑定变量
3. 按"报警字32位解析映射表"配置32位报警指示灯
4. 按"HMI变量导入CSV模板"批量导入变量
5. 按"HMI组态导入说明"配置8连接+脚本+历史记录
6. 按"用户权限矩阵"(另文档)配置3级权限
