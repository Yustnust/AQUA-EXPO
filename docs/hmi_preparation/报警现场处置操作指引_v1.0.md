# 药液配置加注控制系统 — 报警现场处置操作指引 v1.2

**项目**: 药液配置加注控制系统
**配套文档**: 报警字32位解析映射表v1.0、HMI用户权限矩阵v1.0、HMI-PLC变量地址表v1.0
**用途**: 32条报警的现场处置步骤+HMI操作+预计恢复时间，作为操作员现场手册和HMI报警详情页内容依据
**适用范围**: 8套缸单元通用，每条报警处置按"识别→现场检查→HMI操作→恢复"四步法

---

## 一、处置原则

### 1.1 报警分级与响应时效

| 等级 | 报警码 | 颜色 | 响应时效 | 处置原则 |
|---|---|---|---|---|
| 最高级 | 99 | 红闪 | 立即(秒级) | 立即停机检查动力回路，禁止单独消音 |
| 漫溢级 | 10~14 | 红 | 立即(分钟级) | 立即关阀检查液位，防液体溢出 |
| 节奏级 | 20 | 橙 | 尽快(小时内) | 评估节奏滞后原因，人工介入调整 |
| 一般级 | 21,30~66 | 黄 | 择机(班次内) | 记录并择机处理，不强制停机 |

### 1.2 通用处置四步法

1. **识别**: HMI画面5查看报警码+指示灯位置+处置建议
2. **现场检查**: 按处置步骤到现场核实设备状态
3. **HMI操作**: 按权限矩阵执行消音/确认/强制修正等操作
4. **恢复**: 条件消除后报警自动复位(L1模式)或人工确认(L2模式/强制确认类)

### 1.3 报警复位模式(V200.0 M_AlarmAckMode)

- **自动恢复模式(=0)**: 一般级报警条件消失后自动复位，无需人工确认
- **人工确认模式(=1)**: 所有报警需V0.3人工确认+条件消失才复位
- **强制人工确认(不受模式影响)**: 漫溢级(10~14)+节奏严重(20)+继电器故障(99)始终需人工确认

## 二、最高级报警处置(报警码99)

### 报警码99: 安全继电器故障(M_Alarm_SafetyRelay, V300.5)

| 项 | 内容 |
|---|---|
| **触发条件** | 急停触发(I1.1=OFF)后，安全继电器反馈I1.2在T35延时2秒内未到(主触点粘连/继电器故障) |
| **HMI显示** | 画面5: 99红闪"安全继电器故障-立即检查动力回路" |
| **现场检查** | ①检查安全继电器线圈是否得电 ②检查继电器主触点是否粘连 ③检查220V动力回路 ④检查I1.2反馈接线 |
| **HMI操作** | ①L3管理员登录 ②画面5点击"继电器高权限确认" ③输入密码二次验证 ④PLC执行: V0.7+I1.2双确认清V300.5 |
| **预计恢复时间** | 30分钟~2小时(视故障复杂度) |
| **注意事项** | 此报警禁止系统复位按钮清除，必须HMI高权限确认;若I1.2物理反馈不正常，V0.7无法清除 |

| **预计恢复时间** | 30分钟~1小时(可能需重启泵/检查485) |

### 报警码65: RTC时钟丢失(M_Alarm_RTC_Lost, V303.5)

| 项 | 内容 |
|---|---|
| **触发条件** | 开机时PLC RTC时间早于DT_TankB_FullTime(FC0断电恢复检测) |
| **HMI显示** | 画面5: 65黄"RTC时钟丢失-开机时间早于记录，请校时" |
| **现场检查** | ①检查PLC超级电容是否失效(长期断电) ②确认PLC RTC是否需更换电池 |
| **HMI操作** | ①L3管理员登录 ②画面8点击"RTC校时"同步HMI时间至PLC ③画面5报警确认 |
| **预计恢复时间** | 5~10分钟 |
| **注意事项** | RTC丢失后VD_S5_Elapsed无法重算，FC0已转S_ERROR，需校时后系统复位 |

### 报警码66: 流量开关瞬时异常(M_Alarm_FlowSwitch_Instant, V303.6)

| 项 | 内容 |
|---|---|
| **触发条件** | 流量开关信号瞬时异常(详见诊断FC) |
| **HMI显示** | 画面5: 66黄"流量开关瞬时异常-检查流量开关信号" |
| **现场检查** | ①检查流量开关接线 ②检查流量开关是否受干扰 ③观察是否频繁触发 |
| **HMI操作** | ①消音 ②异常消失后 ③自动复位或人工确认 |
| **预计恢复时间** | 5~15分钟 |

## 八、报警处置流程图

### 8.1 通用处置流程

```
报警触发
   ↓
画面5识别报警码+读处置建议
   ↓
┌─────────────────────────────────┐
│ 现场检查 (按本指引"现场检查"列) │
└─────────────────┬───────────────┘
                  ↓
         ┌────────┴────────┐
         │                 │
    能立即处理          需停机检修
         │                 │
    现场处理           报告班长/维护
         │                 │
         └────────┬────────┘
                  ↓
         消音(画面5/物理按钮)
                  ↓
        条件消除(I/O恢复正常)
                  ↓
    ┌─────────────┴─────────────┐
    │                           │
自动恢复模式(=0)          人工确认模式(=1)/强制确认类
    │                           │
 自动复位V300.x           画面5"报警确认"V0.3
    │                           │
    └───────────┬───────────────┘
                ↓
        报警指示灯变绿
                ↓
            恢复运行
```

### 8.2 紧急情况处置(最高级/漫溢级)

```
99红闪/10~14红 报警触发
            ↓
    立即消音(不影响处置)
            ↓
   现场确认是否需急停(如漫溢严重)
            ↓
    ┌───────┴───────┐
    │               │
  需急停          无需急停
    │               │
 现场按急停      现场检查处理
    │               │
 PLC转S_ERROR    条件消除后
    │               │
    └───────┬───────┘
            ↓
   按本指引"HMI操作"列执行
            ↓
   报警确认(需相应权限)
            ↓
    系统复位回S0(物理按钮)
            ↓
        恢复运行
```
