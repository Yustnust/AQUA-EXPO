# 药液配置加注控制系统 — 报警现场处置操作指引 v1.3

**项目**: 药液配置加注控制系统
**配套文档**: 报警字32位解析映射表v1.0、HMI用户权限矩阵v1.0、HMI-PLC变量地址表v1.9、PLC设计文档v10.3
**用途**: 32条报警（含 v2.2 新增 66 = M_Alarm_CycleTimeout）的现场处置步骤+HMI操作+预计恢复时间，作为操作员现场手册和HMI报警详情页内容依据
**适用范围**: 8套缸单元通用，每条报警处置按"识别→现场检查→HMI操作→恢复"四步法
**版本说明**: v1.0 首次发布（28 条报警）；v1.2 修订；**v1.3【v2.2 修订 2026-09-15】新增报警码 66（单轮换水周期超时，复用 V303.6 位地址），同步更新分级表**

---

## 一、处置原则

### 1.1 报警分级与响应时效

| 等级 | 报警码 | 颜色 | 响应时效 | 处置原则 |
|---|---|---|---|---|
| 最高级 | 99 | 红闪 | 立即(秒级) | 立即停机检查动力回路，禁止单独消音 |
| 漫溢级 | 10~14 | 红 | 立即(分钟级) | 立即关阀检查液位，防液体溢出 |
| 节奏级 | 20 | 橙 | 尽快(小时内) | 评估节奏滞后原因，人工介入调整 |
| 一般级 | 21, 30~65, **66【v2.2新增，周期超时】** | 黄 | 择机(班次内) | 21/30~65 记录并择机处理；**66 强制人工确认，不受 V200.0 模式影响** |

### 1.2 通用处置四步法

1. **识别**: HMI画面5查看报警码+指示灯位置+处置建议
2. **现场检查**: 按处置步骤到现场核实设备状态
3. **HMI操作**: 按权限矩阵执行消音/确认/强制修正等操作
4. **恢复**: 条件消除后报警自动复位(L1模式)或人工确认(L2模式/强制确认类)

### 1.3 报警复位模式(V200.0 M_AlarmAckMode)

- **自动恢复模式(=0)**: 一般级报警条件消失后自动复位，无需人工确认
- **人工确认模式(=1)**: 所有报警需V0.3人工确认+条件消失才复位
- **强制人工确认(不受模式影响)**: 漫溢级(10~14)+节奏严重(20)+继电器故障(99)始终需人工确认

## 二、最高级报警处置(报警码99)

### 报警码99: 安全继电器故障(M_Alarm_SafetyRelay, V300.5)

| 项 | 内容 |
|---|---|
| **触发条件** | 急停触发(I1.1=OFF)后，安全继电器反馈I1.2在T35延时2秒内未到(主触点粘连/继电器故障) |
| **HMI显示** | 画面5: 99红闪"安全继电器故障-立即检查动力回路" |
| **现场检查** | ①检查安全继电器线圈是否得电 ②检查继电器主触点是否粘连 ③检查220V动力回路 ④检查I1.2反馈接线 |

| **预计恢复时间** | 30分钟~2小时(视故障复杂度) |
| **注意事项** | 此报警禁止系统复位按钮清除，必须HMI高权限确认;若I1.2物理反馈不正常，V0.7无法清除 |

## 八、v2.2 新增报警处置【v2.2 新增】

> v2.2 流程重构后，报警字 V303.6（v2.2 之前为"流量开关瞬时异常"已删除位）被复用为**单轮换水周期超时报警**，报警码 66，强制人工确认。本节给出该报警的处置四步法。

### 报警码 66：单轮换水周期超时（M_Alarm_CycleTimeout，V303.6）【v2.2 新增】

| 项 | 内容 |
|---|---|
| **触发条件** | FC40 NETWORK 5（v2.2 重写）：(1) 倒计时到 0 未触发 S6 排水 — TimerA(T46) 或 TimerB(T48) 任一在非 S7 状态（VW2≠8）计时到 0；(2) T_cycle ≤ 0 — 周期参数过激进（T_single = 86400/VD414 ≤ VD426 + VD430） |
| **HMI 显示** | 画面 5：66 黄"单轮换水周期超时-24h换水次数无法保证，请检查周期参数或工艺卡滞"；画面 2 显示当前 VW304（上缸状态）、VW2（下缸状态）、VD442/VD446（双倒计时器当前值） |
| **现场检查** | **情况 A（T_cycle ≤ 0）**：①画面 4 查看 VD414（24h换水目标）、VD426（尾端余量，默认30s）、VD430（配液安全余量，默认10s）②计算 T_single = 86400 / VD414，T_cycle = T_single - VD426 - VD430③若 T_cycle ≤ 0：调小 VD414（如从48降到36），或调小 VD426/VD430 |
| | **情况 B（倒计时到 0）**：①画面 6 趋势曲线查看 VW304 状态转换历史、VD442/VD446 倒计时曲线②排查上缸 VW304=2 阶段（FC1A）T38 是否正常计时——若 T38 卡住说明潜水泵或加药子状态机异常③排查下缸 S5→S6 转移：V1.7（下缸排空）信号、FC16→FC17 转 S6 条件、阀 C/流量开关 C/液位计 B④排查 OB1 是否漏调 FC40（NETWORK 7 上缸调度前的 FC40 CALL 缺失则周期管理未生效） |
| | **情况 C（参数或调度错误）**：①检查 M16.0 切换逻辑：S4 完成后必须 `NOT M16.0` 切换计时器标记，否则 TimerA/B 状态错乱②检查 T46/T48 PT 值是否溢出（WORD 范围 0~32767，即 0~3276.7s） |
| **HMI 操作** | ①消音②**强制人工确认**（不受 V200.0 模式影响）：L2 维护登录 → 画面 5 点击"报警确认"（V0.3）→ PLC 执行 FC3 NETWORK 4 复位 V303.6③**根本原因必须先消除**：仅清报警而不调整参数/工艺，下一周期 FC40 NETWORK 5 会再次触发④现场按 I0.3 系统复位按钮回 S0，重新启动首轮 S1 |
| **预计恢复时间** | 30 分钟~2 小时（视工艺卡滞原因） |
| **注意事项** | **本报警为 v2.2 新增，前置 v2.2 之前版本（V303.6 流量开关瞬时异常已删除）不再适用**；本报警严格强制人工确认，不受 V200.0 M_AlarmAckMode 影响；恢复后必须连续观察 2 个完整换水周期确认工艺恢复正常 |
