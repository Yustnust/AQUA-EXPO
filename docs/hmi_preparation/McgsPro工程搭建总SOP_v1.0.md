## 四、实时数据库变量导入

### 4.1 批量导入 CSV

McgsPro 支持通过设备编辑窗口"导入 CSV"批量添加通道，自动在实时数据库创建变量。

1. 双击子设备 0（设备 0-[西门子_Smart200]）→ 打开设备编辑窗口。
2. 点击 **导入 CSV** 按钮。
3. 选择 `docs/hmi_preparation/McgsPro变量导入_8单元_v2.1.csv`。
4. 在导入对话框中：
   - 起始行：2（第 1 行为表头）
   - 分隔符：英文逗号 `,`
   - 编码：UTF-8 或 GBK（若乱码则切换）
5. 点击"导入"，等待完成。
6. **重复步骤 1~5**，为 8 个子设备分别导入同一 CSV。

> **关键注意**：CSV 中的"连接变量"已带 `U1_` 前缀。为子设备 1~7 导入时，需在导入后使用 McgsPro 的"文本查找与替换"工具（组态辅助工具）将变量前缀统一替换为 `U2_` ~ `U8_`，或预先准备 8 份前缀不同的 CSV。

### 4.2 变量前缀批量替换（推荐做法）

为减少出错，建议先准备 8 份 CSV：

```bash
# 在 PowerShell 中执行
$base = "docs/hmi_preparation/McgsPro变量导入_8单元_v2.1.csv"
for ($i = 2; $i -le 8; $i++) {
    (Get-Content $base -Encoding UTF8) -replace "U1_", "U$i`_" |
        Set-Content "docs/hmi_preparation/McgsPro变量导入_8单元_v2.1_U${i}.csv" -Encoding UTF8
}
```

然后为每个子设备导入对应前缀的 CSV。

### 4.3 导入后检查

1. 工作台 → **实时数据库**，确认变量总数约为 8×75 = 600 个。
2. 抽查以下关键变量：
   - `U1_CMD_Start`（开关型，V0.0）
   - `U1_VW2_StateMachine`（整数，VW2）
   - `U1_VD_FlowMeter_Current`（浮点数，VD86）
   - `U1_VD_StepResolution`（浮点数，VD350）
   - `U1_CMD_AckAlarm`（开关型，V0.3）
3. 确认变量名、数据类型、通道地址与 [HMI-PLC 变量地址表_v1.0.md](../HMI-PLC变量地址表_v1.0.md) 一致。

### 6.2 脚本粘贴步骤

1. 双击目标构件 → 属性设置 → **脚本程序** 页。

3. 粘贴到脚本编辑器，点击 **检查** 按钮。
4. 无报错后点击 **确认**。

### 6.3 脚本语法自检清单

根据 McgsPro 帮助文档，脚本必须遵守以下规则：

- [ ] 条件语句用 `If ... Then ... EndIf`，**不支持 `ElseIf`**。
- [ ] 循环语句用 `While ... EndWhile`，**不支持 `For...Next`**。
- [ ] 多条语句在同一行时用英文冒号 `:` 分隔。
- [ ] 注释以英文单引号 `'` 开头。
- [ ] 局部变量声明用 `DIM var AS integer/float/string/byte`。
- [ ] 系统变量以 `$` 开头（如 `$Date`、`$Time`）。
- [ ] 不能对组对象直接赋值，只能调用其方法。

### 6.4 必须验证的脚本

| 脚本名 | 验证内容 |
|---|---|
| 启动实验 | 置位 `CMD_Start=1`，PLC 应答 `STA_StartAck=1` 后清零 |
| 停止实验 | 置位 `CMD_Stop=1`，状态机 VW2 跳转 S7 |
| 报警确认 | 置位 `CMD_AckAlarm=1`，触发灯光 DO 清除逻辑 |
| 手动开阀 A | 置位 `CMD_Manual_ValveA_Open=1`，PLC 自动清零 |
| 单元选择 | 修改 `SelectedUnit` 后，刷新画面绑定变量 |
| 二次确认弹窗 | 使用 `!OpenSubWnd` 正确打开子窗口 |

1. 工作台 → **运行策略**。

如需在 HMI 侧做报警提示音，可新建报警策略：
- 周期 500 ms

> **注意**：本项目的报警主逻辑在 PLC 侧处理，HMI 只做显示和消音。

## 十一、下载到 TPC

### 11.1 通讯设置

1. 用网线连接 PC 与 TPC。
2. PC 网卡 IP 设为 192.168.2.100（与 TPC 同网段）。
3. TPC 出厂默认 IP 一般为 192.168.2.100 或 192.168.0.100，按实际调整。

1. McgsPro → **工具 → 下载工程**。
2. 输入 TPC IP 地址，选择"联机下载"。
3. 下载完成后，TPC 自动重启并运行工程。

### 11.3 现场网络切换

从本机联调切换到现场运行时：

1. 修改 8 个父设备的"远程 IP 地址"为 192.168.2.101~108。
2. 修改 8 个父设备的"远程端口"为 102。
3. 重新下载工程到 TPC。

| 现象 | 可能原因 | 排查方法 |
|---|---|---|
| 模拟运行无连接 | 父设备 IP/端口错 | 对照 SOP 验证父设备参数 |
| 变量显示 "--" | 变量未创建或表达式错 | 实时数据库搜索变量名 |
| 脚本提示"类型不匹配" | 赋值左右类型不一致 | 检查开关型/整数/浮点型 |
| 脚本提示"变量未定义" | 变量名拼写错误或大小写不对 | McgsPro 变量名区分大小写 |
| 8 单元显示同一数据 | 变量前缀未替换 | 检查 U1_~U8_ 前缀 |
| 报警确认无响应 | 仍用旧变量 `CMD_Ack` | 替换为 `CMD_AckAlarm` |
| 单步分辨率参数找不到 | 仍用旧变量 `VD_StepRes` | 替换为 `VD_StepResolution` |
| 写入 VD 后读回乱码 | 字节顺序错 | 父设备属性"字节顺序"=ABCD |
| 手动按钮运行中可用 | 未判断 `VW2` 状态 | 脚本增加 `If VW2=0 OR VW2=99` 判断 |
