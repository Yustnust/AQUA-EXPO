## 重要修正说明(v1.0→v2.0)

经查阅官方文档(McgsProHelp.chm),v1.0有以下错误,v2.0已修正:

### P0 致命错误(脚本无法编译或功能不存在)
1. **脚本语言不是VBScript** — 是"类似Basic的脚本语言",不支持子程序/子函数
2. **`!OpenWindow`不存在** — 应为`!OpenSubWnd(参数1,参数2,参数3,参数4,参数5,参数6)`
3. **`!CloseWindow`不存在** — 应为`!CloseAllSubWnd()`或`!CloseAllWindow(WndName)`
4. **`!MsgBox`不存在** — 改用子窗口或动画按钮
5. **`!CheckUser(2)`不存在** — 应为`!CheckUserGroup("维护组")`,返回0=属于/1=不属于
6. **`!AlarmAck`不存在** — 改用报警策略或`!SetAlmInfo`
7. **`Exit Sub`不支持** — 应为`Exit`(无子程序概念)
8. **`For...To...Next`不支持** — 应为`While...EndWhile`
9. **`!SetDevice(设备0, 1)`错误** — 实际签名为`!SetDevice(DevName, DevOp, CmdStr)`,DevOp=1启动/2停止

### P1 概念/术语错误
10. **用户权限L1/L2/L3数字等级错误** — 实际是"用户组"机制(如"操作员组""维护组""管理员组")
11. **"开关型"/"数值型"数据对象类型术语错误** — 应为"整数""浮点数""字符串""字节型"
12. **`!SetDevice`第二个参数错误** — 1=启动/2=停止(不是0/1)
13. **下载方式"USB下载"不存在** — 实际为"U盘下载"或"TCP/IP下载"

### P2 优化
14. 32位浮点(VD)字节顺序需明确配置
15. 报警组、子窗口、组对象等关键配置需补充

**注**: 一个工程只允许有一个设备窗口,运行时由主控窗口打开,设备窗口在后台独立运行。

## 六、脚本编程(官方第11章 语言要素+基本语句)

### 6.1 脚本语言特性(官方11.3节)

**重要**: McgsPro脚本语言**不是VBScript**,是"类似Basic的脚本语言"。

| 特性 | 支持 | 说明 |
|---|---|---|
| 子程序/子函数 | ❌ 不支持 | 用户不能定义子程序和子函数 |
| 局部变量 | ✅ 支持 | DIM声明,4种类型(byte/integer/float/string) |
| 局部数组变量 | ✅ 支持 | DIM arr(N) AS integer,索引从1开始 |
| 数据对象(全局变量) | ✅ 支持 | 实时数据库中组态的数据对象 |

### 6.2 数据类型(官方11.3.1节)

| 类型 | 关键字 | 说明 |
|---|---|---|
| 字节型 | byte | 仅局部变量 |
| 整数 | integer | 局部变量/数据对象 |
| 浮点数 | float/single | 局部变量/数据对象 |
| 字符串 | string | 局部变量/数据对象 |

### 6.3 基本语句(官方11.4节)

**赋值语句**: `变量 = 表达式`
**条件语句**:
```
If 表达式 Then 语句
' 或
If 表达式 Then
    语句
EndIf
' 或
If 表达式 Then
    语句
Else
    语句
EndIf
```

**注意**: 不支持"Else IF"语句,多分支需嵌套If。

**循环语句**:
```
While 条件表达式
    语句
EndWhile
```

**跳出循环**: `Break`
**退出脚本**: `Exit`(不是Exit Sub)
**注释**: `' 这是注释

### 6.4 局部变量声明(官方11.4.7节)

```
DIM 变量名 AS 类型
' 示例:
DIM a AS integer
DIM b(10) AS integer    ' 整数数组,索引从1开始
DIM s AS string
```

### 6.5 命名规则(官方11.4.8节)

- 不能以关键字命名(if/then/else/endif/while/break/endwhile/and/or/xor/not/exit/byte/integer/single/float/string)
- 不能以数字开头
- 不能含有特殊字符: `` ~!@#$%^&*()-=+\|]}[{'";:/?.>,< ``
- 不能包含下划线`_`
- 不能为空

### 6.6 系统函数(官方第12章 关键函数)

| `!CloseAllWindow(WndName)` | 关闭所有窗口 | `!CloseAllWindow()` |
