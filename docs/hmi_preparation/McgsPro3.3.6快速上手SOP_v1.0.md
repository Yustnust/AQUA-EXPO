**项目**: 药液配置加注控制系统(AQUA-EXPO)
**组态软件**: McgsPro 3.3.6.6354 SP1.3(昆仑通态新一代嵌入版,替代老版McgseSet)

## 三、8连接S7驱动配置(关键)

### 3.3 添加8个子设备(西门子_Smart200)

| 步骤 | 操作 | 确认 |

| 1 | 在设备工具箱中,双击"西门子_Smart200" | □ |

### 4.2 变量类型映射(PLC↔McgsPro)

| PLC类型 | McgsPro数据类型 | 字节数 | 示例 |
|---|---|---|---|
| V位(V0.0) | 开关型 | 1位 | U1_CMD_Start |
| VB | 数值型(8位无符号) | 1字节 | U1_VB300 |
| VW | 数值型(16位有符号) | 2字节 | U1_VW2 |
| VD | 数值型(32位浮点数) | 4字节 | U1_VD10 |

### 4.3 变量批量导入方式

McgsPro 3.3.6有两种变量导入方式:

**方式A: 从数据中心选择(手动添加,适合少量变量)**
| 步骤 | 操作 |
|---|---|
| 1 | 工作台→"实时数据库"标签 |
| 2 | 点击"新增对象"按钮 |
| 3 | 对象名称:U1_VW2 |
| 4 | 数据类型:数值型(16位有符号) |
| 5 | 初值:0 |
| 6 | 点击"确认" |

**方式B: 根据采集信息生成(推荐,适合批量)**
| 步骤 | 操作 |
|---|---|
| 1 | 在设备编辑窗口(3.5节步骤1)中,点击"添加设备通道"按钮 |
| 2 | 通道类型:V区变量 |
| 3 | 数据类型:16位有符号二进制(VW) |
| 4 | 通道地址:2(对应VW2) |
| 5 | 通道个数:1 |
| 6 | 读写方式:读写 |
| 7 | 连接变量:U1_VW2(自动创建到实时数据库) |
| 8 | 点击"确认" |

**推荐方式B**: 每个PLC的91个变量通过"添加设备通道"批量添加,连接变量自动创建到实时数据库,无需手动维护CSV导入。

## 六、脚本基础(McgsPro VBScript)

### 6.1 脚本类型与位置

McgsPro脚本分3类:

| 类型 | 位置 | 触发方式 | 用途 |
|---|---|---|---|
| 策略脚本 | 运行策略→新建策略→脚本程序 | 循环/报警/事件触发 | 周期性逻辑 |
| 窗口脚本 | 用户窗口→事件→脚本 | 窗口打开/关闭/周期 | 画面交互逻辑 |
| 构件脚本 | 构件→事件→脚本 | 按钮按下/抬起等 | 单次操作 |

### 6.2 常用脚本函数(McgsPro 3.3.6)

```vbscript
' 变量读写(直接赋值)
U1_CMD_Start = 1           ' 写入变量
state = U1_VW2             ' 读取变量

' 弹出窗口
!OpenWindow("画面2_单元详情", "U1_VW2")  ' 带参数打开窗口

' 关闭窗口
!CloseWindow()

' 字符串操作
!StrFormat("状态:%d 轮次:%d", U1_VW2, U1_VW8)

' 时间函数
$Time                       ' 系统时间(只读)
$Date                       ' 系统日期(只读)

' 设备控制
!SetDevice("设备0", 1)      ' 启动设备0采集
!SetDevice("设备0", 0)      ' 停止设备0采集

' 报警
!AlarmAck(U1_VW6)          ' 确认报警

' 用户权限
!LogOn()                    ' 弹出登录窗口
!LogOff()                   ' 注销当前用户
!CheckUser(3)              ' 检查是否≥3级权限(管理员)
```

### 6.3 示例:启动按钮脚本

**位置**: 画面1_总览→1号单元卡片→"启动"按钮→抬起事件

```vbscript
' 检查用户权限(需L2维护及以上)
If !CheckUser(2) = 0 Then
    !MsgBox("权限不足,请登录维护账号", "提示")
    !LogOn()
    Exit Sub
End If

' 二次确认

    ' 置CMD_Start上升沿(V0.0)
    U1_CMD_Start = 1
    ' 100ms后清零(由循环策略处理)
End If
```

### 6.4 示例:循环策略脚本(每500ms)
