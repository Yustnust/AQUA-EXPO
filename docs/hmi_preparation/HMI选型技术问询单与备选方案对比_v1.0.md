# HMI选型技术问询单 + 备选方案对比

**项目**: 药液配置加注控制系统
**用途**: 发送触摸屏厂商确认选型关键技术参数;附3款主流12寸HMI能力对比作为备选决策依据
**日期**: 2026-07-15

---

## 一、技术问询单(发送厂商)

### 1.1 项目背景

现场本地集中HMI，通过工业以太网同时连接8台西门子S7-200 SMART PLC，每台PLC独立控制1套上下缸单元。HMI只做人机界面，不承担实时控制逻辑。

### 1.2 必须确认的技术问题

请贵司就以下4项关键技术参数明确回复，作为选型依据：

| # | 问题 | 我们的需求 | 需贵司确认 |
|---|---|---|---|
| **Q1** | **同时连接PLC数量** | 需同时连接8台S7-200 SMART PLC(IP 192.168.2.101~108)，每台独立S7协议连接 | 贵司推荐型号是否支持8连接?若支持8连接需配置什么协议(S7/Modbus TCP)? |
| **Q2** | **变量点数上限** | 本项目PLC变量约728点(8单元×91变量/单元)，含BOOL/WORD/REAL三种类型 | 贵司推荐型号变量点数上限?728点是否在标准授权内?超限需加购授权? |
| **Q3** | **脚本能力(动态显隐)** | 需根据"单元使能+通讯在线"状态动态显隐8个单元卡片(运行时改变控件可见性+可操作性) | 贵司推荐型号是否支持脚本控制控件可见性?脚本语言是什么? |
| **Q4** | **存储容量(报警/历史/趋势)** | 需存储8单元×32报警位×30天历史记录+7条趋势曲线×365天数据 | 贵司推荐型号报警/历史/趋势存储容量?是否支持SD卡扩展? |

### 1.3 附加确认项(非阻塞，但影响实施)

| # | 问题 | 说明 |
|---|---|---|
| Q5 | 屏幕尺寸/分辨率 | 建议12寸 1280×800，请确认推荐型号实际分辨率 |
| Q6 | 防护等级 | 现场环境IP54以上，前面板IP66 |
| Q7 | 通讯接口 | 至少1个以太网(连8 PLC)+1个串口(调试用)，是否支持USB导出历史? |
| Q8 | RTC保持 | 断电后RTC保持时长?是否需电池? |
| Q9 | 画面数上限 | 本项目8个主画面，是否有限制? |
| Q10 | 报警分组 | 是否支持按单元分组报警(8组)? |
| Q11 | 用户权限 | 是否支持3级权限(操作员/维护/管理员)+操作审计日志? |
| Q12 | 中文支持 | 是否完整支持中文显示+中文输入?字体是否有要求? |

### 1.4 期待回复时间

请贵司在 **5个工作日内** 回复以上问询单。回复后我们将最终确认选型并下达采购订单。

如贵司推荐型号在Q1~Q4任一项不满足，请在回复中明确说明替代方案或升级型号。

## 二、备选方案对比(3款主流12寸HMI)

### 2.1 对比对象

| 厂商 | 型号 | 参考价位 | 定位 |
|---|---|---|---|
| 昆仑通态 | TPC1211-T12CE | 中(约3500元) | 国产主流，性价比高 |
| 威纶通 | cMT-3072X | 中高(约4500元) | 台系主流，稳定性好 |
| 西门子 | KTP1200 Basic | 高(约6500元) | 原厂匹配，兼容性最佳 |

### 2.2 关键参数对比

| 参数 | 昆仑通态TPC1211 | 威纶通cMT-3072X | 西门子KTP1200Basic | 我们需求 |
|---|---|---|---|---|
| **屏幕** | 12.1寸 800×600 | 10.2寸 1024×600 | 12.1寸 1280×800 | 12寸 |
| **连接数(S7)** | 支持8连接(Modbus TCP为主，S7需确认) | 支持8连接(S7/Modbus TCP) | 支持8连接(S7原生) | **8连接** |
| **变量点数** | 无硬性上限(基于内存) | 标准版约6000点 | Basic版约2048点 | **728点** |
| **脚本能力** | 支持VBScript/JS | 支持宏指令(类C) | Basic版不支持脚本(Comfort版支持) | **需脚本(动态显隐)** |
| **存储扩展** | 支持SD卡/U盘 | 支持SD卡/U盘 | 支持SD卡 | **需扩展** |
| **报警容量** | 大(基于内存) | 中(约10000条) | Basic版约200条(Comfort版更多) | **8×32×30天** |
| **历史趋势** | 支持，容量大 | 支持，容量中 | Basic版有限(Comfort版好) | **7曲线×365天** |
| **用户权限** | 支持3级+审计 | 支持3级+审计 | 支持3级(Comfort版审计) | **3级+审计** |
| **中文支持** | 完整 | 完整 | 完整 | **必须** |
| **防护等级** | 前IP66/后IP54 | 前IP66/后IP54 | 前IP65/后IP54 | **IP54+** |

### 2.3 关键风险点

| 厂商 | 关键风险 | 缓解措施 |
|---|---|---|
| **昆仑通态** | S7协议连接8台需确认(原生Modbus为主) | 问询厂商确认S7连接数;备选用Modbus TCP(PLC侧配Modbus TCP Server) |
| **威纶通** | 屏幕10.2寸略小于12寸需求 | 实际10.2寸可接受;或升级cMT-3092X(12寸) |
| **西门子KTP1200 Basic** | **Basic版不支持脚本**(动态显隐无法实现) | **必须升级到Comfort版**(约+2000元);或改用S7-1500配套HMI |

### 2.4 推荐排序

**基于本项目需求(8连接+脚本+大容量)的推荐排序**:

1. **威纶通 cMT-3092X(12寸版)** — 综合8连接+脚本+容量均衡，性价比适中，S7协议原生支持
2. **昆仑通态 TPC1211-T12CE** — 价格最优，脚本+容量充足，需确认S7连接数(可备选Modbus TCP)
3. **西门子 KTP1200 Comfort版** — 原厂匹配最佳，但价格最高，Basic版不满足脚本需求必须升级Comfort

**注**: 西门子Basic版因不支持脚本直接排除;若选西门子需明确是Comfort版。

### 2.5 决策建议

| 场景 | 推荐 | 理由 |
|---|---|---|
| 厂商回复满足Q1~Q4全部需求 | 按厂商回复选 | 优先支持国产，昆仑通态性价比最优 |
| 厂商回复S7连接数不足8 | 威纶通cMT-3092X 或 PLC侧改Modbus TCP | 威纶通S7支持最完善 |
| 厂商回复脚本能力不足 | 威纶通或西门子Comfort | 脚本是硬需求(动态显隐) |
| 预算充足追求原厂匹配 | 西门子KTP1200 Comfort | 与S7-200 SMART兼容性最佳 |
| 预算紧张 | 昆仑通态+Modbus TCP方案 | PLC侧配Modbus TCP Server(免费)，HMI用Modbus连接 |

### 2.6 Modbus TCP备选方案(若S7协议受限)

若所选HMI的S7连接数不足8，可在PLC侧启用Modbus TCP Server功能(S7-200 SMART支持)，HMI通过Modbus TCP连接8台PLC:

- 优势:Modbus TCP是通用协议，所有HMI都支持，连接数通常无限制
- 劣势:需在PLC侧配置Modbus TCP Server映射表(V区→Modbus寄存器)，增加约1天开发量
- 实施:PLC侧用MBUS_SERVER指令，将V区映射到Modbus保持寄存器(4xxxxx)
