# 画面变量绑定清单

**项目**：药液配置与加注控制系统 — HMI组态前期准备
**配套文档**：HMI-PLC变量地址表 v1.3、HMI画面架构规划文档 v9.3、报警字32位解析映射表
**适用范围**：8套缸单元通用（每套PLC变量地址一致，HMI通过8个连接PLC_01~PLC_08区分单元）
**用途**：HMI组态阶段画面UI元素与PLC变量的逐项绑定清单，HMI选型确定后按本清单逐画面组态

---

## 绑定总则

1. **单元编号前缀**：所有PLC变量实际绑定形式为 `U{单元号}_{变量名}`，如1号单元状态机为 `U1_VW2_StateMachine`（绑定PLC_01连接的VW2）。本清单为通用模板，表中"绑定PLC变量"列省略单元前缀，组态时按当前选中单元自动套前缀。
2. **连接映射**：HMI工程配置8个连接 PLC_01~PLC_08（IP 192.168.2.101~108），每个变量按当前画面选中单元绑定到对应连接的同名地址。
3. **HMI内部变量**：标记"HMI内部"的元素不读写PLC，存于HMI本地（如单元使能、选中单元号、连接状态）。
4. **DI/DO读取**：I区（DI）和Q区（DO）变量HMI可通过S7协议直接读取（只读），用于状态反馈显示。
5. **二次确认**：标记"二次确认"的写入类按钮需弹窗或长按确认，高优先级报警确认需高权限。
