# 药液配置加注控制系统 — HMI用户权限矩阵 v1.0

**项目**: 药液配置加注控制系统
**配套文档**: HMI画面布局线框图v1.0、画面变量绑定清单v1.0、HMI-PLC变量地址表v1.0
**用途**: 定义3级用户权限对HMI各功能的操作授权，作为HMI组态权限配置和现场操作管理依据
**适用范围**: 8套缸单元集中HMI

---

## 一、权限等级定义

### 1.1 三级权限体系

| 等级 | 名称 | 默认密码策略 | 适用人员 | 登录方式 |
|---|---|---|---|---|
| L1 | 操作员 | 4位数字密码 | 日常操作员、巡检员 | 画面8登录按钮/开机默认 |
| L2 | 维护 | 6位数字密码 | 设备维护工程师、调试人员 | 画面8登录按钮 |
| L3 | 管理员 | 8位字符密码(含字母) | 项目经理、系统管理员 | 画面8登录按钮 |

### 1.2 权限基本原则

1. **默认权限**: 开机/注销后默认L1操作员权限，仅可监控+基础操作
2. **向下兼容**: L3可执行L1+L2+L3所有操作;L2可执行L1+L2;L1仅可执行L1
3. **超时自动注销**: L2/L3登录后15分钟无操作自动降级为L1(防遗忘高权限)
4. **操作审计**: L2/L3所有操作记录到审计日志(时间+用户+操作+单元号)
5. **敏感操作二次确认**: 所有写入类操作需二次确认弹窗;L3级敏感操作需额外高权限确认
6. **密码安全**: 连续3次密码错误锁定5分钟;密码不可见输入;密码强度校验(L3)

## 三、特殊权限场景

### 3.1 继电器故障高权限确认(V0.7)

**场景**: 安全继电器故障(V300.5=1，报警码99)是最高级报警，清除需最高权限。

**操作流程**:
1. 现场确认动力回路已修复，安全继电器反馈I1.2=ON
2. HMI画面5点击"继电器高权限确认"按钮
3. 弹窗提示"此操作将清除继电器故障报警，需管理员权限确认"
4. 输入L3管理员密码二次验证
5. PLC执行: `LD V0.7 EU A I1.2 R V300.5` (FC19 NETWORK4)
6. V300.5清除后，V0.7由PLC自动清零握手

**权限要求**: L3管理员 + I1.2物理反馈正常 + 二次密码确认

### 3.2 急停后系统复位

**场景**: 急停触发后(V300.4=1)，需现场物理复位，HMI不直接下发复位命令。

**操作流程**:
1. 现场旋转释放急停按钮(I1.1恢复ON)
2. HMI画面2/5显示黄色"急停已释放，等待系统复位"
3. 现场按下物理系统复位按钮(I2.3上升沿)
4. PLC执行: FC19 NETWORK3清除V300.4，VW2回到S0
5. HMI显示状态自动更新

**权限要求**: 物理操作，HMI仅显示提示，不涉及HMI权限

### 3.3 强制修正上下缸状态(V0.5/V0.6)

**场景**: 软件标志位(V1.6/V1.7)与实际液位不符时，需人工强制修正。

**操作流程**:
1. L2维护权限登录
2. 画面2点击"强制上缸=空"或"强制上缸=满"
3. 二次确认弹窗"将强制修改上缸状态标志，请确认现场液位已核实"
4. PLC执行: S/R V1.6，置V1.5=1握手
5. HMI显示状态更新

**权限要求**: L2维护 + 二次确认 + 现场核实液位

## 四、HMI组态实施要求

### 4.1 权限配置点

| 画面/控件 | 权限配置 | 实现方式 |
|---|---|---|
| 画面3/4/7入口 | L2以上可见 | 画面加载时校验权限，L1显示"权限不足" |
| 画面4浓度组参数 | L3可编辑 | 控件enable属性绑定当前权限≥L3 |
| V0.7按钮(画面5) | L3可见可操作 | 按钮visible+enable绑定权限=L3 |
| V0.5/V0.6按钮(画面2) | L2以上可操作 | 按钮enable绑定权限≥L2 |
| 手动控制按钮(画面3) | L2以上可操作 | 按钮enable绑定权限≥L2 AND VW2=0或99 |
| 单元使能开关(画面8) | L3可操作 | 控件enable绑定权限=L3 |
| RTC校时按钮(画面8) | L3可操作 | 控件enable绑定权限=L3 |

### 4.2 审计日志格式

| 字段 | 说明 | 示例 |
|---|---|---|
| 时间戳 | 操作时间 | 2026-07-15 14:30:25 |
| 用户 | 操作员ID | admin / maintenance01 / operator02 |
| 权限等级 | 操作时权限 | L3管理员 |
| 单元号 | 操作的单元 | 1号单元 |
| 操作类型 | 命令/参数/系统 | 命令/参数修改/系统设置 |
| 操作内容 | 具体动作 | 启动实验 / 修改VD_C_Set=5.0% / RTC校时 |
| 结果 | 成功/失败 | 成功 / 失败(联锁不满足) |

**容量**: 至少存储10000条审计记录，循环覆盖。支持按时间/用户/单元筛选导出。

### 4.3 超时自动注销

- L2/L3登录后启动15分钟倒计时
- 任意操作重置倒计时
- 倒计时结束自动注销为L1，弹窗提示"权限已超时降级为操作员"
- L1不启动倒计时(默认权限)

## 五、权限分配建议(现场实施)

### 5.1 账号分配建议

| 人员 | 账号 | 权限 | 数量 |
|---|---|---|---|
| 日常操作员 | operator01~03 | L1 | 3个 |
| 值班班长 | shift_lead | L1 | 1个 |
| 设备维护 | maintenance01~02 | L2 | 2个 |
| 调试工程师(首期) | commission | L2 | 1个(首期用) |
| 项目经理 | admin | L3 | 1个 |
| 系统管理员 | sysadmin | L3 | 1个(备份) |

### 5.2 首期验证阶段权限

首期仅1套单元验证时:
- 调试工程师用L2权限(手动控制+参数设置)
- 项目经理用L3权限(全部操作+继电器确认+单元使能)
- 操作员用L1权限(仅监控+启停+消音)

### 5.3 密码管理规范

1. 初始密码首次登录强制修改
2. 密码每90天强制更换(L2/L3)
3. 密码不可重复使用最近5次
4. L3密码需8位以上含大小写+数字+符号
5. 密码不可通过HMI导出，仅管理员可重置他人密码
