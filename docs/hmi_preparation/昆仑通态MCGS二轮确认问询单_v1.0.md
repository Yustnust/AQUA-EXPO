## 二、本项目数据量测算结论(供供应商参考)

我方已完成精确测算(详见《HMI数据量估算与存储时长测算v1.0》):

| 数据类型 | 年数据量(1分钟采样) |
|---|---|
| 报警历史(8单元×32位) | 2.9MB/年 |
| 趋势曲线(8单元×7曲线×1分钟采样) | 237MB/年 |
| 审计日志 | 1.25MB/年 |
| **合计** | **约241MB/年** |

**结论**: 采用1分钟采样间隔,2GB历史区可存8.3年。

## 三、二轮必须确认事项

请贵司就以下7项明确回复,作为最终选型与采购依据:

### Q1: S7协议 vs Modbus TCP 通讯方式推荐

**我方需求**: HMI通过以太网同时连接8台S7-200 SMART PLC(IP 192.168.2.101~108)

**请确认**:
- 贵司推荐使用S7协议还是Modbus TCP?
- 若用S7协议:HMI侧8连接是否需额外授权?S7-200 SMART是否需特殊配置?
- 若用Modbus TCP:PLC侧需启用Modbus TCP Server(MBUS_SERVER指令),HMI侧读取V区映射的保持寄存器,我方需提前开发映射表
- 两种方式对HMI刷新速度的影响?

**我方倾向**: 优先S7协议(免PLC侧开发),若S7连接数受限再考虑Modbus TCP

### Q2: 具体推荐型号与硬件配置

**我方需求**: 12寸触摸屏,8单元总览/报警/参数/趋势画面信息密度较高

**请确认**:
- 贵司推荐的具体型号(如TPC1211-T12CE / TPC1262Hi / 其他)?
- 该型号Flash存储容量?RAM?
- 屏幕分辨率(1280×800还是800×600)?
- 是否支持SD卡扩展存储?
- 若画面信息密度高,是否建议升级到更高配置型号?

**我方测算**: 4GB Flash(2GB历史区)可满足8年存储,但需确认推荐型号实际容量

### Q3: 组态软件授权细节

**请确认**:
- 组态软件名称(McgsPro?MCGS嵌入版?)
- 是否完全免费?有无变量点数限制?
- 工程文件是否可完整导出/备份/二次修改?
- 是否需要工程师认证才能组态?我方工程师可自行组态吗?
- 软件版本更新策略?是否长期免费升级?
