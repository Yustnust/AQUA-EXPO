## 一、备件总则

### 1.1 备件配置原则

1. **关键优先**：直接导致单元停机或安全风险的关键器件（A类）必须现场常备1套，确保4小时内可更换。
2. **数量与套数挂钩**：8套单元同型号器件总量按 `单套用量×8` 核算备件基数；同型号器件按总量的5%~20%配置备件（A类取高限，C类取低限）。
3. **公共设备单独核算**：HMI、交换机等公共设备仅1台/套，备件按"整机1+核心模块1"原则配置。
4. **采购周期匹配**：长采购周期器件（进口/定制）备件量适当上浮；短采购周期器件（国产标准件）可降低备件量。
5. **与BOMv2对齐**：本清单物料名称/规格/单套用量严格对齐BOM清单v2，型号细化中"待确认"项需现场到货后填实。
6. **分期兼容**：首期1套阶段按1套基数+全量8套上限核算；全量8套阶段按本表"8套总用量"列重新核算备件量。

### 1.2 备件等级定义

| 等级 | 定义 | 备件要求 | 采购周期要求 |
|---|---|---|---|
| **A关键** | 直接导致单元停机或安全风险，无替代方案，故障后无法继续运行 | 必须现场备1套以上，确保4小时内更换 | 采购周期>2周的，备件量翻倍 |
| **B重要** | 影响单元功能或冗余度，故障后可降级运行但需尽快更换 | 建议现场备1套，确保48小时内更换 | 按正常采购周期备货 |
| **C一般** | 不影响主流程，可采购周期内到货，或同型号器件可临时借用 | 库存预警，按需采购 | 采购周期<2周可零库存 |

### 5.3 备件领用流程

```
[领用流程]

1. 故障发生 → 维护工程师评估需更换器件
   ↓
2. 查备件台账确认库存
   ├─ 有库存 → 进入Step 3
   └─ 无库存 → 紧急采购（A类）/ 等待采购（B/C类）
   ↓
3. 填写《备件领用单》
   - 领用人/日期/单元编号/故障现象/更换器件编号
   - 维护工程师签字
   ↓
4. 仓库管理员核实后发放备件
   ↓
5. 更换完成后，维护工程师在《设备维护记录》登记
   - 故障原因/处理过程/更换件序列号/恢复时间
   ↓
6. 仓库管理员更新台账库存数
   ├─ 库存<预警阈值 → 触发补货流程（见4.3）
   └─ 库存正常 → 结束
   ↓
7. 故障件按以下方式处理：
   ├─ 在保修期内 → 返厂维修/换新
   ├─ 保修期外可修复 → 送修后入库备用
   └─ 不可修复 → 报废处理，记录报废原因
```

### 5.4 备件定期盘点

| 频次 | 盘点内容 | 责任人 |
|---|---|---|
| 每月 | 实物与台账核对，预警阈值检查 | 仓库管理员 |
| 每季度 | 备件有效期检查（如有），老化检查 | 仓库管理员 + 维护工程师 |
| 每年 | 全量盘点，备件策略评估，根据故障率调整备件量 | 网络与采购工程师 |

### 5.5 备件数据驱动优化

| 数据来源 | 用途 | 优化方向 |
|---|---|---|
| 《设备维护记录》故障率统计 | 识别高故障率器件 | 提升该器件备件等级与备件量 |
| 备件领用频次分析 | 识别零领用备件 | 降低或取消该备件备货 |
| 采购周期实际值 | 修正采购周期估算 | 调整最低库存阈值 |
| 故障停机时长统计 | 评估备件响应有效性 | 优化备件存储位置与领用流程 |
