## 一、适用范围

本文档适用于8套缸单元（IP 192.168.2.101~108）的全部报警诊断。各PLC程序完全相同，报警字地址一致，仅单元编号与IP不同。本字典覆盖 `VW6` 报警码表的全部31个编码（0=无报警，其余30条报警），每条均基于实际STL源码与变量表交叉核验，含触发条件、可能原因、排查步骤、恢复方法、预防措施与关联变量。

## 二、使用说明

### 2.1 如何根据VW6码查字典

1. 在HMI画面5（报警日志页）或画面2（单元详情页）查看 `VW6` 当前值。
2. 跳转到本字典"第三章 故障代码详表"，按报警码定位条目（建议配合附录A快速索引表）。
3. 按条目内"现场排查步骤"逐项执行，参照"关联变量"在画面2/4/6/7交叉核对DI/VD参数。
4. 处置完毕后按"恢复方法"操作复位；若为强制人工确认类（漫溢级/节奏级/继电器故障），还需在HMI画面5下发V0.3或V0.7命令。

### 2.2 报警分级与响应时效

| 等级 | VW6编码段 | HMI颜色 | 响应时效 | 强制人工确认 | 复位主导 |
|---|---|---|---|---|---|
| 最高级 | 99 | 红色闪烁 | 立即（秒级） | 是（HMI二次确认+高权限） | V0.7 + I1.2 |
| 漫溢级 | 10~14 | 红色 | 立即（分钟级） | 是 | V0.3 + DI恢复 |
| 节奏级 | 20 | 橙色 | 尽快（小时内） | 是 | V0.3 + 节奏恢复 |
| 一般级 | 21, 30~66 | 黄色 | 择机（班次内） | 按 `M_AlarmAckMode`（V200.0） | 自动 / V0.3 |

### 2.3 优先级链（FC3 NETWORK1 实现）

```
99 (V300.5) > 10~14 (V300.0~V300.4) > 20 (V300.6) > 21 (V300.7)
            > 30~36 (V301.0~V301.6) > 40~47 (V302.0~V302.7) > 60~66 (V303.0~V303.6)
```

`VW6` 始终保存当前最高优先级未确认报警码（FC3 NETWORK1 用 LD压栈+条件JMP 逐位赋值，JMP到 `nAlarmCodeDone` 跳出）。

### 2.4 复位模式说明（M_AlarmAckMode，V200.0）

| 模式 | 值 | 一般故障级（V301.x/V302.x/V303.x，VW6=21/30~66） | 高优先级（V300.0~V300.6，VW6=10~14/20/99） |
|---|---|---|---|
| 自动恢复 | 0 | 条件消失后FC3 NETWORK5自动R复位→VW6重算为0→自动消光 | **不受此模式影响**，仍强制人工确认 |
| 人工确认 | 1 | 条件消失后需HMI下发V0.3确认→FC3 NETWORK4复位报警位 | 同上，强制人工确认 |

### 2.5 消音/消光分离原则

| 操作 | 命令源 | 效果 | 不影响 |
|---|---|---|---|
| 消音 | I2.1就地按钮 OR V0.4 HMI命令 | 关Q0.7声音，置M_Sound_Latched | 灯光Q1.0、报警锁存位、VW6、状态机 |
| 消光（报警确认） | V0.3 HMI报警确认 | 根本原因消失后关Q1.0灯光、清报警锁存位、VW6=0 | — |
| 新报警重鸣 | VW6由0变非0 | 清M_Sound_Latched，Q0.7重新鸣响 | 操作员需再次消音 |

### 3.1 报警码 99：安全继电器/接触器故障

| 项 | 内容 |
|---|---|
| **报警码** | 99 |
| **报警符号** | M_Alarm_SafetyRelay |
| **报警位地址** | V300.5 |
| **优先级** | **最高级**（红色闪烁） |
| **触发条件** | FC2 NETWORK2：急停锁存后（V300.4=1）且安全继电器反馈I1.2=OFF，T35延时2秒（PT=20，100ms时基）到达上升沿 → `S V300.5, 1`。逻辑含义：急停按下后，安全继电器主触点应在2秒内断开220V/380V动力回路并通过I1.2辅助触点反馈"已断开"信号；2秒未反馈则判定主触点粘连或继电器故障 |
| **可能原因** | **机械原因**：①安全继电器主触点粘连（电弧烧蚀）②继电器机械机构卡死 ③继电器线圈断线/烧毁 |
| | **电气原因**：①220V/380V动力回路短路导致触点熔焊 ②I1.2反馈接线断线/松脱 ③I1.2反馈回路中间继电器故障 ④安全继电器电源（220V线圈）失电 |
| | **软件或操作原因**：①现场未执行急停按钮测试但I1.2反馈触点选型错误（常开/常闭反接）②T35延时参数过短（默认2秒，机械动作慢的继电器可能误报） |
| **现场排查步骤** | 1. HMI画面5查看报警码99红闪，确认继电器故障最高级报警；画面2确认VW2=99（S_ERROR）<br>2. 现场查看安全继电器线圈是否得电（指示灯）<br>3. 用万用表测量I1.2端子电压：ON=24V（动力回路已断开确认），OFF=0V<br>4. 检查继电器主触点状态：断电后用万用表通断挡测主触点，正常应为开路<br>5. 检查220V动力回路绝缘，排除短路<br>6. 检查I1.2反馈接线（强制导向触点→中间继电器→PLC DI）<br>7. 确认急停按钮I1.1状态（应已OFF，即急停已按下） |
| **恢复方法** | 1. 排除机械/电气故障（更换继电器/修复接线/处理短路）<br>2. 旋转释放急停按钮（I1.1恢复ON）<br>3. L3管理员登录HMI，画面5点击"继电器高权限确认"，输入密码二次验证<br>4. PLC执行FC19 NETWORK4：`LD V0.7 EU A I1.2 R V300.5` —— 必须I1.2=ON（反馈确实正常）才清除V300.5<br>5. V300.5清除后，下一周期FC19 NETWORK2不再跳过，可按现场I2.3系统复位按钮回S0<br>**注意**：禁止用系统复位按钮I2.3直接清除V300.5；若I1.2仍OFF（检修未完成），V0.7无法清除报警 |
| **预防措施** | ①每月执行1次急停按钮测试，验证I1.2反馈时序<2秒 ②每年检查继电器主触点烧蚀情况，必要时更换 ③I1.2反馈回路接线端子定期紧固 ④T35延时参数（默认2秒）现场整定，机械慢的继电器可适当延长至3秒（修改FC2 NETWORK2 PT值） |
| **关联变量** | V300.5（报警位）；V300.4（急停锁存，前置条件）；I1.1（急停反馈）；I1.2（安全继电器反馈）；T35（2秒延时，PT=20）；V0.7（CMD_SafetyRelayAck）；VW2（应=99 S_ERROR） |

### 3.2 报警码 10：上缸漫溢（液位计A-高位）

| 项 | 内容 |
|---|---|
| **报警码** | 10 |
| **报警符号** | M_Alarm_Overflow_AHigh |
| **报警位地址** | V300.0 |
| **优先级** | 漫溢级（红色） |
| **触发条件** | FC30 NETWORK1（漫溢保护，全程最高优先级）：`LD I0.5 S V300.0, 1` —— S1/S2期间液位计A-高位 I0.5=ON，立即置位V300.0并联动：S Q0.5（NC球阀-上缸得电关闭第二道保护）、R Q0.2（关阀A）、`MOVB 99, VB2`（转S_ERROR）、Diag_Result_A=2故障 |
| **可能原因** | **机械原因**：①阀A关不到位/卡滞（球体磨损、密封失效）②上缸排水口堵塞 ③管路背压异常导致进水不停 |
| | **电气原因**：①液位计A-高位探头误动作（受潮/接线短路）②液位计探头表面结垢导致提前触发 ③I0.5输入端子接线松脱误接通 |
| | **软件或操作原因**：①VD_Timeout_ValveA超时参数过长，进水过多才报警 ②VD316（目标进水量）设定过大超出缸体容量 ③流量开关A失效，阀A未关仍持续进水 |
| **现场排查步骤** | 1. HMI画面5查看报警码10红，画面2确认VW2=99、上缸状态V1.6<br>2. 现场查看上缸实际液位，确认是否真的接近漫溢<br>3. 检查阀A是否已关闭到位（手摸/听水流声），PLC已自动R Q0.2关阀<br>4. 确认NC球阀-上缸Q0.5已得电（应已自动动作，关闭第二道保护）<br>5. 检查液位计A-高位探头：用万用表测I0.5端子电压，确认是否误通<br>6. 检查液位计探头表面是否结垢，擦拭清洁<br>7. 排查阀A机械：手电动切换，手动操作阀A检查是否灵活<br>8. 检查上缸排水口是否堵塞 |
| **恢复方法** | 1. 现场降低上缸液位（手动排水或等待NC阀泄流），使I0.5=OFF<br>2. 消音（I2.1按钮或HMI V0.4）<br>3. 排查并消除阀A机械/电气故障<br>4. HMI画面5点击"报警确认"下发V0.3<br>5. PLC执行FC3 NETWORK4：`LD V300.0 AN I0.5 R V300.0` —— 必须I0.5=OFF才复位<br>6. V300.0复位后下一周期VW6重算<br>7. 现场按I2.3系统复位按钮回S0（FC19 NETWORK3） |
| **预防措施** | ①每周清洁液位计A探头表面 ②每月测试液位计A-高位动作可靠性 ③VD316目标进水量设定值与缸体容量留≥20%余量 ④VD_Timeout_ValveA（默认60秒）现场整定 ⑤VD_Delay_ValveA_Verify（默认5秒）确保延时验证生效 |
| **关联变量** | V300.0（报警位）；I0.5（液位计A-高位）；Q0.2（阀A输出，应=0）；Q0.5（NC阀-上缸，应=1）；VW2（应=99）；VD316（目标进水量）；VD_Timeout_ValveA（VD48，阀A超时）；VD_Delay_ValveA_Verify（VD66，延时验证） |

```
[1] 报警触发
     ↓ FC2/FC30/FC31/FC32/FC40/FC11/FC12/FC13/FC16/FC0置位V300.x~V303.x
     ↓ FC3 NETWORK1 优先级链计算VW6（最高优先级未确认报警码）
     ↓ FC3 NETWORK2 灯光Q1.0常亮 + 新报警VW6由0变非0清M_Sound_Latched使Q0.7重鸣

[2] HMI识别
     ↓ HMI画面5读取VW6值，按本字典定位报警码条目
     ↓ HMI画面5报警指示灯阵列显示VB300~VB303所有活动报警位
     ↓ HMI画面2交叉确认DI状态（I0.x/I1.x/I2.0等）

[3] 消音（可选，不影响处置）
     ↓ I2.1就地按钮 OR HMI画面5 V0.4命令
     ↓ FC3 NETWORK3: R Q0.7（关声音）+ S M11.1（消音标志）+ S V1.4（握手）
     ↓ 灯光Q1.0、报警锁存位、VW6、状态机不变

[4] 现场检查与处置
     ↓ 按本字典"现场排查步骤"逐项执行
     ↓ 修复机械/电气/软件故障

[5] 条件消除（DI恢复正常）
     ↓ I0.x/I1.x/I2.0等DI反馈恢复正常
     ↓ V300.x/V301.x/V302.x/V303.x报警位条件已消失

[6] 报警复位（按优先级与模式）
     ├─ 最高级（VW6=99）：FC19 NETWORK4 V0.7 EU + I1.2=ON → R V300.5
     ├─ 漫溢级（VW6=10/11/14）：FC3 NETWORK4 V0.3 EU + DI=OFF → R V300.x
     ├─ 漫溢级（VW6=12/13 NC阀）：FC19系统复位按钮处理
     ├─ 节奏级（VW6=20）：FC3 NETWORK4 V0.3确认 + FC40新一轮重置
     └─ 一般级（VW6=21/30~66）：
         ├─ 自动模式（V200.0=0）：FC3 NETWORK5自动R复位（条件消失）
         └─ 人工模式（V200.0=1）：FC3 NETWORK4 V0.3确认 + 条件消失

[7] VW6重算与消光
     ↓ FC3 NETWORK1 下一周期重算VW6
     ↓ 若所有报警位均复位 → VW6=0
     ↓ FC3 NETWORK2: VW6=0 + 自动模式 → R Q1.0（消光）+ R Q0.7 + R M11.1

[8] 系统复位（若已转S_ERROR）
     ↓ 现场按下物理系统复位按钮I2.3
     ↓ FC19 NETWORK3: I1.1=ON + I2.3 EU + V300.5=0 → R V300.4 + R V1.6/V1.7 + VW2=0（S0）+ VW6=0 + R Q0.7
     ↓ 状态机回S0初始化，恢复运行
```

### 5.2 最高级/漫溢级紧急处置流程

```
[1] 99红闪 / 10~14红 报警触发
     ↓ FC2 NETWORK1/2 或 FC30 NETWORK1 或 FC31 NETWORK1 置位V300.5/V300.0~V300.4
     ↓ VW2=99（转S_ERROR），QB0=0（强制安全输出）

[2] 立即消音（不影响处置）
     ↓ I2.1就地按钮 OR HMI V0.4

[3] 现场确认是否需进一步急停
     ├─ 漫溢严重 / 继电器故障 → 现场按急停按钮I1.1=OFF（若未触发）
     └─ 无需急停 → 直接现场检查处理

[4] 现场检查与处置（按本字典"现场排查步骤"）
     ↓ 检查液位/阀机械/继电器/接线
     ↓ 修复故障

[5] 报警确认（按本字典"恢复方法"）
     ├─ VW6=99：L3管理员HMI V0.7 + I1.2=ON（FC19 NETWORK4）
     ├─ VW6=10/11：HMI V0.3 + I0.5/I0.7=OFF（FC3 NETWORK4）
     └─ VW6=14：现场I2.3系统复位按钮（FC19 NETWORK3）

[6] 系统复位
     ↓ 现场按I2.3系统复位按钮
     ↓ FC19 NETWORK3: VW2=0（回S0）+ V1.6/V1.7=0 + VW6=0

[7] 恢复运行
     ↓ HMI画面1总览页确认单元状态绿色
     ↓ 重新启动实验V0.0（CMD_Start）
```

### 5.3 一般级报警处置流程

```
[1] 21/30~66 黄 报警触发
     ↓ FC30/FC31/FC32/FC12/FC13/FC40/FC0置位V300.7/V301.x/V302.x/V303.x
     ↓ FC3 NETWORK1重算VW6（若高于当前VW6则更新）

[2] HMI识别（画面5查看VW6与指示灯阵列）
     ↓ 按本字典定位报警码条目

[3] 消音（可选）

[4] 现场检查与处置（按本字典"现场排查步骤"）

[5] 条件消除与复位
     ├─ 自动模式（V200.0=0）：
     │   ↓ DI条件消失
     │   ↓ FC3 NETWORK5自动R复位V301.x/V302.x/V303.x
     │   ↓ FC3 NETWORK1重算VW6=0
     │   ↓ FC3 NETWORK2自动R Q1.0消光
     │   ↓ 通常不转S_ERROR，系统继续运行（除VW6=20严重滞后外）
     └─ 人工模式（V200.0=1）：
         ↓ DI条件消失
         ↓ HMI画面5报警确认V0.3
         ↓ FC3 NETWORK4复位V301.x/V302.x/V303.x
         ↓ FC3 NETWORK1重算VW6=0
         ↓ FC3 NETWORK2消光

[6] 若已转S_ERROR（如VW6=20/32/34/35等触发转S_ERROR的报警）
     ↓ 现场按I2.3系统复位按钮回S0
```

### 5.4 急停与系统复位专项流程

```
[1] 急停按下
     ↓ I1.1=OFF（常闭触点断开）
     ↓ FC2 NETWORK1: I1.1 NOT EU S V300.4（急停锁存）+ VW2=99（转S_ERROR）
     ↓ FC2 NETWORK3: QB0=0（强制安全输出）+ S Q0.7（声音）

[2] 安全继电器反馈延时校验（FC2 NETWORK2）
     ↓ V300.4=1 AND I1.2=OFF → T35开始计时（2秒）
     ├─ 2秒内I1.2=ON（动力回路已断开）→ T35未到达，不报警
     └─ 2秒后I1.2仍OFF → T35到达EU → S V300.5（继电器故障最高级报警）

[3] 急停解除与系统复位
     ↓ 现场排查急停原因，处理完毕
     ↓ 旋转释放急停按钮 → I1.1=ON
     ↓ HMI显示黄色"急停已释放，等待系统复位"
     ↓ 检查V300.5是否=1：
         ├─ V300.5=1（继电器故障）→ FC19 NETWORK2跳过系统复位，转NETWORK4
         │   ↓ L3管理员HMI V0.7 + I1.2=ON → R V300.5
         │   ↓ 再按I2.3系统复位按钮
         └─ V300.5=0（无继电器故障）→ FC19 NETWORK3
             ↓ I1.1=ON + I2.3 EU + V300.5=0 → R V300.4 + VW2=0 + VW6=0
             ↓ 状态机回S0

[4] 恢复运行
     ↓ HMI画面1确认单元状态绿色
     ↓ 重新启动实验V0.0
```

### 6.2 与配套文档的关系

- **上位文档**：HMI-PLC变量地址表v1.0 第九章（报警标志与报警码定义）
- **平级文档**：报警字32位解析映射表v1.0（HMI组态素材）、报警现场处置操作指引v1.0（操作员手册）

### 6.3 调试要点提示

1. **首次调试必查项**：V300.2/V300.3/V303.6三个预留接口位的STL实现状态，若现场触发Q0.5/Q0.6动作但未报警，需补充置位逻辑。
2. **参数整定优先级**：VD_Delay_ValveA_Verify（5秒）、VD_Timeout_ValveA/B/C（60秒）、T35（2秒继电器反馈）、T52（2秒开到位无流确认）—— 这些参数现场实测后需整定至合理值。
3. **内漏阈值0.1L**：FC30 NETWORK8 硬编码 `AR> VD312, 0.1`，需根据现场实际渗漏允许值修改STL。
4. **断电恢复策略**：FC0 NETWORK7 阀门动作态（S1~S6）断电转S_ERROR，仅S0/S5/S7/S_ERROR可恢复，调试时务必验证。
5. **报警确认模式**：V200.0现场建议默认=1（人工确认模式），避免一般故障级报警自动复位导致操作员忽略故障；最高级/漫溢级/节奏级不受此模式影响。
