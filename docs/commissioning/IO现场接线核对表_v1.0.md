# 药液配置加注控制系统 — IO现场接线核对表 v1.0

**项目**: 药液配置加注控制系统
**适用范围**: 8套缸单元通用(每套1台PLC,IO地址相同)
**用途**: 现场接线施工与调试阶段的逐点核对表,施工方按表接线,调试方按表打点核对
**配套文档**: PLC设计文档v9.3第二章I/O地址分配表、HMI-PLC变量地址表v1.0第二/三章

---

## 一、使用说明

### 1.1 核对流程

```
施工方接线 → 调试方逐点核对 → 发现问题记录 → 整改 → 复核 → 签字确认
```

### 1.2 核对方法

| 类型 | 核对方法 |
|---|---|
| DI(数字量输入) | 现场触发信号源→PLC变量表监控对应I点状态变化 |
| DO(数字量输出) | PLC强制Q点ON→现场确认继电器吸合+负载动作 |
| 公共端 | 万用表测量公共端电压,确认SRC/SINK接法 |

### 1.3 状态标记

- ✅ 合格: 接线正确,功能正常
- ❌ 不合格: 接线错误或功能异常(记录问题处理)
- ⚠️ 待确认: 需进一步核实(如信号类型/接法)

## 附录:常见接线问题速查

| 现象 | 可能原因 | 排查方法 |
|---|---|---|
| DI信号始终ON | 信号源常闭/接线错误 | 查信号源触点类型,确认公共端接法 |
| DI信号始终OFF | 信号源常开/断线/公共端未接 | 万用表测通断,查1M/2M接线 |
| 急停I1.1逻辑反 | 常闭/常开接反 | 确认急停第二组常闭触点 |
| DO无输出 | 1L+/2L+未接24V | 万用表测公共端电压 |
| 继电器不吸合 | 线圈极性反/断线 | 测线圈电压,确认A1/A2接法 |
| 485通讯失败 | D+/D-接反/站号冲突 | 对调D+/D-,查站号唯一性 |
| 阀门限位无信号 | 有源信号未隔离 | 确认经中间继电器转换 |
