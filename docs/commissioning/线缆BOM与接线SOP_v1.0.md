## 二、接线SOP

### 2.1 接线前准备

1. **工具准备**：
   - 棒形端子压接钳(0.5/0.75/1.0/1.5/2.5mm²)
   - 剥线钳(可调0.5~2.5mm²)
   - 万用表(通断+DC24V/AC220V)
   - 号码管打印机
   - 标签机
   - 扭力螺丝刀(0.5~0.6 N·m)
   - 热缩管(2/3/5mm)

2. **线缆预处理**：
   - 所有线头压接棒形端子(U型或针型)
   - 套号码管(编号规则见下)
   - AC220V线头加热缩管(黄/绿标记相线/零线)
   - 屏蔽线预留30mm,准备接地

3. **号码管编号规则**：
   - 格式：`PLC地址-顺序号`
   - 例：`I0.0-1`(I0.0的第1根线)、`Q0.0-1`、`L+-1`、`M-1`
   - 多芯电缆内部芯线：`电缆号-芯号`，如`CAB-09-1`

### 2.2 接线顺序

#### 阶段1：保护接地(必先)

1. 接PE排到控制柜外壳(2.5mm²黄绿)
2. 接PLC本体PE端子到PE排(2.5mm²黄绿)
3. 接开关电源PE到PE排
4. 接所有金属外壳(继电器/接触器)PE到PE排
5. **测试**：PE排到大地电阻≤4Ω

#### 阶段2：AC220V电源(送电前必断QF1)

1. 接AC220V进线到QF1上级
2. QF1下级到开关电源AC输入
3. QF1下级到安全继电器线圈回路
4. QF1下级到负载电源母线(经各接触器)
5. **检查**：相线/零线/PE正确，无短路
6. **送电测试**：合QF1，测开关电源AC输入=AC220V

#### 阶段3：DC24V控制电源

1. 开关电源DC+到PLC本体L+端子(1.5mm²红)
2. 开关电源DC-到PLC本体M端子(1.5mm²蓝)
3. L+/M引出到传感器电源母线(1.5mm²)
4. L+/M引出到中间继电器线圈电源母线
5. **测试**：PLC上电，L+/M间DC24V±0.5V

#### 阶段4：DI信号线

按接线端子图2.1节顺序，逐点接线：
1. I0.0~I0.2（流量开关A/B/C，无源）、I0.5~I0.7（液位计，无源）
2. I1.0~I1.2(急停+安全继电器+液位低位)
3. I8.0(阀A开到位,经KA10)
4. I8.5~I0.3(阀C关到位+消音+复位)
5. **测试**：逐点用磁铁/手动触发，观察PLC输入指示灯

#### 阶段5：DO信号线(经中间继电器)

1. 安装KA1~KA9中间继电器到导轨
2. KA1~KA9线圈接到Q0.0~Q0.7+Q2.0
3. KA1~KA9常开触点接到对应接触器线圈回路
4. **测试**：PLC强制DO输出，测继电器吸合

#### 阶段6：Modbus通讯线

1. 断电状态下接CAB-42(PLC-注射泵)
2. 断电状态下接CAB-43(PLC-流量计)
3. 屏蔽层单端接地(PLC侧)
4. DB9接头焊接检查(2/3/5脚)
5. **测试**：用Modbus Poll软件测试通讯

#### 阶段7：以太网通讯线

1. 接CAB-41到PLC本体以太网口
2. 接另一端到交换机
3. 测试连通性：ping PLC IP(192.168.2.10X)

#### 阶段8：急停回路(AQEX-9)

1. 急停按钮第1组常闭→急停回路
2. 急停按钮第2组常闭→I1.1
3. 急停按钮第3组→安全继电器输入
4. 安全继电器主触点→KM1/KM2/KM3线圈回路
5. 安全继电器反馈13/14→I1.2
6. **测试**：按急停→I1.1=OFF+KM1/2/3失电

### 2.3 接线质量检查清单

#### 通断测试(送电前,万用表蜂鸣档)

- [ ] 每根DI线：PLC端子到传感器端通断正常
- [ ] 每根DO线：PLC端子到继电器线圈通断正常
- [ ] 每根动力线：接触器到负载通断正常
- [ ] PE线：所有金属外壳到PE排通断正常
- [ ] 急停回路：急停按下时回路断开,弹起时导通

#### 绝缘测试(送电前,500V兆欧表)

- [ ] AC220V回路对地绝缘≥0.5MΩ
- [ ] DC24V回路对地绝缘≥0.5MΩ
- [ ] AC220V与DC24V回路间绝缘≥0.5MΩ
- [ ] Modbus通讯线对地绝缘≥0.5MΩ

#### 送电后测试

- [ ] PLC本体RUN指示灯常亮
- [ ] 各模块指示灯正常(DI/DO/ERR)
- [ ] 强制每个DO输出,对应继电器吸合
- [ ] 触发每个DI信号,PLC输入灯亮
- [ ] Modbus通讯测试(读注射泵状态码VW4)
- [ ] 以太网通讯测试(ping PLC)
- [ ] 急停测试(按急停→I1.1=OFF+KM失电)

### 2.4 线缆标识规范

#### 线缆标签(每根线两端贴)

格式：`源设备-目的设备-线号`
例：`FS-A-PLC-I0.0-01`(流量开关A到PLC I0.0,第1号线)

#### 号码管(每个端子压接处)

格式：`PLC地址-顺序号`
例：`I0.0-1`、`Q0.0-1`、`L+-1`

#### 线缆铭牌(线缆两端线身上)

内容：电缆编号+用途+芯数×截面
例：`CAB-01 流量开关A 2×0.75`

### 2.5 常见接线错误与预防

| 错误类型 | 后果 | 预防措施 |
|---|---|---|
| AC220V误接入DC24V回路 | 烧毁PLC DI/DO | 接线前用万用表确认电压等级 |
| 急停常开误接常闭 | 急停失效 | 万用表测通断,确认ON=正常 |
| 屏蔽层双端接地 | 地环路干扰 | 仅PLC侧接地 |
| DO直接驱动负载 | 烧毁DO晶体管 | 必须经中间继电器 |
| 阀门有源反馈直入PLC | 信号短路/误动作 | 必须经中间继电器转换 |
| 中间继电器线圈无续流二极管 | 触点拉弧寿命短 | 选继电器时确认含续流 |
| Modbus线与动力线共槽 | 通讯干扰 | 独立线槽,间距≥50mm |
| 端子螺丝未紧固 | 接触不良/发热 | 扭力螺丝刀0.5~0.6 N·m |

## 三、8套单元批量接线SOP

### 3.1 标准化原则

8套单元程序相同,接线完全相同,仅IP地址不同(192.168.2.101~108)。采用**标准化接线模板+逐套复制**方式。

### 3.2 批量接线流程

1. **第1套接线**：按本SOP完整接线,作为样板
2. **第1套验收**：按2.3检查清单逐项验收
3. **第2~8套复制**：按样板接线,每套验收
4. **IP地址分配**：每套PLC烧录程序后配置独立IP
5. **一致性校验**：8套接线对照样板,无差异

### 3.3 控制柜编号与标识

| 单元编号 | 控制柜编号 | PLC IP | HMI连接 |
|---|---|---|---|
| 1号 | AQUA-EXP-CAB-01 | 192.168.2.101 | HMI连接#1 |
| 2号 | AQUA-EXP-CAB-02 | 192.168.2.102 | HMI连接#2 |
| ... | ... | ... | ... |
| 8号 | AQUA-EXP-CAB-08 | 192.168.2.108 | HMI连接#8 |

每个控制柜门外贴铭牌：单元编号+PLC IP+HMI连接编号。
