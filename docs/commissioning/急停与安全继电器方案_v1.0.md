## 一、设计目标

1. **满足 EN ISO 13850 / IEC 60204-1 / GB 5226.1 急停标准**
2. **硬件安全 + 软件安全双冗余**:急停切断不依赖 PLC
3. **双通道带短路检测**:MSR-P 监控两个触点状态一致性
4. **手动复位**:急停释放后必须人工按按钮,防止"急停还没撤人就启动"
5. **继电器故障自检**:MSR-P 反馈触点接 PLC,2 秒内不响应则报最高级故障
6. **快速响应**:FC2 急停检测用 NO 上升沿(响应 < 1ms)

## 三、核心设计理念

### 3.1 为什么 NC 必须进 MSR-P

MSR-P 是**双通道带短路检测**型安全继电器,要求两个独立触点分别进不同通道,内部监控:
- **NC 触点**(常闭):进 MSR-P 通道 1(S11-S12 或 S21-S22)
- **NO 触点**(常开):进 MSR-P 通道 2(另一个通道)

按下急停时,NC 和 NO **同时动作**(强制导向型按钮的机械互锁保证),MSR-P 内部对比两个通道的状态:
- 两通道**同时变化** → 正常,触发急停
- 两通道**状态不一致**(一个变了另一个没变) → **触点熔焊/卡死**,报故障

如果只接 NO 进 MSR-P,失去通道间短路检测能力,降级为单通道(从 PL e 降到 PL c)。

### 3.2 为什么 NO 还要进 PLC

| 信号 | 路径 | 作用 |
|---|---|---|
| NC → MSR-P 通道 | 硬件 | 切断 KM1/KM2/KM3 接触器线圈(**硬件层面安全**,PLC 死了也工作) |
| NO → PLC I1.1 | 软件 | FC2 NETWORK 1 NO 上升沿立即锁存 V300.4 + QB0=0 + VW2=99(**响应 < 1ms**) |
| MSR-P 13/14 → I1.2 | 自检 | FC2 NETWORK 2 监测 2 秒内必须 ON,否则 V300.5 最高级报警 |

**两条路径冗余 + 互补**:
- MSR-P 提供**硬件安全**(即使 PLC 死机、程序跑飞,MSR-P 也能切断动力)
- PLC I1.1 提供**软件快速响应**(比 MSR-P 内部 MCU 处理快 10-30ms)
- MSR-P 13/14 反馈提供**自检**(确认 MSR-P 真的切了)

### 3.3 为什么 S2 复位按钮和 I0.3 系统复位按钮必须分开

| 维度 | MSR-P 硬件复位 S2 | PLC 系统复位 I0.3 |
|---|---|---|
| **作用对象** | MSR-P 内部锁存 + K3/K4 主触点 | PLC V300.4 锁存 + VW2 + 上下缸状态 |
| **作用层** | 硬件(切断/恢复接触器线圈) | 软件(状态机回 S0) |
| **何时需要按** | 急停按了释放后,MSR-P 仍锁存 | PLC 状态机锁在 S_ERROR 时 |
| **先决条件** | 无 | ① I1.1=OFF(急停已释放)② V300.5=0(无继电器故障) |
| **PLC 代码** | 无(MSR-P 内部处理) | FC19 NETWORK 3 |
| **物理接线** | 按钮 → MSR-P S11/S34 复位端子 | 按钮 → PLC I0.3 |

**两个复位是"串联"关系**,**顺序无关但都必须做**:
1. 急停按下 → MSR-P 切断 K3/K4 + PLC 锁 V300.4
2. 急停释放 → MSR-P 仍锁存(K3/K4 仍断开)
3. **按 S2 复位** → MSR-P 解除锁存,K3/K4 重新吸合
4. **按 I0.3 系统复位** → PLC 清 V300.4,VW2=0,回 S0

**如果用 1 个双路 NO 按钮同时复位两个,会引发关键安全问题**:
- **急停没释放就按** → MSR-P 先解锁 → K3/K4 吸合 → 动力恢复;PLC I0.3 因 I1.1 条件不满足不动作 → **MSR-P 已解锁但 PLC 仍报 S_ERROR**
- **继电器故障(V300.5=1)时按** → MSR-P S2 解锁 → 接触器带电(但 K3/K4 主触点可能粘连,正是 V300.5 触发原因)→ **强行上电,安全失效!**

**结论:用 2 个独立按钮,物理隔离,逻辑清晰**。

## 五、时序验证(v1.3 NO 接法)

### 5.1 正常状态(急停未按)

| 信号 | 状态 | PLC 读取 | 含义 |
|---|---|---|---|
| 急停按钮 NC 触点 | **闭合** | - | MSR-P 通道 1 正常 |
| 急停按钮 NO 触点 | **断开** | **I1.1 = OFF** | PLC 读到 OFF(浮空) |
| MSR-P 13-14 反馈 | **断开** | **I1.2 = OFF** | 动力未切断(但本来就不该切) |
| MSR-P K3, K4 主触点 | **吸合** | KM1/KM2/KM3 通电 | 动力回路正常 |
| QB0(Q0.0~Q0.6) | **S6 转 S5 等正常状态** | - | 由 FC11~FC17 控制 |
| Q0.7 蜂鸣器 | OFF | - | 无报警 |
| Q2.0 报警灯 | OFF | - | 无活动报警 |

### 5.2 按下急停瞬间(假设在 S5 状态)

| 时间 | 事件 | 状态变化 |
|---|---|---|
| **T+0ms** | 操作员按下急停 | NC 断开;NO 闭合 |
| **T+0~5ms** | PLC 扫描 | `LD I1.1` + `EU` 上升沿触发 → `S V300.4` + `MOVW 99, VW2` |
| **T+5~10ms** | FC2 NETWORK 3 | `MOVB 0, QB0` → 泵/阀/NC 电磁阀全部失电(Q0.0~Q0.6=0) |
| **T+5~10ms** | FC2 NETWORK 3 | `S Q0.7` → 蜂鸣器开 |
| **T+10~30ms** | MSR-P 内部检测 | NC 断开 + NO 闭合 → 通道 1 失信号,通道 2 短路 → 触发 |
| **T+30~50ms** | MSR-P 切断输出 | 23-24 / 33-34 / 41-42 断开 → KM1/KM2/KM3 失电 → 动力回路断 |
| **T+30~50ms** | MSR-P 13-14 闭合 | I1.2 = ON |
| **T+50ms** | 报警灯亮 | Q2.0 = 1(FC3 处理) |
| **T+2s** | 继电器故障检查 | I1.2 已 ON,V300.5 不触发(正常) |

### 5.3 急停释放后(但没按复位)

| 信号 | 状态 | 说明 |
|---|---|---|
| 急停按钮 NC | 闭合(恢复) | MSR-P 通道 1 恢复信号 |
| 急停按钮 NO | 断开(恢复) | I1.1 = OFF |
| MSR-P 内部 | **仍锁存在急停态** | 手动复位模式 |
| MSR-P K3, K4 | **仍断开** | 动力仍切断 |
| MSR-P 13-14 | 仍闭合(急停锁存时保持) | I1.2 = ON |
| PLC V300.4 | **仍 = 1** | 急停锁存 |
| PLC VW2 | **仍 = 99** | 仍 S_ERROR |
| Q0.7 蜂鸣器 | ON(可按 V0.4 消音) | 由 FC3 管理 |
| Q2.0 报警灯 | ON(常亮) | FC3 管理 |

### 5.4 按 S2 复位按钮(MSR-P 硬件复位)

| 信号 | 状态 | 说明 |
|---|---|---|
| S2 按钮 | 按下 → 释放 | S11-S34 短路 → MSR-P 检测到 |
| MSR-P 内部 | **解除急停锁存** | K3/K4 准备吸合 |
| MSR-P K3, K4 | **吸合** | 动力回路恢复(但 PLC 仍 S_ERROR) |
| KM1/KM2/KM3 | **带电** | 接触器吸合 |
| Q0.0~Q0.6(中间继电器) | **OFF**(FC19 NETWORK 1 强制) | **泵/阀仍不动作** |
| PLC V300.4 | **仍 = 1** | 需 PLC I0.3 复位 |
| PLC VW2 | **仍 = 99** | 需 PLC I0.3 复位 |

**关键安全保护**:即使 MSR-P 硬件复位了,PLC 仍锁在 S_ERROR,Q0.0~Q0.6 仍为 0 → **泵/阀不会突然启动**。

### 5.5 按 I0.3 系统复位按钮

| 信号 | 状态 | 说明 |
|---|---|---|
| I0.3 | 上升沿(按下) | `LDN I1.1` + `A I0.3` + `EU` |
| PLC V300.4 | **= 0** | 急停锁存清除 |
| PLC V1.6, V1.7 | **= 0** | 上下缸状态强制置空 |
| PLC VW2 | **= 0** | 回 S0 |
| PLC VW6 | **= 0** | 报警码清 |
| PLC Q0.7 | OFF | 停蜂鸣器 |
| FC19 NETWORK 1 | QB0 已 = 0 | 继续保持 |
| HMI | 画面回到 S0 主页面 | 等待启动命令 |

**前提条件**(FC19 NETWORK 2-3):
1. ✅ I1.1 = OFF(急停已释放)
2. ✅ V300.5 = 0(无继电器故障)
3. ✅ V300.4 = 1(有急停锁存,才需要复位)

如果 V300.5 = 1(继电器故障),NETWORK 2 JMP 跳过,按 I0.3 **无效** → 必须 HMI 高权限 V0.7 + I1.2 正常 双确认清除 V300.5 后,才能按 I0.3。

### 5.6 完整急停→复位 操作序列

| 步骤 | 操作 | 物理动作 | PLC 状态 | MSR-P 状态 |
|---|---|---|---|---|
| 1 | 急停按下 | NC 断开,NO 闭合 | V300.4=1,VW2=99,Q0.7=ON | K3/K4 断开 |
| 2 | 急停释放 | NC 闭合,NO 断开 | 同上(Q0.0~Q0.6=0) | K3/K4 仍断开(锁存) |
| 3 | 按 S2 按钮 | S11-S34 短路 | 同上 | K3/K4 重新吸合 |
| 4 | 按 I0.3 按钮 | I0.3 上升沿 | V300.4=0,V1.6=0,V1.7=0,VW2=0 | K3/K4 吸合(Q0.0~Q0.6 由 S0 流程决定) |
| 5 | HMI 启动 | CMD_Start(V0.0) | VW2=1(S1 上缸进水) | 正常 |

**总共 2 个复位动作**:S2 硬件复位 + I0.3 系统复位。

## 六、关键安全保护(纵深防御)

### 6.1 第一层:MSR-P 硬件切断动力

- K3/K4 主触点直接切断 KM1/KM2/KM3 接触器线圈
- **PLC 死了也安全**(不依赖软件)
- 通道间短路检测:触点熔焊/卡死时报警

### 6.2 第二层:PLC FC2 急停锁存

- I1.1 上升沿 → V300.4 锁存 + QB0=0 + VW2=99
- **响应 < 1ms**(比 MSR-P 内部 MCU 快 10-30ms)
- 即使 MSR-P 故障,PLC 仍能把 QB0 清零,中间继电器失电,泵/阀不动作

### 6.3 第三层:FC19 S_ERROR 双保险

- FC19 NETWORK 1 每周期 `MOVB 0, QB0`(即使 FC2 没执行,也强制安全)
- 急停锁存期间,所有 DO 输出 = 0

### 6.4 第四层:MSR-P 13-14 反馈自检

- 急停后 2 秒内 I1.2 必须 ON,否则 V300.5 最高级报警
- 检测 MSR-P 主触点粘连

### 6.5 第五层:V300.5 禁止系统复位

- FC19 NETWORK 2:`LD V300.5 JMP 1` → 继电器故障时跳过系统复位
- 必须 HMI V0.7(高权限)+ I1.2 正常 双确认清除

### 6.6 第六层:MSR-P 手动复位(防急停自动恢复)

- 急停释放后,MSR-P 仍锁存,K3/K4 仍断开
- 必须按 S2 才能解锁
- **防止"急停还没撤人就启动"**

### 6.7 第七层:MSR-P S2 与 PLC I0.3 物理隔离

- 两个独立按钮,操作员明确知道"硬件复位"和"软件复位"是两件事
- 防止 1 个双路按钮的"逻辑短路"风险

## 九、验收测试步骤(快速版)

1. **接线核对**:
   - 急停按钮 NC 动端 → MSR-P 通道 + PLC I1.1(短接)
   - 急停按钮 NO 动端 → MSR-P 通道
   - MSR-P 13 → PLC I1.2
   - S2 按钮 → MSR-P S11-S34
   - I0.3 按钮 → PLC I0.3
   - 紧急按钮背景黄色
2. **上电测试**:
   - 正常状态:I1.1=OFF,I1.2=OFF,Q0.7=OFF,Q2.0=OFF
3. **急停功能测试**:
   - 按下急停:1ms 内 V300.4=1,VW2=99,Q0.7=ON,Q2.0=ON(由 FC3 管理)
   - 2s 内 I1.2=ON(V300.5 不触发)
4. **MSR-P 复位测试**:
   - 急停释放 → MSR-P K3/K4 仍断开
   - 按 S2 → MSR-P K3/K4 吸合(可听声音或万用表测)
5. **PLC 复位测试**:
   - 按 I0.3 → VW2=0,V300.4=0,V1.6=0,V1.7=0,Q0.7=OFF
6. **继电器故障模拟**:
   - 断开 MSR-P 13-14,2s 内 V300.5=1,VW6=99
   - 此时按 I0.3 无效(必须 V0.7 确认)
7. **HMI 报警测试**:
   - 报警时画面5指示灯亮,蜂鸣器响
   - 按 V0.3 或 I0.4 消音,声音停,灯保持

## 十、常见错误与规避

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 急停按钮装得太低(< 1.2m)或太高(> 1.8m) | 紧急时够不到 | 1.4-1.6m,容易抓 |
| 急停按钮没有黄色背景 | 违反 ISO 13850 | 必须用黄色面板/底座 |
| 蜂鸣器/警灯直接从 PLC DO 驱动(不经继电器) | 电流过大烧 PLC 输出口 | 必须经中间继电器 KA 隔离 |
| 用 1 个双路 NO 按钮同时复位 MSR-P 和 PLC | 继电器故障时强行上电,安全失效 | 用 2 个独立按钮(S2 + I0.3) |
| MSR-P 配置为"自动复位"模式 | 急停释放后设备自动启动,可能伤人 | 配置为"手动复位"模式 |
| NC 进 PLC,NO 进 MSR-P(反接) | FC2 急停检测失效 | NC 进 MSR-P(短路检测),NO 进 PLC(快速响应) |
| 1 个 NC 触点同时给 MSR-P 和 PLC 但不短接 | 接线错误,触点电流过大 | NC 动端分两路,在端子排短接 |
