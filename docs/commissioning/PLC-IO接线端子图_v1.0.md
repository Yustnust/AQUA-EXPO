## 五、供电与接地

### 5.1 供电回路

```
┌─────────────────────────────────────────────────────────┐
│  AC220V总电源 → 断路器QF1(2P 16A)                       │
│      ├→ 开关电源AC220V/DC24V(10A)                        │
│      │     ├→ PLC本体L+/M(24V DC供电)                    │
│      │     ├→ 传感器电源(DI公共端)                       │
│      │     ├→ 中间继电器线圈电源(KA1~KA9)                │
│      │     └→ HMI供电                                    │
│      ├→ 安全继电器线圈(AQEX-9 急停回路,220V)             │
│      └→ 负载电源(泵/阀/报警器,经接触器/继电器隔离)       │
└─────────────────────────────────────────────────────────┘
```

### 5.2 接地规范

| 接地点 | 接地类型 | 接地电阻 | 说明 |
|---|---|---|---|
| PLC本体PE端子 | 保护接地 | ≤4Ω | 必须接地，导线≥2.5mm²黄绿 |
| 开关电源PE | 保护接地 | ≤4Ω | 与PLC共地 |
| 屏蔽层接地 | 屏蔽接地 | — | 单端接地（PLC侧），避免地环路 |
| 安全继电器PE | 保护接地 | ≤4Ω | 独立接地点 |
| 控制柜PE排 | 等电位接地 | ≤1Ω | 所有PE汇总至PE排 |

### 5.3 电源容量核算

| 负载 | 电流 | 数量 | 小计 |
|---|---|---|---|
| PLC本体 | 0.3A | 1 | 0.3A |
| EM DT16 | 0.05A | 1 | 0.05A |
| EM DR16 | 0.1A | 1 | 0.1A |
| HMI(昆仑通态12寸) | 0.5A | 1 | 0.5A |
| 中间继电器线圈 | 0.04A | 9 | 0.36A |
| 传感器(DI功耗) | 0.01A | 19 | 0.19A |
| **合计** | — | — | **1.5A** |

**结论**：开关电源选10A规格，余量8.5A，满足扩展需求。

## 六、中间继电器接线（有源信号转换）

### 6.1 阀门限位反馈转换（4路，KA10~KA13）

阀门限位反馈为**有源正极输出**（24VDC），不能直接接入PLC DI（PLC DI共享24V回路，会短路）。必须经中间继电器转换：

```
阀门限位反馈(有源24V+)
       │
       ↓
    KA10线圈(24V)
       │
    0V(阀门公共)
       
KA10常开触点:
    一端 → 24V L+
    另端 → PLC I8.0(I8.1/I8.2/I8.3/I8.4同理)
```

| 中间继电器 | 线圈电源 | 触点接入 | 对应DI |
|---|---|---|---|
| KA10 | 阀A限位24V+ | 常开→I8.0 | DI_ValveA_Open |
| KA11 | 阀A限位24V+(关到位另一组) | 常开→I8.1 | DI_ValveA_Close |
| KA12 | 阀B限位24V+ | 常开→I8.2 | DI_ValveB_Open |
| KA13 | 阀B限位24V+(关到位另一组) | 常开→I8.3 | DI_ValveB_Close |
| KA14 | 阀C限位24V+ | 常开→I8.4 | DI_ValveC_Open |
| KA15 | 阀C限位24V+(关到位另一组) | 常开→I8.5 | DI_ValveC_Close |

**选型**：DC24V线圈，触点≥5A，导轨式（如欧姆龙MY2NJ-DC24 + PYF08A底座）。

### 6.2 DO驱动中间继电器（9路，KA1~KA9）

DO晶体管输出驱动中间继电器线圈，继电器触点接通负载电源：

| 中间继电器 | 线圈由DO驱动 | 触点驱动负载 | 触点规格 |

| KA1 | Q0.0 | 潜水泵1接触器KM1线圈(AC220V) | 5A/AC250V |
| KA2 | Q0.1 | 潜水泵2接触器KM2线圈 | 5A/AC250V |
| KA3 | Q0.2 | 电动球阀A接触器 | 5A/AC250V |
| KA4 | Q0.3 | 电动球阀B接触器 | 5A/AC250V |
| KA5 | Q0.4 | 电动球阀C接触器 | 5A/AC250V |

## 七、屏蔽与走线规范

### 7.1 屏蔽线缆要求

| 信号类型 | 线缆类型 | 屏蔽要求 | 屏蔽层接地 |
|---|---|---|---|
| DI/DO信号线 | RVV 0.75mm²多芯 | 一般不需屏蔽 | — |
| Modbus通讯线 | 屏蔽双绞线 | **必须屏蔽** | 单端接地(PLC侧) |
| 模拟量(如有) | 屏蔽双绞线 | **必须屏蔽** | 单端接地 |
| 急停回路 | RVV 1.0mm² | 不需屏蔽 | — |
| 安全继电器反馈 | RVV 0.75mm² | 建议屏蔽 | 单端接地 |

### 7.2 走线规范

1. **强电弱电分离**：AC220V动力线与DC24V控制线分槽敷设，最小间距50mm
2. **Modbus通讯线独立走线**：不与动力线共槽，必须穿金属管或独立线槽
3. **急停回路独立**：急停回路不与其他信号共线，使用独立线管
4. **线缆颜色规范**：
   - DC24V正极：红色
   - DC24V负极：蓝色
   - AC220V相线：红色（带黄色热缩标记）
   - AC220V零线：蓝色（带绿色热缩标记）
   - 保护接地：黄绿双色
   - 急停回路：橙色（专用识别）
5. **端子编号**：所有端子贴号码管，编号规则：PLC地址-顺序号（如I0.0-1）
6. **线缆标识**：每根线缆两端贴标签，标注：源-目的-线号

### 7.3 接线顺序SOP

1. 先接PE保护接地线（最粗，2.5mm²黄绿）
2. 再接AC220V电源进线（带电前必断QF1）
3. 然后接DC24V控制电源（开关电源输出）
4. 最后接DI/DO信号线
5. Modbus通讯线最后接，且必须断电状态下接
6. 急停回路接线后必须用万用表通断测试

### 7.4 接线检查清单（送电前必查）

- [ ] 所有PE端子已可靠接地，接地电阻≤4Ω
- [ ] AC220V/DC24V电源极性正确，无短路
- [ ] 所有DI信号线与端子号对应
- [ ] 所有DO经中间继电器隔离，无直接驱动负载
- [ ] 急停按钮按下时I1.1=OFF（万用表测通断）
- [ ] 安全继电器线圈已接线，反馈触点接I1.2
- [ ] Modbus通讯线屏蔽层单端接地（PLC侧）
- [ ] 所有端子螺丝已紧固（扭矩0.5~0.6 N·m）
- [ ] 线缆号码管/标签齐全清晰
- [ ] 控制柜门接地簧片已安装
