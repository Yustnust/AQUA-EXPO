## 二、批量部署策略

### 2.1 部署策略选择

**推荐方案: 串行部署(逐台验证)**

| 策略 | 描述 | 优势 | 劣势 | 推荐 |
|---|---|---|---|---|
| 串行部署 | 2号→3号→...→8号,每台验证通过再下一台 | 故障隔离好,易定位 | 耗时较长(每台~1.5h) | **推荐** |
| 并行部署 | 2~8号同时下装 | 速度快 | 故障定位难,需多人多PC | 不推荐 |
| 分组部署 | 2人分2组,每组4台 | 平衡速度与隔离 | 中等 | 备选 |

**本SOP按串行部署编写,并行/分组可参考执行。**

### 2.2 单台部署预估时间

| 阶段 | 工作内容 | 预估时间 |
|---|---|---|
| 1. 硬件接线复核 | DI/DO/485/网络接线检查 | 15 min |
| 2. 项目文件准备 | 复制1号项目,改IP,改项目名 | 5 min |
| 3. 程序下装 | 编译→下装(全部块+系统块) | 5 min |
| 4. 上电自检 | RUN灯/通讯/状态图初始值 | 10 min |
| 5. IO打点 | 20DI+9DO+485逐点核对 | 30 min |
| 6. 单元功能验证 | 急停+Modbus+断电恢复抽样 | 20 min |
| 7. 签字移交 | 验证清单填写 | 5 min |
| **单台合计** | | **~90 min** |
| **8台总计** | | **~12小时(2工作日)** |

### 2.3 部署顺序与里程碑

```
Day 1 上午: 2号单元部署 + 验证
Day 1 下午: 3号单元部署 + 验证
Day 2 上午: 4号+5号单元部署
Day 2 下午: 6号+7号单元部署
Day 3 上午: 8号单元部署 + 全网联调
Day 3 下午: 8单元联调验证(总览页/通讯/报警联动)
```


#### 3.3.2 下装操作

```
1. PC直连PLC以太网口(临时IP设为192.168.2.200,与目标PLC同网段)
2. PLC上电(此时PLC无程序,STOP灯慢闪)
3. STEP7: PLC → 查找CPU → 应自动发现192.168.2.10N
4. 文件 → 下载
   - 勾选: 程序块(全部)
   - 勾选: 系统块(含IP配置+断电保持)
   - 勾选: 数据块(如有)
5. 点击"下载" → 确认PLC模式切换 → 等待下载完成(约30秒)
6. PLC自动重启 → RUN灯常亮
```

## 五、常见部署问题与排查

### 5.1 IP冲突

**现象**: 第二台PLC下装后,HMI/PC连接混乱
**原因**: 忘记修改IP,两台PLC都是192.168.2.101
**排查**:
- STEP7: PLC→查找CPU,应只发现1个192.168.2.10N
- 临时拔掉其他PLC网线,逐台确认
**修复**: 重新下装系统块,确保IP正确

### 5.2 程序下装失败

**现象**: 下装报错"无法连接CPU"
**排查**:
| 检查项 | 期望 | 处理 |
|---|---|---|
| PC IP同网段 | 192.168.2.200 | 修改PC网卡IP |
| PLC上电 | RUN/STOP灯亮 | 检查24V供电 |
| 网线连通 | ping通 | 换网线/换交换机口 |
| 防火墙 | 关闭 | Windows防火墙关 |
| STEP7版本 | V2.5+ | 升级STEP7 |

### 5.3 RS485通讯不通

**现象**: VW4/VW86不更新,V303.4置位
**排查**:
| 检查项 | 期望 | 处理 |
|---|---|---|
| 接线2/3/5脚 | DB9正确 | 重新焊DB9 |
| 从站地址 | 泵=1, 流量计=2 | 检查设备配置 |
| 波特率 | 9600 | 与设备一致 |
| 终端电阻 | 总线两端120Ω | 加装 |
| 屏蔽接地 | PLC侧单端接地 | 重新接地 |

### 5.4 断电保持失效

**现象**: PLC断电后VW2/VW6归零
**原因**: 系统块断电保持范围未下装,或下装后未断电重启
**修复**:
1. 重新打开项目,确认系统块→断电保持7段V区+3段M区已配
2. 重新下装(勾选系统块)
3. PLC断电→上电,重做断电保持配置清单4.2节验证

### 5.5 HMI连接不上PLC

**现象**: HMI某连接红色"通讯中断"
**排查**:
| 检查项 | 期望 | 处理 |
|---|---|---|
| PLC IP正确 | 192.168.2.10N | 重新下装系统块 |
| PLC运行 | RUN灯亮 | 上电/清错 |
| HMI配置 | IP+协议+TSAP正确 | 见MCGS通讯配置SOP |
| 防火墙 | 关闭 | — |
| 物理连接 | HMI↔交换机↔PLC | 换线/换口 |
