**用途**: 网络与采购工程师及现场调试工程师的网络方案、IP编址、设备选型、调试与故障排查依据；与《HMI-PLC变量地址表_v1.0》第十二章、PLC设计文档v9.3第十二章配套使用

## 一、IP编址总则

### 1.1 编址原则

1. **网段统一**：8台PLC与1台HMI统一规划于 `192.168.2.0/24` 同一网段，避免跨网段路由，降低故障面。
2. **PLC地址与单元编号一一对应**：PLC#N 的 IP 末位为 `100+N`（即1号=101、8号=108），便于故障定位与运维记忆。
3. **HMI地址紧邻PLC段头**：HMI IP `192.168.2.100`，与PLC段 101~108 物理相邻、视觉清晰。
4. **预留地址段**：网段内 192.168.2.1（网关/管理IP）、.2~.9（网络设备）、.10~.99（调试与上位机预留）、.109~.254（扩展预留）。
5. **子网掩码统一**：C类 `255.255.255.0`，无网关需求场景下网关可填 `192.168.2.1` 但不强制启用。

### 1.2 与历史文档的差异说明

> PLC设计文档v9.3第12.2节与变量地址表v12.1节中HMI示例IP为 `192.168.2.10`。本规划根据现场调试便利性调整为 `192.168.2.100`（紧邻PLC段），并相应将预留段 .10~.99 用于调试/上位机。两版差异仅在HMI末位（10→100），PLC地址段不变。如现场已按 `.10` 实施，可在交换机/HMI侧同步切换，不影响PLC侧配置。

## 五、VLAN与隔离规划

### 5.1 VLAN划分方案

| VLAN ID | 用途 | 包含端口 | IP段 | 说明 |
|---|---|---|---|---|
| VLAN10 | 运行网 | Port1（HMI）、Port2~9（PLC#1~8）、Port11（上位机预留） | 192.168.2.100~108, .201 | 主业务网络，承载S7/Modbus TCP通讯 |
| VLAN20 | 调试网 | Port10（调试口） | 192.168.2.200（DHCP可选） | 调试笔记本接入，默认与运行网隔离 |
| VLAN1（默认） | 管理网 | 交换机管理口 | 192.168.2.2 | 仅交换机管理访问，逻辑隔离 |

### 5.2 隔离策略

| 隔离对象 | 隔离方式 | 实施方法 |
|---|---|---|
| 调试网 ↔ 运行网 | VLAN隔离 | 调试口默认VLAN20，调试时若需访问运行网PLC，按需临时切至VLAN10或建立VLAN间路由（管理型交换机支持） |
| 运行网 ↔ 办公网 | 物理隔离 | 不接入厂区办公网；远程维护通过VPN网关在上位机预留口接入（Port11） |
| 交换机管理 ↔ 业务 | 802.1Q + ACL | 管理IP仅允许指定维护终端访问，业务端口不响应管理报文 |

### 5.3 是否需VLAN的决策建议

| 场景 | 是否需要VLAN | 理由 |
|---|---|---|
| 首期1套单元、调试与运行可共用 | 否 | 9口非网管型交换机即可，无VLAN能力 |
| 全量8套运行+调试频繁 | **是** | 调试操作（如下装程序、强制变量）不应干扰运行单元通讯；VLAN隔离降低误操作风险 |
| 接入厂区SCADA/远程维护 | **是** | 必须VLAN或防火墙隔离，防止办公网攻击面蔓延至PLC |
| 监管合规要求（如GMP/审计） | **是** | 需独立调试日志记录与访问控制 |

**结论建议**：全量8套阶段必须采用管理型交换机+VLAN隔离；首期1套可用非网管型过渡。

## 六、S7协议 vs Modbus TCP方案对比与切换策略

### 6.1 协议方案对比

| 对比项 | S7协议（推荐） | Modbus TCP（备选） |
|---|---|---|
| 原生支持 | S7-200 SMART CPU本体以太网口原生支持 | S7-200 SMART需调用MBUS_SERVER指令实现TCP服务器 |
| HMI驱动要求 | HMI需具备S7-200 SMART驱动（昆仑通态/威纶通/西门子原生支持） | 所有主流HMI均支持，通用性最好 |
| PLC侧工作量 | 无需额外编程，STEP 7-Micro/WIN SMART中配置PG/PC接口即可 | 需在PLC程序中调用MBUS_SERVER指令，配置V区→Modbus寄存器映射表，约1天开发量 |
| 通讯效率 | 高（西门子优化协议，ISO-on-TCP，102端口） | 中（Modbus TCP 502端口，请求-响应模式） |
| 变量访问方式 | 直接读写V区/M区/I/Q/DB，按符号或地址访问 | 仅映射至保持寄存器4xxxxx，BOOL需映射至线圈或位操作 |
| 数据类型支持 | BOOL/INT/REAL/DWORD等全类型，原生REAL | 寄存器16位，REAL需双寄存器拼装，BOOL打包处理 |
| 8连接数限制 | 受HMI驱动授权限制，昆仑通态需向厂商确认（变量地址表14.2节待确认事项第7项） | 通常无连接数硬限制，HMI作客户端可并发轮询8台 |
| 诊断手段 | STEP 7-Micro/WIN SMART在线连接状态、HMI驱动层连接状态 | Modbus Poll工具、Wireshark抓包，异常码易定位 |
| 长期维护 | 与西门子生态深度集成，维护资料丰富 | 通用协议，第三方维护方便，但映射表需同步维护 |

### 6.2 8连接数限制分析

S7-200 SMART CPU ST20本体以太网口**最多支持8个以太网连接**（含PG/HMI/OP/Open IE等），具体分配：

| 连接类型 | 默认数量 | 说明 |
|---|---|---|
| PG（编程器） | 1 | STEP 7-Micro/WIN SMART在线调试占用 |
| HMI/OP | 4~8（取决于CPU固件版本，ST20典型为8） | HMI连接占用，8台HMI连接需CPU固件V2.5以上支持 |
| Open IE（PUT/GET/Modbus TCP） | 8（与HMI共享总数） | 启用Modbus TCP Server时占用此额度 |

**关键限制点**：
- **每台PLC只与1台HMI建立1条连接**（HMI侧共建立8条连接至8台PLC，每台PLC侧仅占1个HMI连接资源），PLC侧连接数无瓶颈。
- **真正的瓶颈在HMI侧**：昆仑通态MCGS嵌入式组态软件的S7驱动是否支持同时建立8个站点连接，需向厂商确认（《HMI选型技术问询单》Q1已问询，待回复）。
- 若HMI侧S7驱动仅支持4连接，则必须启用Modbus TCP方案。

### 6.3 协议切换策略

```
[决策流程]

Step 1: HMI选型确认（依据HMI选型技术问询单厂商回复）
   ├─ Q1回复"支持8连接S7" → 采用S7协议（首选）
   └─ Q1回复"不支持8连接S7" → 进入Step 2

Step 2: 评估Modbus TCP方案
   ├─ PLC侧启用MBUS_SERVER，将V区映射至Modbus保持寄存器
   ├─ HMI侧改用Modbus TCP客户端驱动，连接8台PLC的502端口
   └─ 配置变量地址表第十一章Modbus映射表 → PLC程序

Step 3: 混合方案（备选）
   ├─ HMI对1~4号PLC用S7协议，5~8号PLC用Modbus TCP
   └─ 不推荐，维护复杂度高

[切换实施步骤（从S7切至Modbus TCP）]
1. PLC侧程序：在OB1调用MBUS_SERVER指令，绑定Port0/某V区缓冲
2. PLC侧配置：系统块→Modbus TCP端口502，Max Hold/Max AI参数按变量表11章核算
3. HMI侧：组态软件中删除S7驱动，新增Modbus TCP客户端，建立8个设备连接
4. HMI侧：变量绑定由V区地址改写为Modbus寄存器4xxxxx地址（按11章映射表）
5. 调试：见第七章网络调试步骤
```

### 6.4 推荐方案

**首选S7协议**：昆仑通态MCGS TPC1211-T12CE经问询确认支持8连接后采用，理由：
- PLC侧零额外编程，开发周期短
- REAL数据类型原生支持，无需拼装
- 与西门子生态兼容性最佳

**备选Modbus TCP**：若昆仑通态S7驱动8连接能力不满足，PLC侧启用MBUS_SERVER，按变量地址表第十一章映射表配置（V区→4xxxxx）。

## 八、网络故障排查指引

### 8.1 常见故障速查表

| 现象 | 可能原因 | 排查命令/方法 | 解决措施 |
|---|---|---|---|
| 单台PLC ping不通 | 网线压接不良/网线断/PLC IP未配置/端口DOWN | `ping IP`；查PLC系统块IP；查交换机端口灯 | 重新压接RJ45；配置PLC IP；更换交换机端口 |
| 全部PLC ping不通 | 交换机故障/调试机IP段错误/交换机断电 | `ping 192.168.2.2`（交换机管理IP）；`ipconfig`查调试机IP | 检查交换机供电；修正调试机IP至192.168.2.x段 |
| HMI ping通但S7连不上 | HMI驱动未配置/PG/PC接口占用/PLC连接数满 | STEP 7在线测试；查HMI驱动日志 | 关闭STEP 7释放PG连接；检查PLC连接数 |
| HMI某单元"通讯中断" | 该PLC掉线/网线松动/IP冲突 | `ping 192.168.2.10X`；`arp -a`查MAC冲突 | 修复该PLC网络；解决IP冲突 |
| HMI显示某单元数据不动 | S7连接假死/PLC扫描周期阻塞 | STEP 7在线查看PLC RUN灯/STOP状态 | 重启PLC；检查程序死循环 |
| 丢包率高 | 网线质量差/干扰/交换机背板带宽不足 | `ping -t IP`；查网线与强电距离 | 换STP屏蔽线；远离变频器/强电 |
| 延迟>100ms | 广播风暴/环路/交换机过载 | Wireshark抓包看广播包比例 | 启用风暴抑制；查STP环路 |
| Modbus TCP返回异常码02 | 寄存器地址超出MBUS_SERVER映射范围 | 核对变量地址表第十一章映射表 | 调整HoldStart/Max Hold参数 |
| Modbus TCP连接被拒 | PLC连接数满/502端口未开放 | `telnet 192.168.2.101 502` | 减少并发连接数；检查MBUS_SERVER调用 |
| 偶发性通讯中断（夜间） | 网络设备重启/UPS切换/温度异常 | 查HMI连接日志时间分布 | 加UPS稳压；查机柜温度 |

### 8.2 常用排查命令

```bash
# 1. 连通性测试（Windows调试机）
ping 192.168.2.101              # 单次4包
ping -t 192.168.2.101           # 持续ping，Ctrl+C停止
ping -l 1472 -f 192.168.2.101   # MTU不分片测试

# 2. ARP表查看（IP冲突排查）
arp -a                          # 查看IP-MAC对应表，发现同一IP对应多个MAC即冲突

# 3. 端口连通性（Modbus TCP 502端口）
telnet 192.168.2.101 502        # 连接成功=端口开放

# 4. 路由表
route print                     # 查看本机路由，确认无错误默认路由

# 5. 网卡状态
ipconfig /all                   # 查看IP/掩码/网关/MAC

# 6. Linux调试机抓包
sudo tcpdump -i eth0 host 192.168.2.101 and port 502 -nn

# 7. Wireshark过滤器（S7协议）
s7comm                          # S7协议过滤
tcp.port == 102                 # S7 ISO-on-TCP端口
tcp.port == 502                 # Modbus TCP端口
modbus                          # Modbus协议过滤
```

### 8.3 故障排查流程

```
现象：HMI显示某单元通讯中断
  │
  ├─ Step1: 调试机ping该PLC IP
  │    ├─ ping通 → 网络OK，转Step2
  │    └─ ping不通 → 检查网线/交换机端口/PLC IP/供电
  │
  ├─ Step2: STEP 7在线连接该PLC
  │    ├─ 在线成功 → PLC正常，转Step3
  │    └─ 在线失败 → PLC停机/连接数满，检查RUN灯/连接资源
  │
  ├─ Step3: HMI工程检查该单元驱动配置
  │    ├─ 配置正确 → 转Step4
  │    └─ 配置错误 → 修正IP/单元使能
  │
  └─ Step4: Wireshark抓包分析
       ├─ HMI有请求、PLC有响应 → 检查HMI变量绑定
       └─ HMI无请求 → 检查HMI驱动层/单元使能变量
```

## 九、网络安全建议

### 9.1 PLC侧安全配置

| # | 安全项 | 配置方法 | 优先级 |
|---|---|---|---|
| 1 | **修改PLC默认密码** | STEP 7-Micro/WIN SMART→系统块→保护→访问权限，设置Level 4密码（非空、非弱口令），密码长度≥8位含数字字母 | **高（必须）** |
| 2 | **关闭PLC Web服务器** | 系统块→Web服务器→取消勾选"启用Web服务器"（S7-200 SMART部分固件支持Web，默认关闭） | **高（必须）** |
| 3 | **禁用PUT/GET（如不使用）** | 系统块→通信→"允许PUT/GET通信访问"按需勾选；S7协议HMI连接不需要PUT/GET，应禁用 | 高 |
| 4 | **限制Modbus TCP连接数** | MBUS_SERVER指令Max Hold/连接数参数按需配置，不超出实际需求 | 中 |
| 5 | **关闭不必要的TCP服务** | 系统块中仅保留PG/PC接口和HMI接口，禁用Open IE多余服务 | 中 |
| 6 | **配置PLC固件为最新稳定版** | 检查西门子官网是否有ST20固件升级包，按需升级 | 中 |

### 9.2 HMI侧安全配置

| # | 安全项 | 配置方法 | 优先级 |
|---|---|---|---|
| 1 | **HMI开机密码** | MCGS组态→用户管理→设置3级权限（操作员/维护/管理员），见HMI用户权限矩阵v1.0 | **高（必须）** |
| 2 | **HMI默认密码修改** | 出厂默认密码（如888888/admin）必须修改为强密码 | **高（必须）** |
| 3 | **HMI禁用USB自动运行** | 防止U盘病毒，仅允许管理员授权U盘导出数据 | 高 |
| 4 | **HMI关闭远程桌面/TELNET** | MCGS Windows CE环境如开放远程桌面，须关闭或限制IP | 中 |
| 5 | **HMI审计日志开启** | 启用操作审计日志，记录L2/L3权限所有操作（见HMI数据量估算2.3节） | 中 |

### 9.3 网络层安全

| # | 安全项 | 配置方法 | 优先级 |
|---|---|---|---|
| 1 | **交换机端口绑定MAC** | 管理型交换机→端口安全→绑定PLC/HMI MAC，防止未授权设备接入 | 高 |
| 2 | **VLAN隔离调试与运行** | 调试口默认VLAN20，按需切换；运行网VLAN10不暴露调试入口 | 高 |

| 4 | **不接入办公网/互联网** | 运行网物理隔离，远程维护通过上位机预留口VPN接入 | **高（必须）** |
| 5 | **风暴抑制** | 交换机端口启用广播/组播/未知单播风暴抑制（建议阈值5%） | 中 |
| 6 | **SNMP只读社区字符串修改** | 若启用SNMP监控，修改默认public为强字符串，禁用SNMPv1 | 中 |
