### 1.3 符号表自动生成

**方法**：用变量地址表生成的CSV模板直接导入STEP7符号表。

CSV格式：

```
符号,地址,数据类型,注释
DI_FlowSwitch_A,I0.0,BOOL,流量开关A-阀A进水
DI_FlowSwitch_B,I0.1,BOOL,流量开关B-上下转移
...
```

变量总数：73个（19DI + 9DO + 8命令位 + 8状态位 + 6VW + 24VD + 其他）

### 2.2 数字量输入滤波

| DI组        | 滤波时间   | 原因                 |
| ---------- | ------ | ------------------ |
| I0.0\~I0.7 | 6.4ms  | 流量开关/液位计有抖动,需滤波    |
| I1.0\~I8.0 | 12.8ms | 急停/安全继电器/阀门反馈,需更稳定 |
| I8.5\~I2.7 | 6.4ms  | 按钮/预留              |

### 2.3 脉冲捕获

- 所有DI：**禁用**（本设计无高速计数需求）

### 2.4 数字量输出

- 脉冲输出：**禁用**（无PTO/PWM需求）

- STOP模式下输出状态：**全部OFF**（失效安全）

### 2.5 模拟量输入（如有）

- 本设计无AI模块，跳过

### 2.6 日期时间

- 启用RTC（实时时钟）：**是**

- RTC电池：CPU本体内置超级电容，断电保持≥7天

### 2.7 安全

- 启用密码保护：**是**（L3管理员权限）

- 密码等级：等级4（完全控制，含上传/下载）

- 上传需密码：**是**

### 2.8 启动模式

- 启动模式：**暖启动**（RUN模式启动）

- 模块错误时动作：**STOP**（安全第一）

## 三、断电保持区配置（关键）

打开方式：系统块→断电保持

### 3.1 V区断电保持范围

**重要**：以下V区范围必须配置为断电保持，否则断电后数据丢失。

| 起始地址      | 结束地址      | 字节数    | 用途                                                              | 关联Story            |
| --------- | --------- | ------ | --------------------------------------------------------------- | ------------------ |
| VB0       | VB9       | 10     | 命令位+状态位(V0/V1区)                                                 | AQEX-7             |
| VB10      | VB19      | 10     | 时间戳DT10\~DT17                                                   | AQEX-7             |
| VB200     | VB223     | 24     | Modbus映射区(VW200\~VW222)                                         | AQEX-5             |
| VB230     | VB289     | 60     | 阀门诊断子状态/结果/PT(VW230\~VW288)                                     | AQEX-7             |
| VB300     | VB349     | 50     | 报警字(VB300~~303)+诊断数据(VD308~~344)                                | AQEX-7             |
| **VB350** | **VB377** | **28** | **VD350\~374迁移参数(StepResolution/CycleSetpoint/Timeout/流量计降级值)** | **AQEX-36/AQEX-5** |
| VB500     | VB599     | 100    | 报警日志缓冲区                                                         | AQEX-6             |

**注意 — 地址冲突规避**：

- **VB250\~VB253** 已被 HMI 参数 **VD250**（目标进水量）占用，禁止挪作他用。

- FC4 的 Modbus 轮询计数器已迁移至 **VB290\~VB297**：

  - VW290：轮询计数器

  - VW292：当前任务重试计数

  - VW294：注射泵连续失败计数

  - VW296：流量计连续失败计数

- 上述 VB290\~VB297 由 FC0 在首次扫描时初始化，无需断电保持。

### 3.2 配置操作

1. 系统块→断电保持
2. 在"断电保持"对话框中，逐个添加上述范围
3. 总计断电保持V区：**188字节**
4. ST20可用断电保持V区：**默认10KB**（足够）

### 3.3 配置验证

下载项目后，断电PLC再上电，检查：

- [ ] V0.0\~V0.7命令位保持

- [ ] V1.0\~V1.7状态位保持

- [ ] VW2状态机保持

- [ ] VW6报警码保持

- [ ] VD10\~VD140参数保持

- [ ] VD350\~VD374迁移参数保持(关键!,含流量计降级值VD374)

- [ ] VB300\~303报警字保持

- [ ] DT10\~DT17时间戳保持

### 3.4 M区位保持（可选）

| 起始    | 结束    | 用途          |
| ----- | ----- | ----------- |
| M0.0  | M0.7  | 急停锁存标志      |
| M10.0 | M10.7 | 状态机首次进入脉冲标志 |
| M11.0 | M11.7 | 边沿检测上一周期状态  |

**注**：M区位保持非必须（每次上电重新计算），但建议保持以避免抖动。

### 3.5 T/C位保持

- 定时器T：**不保持**（每次上电重新计时）

- 计数器C：按需保持（VW8实验轮次计数用VW8保持，不用C）

## 五、Modbus参数现场整定SOP

### 5.1 整定前准备

1. **接线检查**：

   - [ ] Modbus RTU通讯线屏蔽层单端接地（PLC侧）

   - [ ] DB9接头3/5/8脚焊接正确（Pin3→A+，Pin8→B-，Pin5→GND，见4.2.1节）

   - [ ] 终端电阻120Ω已安装在总线两端（首末设备）

2. **设备上电**：

   - [ ] PLC上电，RUN灯常亮

   - [ ] 注射泵控制器上电

   - [ ] 流量计上电

3. **设备地址确认**：

   - [ ] 注射泵Modbus地址=1（按设备厂商手册配置）

   - [ ] 流量计Modbus地址=2

   - [ ] 总线无地址冲突

### 5.2 整定流程

#### 阶段1：单设备测试

**目标**：用Modbus Poll软件单独测试每个从站。

1. 断开其他设备，仅PLC+1个从站
2. 用Modbus Poll软件（PC直连PLC串口或USB转串口）：

   - 设置串口：9600/8/N/1

   - 设置从站地址：1（注射泵）

   - 读取40001（状态码，应返回0=空闲）
3. 若超时/错误：

   - 检查接线（2/3是否接反）

   - 检查波特率（9600是否与设备一致）

   - 检查校验位（无/偶/奇）

   - 检查从站地址
4. 重复测试从站2（流量计）

#### 阶段2：双设备总线测试

1. PLC+注射泵+流量计同时挂在Modbus总线
2. 用Modbus Poll分别测试2个从站
3. 若某个从站失败：

   - 检查终端电阻（120Ω）

   - 检查总线长度（≤1200m）

   - 检查分支长度（≤1m）

#### 阶段3：PLC轮询测试

1. PLC下载程序（含FC4）
2. 监控VW4（注射泵状态码）：应周期性更新
3. 监控VD86（流量计累计值）：应周期性更新
4. 监控VW204\~VW212（注射泵步数/速度）：应周期性更新
5. 用STEP7状态图监控VW250（轮询计数器0\~3循环）
6. 用STEP7状态图监控M10.0\~M10.3（Done位周期性变化）

#### 阶段4：故障注入测试

**测试1：注射泵断电**

1. 断开注射泵电源
2. 等待30秒（10秒超时×3次重试）
3. 观察：

   - V303.4置位（注射泵故障报警）

   - M10.4置位（连续5次失败后降级模式）

   - VW4保持上一有效值
4. 恢复注射泵电源
5. 观察：

   - V303.4复位（通讯恢复）

   - M10.4复位（退出降级模式）

   - VW4恢复实时更新

**测试2：流量计断电**

1. 断开流量计电源
2. 等待30秒
   ~~3. 观察：V303.6置位~~ **2026-09-08已删除**
   ~~4. 恢复：V303.6复位~~ **2026-09-08已删除**

**测试3：通讯线干扰**

1. 在Modbus线附近放置运行中的变频器
2. 观察VB379/VB384错误码是否增加
3. 若频繁超时：

   - 增加FC4超时时间（T50/T51从100→200，即20秒）

   - 加强屏蔽（双层屏蔽线）

   - 重新走线（远离动力线）

### C.1 最终稳定的 FC4 程序结构（STEP7 手动 LAD 绘制）

FC4 直接在 STEP7 中用 LAD 手动搭建。原因：STEP7 导入 STL 会合并 NETWORK、丢失代码、篡改 LBL 编号；且 LAD 中 MBUS\_MSG 的 Addr/Count/DataPtr 必须是常量，无法像 STL 那样用变量动态切换。

**NETWORK 1**：MBUS\_CTRL（初始化，9600/8/N/1，Timeout=1000ms）

```
LD SM0.0
CALL MBUS_CTRL, SM0.0, 9600, 16#00, 16#00, 1000, M11.0, VB378
```

**NETWORK 2\~4**：T101 2秒脉冲发生器（TON + 自复位）

```
LD  SM0.0
TON T101, 20          // PT=20 × 100ms = 2s

LD  T101
=   M14.6             // 脉冲输出（1个扫描周期）
R   T101, 1           // 自复位
```

**NETWORK 5**：参数选择（根据 VW290 任务号动态写入 VB400\~VW406）

- VW290=0 → VB400=1, VD402=16#A029（41001 注射泵状态）, VW406=1

- VW290=1 → VB400=2, VD402=16#9C49（40009 流量计流量）, VW406=2

**NETWORK 6**：MBUS\_MSG（单块，First 接 M14.6，动态参数来自 VB400\~VW406）

```
CALL MBUS_MSG, M14.6, 16#01, VB400, VD402, VW406, &VB410, M10.0, VB379
```

- First 接 M14.6（T101 的 1 扫描周期脉冲，自动实现"每 2 秒触发一次"）

- 从站地址、寄存器地址、数量全部来自 VB400\~VW406 变量（LAD 中用 MOV 赋值）

- **不再使用多个 MBUS\_MSG 调用**，彻底避免库状态机竞争

**NETWORK 8~~10 / 11~~13 / 15\~17**：任务完成/失败处理

- 任务0成功：R M10.0 → MOVW VW410, VW4 → INC VW500 → MOVW 1, VW290

- 任务0失败：INC VW292 → R M10.0

- 任务1成功：R M14.0 → MOVD VD410, VD86 → INC VW502 → MOVW 2, VW290

- 任务1失败：INC VW294 → R M14.0

- 任务2成功：R M10.1 → MOVW VW410, VW222 → INC VW504 → MOVW 0, VW290

- 任务2失败：INC VW296 → R M10.1

- 注射泵成功：MOVW VB410, VW4；SWAP VW4（16 位字交换）

- 流量计成功：MOVD VB410, VD86（32 位直接搬运，MBUS\_MSG 已处理字节顺序）

**任务切换已合并到各任务成功处理网络末尾**

**FC0 首次扫描配合**（冷启动路径内）：

```
FILL 0, VW600, 143    // VB600~VB885 清零（Modbus 库存储区）
MOVB 0, VB378         // 清 MBUS_CTRL Error
MOVB 0, VB379         // 清 MBUS_MSG Error
R M10.0, 6            // 清 M10.0~M10.5（Done 位）
R M11.0, 1            // 清 MBUS_CTRL Done 位
```

### C.4 最终确定的编程原则（避免下次重踩）

1. **STEP7 不要导入 STL**：FC4/FC99 等复杂 FC 直接用 LAD 手动绘制。STL 导入会合并 NETWORK、丢失代码、篡改 LBL。
2. **单 MBUS\_MSG 块，参数动态选择**：避免多块库状态机竞争。
3. **First 脉冲必须是 1 扫描周期**：TON+自复位的 M14.6 天然满足，不要加 P/EU 触点。
4. **Done 必须手动清零**：R M10.0, 1 在每次使用前执行，不要依赖自动复位。
5. **库存储区首次扫描必须清零**：FILL 0, VW600, 143。V 区断电不丢，残留状态机是 Error=6 的头号元凶。
6. **Error 引脚必须接 VB 字节**，Count 必须是整数常量，Addr 必须用 16# 十六进制。
7. **定时器使用前必须检查其他 FC 是否占用**：STEP7 没有全局搜索定时器用法的快捷方式，需要逐个 FC 打开看。
8. **32 位浮点数据不要手动 SWAP**：MBUS\_MSG 已自动处理 16 位字顺序；如果读取数据明显是字节反序，检查从站是否返回大端/小端。
9. **STL 指令限制**：不支持 L# 前缀、LDN 不能用于字类型、JMP/LBL 只能数字 0\~255、RTC 用 TODR 不用 READ\_RTC（LAD 才用 READ\_RTC）。
10. **Modbus RTU 总线上只能有一个 Master**：PLC 与调试工具（Modbus Poll）不能同时在线。
11. **V303.6 流量开关瞬时异常报警已删除**（2026-09-08）：三个流量开关各自有独立报警位 V301.0\~V303.1，抖动检测逻辑（2 秒窗口≥5 次翻转）误报严重且无法根治。
12. **FC0 冷启动路径和断电恢复路径都要做必要初始化**：Modbus 库存储区清零不区分冷启动/断电恢复，STOP→RUN 后库状态机必须复位。
