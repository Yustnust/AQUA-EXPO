## 一、STEP7项目创建清单

### 1.1 软件版本

- STEP 7-Micro/WIN SMART V2.5 或更高
-操作系统：Windows 7/10 64位

### 1.2 项目创建步骤

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1 | 文件→新建 | 项目名：AQUA_EXPO_Unit_X（X=1~8） |
| 2 | PLC类型→CPU ST20 | 6ES7-288-1ST20-0AA0 |
| 3 | 添加扩展模块EM DT16 | 槽位1，6ES7-288-2DE08-0AA0 |
| 4 | 添加扩展模块EM DR16 | 槽位2，6ES7-288-2DR16-0AA0 |

| 7 | 配置通讯端口 | 见第四节 |
| 8 | 创建符号表 | 导入变量地址表生成的CSV |
| 9 | 创建FC/OB | 逐个新建并粘贴STL代码（21个FC+OB1） |

### 1.3 符号表自动生成

**方法**：用变量地址表生成的CSV模板直接导入STEP7符号表。

CSV格式：
```

DI_FlowSwitch_A,I0.0,BOOL,流量开关A-阀A进水
DI_FlowSwitch_B,I0.1,BOOL,流量开关B-上下转移
...
```

变量总数：73个（19DI + 9DO + 8命令位 + 8状态位 + 6VW + 24VD + 其他）

## 二、系统块配置

打开方式：项目树→CPU ST20→系统块

### 2.1 通讯端口

| 端口 | 协议 | 参数 | 说明 |
|---|---|---|---|
| 以太网口 | TCP/IP | IP: 192.168.2.10X / 掩码: 255.255.255.0 / 网关: 192.168.2.1 | X=1~8,8套PLC独立IP |
| 串口(P0) | Modbus RTU | 9600/8/N/1 | 用于MBUS_CTRL(主站) |

### 2.2 数字量输入滤波

| DI组 | 滤波时间 | 原因 |
|---|---|---|
| I0.0~I0.7 | 6.4ms | 流量开关/液位计有抖动,需滤波 |
| I1.0~I1.3 | 12.8ms | 急停/安全继电器/阀门反馈,需更稳定 |
| I2.0~I2.7 | 6.4ms | 按钮/预留 |

### 2.3 脉冲捕获

- 所有DI：**禁用**（本设计无高速计数需求）

### 2.4 数字量输出

- 脉冲输出：**禁用**（无PTO/PWM需求）
- STOP模式下输出状态：**全部OFF**（失效安全）

### 2.5 模拟量输入（如有）

- 本设计无AI模块，跳过

### 2.6 日期时间

- 启用RTC（实时时钟）：**是**
- RTC电池：CPU本体内置超级电容，断电保持≥7天

### 2.7 安全

- 启用密码保护：**是**（L3管理员权限）
- 密码等级：等级4（完全控制，含上传/下载）
- 上传需密码：**是**

### 2.8 启动模式

- 启动模式：**暖启动**（RUN模式启动）
- 模块错误时动作：**STOP**（安全第一）

## 三、断电保持区配置（关键）

打开方式：系统块→断电保持

### 3.1 V区断电保持范围

**重要**：以下V区范围必须配置为断电保持，否则断电后数据丢失。

| 起始地址 | 结束地址 | 字节数 | 用途 | 关联Story |
|---|---|---|---|---|
| VB0 | VB9 | 10 | 命令位+状态位(V0/V1区) | AQEX-7 |
| VB10 | VB19 | 10 | 时间戳DT10~DT17 | AQEX-7 |
| VB200 | VB223 | 24 | Modbus映射区(VW200~VW222) | AQEX-5 |
| VB230 | VB289 | 60 | 阀门诊断子状态/结果/PT(VW230~VW288) | AQEX-7 |
| VB300 | VB349 | 50 | 报警字(VB300~303)+诊断数据(VD308~344) | AQEX-7 |
| **VB350** | **VB377** | **28** | **VD350~374迁移参数(StepResolution/CycleSetpoint/Timeout/流量计降级值)** | **AQEX-36/AQEX-5** |
| VB500 | VB599 | 100 | 报警日志缓冲区 | AQEX-6 |

**注意 — 地址冲突规避**：
- **VB250~VB253** 已被 HMI 参数 **VD250**（目标进水量）占用，禁止挪作他用。
- FC4 的 Modbus 轮询计数器已迁移至 **VB290~VB297**：
  - VW290：轮询计数器
  - VW292：当前任务重试计数
  - VW294：注射泵连续失败计数
  - VW296：流量计连续失败计数
- 上述 VB290~VB297 由 FC0 在首次扫描时初始化，无需断电保持。

### 3.2 配置操作

1. 系统块→断电保持
2. 在"断电保持"对话框中，逐个添加上述范围
3. 总计断电保持V区：**188字节**
4. ST20可用断电保持V区：**默认10KB**（足够）

### 3.3 配置验证

下载项目后，断电PLC再上电，检查：
- [ ] V0.0~V0.7命令位保持
- [ ] V1.0~V1.7状态位保持
- [ ] VW2状态机保持
- [ ] VW6报警码保持
- [ ] VD10~VD140参数保持
- [ ] VD350~VD374迁移参数保持(关键!,含流量计降级值VD374)
- [ ] VB300~303报警字保持
- [ ] DT10~DT17时间戳保持

### 3.4 M区位保持（可选）

| 起始 | 结束 | 用途 |
|---|---|---|
| M0.0 | M0.7 | 急停锁存标志 |
| M10.0 | M10.7 | 状态机首次进入脉冲标志 |
| M11.0 | M11.7 | 边沿检测上一周期状态 |

**注**：M区位保持非必须（每次上电重新计算），但建议保持以避免抖动。

### 3.5 T/C位保持

- 定时器T：**不保持**（每次上电重新计时）
- 计数器C：按需保持（VW8实验轮次计数用VW8保持，不用C）

#### 4.2.1 DB9接线定义（CPU ST20 Port 0）

| DB9针脚 | 信号 | PLC侧定义 | 说明 |
|---|---|---|---|
| Pin 3 | RS485 B | RS485信号B（部分厂商标为B-/B） | — |

- PLC DB9 Pin 3 → 积算仪 A+
- PLC DB9 Pin 8 → 积算仪 B-
- PLC DB9 Pin 5 → 积算仪 GND

> 注意：不同厂商对 A/B 或 A+/B- 的标法可能相反。若通讯无数据，可先对调 Pin 3 与 Pin 8 测试。

## 五、Modbus参数现场整定SOP

### 5.1 整定前准备

1. **接线检查**：
   - [ ] Modbus RTU通讯线屏蔽层单端接地（PLC侧）
   - [ ] DB9接头3/5/8脚焊接正确（Pin3→A+，Pin8→B-，Pin5→GND，见4.2.1节）
   - [ ] 终端电阻120Ω已安装在总线两端（首末设备）

2. **设备上电**：
   - [ ] PLC上电，RUN灯常亮
   - [ ] 注射泵控制器上电
   - [ ] 流量计上电

3. **设备地址确认**：
   - [ ] 注射泵Modbus地址=1（按设备厂商手册配置）
   - [ ] 流量计Modbus地址=2
   - [ ] 总线无地址冲突

### 5.2 整定流程

#### 阶段1：单设备测试

**目标**：用Modbus Poll软件单独测试每个从站。

1. 断开其他设备，仅PLC+1个从站
2. 用Modbus Poll软件（PC直连PLC串口或USB转串口）：
   - 设置串口：9600/8/N/1
   - 设置从站地址：1（注射泵）
   - 读取40001（状态码，应返回0=空闲）
3. 若超时/错误：
   - 检查接线（2/3是否接反）
   - 检查波特率（9600是否与设备一致）
   - 检查校验位（无/偶/奇）
   - 检查从站地址
4. 重复测试从站2（流量计）

#### 阶段2：双设备总线测试

1. PLC+注射泵+流量计同时挂在Modbus总线
2. 用Modbus Poll分别测试2个从站
3. 若某个从站失败：
   - 检查终端电阻（120Ω）
   - 检查总线长度（≤1200m）
   - 检查分支长度（≤1m）

#### 阶段3：PLC轮询测试

1. PLC下载程序（含FC4）
2. 监控VW4（注射泵状态码）：应周期性更新
3. 监控VD86（流量计累计值）：应周期性更新
4. 监控VW204~VW212（注射泵步数/速度）：应周期性更新
5. 用STEP7状态图监控VW250（轮询计数器0~3循环）
6. 用STEP7状态图监控M10.0~M10.3（Done位周期性变化）

#### 阶段4：故障注入测试

**测试1：注射泵断电**
1. 断开注射泵电源
2. 等待30秒（10秒超时×3次重试）
3. 观察：
   - V303.4置位（注射泵故障报警）
   - M10.4置位（连续5次失败后降级模式）
   - VW4保持上一有效值
4. 恢复注射泵电源
5. 观察：
   - V303.4复位（通讯恢复）
   - M10.4复位（退出降级模式）
   - VW4恢复实时更新

**测试2：流量计断电**
1. 断开流量计电源
2. 等待30秒
3. 观察：V303.6置位 + M10.5置位 + VD86保持上一值
4. 恢复：V303.6复位 + M10.5复位 + VD86恢复实时

**测试3：通讯线干扰**
1. 在Modbus线附近放置运行中的变频器
2. 观察VB379/VB384错误码是否增加
3. 若频繁超时：
   - 增加FC4超时时间（T50/T51从100→200，即20秒）
   - 加强屏蔽（双层屏蔽线）
   - 重新走线（远离动力线）
