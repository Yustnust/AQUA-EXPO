# S2-S4 流程重构与 24h 换水次数硬约束设计方案 v2.1

> **配套文档**：《药液配置加注控制系统_PLC设计文档》v9.x、《HMI-PLC变量地址表_v1.8+》、《PLC_完整寄存器映射表_v1.1》  
> **适用范围**：8套缸单元（S7-200 SMART CPU ST20 + EM DT16/DR16），1台本地集中HMI  
> **文档性质**：设计调整方案（已按用户后续8点意见修正），待用户确认后实施  

---

## 一、设计目标

本次调整解决三个核心问题：

1. **取消独立预循环环节**：S1 上缸注水结束后，直接进入 **S2 搅拌 + 加药** 合并阶段；S2 时间到达后进入 **S3 配完等待转移**；接到下缸排空信号后进入 S4 上下缸转移。
2. **实现上下缸并行工作**：在单 VW2 状态机下无法真正并行，新增上缸配液子流程状态字 **VW208** + 触发标志 **M10.3**。下缸实验（S4~S6）与上缸配液（S1~S3）并行。
3. **引入 24h 换水次数硬约束**：用户设定 24h 内下缸必须完成的换水次数 `VD414`。第一轮后的循环必须严格满足；搅拌时间严格固定；S5 实验时间覆盖 S4~S6 全过程，作为弹性量自动调节周期。

## 二、状态机重新定义

### 2.1 VW2（下缸主状态机）

| 值 | 状态 | 说明 |
|---|---|---|
| 0 | S0 初始化 | 待机、等待启动 |
| 5 | S4 转移 | 上缸 → 下缸转移（交汇点） |
| 6 | S5 实验运行 | 下缸内有液或正在转移/排水，实验计时中 |
| 7 | S6 下缸排水 | 下缸排空 |
| 8 | S7 实验结束 | 全部结束 |
| 99 | S_ERROR | 报警停机 |

> S5 计时区间：**从 S4 启动开始，到 S6 排水结束为止**。  
> S6 启动采用**倒计时**：在 S5 目标时长剩余 S6_est 时启动排水，确保总周期 = VD418。

### 2.2 VW208（上缸配液子流程）

| 值 | 状态 | 说明 |
|---|---|---|
| 0 | 空闲 | 上缸无配液任务 |
| 1 | S1 上缸进水 | 阀A开，流量计累计 |
| 2 | S2 搅拌 + 加药 | 潜水泵运行，同时注射泵加药 |
| 3 | S3 配完等待转移 | 已完成，等下缸排空 |
| 4 | 已转移 | 本轮完成，准备下一轮触发 |

### 2.3 正常时序

```
时间轴 ──────────────────────────────────────────────────────────────→

VW2  │S0│        S5（S4+S5+S6）         │        S5（S4+S5+S6）         │...│S7│
     └──┘   ↑_____↑_________↑_________↑   ↑_____↑_________↑_________↑
           S4启动  上缸启动S1   S6启动     S4启动  上缸启动S1   S6启动
                  (FC40预规划)            (FC40预规划)

VW208│0│  1→2→3                    1→2→3                    1→2→3
     ──┘  ↑   ↑                    ↑   ↑
         S4启动触发首轮           S4启动触发下一轮
```

### 2.4 关键规则

- **S4 转移是唯一的上下缸交汇点**：必须同时满足“下缸排空（V1.7=0）”和“上缸已配完（VW208=3）”。
- **S4 启动瞬间即开始 S5 计时**，S5 覆盖 S4/S5/S6 全过程。
- **上缸启动时机由 FC40 预规划**：保证上缸 S1+S2 完成时刻 ≤ S6 启动时刻。
- **S6 采用倒计时启动**：当 S5 剩余时间 = S6_est 时启动排水，确保单次总周期 = VD418。
- **S6 结束后上缸未配完**：直接报警“24h换水次数无法保证”，不再回 S5 空等。
- **搅拌时间严格固定**：VD28 为 HMI 设定参数，不可压缩。
- **结束条件**：总换水次数 ≥ VD414 **且** 总实验时间 ≥ VD_ExperimentTarget，同时满足才进 S7。

## 四、关键算法

### 4.1 单次周期与 S5 目标总时长计算

每轮 **S4 启动瞬间**执行一次：

```
T_single = 86400.0 / VD414          // 单次目标周期（秒）

S6_est = VD116
IF S6_est < 1.0 THEN S6_est = VD108 // 首轮无滚动值用默认值

VD418 = T_single - S6_est - VD426   // S5目标总时长 = 单次周期 - S6 - S4转移余量

IF VD418 < VD422 THEN
    报警 V303.6 = 24h换水次数设置过激进
    VD418 = VD422                   // 安全兜底
END_IF
```

### 4.2 S6 启动倒计时

```
S6_Start_Countdown = VD418 - S6_est

IF VD_S5_Elapsed >= S6_Start_Countdown THEN
    MOVW 7, VW2                     // 转S6排水
END_IF
```

### 4.3 上缸启动预规划（FC40 新功能）

FC40 每周期调用，计算是否触发上缸新一轮配液。

```
S1_est = VD70
IF S1_est < 1.0 THEN S1_est = 20.0

Prep_Needed = S1_est + VD28 + VD430 // 上缸配液所需时间 + 安全余量

Remaining_To_S6 = (VD418 - S6_est) - VD_S5_Elapsed
// 即：距离S6启动还有多少秒

IF Remaining_To_S6 <= Prep_Needed THEN
    IF VW208 = 0 AND VW6 = 0 THEN
        S M10.3, 1                  // 触发上缸配液
    END_IF
END_IF
```

> 注：FC40 也负责在首轮 S0 启动时尽早触发上缸配液。S0 启动后立即置 M10.3，FC40 同时持续监控。

### 4.4 S6 结束后逻辑

```
IF V1.7 = 0 THEN                    // 下缸排空
    IF VW208 = 3 THEN               // 上缸已配完
        IF 结束条件满足 THEN
            MOVW 8, VW2             // 进S7
        ELSE
            MOVW 5, VW2             // 转S4转移
            INCW VW212              // 换水次数+1
        END_IF
    ELSE
        // 上缸未配完
        报警 = 上缸配液未完成，24h换水次数无法保证
        MOVW 99, VW2                // 或保持S6等待，视报警策略
    END_IF
END_IF
```

### 4.5 结束条件

```
结束条件（同时满足）:
    VW212 >= VD414                    // 换水次数达标
    AND VD_ExperimentDuration_Accum >= VD_ExperimentTarget  // 总实验时间达标

满足后:
    等当前这一轮 S4→S6 正常收尾
    MOVW 8, VW2                       // 进S7实验结束
```

## 五、逐FC改动清单

### 5.1 FC40_RhythmCorrection.stl — 功能重构

**删除原功能**：三层纠偏。

**新增功能**：上缸配液启动预规划。

```stl
NETWORK 1: 计算距离S6启动的剩余时间
  LD     SM0.0
  MOVR   VD418, VD186               // S5目标总时长
  -R     VD116, VD186               // - S6_est = S6启动前总时长
  -R     VD178, VD186               // - S5已运行 = 剩余到S6启动

NETWORK 2: 计算上缸配液所需时间
  MOVR   VD70, VD194
  AR<    VD194, 1.0
  MOVR   20.0, VD194                // S1默认
  +R     VD28, VD194                // + 搅拌
  +R     VD430, VD194               // + 安全余量

NETWORK 3: 触发上缸启动
  LD     SM0.0
  AR<=   VD186, VD194               // 剩余到S6 <= 配液所需
  LDW=   VW208, 0                   // 上缸空闲
  ALD
  AW=    VW6, 0
  S      M10.3, 1
```

### 5.2 新建 FC1A_State_S2_MixDose.stl

由 **FC12 + FC13 合并**而来。

**NETWORK 1：首次进入 S2**
```stl
LDW=   VW208, 2
AN     M10.4                        // S2首次进入标志
S      M10.4, 1
S      Q0.0, 1                      // 开潜水泵1
S      Q0.1, 1                      // 开潜水泵2
MOVR   VD28, VD336
*R     10.0, VD336
ROUND  VD336, AC0
MOVW   AC0, VW252
TON    T120, VW252                  // 搅拌总时长
MOVW   0, VW226                     // 加药子状态机初始化
R      V303.4, 1
MOVR   VD584, VD372                 // 剩余量=目标量
MOVR   0.0, VD440                   // 累计加药量清零
```

**NETWORK 2~N：加药子状态机**
复用 FC13 全部状态机逻辑（VW226 0~9），去掉原潜水泵启停和转 S3.5 逻辑。

**NETWORK X：完成判定**
```stl
LDW=   VW226, 9                     // 加药完成
A      T120                         // 搅拌时间到
R      Q0.0, 1
R      Q0.1, 1
R      T120, 1
MOVW   3, VW208                     // 进S3等转移
```

**NETWORK X+1：搅拌到但加药未完**
```stl
LD     T120
AN     VW226.9                      // 加药未完成
// 继续等待加药完成，不报警
```
