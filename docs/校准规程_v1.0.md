## 第1章 校准总则

### 1.1 校准目的

本系统为药液配置加注控制系统,目标浓度VD_C_Set由流量计K24测得的进水量与注射泵步数精度共同决定,浓度计算链路如下:

```
VD_Vol_Target(VD98) = VD_C_Set × VD90(进水量) / VD_C_Stock
VD_Dose_Steps(VD102) = VD_Vol_Target ÷ VD_StepResolution
实际抽取体积 = VD_Dose_Steps × VD_StepResolution
最终浓度 = 实际抽取体积 × VD_C_Stock / VD90
```

校准目的:
1. **保证浓度计算精度**:流量计K24的进水量测量误差、注射泵的步数分辨率误差,均直接传递至最终药液浓度。通过校准控制各环节误差,确保实际浓度与设定浓度VD_C_Set的偏差在允许范围内(建议±5%**待确认**)。
2. **保证安全联锁可靠**:液位计A/B高位为防漫溢安全关键器件,触发液位偏差可能导致漫溢事故或误报停机,必须定期校准。
3. **保证计量数据可追溯**:为FMEA(RPN=192注射泵失步、RPN=144液位计信号丢失等高风险项)提供预防性探测手段,降低未探测到失效的概率。
4. **满足维护手册要求**:维护手册v1.0第二章明确每半年需进行注射泵/流量计/液位计校准,本规程为该维护项的具体作业指导。

## 第2章 流量计K24校准规程

### 2.1 计量原理与精度要求

**计量原理**:流量计K24通过Modbus RTU(站号02)向PLC提供累计流量"计量值"寄存器0x0009(DWORD,0~99999999,低3位为小数部分,即实际值=读数值/1000,单位L)。该寄存器持续累加,**无清零/复位功能**,因此PLC采用差值法计算单次进水量:

```
阀A开启瞬间:VD82(VD_FlowMeter_Snapshot) = 0x0009当前读数
进水过程中:VD86(VD_FlowMeter_Current) = 0x0009轮询读数
本次进水量:VD90(VD_Current_InletVolume) = VD86 − VD82  [单位L]
```

VD90(进水量)直接进入浓度计算公式 `VD_Vol_Target = VD_C_Set × VD90 / VD_C_Stock`,因此流量计误差直接传递至浓度。

**精度要求**:

| 参数 | 指标 | 来源/标注 |
|---|---|---|
| 计量值精度(允许相对误差) | **±1.0%(待确认)** | 厂商规格书未提供,本规程建议值。依据:微小流量485流量计通常精度等级±0.5%~±2.0%,取中值±1.0%作为周期校准限值,首次校准收紧至±0.5% |
| 重复性 | ≤0.5%(相同校准点3次测量极差/平均值) | 本规程建议 |
| 差值法计算正确性 | VD90与标准体积偏差≤±1.0% | 与计量值精度一致 |
| 单位配置(0x0012) | 必须为0x03=升L | 现场读取确认,默认值假设 |
| 字节序(0x0009 DWORD) | 与K24协议一致 | **待确认**:首次校准时通过抓包确认大端/小端 |

### 2.3 校准步骤(实物比对法,多点校准)

**前置准备**:
1. 确认校准环境满足1.3节要求。
2. 确认标准器均在检定有效期内,记录标准器编号和证书编号。
3. 系统断电+急停,挂"校准作业中"警示牌(参照维护手册12.1节)。
4. 通过HMI画面8确认VW2=0(S0初始化)或VW2=99(S_ERROR),确保不在自动运行状态。
5. 用Modbus Poll通过USB转RS485并联总线,确认能读到K24(站号02)的0x0009/0x0012/0x0017寄存器。
6. 读取0x0012确认单位=0x03=升L;若不是,用FC06写0x0012=0x03(并记录修改)。

**校准点选择(3点)**:

| 校准点 | 进水体积(标准) | 对应工况 | 流量范围(参考) |
|---|---|---|---|
| 小流量点 | 1.000 L | 小缸配液 | 0.5~2 L/min |
| 中流量点 | 5.000 L | 正常配液(S1典型工况) | 2~5 L/min |
| 大流量点 | 10.000 L | 满缸配液 | 5~10 L/min |

> **注**:校准体积应根据上缸实际容积调整,建议覆盖S1实际进水量的低/中/高三档。校准体积值**待确认**:需根据上缸实际容积和S1典型进水量定型。

**单点校准操作(以小流量点1.000L为例)**:

1. **标准器就位**:将1000mL A级标准量筒放置于上缸进水口下方,确保进水全部接入量筒(必要时拆下进水管接入量筒)。
2. **读取初始计量值**:用Modbus Poll读取0x0009当前值,记录为R0_start(实际累计流量,L)。同时通过HMI画面2读取VD86,核对一致。
3. **开启阀A进水**:通过HMI画面3手动控制下发CMD_Manual_ValveA_Open(V2.4=1),或人工手动开启阀A旁路,开始进水至量筒。
4. **进水至目标体积**:观察量筒液位,达到1000mL时立即关闭阀A(CMD_Manual_ValveA_Close,V2.5=1)。
5. **静置稳定**:等待3秒,排除管路残留滴水,读取量筒最终体积V_std(mL,精确至1mL)。
6. **读取终止计量值**:用Modbus Poll读取0x0009当前值,记录为R0_end(L)。同时读取HMI VD86,核对一致。
7. **计算差值**:
   - 仪表差值流量:Q_meter = R0_end − R0_start (L)
   - 标准体积:V_std_L = V_std / 1000 (L)
   - 误差:E = Q_meter − V_std_L (L)
   - 相对误差:δ = E / V_std_L × 100%
8. **重复测量**:同一校准点重复3次,记录R1、R2、R3,计算重复性。
9. **判定**:δ均在±1.0%(待确认)内,且重复性≤0.5%,判定本点合格。

**中流量点(5.000L)、大流量点(10.000L)**:更换5L/10L标准容器,重复步骤1~9。

**记录数据**:填入2.6节校准记录表。

### 2.4 Modbus读数核对

**目的**:验证PLC通过FC4轮询读到的VD86与流量计实际寄存器值一致,排除通讯字节序/转换错误。

**操作**:
1. 用Modbus Poll直接读取K24寄存器0x0009(2个寄存器,FC03),得到原始4字节十六进制,按K24协议字节序解析为DWORD,除以1000得到实际L值,记为R_modbus。
2. 通过HMI画面2读取VD86(VD_FlowMeter_Current)显示值,记为R_hmi。
3. 同时读取0x0017(瞬时流速)解析为L/min,与HMI VD94显示比对。
4. 比对:R_modbus 与 R_hmi 应完全一致(允许末位±1个字,因轮询时刻不同)。

**报文示例(参照Modbus报文规格书5.2.4节)**:
- 请求帧:`02 03 00 09 00 02 D4 0F`
- 响应帧(假设计量值=12.345678L,即读数值12345678=0x00BC614E):`02 03 04 00 BC 61 4E XX XX`

**判定**:
- R_modbus 与 R_hmi 一致 → 通讯链路正常。
- 不一致 → 检查FC4字节序处理(参见Modbus报文规格书10.1节待确认事项#2字节序),修正后重测。

### 2.5 误差计算与判定公式

**误差计算**:

```
绝对误差:E_i = Q_meter_i − V_std_i                    (单位L)
相对误差:δ_i = (Q_meter_i − V_std_i) / V_std_i × 100%  (单位%)
重复性  :S = (max(Q_meter_i) − min(Q_meter_i)) / avg(Q_meter_i) × 100%  (i=1,2,3)
```

其中:Q_meter_i = R_end_i − R_start_i(第i次测量的差值流量)

**判定准则**:

| 项目 | 合格限 | 不合格处置 |
|---|---|---|
| 各点相对误差 δ_i | ≤±1.0%(待确认) | 任一点超差→2.7节偏差修正或送修 |
| 重复性 S | ≤0.5% | 重复性超差→检查安装稳定性/管路气泡 |
| Modbus读数核对 | R_modbus 与 R_hmi 一致 | 不一致→检查通讯链路 |
| 单位配置 | 0x0012=0x03 | 不符→FC06写0x03 |

### 2.7 偏差修正

**K24是否有系数调整寄存器**:根据PLC设计文档2.3节及Modbus报文规格书4.2节,0x0011~0x0015等可写寄存器为通讯地址/波特率/单价/单位/校正参数等配置项。**校正参数寄存器(具体地址待厂商提供完整寄存器表)**可能存在,但本规程不建议直接修改流量计内部校正参数(可能影响厂商保修)。

**偏差修正策略**:

| 偏差情况 | 修正方式 |
|---|---|
| 各点相对误差均超差且方向一致(如全部+2%) | (1)优先排查安装因素:管路直管段是否足够、有无气泡、阀A是否内漏;(2)排查后仍超差,联系厂商按其校正参数寄存器调整或返厂;(3)现场可通过PLC程序在VD90计算后乘以修正系数K=1/(1+δ_avg),但需在程序注释中标注并经计量工程师批准,且K值写入断电保持区(建议VD150~VD190纠偏中间变量区) |
| 各点相对误差方向不一致(如小流量+2%、大流量-1%) | 流量计线性度异常,不可单点修正,联系厂商返厂 |
| 单点超差但其他点合格 | 检查该点工况(流速是否在流量计正常测量范围),若在范围内则流量计线性变差,返厂 |
| Modbus读数与HMI显示不一致 | 非流量计问题,排查PLC FC4字节序处理逻辑(参见Modbus报文规格书10.1节#2) |

**VD参数补偿**:若采用PLC程序侧补偿,补偿公式:

```
VD90_compensated = (VD86 − VD82) × K
其中 K = V_std_avg / Q_meter_avg (校准3点平均修正系数)
```

补偿后需重新校准1点验证补偿效果。

## 第3章 注射泵步数精度校准规程

### 3.1 计量原理

**计量原理**:注射泵为南京润泽泵阀一体柱塞式计量泵(站号01),步进电机驱动丝杆推动活塞,一次行程完成固定体积的抽取或排放。控制方式为直接写入目标步数:

```
抽液:PLC写40006(0x0005)=N步 → 泵执行抽液 → 轮询41001状态码=0完成
排液:PLC写40007(0x0006)=N步 → 泵执行排液 → 轮询41001状态码=0完成
```

**步数分辨率**:VD_StepResolution(VD18)=单步抽取体积(µL/步),取决于进样器规格。5ml进样器默认0.2083µL/步(参见PLC设计文档第十一章待确认事项#1及SY11文档2.4节换算方法)。

**浓度计算链路**:

```
VD_Vol_Target(VD98) = VD_C_Set × VD90(进水量) / VD_C_Stock   [µL]
VD_Dose_Steps(VD102) = VD_Vol_Target ÷ VD_StepResolution     [步]
实际抽取体积 V_actual = VD_Dose_Steps × VD_StepResolution      [µL]
最终浓度 C_actual = V_actual × VD_C_Stock / VD90              [%]
```

**位置反馈核对**:41007(0x03EE)位置反馈寄存器,单位**半步**,可用于核对实际抽排步数是否到位(参见FMEA 2.8节改进建议#4:读取VW222核对VD_Dose_Steps,偏差超限报警)。**注**:位置反馈单位为半步,与目标步数(单位步)的换算关系为 1步=2半步。

**精度要求**:

| 参数 | 指标 | 来源/标注 |
|---|---|---|
| 步数分辨率VD18精度 | **±1.0%(待确认)** | 厂商规格书未提供,本规程建议。依据:步进计量泵典型精度±0.5%~±2%,取±1.0% |
| 重复性 | ≤1.0%(相同步数3次测量极差/平均值) | 本规程建议 |
| 位置反馈核对 | VW222(半步)与VD_Dose_Steps(步)×2 偏差≤±1步 | 探测失步(FMEA RPN=192) |
| 速度参数影响 | 不同速度档位下精度变化≤±0.5% | 本规程建议 |

### 3.2 标准器

**密度换算公式**(纯水,称重法):

```
V_actual (µL) = m (mg) / ρ (g/mL)
其中 ρ 按水温查表:
  20℃: ρ = 0.99820 g/mL
  25℃: ρ = 0.99705 g/mL
  其他温度按JJG常规水密度表查取
```

### 3.3 校准步骤(称重法,多档位校准)

**前置准备**:
1. 确认校准环境满足1.3节要求,特别是无振动、无气流干扰(影响微量天平读数)。
2. 微量天平预热≥30分钟,水平调平,用F1砝码核查示值误差≤±0.01mg。
3. 用温度计测量纯净水温度,记录T_water,查表得ρ。
4. 通过HMI画面4读取VD_StepResolution(VD18)当前值,记录(应=0.2083,5ml进样器默认)。
5. 通过HMI画面8确认VW2=0或99,不在自动运行状态。
6. 注射泵进样器吸入纯净水,排除气泡(反复抽排3~5次,直到管路无明显气泡)。
7. 用Modbus Poll确认能读写注射泵(站号01)寄存器:40002强停/40003复位/40006抽液/40007排液/41001状态码/41007位置反馈。

**校准档位选择(3档)**:

| 档位 | 设定步数 N | 理论抽取体积 V_theory = N × VD18 (µL) | 对应工况 |
|---|---|---|---|
| 小步数档 | 1000 步 | 1000 × 0.2083 = 208.3 µL | 微量加药(低浓度) |
| 中步数档 | 5000 步 | 5000 × 0.2083 = 1041.5 µL ≈ 1.041 mL | 正常加药(S3典型工况) |
| 大步数档 | 20000 步 | 20000 × 0.2083 = 4166.0 µL ≈ 4.166 mL | 大量加药(高浓度) |

> **注**:档位步数应根据实际进样器最大行程调整,不能超过最大行程步数(**待确认**:注射泵最大行程步数需厂商提供,参见Modbus报文规格书10.2节#7)。

**单档校准操作(以小步数档1000步为例)**:

1. **天平调零**:将清洁干燥的10mL烧杯置于微量天平称盘上,去皮(清零),记录m0=0.000mg。
2. **记录初始位置反馈**:用Modbus Poll读取41007(0x03EE)位置反馈,记录P_start(单位半步)。
3. **下发抽液指令**:用Modbus Poll FC06写40006(0x0005)=1000(步),触发抽液动作。
4. **轮询状态码**:用Modbus Poll FC03循环读41001(0x03E8),状态码从0→1→2(抽液中)→0(完成),记录完成时刻。
5. **记录终止位置反馈**:读取41007,记录P_end(半步)。
6. **排液至烧杯**:用Modbus Poll FC06写40007(0x0006)=1000(步),触发排液动作,排液口对准烧杯。
7. **轮询状态码**:状态码从0→1→3(排液中)→0(完成)。
8. **称重**:将烧杯放回天平,读取质量m1(mg)。
9. **计算实际抽取体积**:V_actual = (m1 − m0) / ρ (µL)
10. **计算误差**:
    - 理论体积:V_theory = 1000 × 0.2083 = 208.3 µL
    - 绝对误差:E = V_actual − V_theory (µL)
    - 相对误差:δ = E / V_theory × 100%
11. **位置反馈核对**:
    - 期望位置变化:ΔP_exp = N × 2 = 1000 × 2 = 2000 半步
    - 实际位置变化:ΔP_act = P_end − P_start (半步)
    - 位置偏差:Δ = ΔP_act − ΔP_exp (半步),|Δ| ≤ 2(即±1步)合格
12. **重复测量**:同一档位重复3次(每次重新抽排),记录V1、V2、V3,计算重复性。
13. **判定**:δ均在±1.0%(待确认)内,重复性≤1.0%,位置偏差≤±1步,判定本档合格。

**中步数档(5000步)、大步数档(20000步)**:更换50mL烧杯,重复步骤1~13。

**记录数据**:填入3.6节校准记录表。

### 3.4 步数分辨率VD18的实测修正

**修正条件**:当任一档位相对误差 |δ| > ±1.0%(待确认)且方向一致(如全部+1.5%),表明VD18设定值与实际分辨率不符,需重新计算VD18并写入。

**修正方法**:

1. **计算实测平均分辨率**:

```
VD18_measured = avg(V_actual_i) / N_i   (i=各档位)
其中 V_actual_i 为该档位3次测量的平均实际体积,N_i 为该档位设定步数
```

示例:小步数档(1000步)3次平均V_actual=211.5µL,则该档VD18_measured=211.5/1000=0.2115µL/步。

2. **多档位加权平均**:取3个档位VD18_measured的算术平均值作为最终修正值:

```
VD18_corrected = (VD18_small + VD18_mid + VD18_large) / 3
```

3. **写入VD18**:通过HMI画面4(参数设置页)将VD18(VD18,即VD18地址)从0.2083修改为VD18_corrected,记录修改前/后值。
4. **重新校准验证**:写入新VD18后,任选1档位(建议中步数档)重新校准,验证δ降至±1.0%以内。
5. **记录**:在校准记录表"VD18修正"栏记录原值、新值、修正日期、批准人。

**注意事项**:
- VD18修改后,所有依赖VD18的浓度计算(VD102=VD98÷VD18)自动按新值计算,无需额外改程序。
- VD18为断电保持REAL变量,修改后断电不丢失(参见变量地址表附录A)。
- 修正后需在HMI画面4标注"已校准修正"备注,通知所有操作员。
- 若多档位δ方向不一致(如小步数+2%、大步数-1%),表明泵线性度异常,不可修正VD18,需返厂检修。

### 3.5 速度参数影响验证

**目的**:注射泵速度参数VD132(启动)/VD136(最高)/VD140(截止)影响步进电机加减速曲线,可能因失步影响精度。本项验证不同速度档位下的精度变化。

**操作**:
1. 选取中步数档(5000步)作为基准。
2. 设置3组速度档位(通过HMI画面4设定VD132/VD136/VD140):

| 速度档位 | VD132 启动速度(Hz) | VD136 最高速度(Hz) | VD140 截止速度(Hz) | 说明 |
|---|---|---|---|---|
| 低速 | 100 | 500 | 100 | 厂商默认值**待确认** |
| 中速 | 200 | 1000 | 200 | S3典型工况**待确认** |
| 高速 | 500 | 2000 | 500 | 测试上限**待确认** |

> **注**:速度参数默认值及范围**待确认**,需厂商提供。本表为建议值,首次校准时按厂商推荐值调整。

3. 每组速度档位按3.3节步骤校准1次(5000步),记录V_actual和δ。
4. **判定**:3组速度档位δ极差 ≤0.5%,判定速度参数对精度影响可接受;若极差>0.5%,建议S3工况选用δ最小的速度档位作为日常运行参数。

## 第4章 液位计校准规程

### 4.1 液位计类型与触发点位

**液位计类型**:全部为**无源常开触点浮子式液位开关**,直接接入PLC自身24VDC回路(不经继电器转换,见PLC设计文档2.1节接线原则)。常开触点:浮子未动作时触点断开(OFF),浮子动作(液位达到触发点)时触点闭合(ON)。

**4个液位计及触发点位**:

| 液位计 | PLC地址 | 触发条件 | 标称触发液位 | 安装位置 | 用途 |
|---|---|---|---|---|---|
| 液位计A-高位 | I0.5 | 上缸液位达最高警戒 | **待确认**(建议=上缸防漫溢警戒线,距缸口50mm) | 上缸上部 | 防漫溢保护(强制关阀A+NC球阀-上缸) |
| 液位计A-低位 | I0.6 | 上缸液位达排空线 | **待确认**(建议=上缸排空线,距缸底20mm) | 上缸下部 | 阀B四态诊断(上缸排空判断) |
| 液位计B-高位 | I0.7 | 下缸液位达最高警戒 | **待确认**(建议=下缸防漫溢警戒线,距缸口50mm) | 下缸上部 | 防漫溢保护(强制关阀B+NC球阀-下缸) |
| 液位计B-低位 | I1.0 | 下缸液位达排空线 | **待确认**(建议=下缸排空线,距缸底20mm) | 下缸下部 | 阀C四态诊断(下缸排空判断) |

> **注**:标称触发液位**待确认**,需现场测量上下缸实际尺寸后,确定防漫溢警戒线和排空线的具体液位值(mm)。本规程建议值仅供校准时参考,实际值以现场标定为准。

### 4.2 校准步骤(实物液位法)

**前置准备**:
1. 确认校准环境满足1.3节要求。
2. 准备液位测量工具:钢直尺(0~500mm,分度1mm)或电子液位计(精度±1mm)。
3. 系统断电+急停,挂"校准作业中"警示牌。
4. 通过HMI画面8确认VW2=0或99,不在自动运行状态。
5. 将上缸/下缸排空(通过手动开阀B/C排水至低位液位计触发)。

**单只液位计校准操作(以液位计A-高位为例)**:

1. **安装位置核对**:目视检查液位计A-高位浮子安装位置,确认浮子处于上缸防漫溢警戒线附近(距缸口约50mm,**待确认**)。
2. **记录初始状态**:通过HMI画面2读取I0.5状态,应为OFF(常开,未触发)。若为ON,检查浮子是否卡死或触点粘连。
3. **注水升液位**:通过手动开阀A(或人工注水)缓慢向上缸注水。
4. **接近触发点时减速**:当液位接近浮子位置(约低10mm)时,改用容器缓慢定量注水(每次10mL),便于精确捕捉触发点。
5. **捕捉触发点**:每注水10mL后,用钢直尺测量液位高度H(mm,距缸底),同时观察HMI I0.5状态。
6. **记录动作液位**:I0.5由OFF变为ON的瞬间,记录此时液位高度H_act(mm),即为实测动作液位。
7. **继续注水验证**:再注水至浮子完全浸没,确认I0.5保持ON(防误触发)。
8. **排水降液位**:通过手动开阀B缓慢排水。
9. **捕捉复位点**:I0.5由ON变为OFF的瞬间,记录此时液位高度H_reset(mm),即为复位液位。
10. **计算偏差**:
    - 标称液位:H_nom(待确认,现场标定值)
    - 动作偏差:Δ = H_act − H_nom (mm)
    - 滞回:H_hys = H_act − H_reset (mm)
11. **重复测量**:排水后重新注水,重复3次,记录H_act_1/2/3。
12. **判定**:|Δ| ≤ ±3mm(待确认),且3次动作液位极差≤2mm(重复性),判定合格。

**液位计A-低位、B-高位、B-低位**:重复步骤1~12,分别注水/排水至对应浮子位置。

**记录数据**:填入4.4节校准记录表。

### 4.3 安装位置核对

**高位触点(防漫溢警戒线)**:

| 液位计 | 安装要求 | 核对方法 |
|---|---|---|
| 液位计A-高位(I0.5) | 浮子触发点应在上缸**防漫溢警戒线**(距缸口约50mm,**待确认**),且低于缸口沿至少30mm,确保触发后阀A关闭+NC球阀-上缸动作的响应时间内(约2~3秒)不会溢出 | 测量浮子触发点至缸口沿的垂直距离,应≥30mm;若<30mm,需下调浮子安装位置 |
| 液位计B-高位(I0.7) | 浮子触发点应在下缸**防漫溢警戒线**(距缸口约50mm,**待确认**),且低于缸口沿至少30mm | 同上 |

**低位触点(排空线)**:

| 液位计 | 安装要求 | 核对方法 |
|---|---|---|
| 液位计A-低位(I0.6) | 浮子触发点应在**上缸排空线**(距缸底约20mm,**待确认**),确保阀B四态诊断能正确判断上缸排空;过低会导致阀B关闭时上缸仍有较多残留,过高会导致提前关阀B | 测量浮子触发点至缸底的垂直距离,应与标称排空线一致(±3mm);若偏差大,需调整浮子安装位置 |
| 液位计B-低位(I1.0) | 浮子触发点应在**下缸排空线**(距缸底约20mm,**待确认**),确保阀C四态诊断能正确判断下缸排空 | 同上 |

**冗余设计建议(参照FMEA 3.3/3.4节高风险项RPN=144)**:
- 液位计A-高位、B-高位为安全关键器件(防漫溢),FMEA建议冗余设计(双开关)或定期测试。本规程要求高位液位计校准周期内的每月现场测试(手动抬浮子验证触发)。

## 第5章 浓度计算链路整体校验

### 5.1 校验目的

第2~4章分别校准了流量计、注射泵、液位计的单体精度,但实际浓度计算是上述器具协同工作的结果。本章通过**综合校验**验证整条计量链:

```
流量计VD90(进水量) → VD_Vol_Target(VD98)=VD_C_Set×VD90/VD_C_Stock
                  → VD_Dose_Steps(VD102)=VD98÷VD18
                  → 注射泵实际抽取V_actual=VD102×VD18
                  → 最终浓度C_actual=V_actual×VD_C_Stock/VD90
```

通过设定已知VD_C_Set/VD_C_Stock,实际进水+加药,取样化验实际浓度,与设定浓度VD_C_Set比对,验证整条链路。

### 5.2 校验条件

- 流量计K24、注射泵、液位计A/B高位低位均已完成周期校准且合格。
- 系统处于S0初始化状态,无活动报警(VW6=0)。
- 准备已知浓度的母液(VD_C_Stock,如100%纯母液,或经化验室标定的已知浓度)。
- 准备化验室浓度分析仪器(精度优于±0.5%,如分光光度计/滴定仪,**待确认**具体仪器)。

### 5.3 校验步骤

1. **设定参数**:通过HMI画面4设定:
   - VD_C_Set(VD10)=5.0%(目标浓度,典型工况)
   - VD_C_Stock(VD14)=母液实际浓度(化验室标定值,如100.0%)
   - VD18(VD_StepResolution)=已校准值(如0.2083µL/步)
   - 进水量设定值=5.000L(典型S1进水量,**待确认**)

2. **启动一轮完整配液**:通过HMI画面3下发CMD_Start(V0.0=1),系统自动执行S1(进水)→S2(预循环)→S3(加药)→S3.5(静止等候)→S4(转移)。

3. **记录关键变量**(通过HMI画面2单元详情页读取):
   - VD90(本次进水量,L)
   - VD98(VD_Vol_Target,目标抽取体积,µL)
   - VD102(VD_Dose_Steps,目标步数,步)
   - VD94(瞬时流速,L/min,参考)
   - VW4(注射泵状态码,应完成=0)
   - VW222(位置反馈,半步)

4. **理论浓度计算**:

```
C_theory = VD98 × VD_C_Stock / VD90 × 100%
       = VD98 × 100.0% / VD90 × 100%
```

理论浓度应=VD_C_Set=5.0%(允许小数舍入误差)。

5. **取样化验**:
   - S4转移完成后,在下缸取样3份(每份100mL),分别送化验室分析实际浓度C_lab_1/2/3。
   - 取3份平均值C_lab_avg作为实际浓度。

6. **偏差计算**:

```
浓度偏差 ΔC = C_lab_avg − VD_C_Set
浓度相对偏差 δC = (C_lab_avg − VD_C_Set) / VD_C_Set × 100%
```

7. **判定**:

| 判定 | 条件 |
|---|---|
| 合格 | |δC| ≤ ±5.0%(待确认) |
| 不合格 | |δC| > ±5.0%,需排查链路 |

8. **链路分解排查**(不合格时):

| 偏差来源 | 排查方法 |
|---|---|
| 流量计VD90误差 | 用标准量筒核对本次进水量VD90(参见第2章) |
| 注射泵实际抽取量误差 | 用位置反馈VW222核对实际步数;必要时用称重法核对抽取体积(参见第3章) |
| VD18设定值偏差 | 重新校准VD18(参见3.4节) |
| 母液浓度VD_C_Stock偏差 | 重新化验母液浓度 |
| 取样/化验误差 | 重新取样3份,核对化验过程 |
| 搅拌不均匀 | 检查S2预循环时长VD28是否足够,潜水泵1/2运行是否正常 |

9. **重复校验**:同一VD_C_Set重复2轮,记录2轮C_lab_avg,验证一致性。

## 第6章 校准不合格处置

### 6.1 停用标识

任一计量器具校准不合格,立即执行:

1. **物理停用**:在器具明显位置粘贴红色"停用"标签,注明"校准不合格,禁止使用,待维修/更换"。
2. **系统停用**:通过HMI画面8将该单元Unit_X_Enabled=FALSE(灰显"未接入"),或在PLC程序中强制该单元VW2=99(S_ERROR),禁止自动运行。
3. **台账更新**:在校准台账(第7章)记录不合格日期、不合格项、处置方式。
4. **通知相关人员**:通知维护工程师、操作员、项目经理。

### 6.2 维修/更换流程

```
校准不合格
    ↓
停用标识 + 系统停用
    ↓
不合格原因分析(参照FMEA及本规程各章偏差修正策略)
    ↓
┌─可现场修复(如液位计浮子调整、VD18修正、单位寄存器修正)
│   → 现场修复 → 重新校准 → 合格 → 投用
│                                → 不合格 → 转更换
│
└─不可现场修复(如流量计传感器故障、注射泵机械损坏)
    → 联系厂商返修/更换备件(参见维护手册第十章备件清单)
    → 更换后首次校准 → 合格 → 投用
                       → 不合格 → 厂商返厂
```

### 6.3 降级使用限制

若计量器具无法恢复至本规程精度要求,但可满足降级使用条件,经计量工程师批准可降级使用:

| 器具 | 降级条件 | 降级后限制 |
|---|---|---|
| 流量计K24 | 相对误差δ在±1.0%~±2.0%之间,且方向一致可修正 | (1)PLC程序侧加修正系数K;(2)HMI标注"降级使用";(3)浓度计算链路整体校验频次加倍(6个月→3个月);(4)通知操作员浓度偏差可能放大 |
| 注射泵 | VD18修正后δ在±1.0%~±2.0%之间 | (1)HMI标注"降级使用";(2)浓度计算链路整体校验频次加倍;(3)严禁用于高浓度配液(VD_C_Set>5%) |
| 液位计 | 动作偏差Δ在±3mm~±5mm之间 | (1)仅限非安全关键器件降级(液位计A/B高位**不允许降级**,必须合格或更换);(2)液位计A/B低位降级需在HMI标注,并加强阀B/C四态诊断监控 |

### 6.4 追溯影响(已生产批次)

校准不合格且该器具自上次合格校准以来已参与生产,需追溯影响:

1. **追溯范围**:自上次合格校准日期起,至本次不合格校准日期止,期间所有使用该器具生产的产品批次。
2. **影响评估**:
   - 流量计/注射泵不合格:评估已生产批次的浓度偏差范围(按校准超差幅度估算),必要时召回已生产批次重新化验。
   - 液位计A/B高位不合格:评估期间是否发生漫溢事件(查HMI报警日志V300.0/V300.1),若有则需评估环境影响。
   - 液位计A/B低位不合格:评估期间阀B/C四态诊断是否有误判(查V302.0/V302.5报警)。
3. **追溯记录**:在校准台账"不合格追溯"栏记录追溯范围、影响评估结论、处置措施。
4. **报告**:重大不合格(影响已生产批次浓度超±10%或发生漫溢)需上报项目经理,48小时内出具追溯报告。

### 8.2 与维护手册6级周期的衔接

维护手册v1.0第二章定义了6级维护周期(每日/每周/每月/每季度/每半年/每年),本规程与维护周期的衔接关系如下:

| 维护手册周期 | 维护内容(摘要) | 本规程对应校准 | 衔接说明 |
|---|---|---|---|
| 每日 | 外观巡检+报警检查+液位确认 | — | 操作员日常巡检,发现异常触发"怀疑异常时"校准 |
| 每周 | 急停/复位/消音功能测试+HMI日志导出 | — | 不涉及计量校准 |
| 每月 | RTC校时+断电保持测试+接线紧固+485稳定性 | 液位计A/B高位现场测试(手动抬浮子) | **本规程新增**:高位液位计每月现场测试(FMEA RPN=144高风险项预防性探测) |
| 每季度 | 安全继电器测试+NC阀动作+阀门润滑+密码更换 | 注射泵周期校准(3个月) | **本规程收紧**:维护手册"每半年注射泵校准"收紧至每季度(因FMEA失步RPN=192) |
| 每半年 | 注射泵校准+流量计校准+PLC除尘+全量备份 | 流量计周期校准(6个月)<br>注射泵冗余备份校准(6个月) | 流量计6个月周期校准;注射泵6个月作为3个月周期的冗余备份校准 |
| 每年 | 全系统深度维护+传感器校准+电缆检查+文档更新 | 液位计周期校准(12个月)<br>浓度计算链路整体校验(12个月)<br>称重秤溯源(12个月) | 液位计12个月;整体校验12个月;标准器溯源12个月 |

**衔接原则**:
1. 本规程校准周期**不短于**维护手册对应维护周期(即校准频次**不低于**维护频次)。
2. 本规程收紧的周期(注射泵3个月 vs 维护手册每半年)以本规程为准。
3. 维护手册"每半年/每年传感器校准"在本规程中拆分为:流量计6个月、注射泵3个月、液位计12个月,更精细化。
4. 校准作业可与维护手册对应周期维护**同步执行**,减少设备停机次数(如季度维护+注射泵校准同步安排)。
5. 维护手册月度维护新增"高位液位计现场测试"项,作为本规程12个月周期校准之间的预防性探测。

### 8.3 校准计划执行与考核

1. **计划制定**:计量工程师每年12月制定下一年度校准计划(参照8.1节),报项目经理批准。
2. **计划执行**:计量工程师按计划组织校准,校准完成后5个工作日内更新台账(第7章)。
3. **执行考核**:校准计划执行率纳入维护工程师年度考核,目标执行率≥95%(因设备故障等不可抗力未执行的需说明)。
4. **计划调整**:因设备维修、生产任务等原因需调整校准计划的,经计量工程师批准后调整,但调整后周期不得超过本规程规定周期的1.5倍(如注射泵3个月最长不得超过4.5个月)。
