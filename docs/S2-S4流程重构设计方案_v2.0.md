# S2-S4 流程重构与 24h 换水次数硬约束设计方案 v2.0

> **配套文档**：《药液配置加注控制系统_PLC设计文档》v9.x、《HMI-PLC变量地址表_v1.8+》、《PLC_完整寄存器映射表_v1.1》  
> **适用范围**：8套缸单元（S7-200 SMART CPU ST20 + EM DT16/DR16），1台本地集中HMI  
> **文档性质**：设计调整方案（已按用户14点意见修正），待用户确认后实施  

---

## 一、设计目标

本次调整解决三个核心问题：

1. **取消独立预循环环节**：S1 上缸注水结束后，直接进入 **S2 搅拌 + 加药** 合并阶段；S2 时间到达后进入 **S3 配完等待转移**；接到下缸排空信号后进入 S4 上下缸转移。
2. **实现上下缸并行工作**：在单 VW2 状态机下无法真正并行，新增上缸配液子流程状态字 **VW208** + 触发标志 **M10.3**。下缸实验（S4~S6）与上缸配液（S1~S3）并行。
3. **引入 24h 换水次数硬约束**：用户设定 24h 内下缸必须完成的换水次数 `VD414`。第一轮后的循环必须严格满足；搅拌时间严格固定；S5 实验时间覆盖 S4~S6 全过程，作为弹性量自动调节周期。

## 二、状态机重新定义

### 2.1 VW2（下缸主状态机）

| 值 | 状态 | 说明 |
|---|---|---|
| 0 | S0 初始化 | 待机、等待启动 |
| 5 | S4 转移 | 上缸 → 下缸转移（交汇点） |
| 6 | S5 实验运行 | 下缸内有液或正在转移/排水，实验计时中 |
| 7 | S6 下缸排水 | 下缸排空 |
| 8 | S7 实验结束 | 全部结束 |
| 99 | S_ERROR | 报警停机 |

> S5 计时区间：**从 S4 启动开始，到 S6 排水结束为止**。

### 2.2 VW208（上缸配液子流程）

| 值 | 状态 | 说明 |
|---|---|---|
| 0 | 空闲 | 上缸无配液任务 |
| 1 | S1 上缸进水 | 阀A开，流量计累计 |
| 2 | S2 搅拌 + 加药 | 潜水泵运行，同时注射泵加药 |
| 3 | S3 配完等待转移 | 已完成，等下缸排空 |
| 4 | 已转移 | 本轮完成，准备下一轮触发 |

### 2.3 正常时序

```
时间轴 ──────────────────────────────────────────────────────────────→

VW2  │S0│     S5实验运行（S4+S5+S6）      │     S5实验运行（S4+S5+S6）      │...│S7│
     └──┘   ↑_______↑________↑_________↑   ↑_______↑________↑_________↑
           S4启动    下缸满    S6结束      S4启动    下缸满    S6结束

VW208│0│  1(进水)→2(搅拌加药)→3(等)         1(进水)→2(搅拌加药)→3(等)
     ──┘          ↑                              ↑
                  │                              └── 上缸启动时刻由FC40预规划
                  └── 上缸启动时刻由FC40预规划
```

### 2.4 关键规则

- **S4 转移是唯一的上下缸交汇点**：必须同时满足“下缸排空（V1.7=0）”和“上缸已配完（VW208=3）”。
- **S4 启动瞬间即开始 S5 计时**，S5 覆盖 S4/S5/S6 全过程。
- **上缸启动时机由 FC40 预规划**：保证上缸 S1+S2 完成时刻 ≤ 预计下缸排空时刻。
- **S6 结束后的去向**：
  - 上缸已配完（VW208=3）→ 启动 S4 转移
  - 上缸未配完（VW208≠3）→ 回 S5 继续等待（空等，计入 S5 时间）
- **搅拌时间严格固定**：VD28 为 HMI 设定参数，不可压缩。
- **结束条件**：总换水次数 ≥ VD414 **且** 总实验时间 ≥ VD_ExperimentTarget，同时满足才进 S7。

## 四、关键算法

### 4.1 单次周期与 S5 目标时长计算

每轮 **S4 启动瞬间**（下缸开始接收上缸液体）执行一次：

```
T_single = 86400.0 / VD414          // 单次目标周期（秒）

S1_est = VD70
IF S1_est < 1.0 THEN S1_est = 20.0  // 首轮无实测值用默认值

Stir_fixed = VD28                   // S2搅拌固定时长

S6_est = VD116
IF S6_est < 1.0 THEN S6_est = VD108 // 首轮无滚动值用默认值

Transfer_margin = 30.0              // S4转移安全余量（秒）

// S5目标 = 单次总周期 - 上缸固定配液 - S6 - 转移余量
VD418 = T_single - S1_est - Stir_fixed - S6_est - Transfer_margin

IF VD418 < VD422 THEN
    报警 V303.6 = 24h换水次数设置过激进
    VD418 = VD422                   // 安全兜底
END_IF
```

### 4.2 S5 结束条件

```
S5结束条件（全部满足）:
    VW2 = 6 或 7                      // 当前处于S5或S6等待收尾
    VD_S5_Elapsed >= VD418            // S5目标实验时间到
    VW208 = 3                         // 上缸已配完，确保转移后有液可换
    VW6 = 0                           // 无报警

满足后:
    MOVW 7, VW2                       // 转S6排水（即使已在S6也保持）
```

若 `VD_S5_Elapsed >= VD418` 但 `VW208 ≠ 3`：
- 继续等待上缸配完
- 若空等时间超过 VD_S4WaitTimeout → 报警“上缸配液超时”

### 4.3 上缸启动预规划（FC40 新功能）

FC40 不再做三层纠偏，改为计算**上缸应开始进水的时刻**。

输入：
- 当前 RTC 时间（秒）
- 预计下缸排空时刻 = 当前时刻 + (VD418 - VD_S5_Elapsed) + S6_est
  - 或简化为：当前时刻 + 下缸剩余实验时间 + S6_est
- S1_est = VD70（或默认20）
- Stir_fixed = VD28
- Safety_Margin = 10.0 秒

输出：
```
IF 当前时刻 >= (预计下缸排空时刻 - S1_est - Stir_fixed - Safety_Margin)
   AND VW208 = 0                    // 上缸当前空闲
   AND VW6 = 0
THEN
    S M10.3, 1                      // 触发上缸新一轮配液
END_IF
```

**简化实现**：不存“预计下缸排空时刻”这个绝对时间点，而是每周期计算一个“剩余可用时间”：
```
Remaining_To_Empty = (VD418 - VD_S5_Elapsed) + S6_est
Prep_Needed = S1_est + Stir_fixed + Safety_Margin

IF Remaining_To_Empty <= Prep_Needed AND VW208 = 0 AND VW6 = 0 THEN
    S M10.3, 1
END_IF
```

### 4.4 结束条件

```
结束条件（同时满足）:
    VW212 >= VD414                    // 换水次数达标
    AND VD_ExperimentDuration_Accum >= VD_ExperimentTarget  // 总实验时间达标

满足后:
    等当前这一轮 S4→S6 正常收尾
    MOVW 8, VW2                       // 进S7实验结束
```

## 五、逐FC改动清单

### 5.1 FC40_RhythmCorrection.stl — 功能重构

**删除原功能**：三层纠偏（压缩 S2/S3.5、顺延周期）。

**新增功能**：上缸配液启动预规划。

```stl
NETWORK 1: 计算剩余到下缸排空的时间
  LD     SM0.0
  MOVR   VD418, VD186               // S5目标
  -R     VD178, VD186               // - S5已运行 = S5剩余
  MOVR   VD116, VD190
  AR<    VD190, 1.0
  MOVR   VD108, VD190               // S6估算
  +R     VD190, VD186               // + S6 = 剩余到下缸排空

NETWORK 2: 计算上缸配液所需时间
  MOVR   VD70, VD194
  AR<    VD194, 1.0
  MOVR   20.0, VD194                // S1默认
  +R     VD28, VD194                // + 搅拌
  MOVR   10.0, VD198
  +R     VD198, VD194               // + 安全余量

NETWORK 3: 触发上缸启动
  LD     SM0.0
  AR<=   VD186, VD194               // 剩余排空时间 <= 配液所需
  LDW=   VW208, 0                   // 上缸空闲
  ALD
  AW=    VW6, 0
  S      M10.3, 1
```

### 5.2 新建 FC1A_State_S2_MixDose.stl

由 **FC12 + FC13 合并**而来，实现“搅拌 + 加药同时进行”。

**NETWORK 1：首次进入 S2**
```stl
LDW=   VW208, 2
AN     M10.4                        // S2首次进入标志
S      M10.4, 1
S      Q0.0, 1                      // 开潜水泵1
S      Q0.1, 1                      // 开潜水泵2
MOVR   VD28, VD336
*R     10.0, VD336
ROUND  VD336, AC0
MOVW   AC0, VW252
TON    T120, VW252                  // 搅拌总时长
MOVW   0, VW226                     // 加药子状态机初始化
R      V303.4, 1
MOVR   VD584, VD372                 // 剩余量=目标量
MOVR   0.0, VD440                   // 累计加药量清零
```

**NETWORK 2~N：加药子状态机**
复用 FC13 全部状态机逻辑（VW226 0~9），仅去掉原 FC13 中的潜水泵启停和转 S3.5 逻辑。

**NETWORK X：完成判定**
```stl
LDW=   VW226, 9                     // 加药完成
A      T120                         // 搅拌时间到
// 完成
R      Q0.0, 1
R      Q0.1, 1
R      T120, 1
MOVW   3, VW208                     // 进S3等转移
```

**NETWORK X+1：搅拌到但加药未完**
```stl
LD     T120
AN     VW226.9                      // 加药未完成
// 不停泵，继续搅拌/加药直到加药完成
// 不报警
```
