# 药液配置与加注控制系统 — 8套集中HMI画面架构规划

**配套文档**：《药液配置加注控制系统_PLC设计文档》（v9.1）
**触摸屏**：初步考虑昆仑通态 MCGS 12寸，本项目为**1台本地HMI集中监控8台独立PLC**
**本文档目的**：规划本地集中HMI的画面结构、单元选择方式、报警确认逻辑、参数设置方式和采购前确认事项，作为后续MCGS组态开发依据。

---

## 一、总体原则

本HMI不是单套缸的就地屏，而是现场本地集中屏。HMI通过工业以太网交换机同时连接8台S7-200 SMART PLC，每台PLC独立控制1套上下缸单元。

```
现场本地集中HMI
  ├─ PLC#1：1号缸单元
  ├─ PLC#2：2号缸单元
  ├─ PLC#3：3号缸单元
  ├─ ...
  └─ PLC#8：8号缸单元
```

HMI只做人机界面，不承担实时控制逻辑。每套PLC内部仍完整保存状态机、报警锁存、急停处理、断电恢复、485设备轮询和泵阀控制逻辑。HMI故障或断网时，不应影响PLC本地安全联锁和正在运行的自动流程。

**操作边界：**
- 急停：每套单元物理急停按钮，不经过HMI。
- 急停后的系统复位：每套单元物理系统复位按钮，HMI只显示提示，不直接下发系统复位命令。
- 报警确认/消光：在HMI报警详情页执行，必须明确单元号和报警内容。
- 消音：可在HMI执行，也可保留就地物理消音按钮。
- 参数设置、历史记录、趋势、调试：由HMI集中完成。

## 二、画面架构总览

```
                         ┌────────────────────┐
                         │  画面1：8套总览首页  │
                         └─────────┬──────────┘
                                   │ 选择1~8号单元
        ┌──────────────┬───────────┼───────────┬──────────────┐
        ▼              ▼           ▼           ▼              ▼
  画面2：单元详情  画面3：手动控制  画面4：参数设置  画面5：报警与日志  画面6：趋势曲线
        │              │           │           │              │
        └──────────────┴───────────┼───────────┴──────────────┘
                                   ▼
                         画面7：通讯与维护
                                   │
                                   ▼
                         画面8：系统设置
```

建议共规划 **8个主画面**。所有操作类画面都必须有清晰的“当前选中单元号”，例如“当前操作：3号单元”。涉及启动、停止、手动动作、报警确认、参数保存等命令时，必须避免误操作到其他单元。

## 三、画面清单与内容规划

### 画面1｜8套总览首页

**用途**：操作员日常巡检第一屏，一眼看到8套系统是否正常运行。

**显示方式**：建议采用8个单元卡片，按1~8号排列。每个卡片显示该单元核心状态。

**每个单元卡片显示内容：**
- 单元编号：1号~8号
- PLC通讯状态：在线/离线
- 当前流程状态：S0初始化、S1进水、S2预循环、S3加药、S3.5静置、S4转移、S5实验运行、S6排水、S7结束
- 上缸状态：空/满/异常
- 下缸状态：空/满/异常
- 自动/手动模式
- 急停状态：正常/急停触发/急停释放等待物理复位
- 报警状态：无报警/一般/漫溢/节奏滞后/安全继电器故障
- 关键实时值：温度、pH、瞬时流量或本轮进水量

**主要操作：**
- 点击某个单元卡片进入“单元详情页”
- 顶部显示全局报警横幅，提示最高优先级报警和所属单元
- 可设置“全局消音”按钮，但不得设置默认“一键确认全部报警”

---

### 画面2｜单元详情页（1~8号共用模板）

**用途**：查看某一套缸的详细状态。该页面应是后续操作的主要入口。

**进入方式**：从首页点击单元卡片进入，或在页面顶部用单元选择器切换1~8号。

**主要显示内容：**
- 当前选中单元号，醒目显示
- 上缸/下缸图示：空、满、高位报警、低位状态
- 当前状态机步骤和步骤运行时间
- 阀A/B/C状态：开命令、关命令、开到位、关到位、流量开关反馈
- 潜水泵1/2运行状态和流量反馈
- 注射泵状态码、动作阶段、目标步数、当前位置反馈
- 本轮进水量、目标进水量、目标浓度、母液浓度
- 温度、pH、流量计读数
- 当前活动报警摘要
- 急停/等待物理系统复位提示

**主要操作入口：**
- 进入该单元手动控制
- 进入该单元参数设置
- 进入该单元报警详情
- 进入该单元趋势曲线

---

### 画面3｜单元手动控制页

**用途**：调试阶段和异常处理时，对指定单元执行手动动作。

**关键规则：**
- 必须先选择1~8号单元，页面顶部固定显示“当前手动操作单元：X号”。
- 只有该单元处于手动模式、无急停、无禁止手动的高优先级报警时，操作按钮才可用。
- 自动模式下所有手动动作按钮置灰。
- 手动动作建议做二次确认或长按，尤其是开阀、启动泵、注射泵抽/排液。

**主要显示与操作：**

| 设备 | 显示内容 | 操作 |
|---|---|---|
| 电动球阀A/B/C | 开/关命令、开到位、关到位、流量开关 | 开、关 |
| NC电磁阀-上缸/下缸 | 当前输出状态 | 开、关 |
| 潜水泵1/2 | 运行状态、流量反馈 | 启动、停止 |
| 注射泵 | 状态码、位置反馈、通讯状态 | 复位、手动抽液、手动排液 |
| 声/光报警器 | 声音、灯光状态 | 声音测试、灯光测试 |

**安全提示**：页面固定显示“手动操作前请确认液路状态、液位状态和现场安全，避免空转、溢流或误动作”。

---

### 画面4｜参数设置页

**用途**：集中管理8套单元的HMI可调参数。

**推荐结构：**
- 顶部选择当前参数对象：1号~8号单元
- 显示该单元当前参数
- 修改后点击“保存到当前单元”
- 提供“复制到其他单元”功能，但必须二次确认

**参数分组：**

**4.1 浓度与配液参数**
- 目标浓度 `VD_C_Set`
- 母液浓度 `VD_C_Stock`
- 上缸目标进水量
- 注射泵单步分辨率 `VD_StepResolution`

**4.2 时间与周期参数**
- 换水周期 `VD_CycleSetpoint`
- 潜水泵预循环标称时长 `VD_PreMixTime`
- 预循环压缩下限 `VD_PreMixTime_MinSafe`
- 静止等候标称时长 `VD_RestTime`
- 静止等候压缩下限 `VD_RestTime_Min`
- 换水周期顺延最大允许幅度 `VD_CycleExtend_Max`
- 实验时长目标 `VD_ExperimentTarget`

**4.3 超时与验证参数**
- 阀A/B/C动作超时 `VD_Timeout_ValveA/B/C`
- 潜水泵1/2动作超时 `VD_Timeout_Pump1/2`
- 阀A关闭后延时验证时长 `VD_Delay_ValveA_Verify`

**4.4 报警阈值与模式**
- 温度报警上下限
- pH报警上下限
- 报警确认模式：自动恢复/人工确认

**参数复制规则：**
- 支持“复制当前单元参数到指定单元”或“复制到全部其他单元”
- 复制前弹窗显示源单元、目标单元和参数类别
- 不建议默认复制运行中单元的关键参数，运行中修改是否生效需在PLC逻辑中限定

---

### 画面5｜报警与日志页

**用途**：查看8套系统当前报警和历史报警，并执行报警确认。

**当前报警显示：**
- 按单元分组，显示1~8号单元报警状态
- 支持筛选：全部、当前活动报警、未确认报警、高优先级报警
- 每条报警显示：单元号、报警文本、级别、触发时间、当前状态、是否已知晓

**报警确认逻辑：**
- 操作员必须先选中具体报警，查看报警详情后再确认
- 默认不设置“一键确认全部8套”
- 故障条件未消失时，确认只记录“已知晓”，不得清除报警锁存或解锁流程
- 故障条件消失后，HMI下发该单元对应报警确认命令，PLC才允许消光、清除锁存和解锁状态机
- 漫溢、节奏滞后人工介入、安全继电器故障等高优先级报警必须二次确认或长按确认

**消音逻辑：**
- 可设置“当前单元消音”和“全局消音”
- 消音只关闭声音，不清除报警、不关闭报警灯、不解锁流程

**历史日志字段：**
- 时间戳
- 单元号
- 报警类型
- 报警级别
- 动作：触发、消音、已知晓、复位
- 可选：操作员名称（若后续启用权限登录）

---

### 画面6｜趋势曲线页

**用途**：查看某一单元或多个单元的温度、pH、流量等历史趋势。

**推荐结构：**
- 顶部选择单元：1~8号
- 选择趋势类型：温度、pH、流量、进水量、实验时长
- 选择时间范围：最近1小时、24小时、7天、自定义
- 曲线上标注报警阈值线

**可选增强：**
- 支持最多2~4个单元的同类数据叠加对比
- 支持导出历史数据到U盘，需确认HMI型号是否支持

---

### 画面7｜通讯与维护页

**用途**：集中查看8台PLC和每套PLC下4个485从站的通讯状态。

**显示内容：**
- HMI与PLC#1~PLC#8以太网通讯状态
- 每台PLC的IP地址、在线/离线、最后通讯时间
- 每套单元485从站状态：
  - 注射泵
  - 温度计
  - pH计
  - 流量计
- 8套共32个485从站的在线/离线摘要
- 通讯故障报警入口

**维护操作：**
- PLC时钟显示与校准入口
- HMI工程版本、PLC程序版本显示
- 参数备份/恢复入口（若HMI支持）
- 历史记录导出入口（若HMI支持）

---

### 画面8｜系统设置页

**用途**：HMI自身设置和权限相关维护。

**主要内容：**
- HMI系统时间
- 画面亮度、蜂鸣器、语言/单位等基础设置
- 用户权限设置：操作员、维护人员、管理员
- 手动控制、参数修改、报警高级确认等权限分级
- 急停/系统复位状态提示说明
- 采购型号、HMI工程版本、项目版本说明

**注意**：系统复位本身由各单元就地物理按钮执行，HMI只显示“急停触发、急停已释放、等待现场物理系统复位”等状态，不直接下发系统复位命令。

## 四、导航与权限设计建议

1. **单元选择常驻**：除8套总览首页外，操作类页面顶部都应固定显示当前单元号，并提供1~8号切换。
2. **操作对象明确**：启动、停止、手动控制、参数保存、报警确认等动作必须显示目标单元号。
3. **高风险动作二次确认**：手动开阀、启动泵、注射泵动作、报警高级确认、参数复制到多单元等操作，应采用弹窗确认或长按确认。
4. **权限隔离**：普通操作员可查看和消音；维护人员可报警确认和参数修改；管理员可手动控制、批量参数复制、历史导出和系统设置。
5. **自动/手动互锁**：自动运行时禁止手动动作；手动模式下应限制自动状态机启动。
6. **通讯异常处理**：某一PLC离线时，该单元卡片置为通讯中断，禁止对该单元下发HMI命令，但不影响其他单元。

## 五、待确认事项

1. 12寸屏幕是否足够显示8套总览、报警摘要和关键数据；若总览过挤，考虑15寸或更高分辨率型号。
2. 参数设置页是否允许“复制到全部单元”，还是仅允许复制到指定单元。
3. 趋势曲线是否需要多单元叠加对比，还是只按单元单独查看。
4. 报警历史日志本地存储容量和导出方式。
5. 是否启用用户登录和权限分级；若启用，报警确认记录是否需要带操作员名称。
6. HMI与PLC变量表需单独整理：8套PLC变量命名、地址映射、报警码、命令位、握手位。

### 5.1 昆仑通态触摸屏采购前需向卖家/厂家确认

初步选型方向为**昆仑通态 MCGS 12寸触摸屏**。采购前需将本项目“1台HMI通过以太网同时监控8台西门子S7-200 SMART PLC”的架构明确告知卖家/厂家，并要求确认以下事项：

1. 所选具体型号是否支持**西门子 S7-200 SMART 以太网通讯驱动**，以及推荐使用S7协议还是Modbus TCP方式通讯。
2. 同一个HMI工程是否支持**同时连接8台 S7-200 SMART PLC**，每台PLC使用不同固定IP地址。
3. 8台PLC同时在线时，HMI的**变量点数、通讯连接数、画面刷新速度**是否满足本项目需求；需避免低配入门屏资源不足。
4. 是否支持8套单元的**报警记录、历史日志、趋势曲线、数据保存**，以及本地可保存的条数/时长。
5. 组态软件是否免费提供，是否需要单独授权；工程文件是否可完整导出、备份和二次修改。
6. HMI是否支持报警确认的**二次确认弹窗**或**长按确认**交互，用于漫溢、节奏滞后、安全继电器故障等高优先级报警。
7. HMI是否支持断电保持、配方/参数保存、U盘导出历史记录等维护功能。
8. 推荐的屏幕尺寸和型号：12寸为初步方案，如卖家认为8套总览、报警、参数和趋势画面信息密度较高，应建议更高配置或更大尺寸型号。
