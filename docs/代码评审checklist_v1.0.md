# 药液配置加注控制系统 — 代码评审checklist v1.0

**项目**: AQUA-EXPO 药液配置与加注控制系统
**适用范围**: PLC STL代码(20个FC文件)+ HMI变量接口
**评审依据**: PLC代码完整性校验报告v1.0、PLC代码静态分析报告v1.0、HMI-PLC变量地址表v1.0、PLC设计文档v9.3
**版本**: v1.0
**日期**: 2026-07-18
**适用阶段**: Story 1.2~1.7迭代交付、缺陷修复、发布前回归、紧急变更

---

## 第1章 评审流程

### 1.1 评审时机

| 时机 | 触发条件 | 评审范围 | 强制等级 |
|---|---|---|---|
| 提交PR时 | feature-*/fix-*/hotfix-* 合并到 develop/main | PR涉及的全部STL文件+变量表 | 强制 |
| 发布前 | release-x.y 合并到 main | 全部20个FC+变量表+CHANGELOG | 强制 |
| 缺陷修复后 | 校验报告/静态分析问题修复 | 修复涉及的FC+回归相关FC | 强制 |
| 紧急变更后 | hotfix 修复现场缺陷 | 修复涉及的FC(简化评审) | 强制(简化) |
| 重大架构变更 | 状态机重构/编址区迁移/通讯协议切换 | 全部FC+全部文档 | 强制(扩大) |
| 定期评审 | 每季度一次 | 全部FC+文档同步性 | 建议 |

### 1.2 评审人

| 评审类型 | 评审人要求 | 备注 |
|---|---|---|
| 常规PR评审 | 至少1名PLC工程师 | 评审人不得是提交人 |
| 发布前评审 | 至少1名PLC工程师 + 1名HMI工程师 | 跨专业评审变量接口 |
| 缺陷修复评审 | 至少1名PLC工程师 + 1名调试工程师 | 调试工程师关注现场可执行性 |
| 紧急变更评审 | 至少1名L3管理员(事后补评) | 紧急变更可先合并后评审,但24小时内必须补评 |
| 重大架构变更 | 项目负责人 + 至少2名PLC工程师 + HMI工程师 | 需召开评审会议 |

### 1.3 评审工具

| 工具 | 用途 |
|---|---|
| GitHub Pull Request | PR提交/评审/讨论/合并 |
| GitHub PR Review | 逐行评论/批准/请求修改 |
| `tools/stl_static_analyzer.py` | 自动静态分析(225类问题自动检出) |
| 校验报告v1.0(人工部分) | JMP/LBL/定时器/状态机一致性等需人工判断项 |
| 本checklist | 评审人逐项勾选 |
| GitHub Actions CI | PR自动触发静态分析,失败禁止合并 |

### 1.4 评审周期

| 评审类型 | 周期 |
|---|---|
| 常规PR评审 | 提交后2个工作日内响应 |
| 紧急变更评审 | 现场合并后24小时内补评 |
| 发布前评审 | release分支创建后5个工作日内完成 |
| 缺陷修复评审 | 修复提交后1个工作日内响应 |
| 评审意见修改后复审 | 修改提交后1个工作日内复审 |

### 1.5 评审流程

```
开发者提交PR
    ↓
CI自动运行 stl_static_analyzer.py
    ↓
CI通过 → 评审人收到通知 → 进入人工评审(第2~4章checklist)
CI失败 → 开发者修复 → 重新触发CI
    ↓
人工评审
    ├── 通过 → 评审人Approve → 合并到目标分支
    ├── 需修改 → 评审人Request Changes → 开发者修改 → 复审
    └── 拒绝 → 评审人Close PR + 说明原因
    ↓
合并后归档评审记录(PR链接存入变更单)
```

### 6.4 评审人快速识别清单

评审STL代码时,优先关注以下"高发问题"信号:

| 信号 | 可能问题 | 立即检查 |
|---|---|---|
| 出现 `MOVB x, VWyyy` | 字节指令写字地址 | 改 `MOVW x, VWyyy` |
| 出现 `MOVD x, VDyyy` 且 yyy%4≠0 | VD非4字节对齐 | 评估是否可调整地址 |
| 计时器 `TON Tn, VWm` 但VWm未在该FC内赋值 | PT值可能未写入 | 检查写入链(如VD→VW转换) |
| 计时器 `TON Tn, +N`(立即数) | 可能未做×10转换 | 确认N=期望秒数×10 |
| 出现 `*R 10.0, VDxxx`(xxx为HMI参数) | 直接修改HMI参数 | 改用中间变量 |
| 同一VW/VD地址在多个FC中出现 | 跨FC写入冲突 | 查静态分析"跨FC写入冲突"清单 |
| 注释中出现旧地址(如V0.5/V124.0) | Story1.6修复残留 | 改为新地址 |
| 文件头无修改记录 | 可追溯性缺失 | 补登修改记录 |
| NETWORK无注释 | 可维护性差 | 补充NETWORK注释 |
| JMP标签无对应LBL | 悬空JMP | 静态分析器自动检出 |
