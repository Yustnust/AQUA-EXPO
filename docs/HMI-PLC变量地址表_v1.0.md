## 一、编址总则与地址区规划

### 1.1 编址总则

1. **8套PLC程序完全相同**：每台PLC使用相同的变量地址表，区别仅在IP地址（192.168.2.101~108）。HMI通过不同IP连接不同单元，变量地址在各PLC内一致。
2. **断电保持**：所有需要断电保持的V区变量，需在STEP 7-Micro/WIN SMART的"系统块→断电保持"中配置对应V区范围为断电保持。
3. **HMI访问方式**：HMI通过以太网（S7协议或Modbus TCP，待HMI选型确认）读写PLC的V区变量，按本表地址直接映射。
4. **命名规范**：变量符号采用 `类型_功能_细分` 命名，如 `VD_C_Set`（VD双字/浓度/设定值）、`M_Alarm_Overflow`（M位/报警/漫溢）。
5. **单元编号**：本表适用于1~8号任一单元，HMI侧按单元编号区分（如"1号单元的VD_C_Set"通过连接PLC#1的192.168.2.101读取）。

|---|---|---|---|

## 四、系统命令位与状态位（HMI-PLC交互）

### 4.1 系统命令位（V0区，HMI→PLC，断电保持）

HMI下发的命令位，PLC扫描周期内响应。采用"上升沿触发+握手确认"机制，防止重复执行。

| 地址 | 符号 | 说明 | 握手确认 |
|---|---|---|---|
| V0.0 | CMD_Start | 启动实验（从S0进入S1） | PLC置V1.0=1确认 |
| V0.1 | CMD_Pause | 暂停实验（保留，当前状态机无暂停态，预留） | PLC置V1.1=1确认 |
| V0.2 | CMD_Stop | 停止实验（进入S7实验结束） | PLC置V1.2=1确认 |
| V0.3 | CMD_AckAlarm | 报警确认（HMI报警详情页下发） | PLC置V1.3=1确认，清除灯光DO（仅根本原因消失后） |
| V0.4 | CMD_Mute | 消音命令（HMI执行对应单元消音） | PLC置V1.4=1确认，声音DO置OFF |
| V0.5 | CMD_ForceTankA_Empty | 强制修正上缸状态=空 | PLC置V1.5=1确认 |
| V0.6 | CMD_ForceTankA_Full | 强制修正上缸状态=满 | PLC置V1.5=1确认 |
| V0.7 | CMD_SafetyRelayAck【Story1.5/1.6修正】 | 继电器故障HMI高权限确认（需二次确认/高权限，配合I1.2清除V300.5） | PLC清V0.7=0确认 |

**注**：`V0.1`（暂停）、`V0.5`（强制上缸空）、`V0.6`（强制上缸满）在PLC当前程序中**未实现**，首期HMI可保留占位但不下发有效命令；若后续启用需同步PLC与HMI。

### 4.2 系统状态位（V1区，PLC→HMI，断电保持）

PLC当前状态反馈给HMI，用于画面显示。

| 地址 | 符号 | 说明 |
|---|---|---|
| V1.0 | STA_StartAck | 启动命令已接收 |
| V1.1 | STA_PauseAck | 暂停命令已接收（预留） |
| V1.2 | STA_StopAck | 停止命令已接收 |
| V1.3 | STA_AlarmAckDone | 报警确认已执行 |
| V1.4 | STA_MuteDone | 消音已执行 |
| V1.5 | STA_ForceDone | 状态强制修正已执行 |
| V1.6 | STA_TankA_State | 上缸状态：0=空，1=满 |
| V1.7 | STA_TankB_State | 下缸状态：0=空，1=满 |

### 4.3 急停与安全状态（直接映射DI，供HMI读取）

| 信号 | 来源 | HMI显示 |
|---|---|---|
| 急停触发 | I1.1=OFF | 红色"急停触发" |
| 安全继电器反馈 | I1.2 | 正常/故障（I1.1=OFF且I1.2超时未反馈→继电器故障最高报警） |
| 急停已解除待复位 | I1.1=ON 且 M_EStop_Latch=1 | 黄色"急停已释放，等待系统复位" |

### 4.4 手动控制命令位（V2.4~V3.5区，HMI→PLC，断电保持）【校验修复新增】

V0区8位已满（系统命令位），手动调试用命令位扩展至V2.4~V3.5区。仅S0态响应（避免运行中误操作），由OB1条件调用FC20。对应HMI画面3"手动控制"。

| 地址 | 符号 | 说明 | 响应条件 | 握手确认 |
|---|---|---|---|---|
| V2.4 | CMD_Manual_ValveA_Open | 手动开阀A | VW2=0 | PLC置V2.4=0确认 |
| V2.5 | CMD_Manual_ValveA_Close | 手动关阀A | VW2=0 | PLC置V2.5=0确认 |
| V2.6 | CMD_Manual_ValveB_Open | 手动开阀B | VW2=0 | PLC置V2.6=0确认 |
| V2.7 | CMD_Manual_ValveB_Close | 手动关阀B | VW2=0 | PLC置V2.7=0确认 |
| V3.0 | CMD_Manual_ValveC_Open | 手动开阀C | VW2=0 | PLC置V3.0=0确认 |
| V3.1 | CMD_Manual_ValveC_Close | 手动关阀C | VW2=0 | PLC置V3.1=0确认 |
| V3.2 | CMD_Manual_Pump1_On | 手动启动潜水泵1 | VW2=0 | PLC置V3.2=0确认 |
| V3.3 | CMD_Manual_Pump1_Off | 手动停止潜水泵1 | VW2=0 | PLC置V3.3=0确认 |
| V3.4 | CMD_Manual_Pump2_On | 手动启动潜水泵2 | VW2=0 | PLC置V3.4=0确认 |

**注1**：手动命令位采用"上升沿触发+PLC清零握手"机制（区别于V0区的置位握手），避免HMI侧残留1值导致重复触发。
**注2**：潜水泵2手动启停由V3.4/V3.5控制，FC20中映射到Q0.1。
**注3**：手动操作时安全联锁仍生效（如阀B开启需上缸=满下缸=空，阀C开启需下缸=满），由PLC在响应逻辑中校验，HMI侧仅下发命令不负责联锁。

## 五、状态机与泵状态

### 5.1 状态机当前状态（VW2，WORD/INT，断电保持）

| 值 | 状态 | 说明 |
|---|---|---|
| 0 | S0 | 初始化（上下缸状态置空，输出复位） |
| 1 | S1 | 上缸进水（阀A差值法计量，液位计A高位漫溢保护） |
| 2 | S2 | 预循环（潜水泵1/2搅拌） |
| 3 | S3 | 加药（注射泵抽液→排液） |
| 4 | S3.5 | 静止等候（溶液沉降） |
| 5 | S4 | 上→下转移（阀B四态诊断+液位计B高位漫溢保护） |
| 6 | S5 | 实验运行中（换水周期计时+实验时长累加+S5上升沿触发预规划） |
| 7 | S6 | 下缸排水（阀C四态诊断+S6实测时长滚动更新） |
| 8 | S7 | 实验结束（状态机锁定，需人工HMI确认重启） |
| 99 | S_ERROR | 故障锁定（急停或最高级报警触发，需系统复位） |

### 5.2 注射泵状态码（VW4，WORD/INT，非断电保持）

映射自Modbus寄存器41001，PLC轮询后更新。HMI读取用于判断抽/排液动作状态。

| 状态码 | 含义 | HMI处理 |
|---|---|---|
| 0 | 空闲/完成 | 可下发新指令 |
| 1 | 运行中 | 等待 |
| 2 | 抽液中 | 显示"加药中" |
| 3 | 排液中 | 显示"排液中" |
| 其他非0 | 错误码（按泵厂商定义） | 触发注射泵故障报警 |

### 5.3 当前报警码（VW6，WORD/INT，断电保持）

当前最高优先级未确认报警的编码，详见第九章。0=无报警。

### 5.4 实验轮次计数（VW8，WORD/INT，断电保持）

每完成一个换水周期（S1→S6）累加1，用于HMI显示和趋势曲线X轴。

## 九、报警标志与报警码定义

### 9.1 报警字（VB300~VB303，4字节32位，断电保持，按位编码）

### 11.4 差值法进水计量逻辑（S1阶段）

```
阀A开启瞬间：
  VD_FlowMeter_Snapshot = MB_Flow_Total（当前累计流量快照）

进水过程中（周期轮询）：
  VD_Current_InletVolume = MB_Flow_Total − VD_FlowMeter_Snapshot

阀A关闭且验证通过：
  本轮进水量最终值 = VD_Current_InletVolume（锁定）
  用于计算 VD_Vol_Target = VD_C_Set × 本轮进水量 / VD_C_Stock
  用于计算 VD_Dose_Steps = VD_Vol_Target ÷ VD_StepResolution
```

### 11.5 Modbus通讯状态字（FC4 LAD指令引脚输出，2026-07-27新增）

**背景**：MBUS_CTRL和MBUS_MSG指令盒的Done/Error引脚必须连接到具体地址，不能留空（否则编译错误32）。本节登记FC4中LAD指令盒所占用的Done位和Error错误码地址。

**地址分配原则**：
- Done位用M区（BOOL），Error错误码用VB区（BYTE，错误码0~255）
- 避开VD380/VW380定时器暂存区（VB380~383，FC11/FC15/FC17/FC3共用；VW380与VD380为同一物理地址的字/双字视图，属临时变量，不同时长存数据）
- 避开VD374降级值区（VB374~377）
- 避开VB500~599报警日志区和VB600+ Modbus库区

| 地址 | 符号 | 类型 | 用途 | 来源 |
|---|---|---|---|---|
| M10.0 | M_FC4_Done_Pump | BOOL | MBUS_MSG任务0(注射泵状态码)Done位 | LAD引脚输出 |
| M10.1 | M_FC4_Done_Flow | BOOL | MBUS_MSG任务1(流量计累计值)Done位 | LAD引脚输出 |
| M10.2 | M_FC4_Done_PumpStep | BOOL | MBUS_MSG任务2(注射泵步数)Done位，预留 | LAD引脚输出 |
| M10.3 | M_FC4_Done_PumpSpeed | BOOL | MBUS_MSG任务3(注射泵速度)Done位，预留 | LAD引脚输出 |
| M10.4 | M_FC4_Degraded_Pump | BOOL | 注射泵降级模式标志（连续5次失败） | FC4内部逻辑 |
| M10.5 | M_FC4_Degraded_Flow | BOOL | 流量计降级模式标志 | FC4内部逻辑 |
| M11.0 | M_MBUS_CTRL_Done | BOOL | MBUS_CTRL Done位（每周期脉冲） | LAD引脚输出 |
| VB378 | VB_MBUS_CTRL_Error | BYTE | MBUS_CTRL Error错误码 | LAD引脚输出 |
| VB379 | VB_MBUS_MSG_Pump_Error | BYTE | MBUS_MSG注射泵轮询错误码 | LAD引脚输出 |
| VB384 | VB_MBUS_MSG_Flow_Error | BYTE | MBUS_MSG流量计轮询错误码（避开VD380暂存区） | LAD引脚输出 |

**错误码含义**（参考西门子Modbus RTU Master库手册）：
- 0 = 无错误
- 1 = 从站无响应（超时）
- 2 = 接收校验错误（CRC/奇偶）
- 3 = 从站返回异常码（Modbus Exception）
- 4 = 请求队列满
- 5~6 = 库内部错误
- 101+ = 参数错误（Addr/Count/DataPtr配置非法）

**HMI读取建议**：HMI可通过VB378/VB379/VB384读取通讯错误码，在"通讯维护页"显示Modbus总线状态。当错误码≠0持续超过10秒，建议HMI提示"通讯异常"。

### 11.6 FC4 Modbus 轮询内部计数器（2026-07-28 修正）

**背景**：原 FC4 使用 VW250/VW252/VW254/VW256 作为轮询计数器/重试计数/连续失败计数，但运行中发现：
- VD250（目标进水量，HMI 设定区；地址表规划已迁移至 VD316，需确认 HMI 侧已同步）占用 VB250~VB253，覆盖 VW250/VW252；
- FC12 的 T38 PT 转换值使用 VW252；
- FC14 的 T39 PT 转换值使用 VW254。

以上冲突会导致轮询计数器被意外覆盖、轮询状态机卡死。AQEX-48 修复后迁移至 VW290~VW297 空闲区。

| 地址 | 符号 | 类型 | 用途 | 备注 |
|---|---|---|---|---|
| VW290 | VW_FC4_PollIndex | INT/WORD | 轮询从站计数器（0=注射泵状态码，1=流量计累计值，2=注射泵步数，3=注射泵速度） | 当前 STEP7 中仅实现任务 1（流量计），泵任务待硬件到货后补充 |
| VW292 | VW_FC4_RetryCount | INT/WORD | 当前任务重试计数（0~3，超 3 次标记本任务失败并报警） | 每次任务成功清零 |
| VW294 | VW_FC4_PumpFailCount | INT/WORD | 注射泵连续失败计数（≥5 次进入降级模式，使用上一有效值） | 通讯恢复后清零 |
| VW296 | VW_FC4_FlowFailCount | INT/WORD | 流量计连续失败计数（≥5 次进入降级模式） | 通讯恢复后清零 |

**注意**：VW290~VW297 由 FC0 在首次扫描时初始化，不配置断电保持。
