7.4.4
多重复制
在组态画面过程中，经常需要快速创建一批同质不同地址
(
变量
)
的动画构件。因此组态软件提供了构件多重复制功能。
支持多重复制构件可配置项目有普通文本、多语言文本、变量名称、表达式。
l
多语言文本：属性值使用了多语言项内容，自动创建或关联对应的多语言项内容。不使用多语言项内容，依旧保持不使用多语言项内容。
l
变量名称：变量名称不存在时，在实时数据库中自动创建对应变量。
l
表达式：表达式中存在未知变量时，在实时数据库中自动创建对应变量。
多重复制功能仅针对变化项目配置中已勾选的项目进行内容变化分发，其他未勾选的，保持跟基础构件内容一致。
变量名称不存在时，会自动创建对应类型的变量。

自动递增：按照自动递增的一些预置规则进行内容变化。默认选中。
（列表索引下的表格可预览配置对应的矩阵内容）。
内容：基础构件对应属性下的值，
{R}
这三个字符代表变化部分。
起始值、定长、间隔、进制配置变化影响的都是
{R}
所在的内容。
原值末尾是数字时，自动提取到起始值、定长。

起始值：配置
{R}

0

”
文
3

3

l
间隔：配置
{R}
部分的数字间隔，默认为
1
。
l
定长：配置
{R}
部分的数字整体长度，默认不勾选，原值末尾时定长数字时，定长长度为该数值。例如，
”
文
0003
“

4

l
进制：配置
{R}
部分的变化，起始值、间隔、定长按照八进制
/

l
列表索引：开启列表索引下的表格内容编辑。默认不选中。
l
变量选择：在列表索引选中时，可对表格内容做整体替换。（多选）
l
预览：预览构件矩阵的个数、间隔象素、整体偏移象素。
(
暂不支持内容预览

l
确定：构件矩阵按照勾选的可变化项目配置进行整体变化内容

”
分发。
l
取消：取消多重复制基础构件。
l
帮助：打开多重复制所在的帮助位置。
（
2
）使用方法
打开动画组态窗口，保持
编辑条工具按钮处于选中状态。在编辑条中
多重复制工具按钮。当选中一个基础构件时，多重复制工具按钮可用。未选中构件时，多重复制工具按钮不可用。
也可以在选中一个基础构件后，右键菜单“排列
|
多重复制”。
以上两种方式均可打开多重复制对话框，进行基础构件的多重复制工作。

（
4
）注意事项
l
基础构件属性设置完成后再进行多重复制。
l
变化项目配置中勾选对应项才能按照预定义配置进行内容变化。未勾选项内容保持不变
(
与基础构件
)
。
l
变量名称需要命名合法，表达式内容编译正确，才能自动对应的数据库变量。
l
部分勾选项不能保证内容分发成功。例如：显示输出，如果输出值类型，选择整数，此时单位是不可编辑的，即使在多重复制变化项目配置勾选了单位，因构件本身的属性项互斥，也会导致属性值设置失败。
