15.9
注意事项
（
1
）删除报警时，如果未选择需要删除的报警数据则删除不生效。
（
2
）报警导出时只是导出表格中的数据，不检查表格中的数据是否正确，而且报警描述只能导出当前语种的信息，不能导出其它语种描述信息。
（
3
）报警导出时如果表格中没有数据则无法导出。
（
4
）报警导入时不检查文件中的报警的合法性，全部导入数据到画面后，可进行再次编辑，保存时才检查所有的报警信息是否正确。
（
5
）导出的文件使用
excel
打开，不能增加和删除列，可以新增行或在原有行进行修改；使用
excel
修改文件内容后保存需要保存为
xml
格式。
（
6
）目前报警描述只支持单行，已编辑多行多语言单行显示。
（
7
）查找替换已到末尾，如果还需要再次查找替换则需要手动选中左上角第一个数据单元格才能再次进行查找替换。
（
8
）报警文件使用
excel
打开后，新增需要在表格已有数据最右下角拖动方式进行数据行增加，不能直接插入行，不能直接在已有数据后面的空白行进行编辑。
（
9
）导入文件中序号列暂时备用，可重复但不能为空，为空时此行数据全部忽略。
（
10
）导入文件中如果多语言
ID
不小于
0
时，且多语言
ID
重复则对应的报警描述只有最后一条生效，其它相同多语言
ID
的报警描述将被覆盖。
