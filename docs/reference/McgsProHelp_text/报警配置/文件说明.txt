15.8
文件说明
报警导入导出使用的文件格式为
xml
格式。当需要对导出的报警数据进行修改时可以使用
Excel
将导出的
xml
文件打后（如图
15.8-1
所示）进行编辑。文本中已保留了部分可直接添加数据的空白行，如果已有格式的空白行不足新增数据时需要使用已有数据右下角按住往下拖动方式（图
15.8-1
中红框部分），不能直接插入行，不能直接在已有数据后面空白行编辑数据。
图
15.8-1
导出的报警数据使用
Excel
打开后结构
数据列说明：
l
ID
：目前备用，内容为整数，不能为空字符串。
l
变量名称：编辑报警信息判断的变量名称，不能为空字符串。
l
变量类型：报警信息关联的变量的类型，一般为浮点数或整数，其它类型导入后保存时会提示错误，不能为空字符串。
l
报警类型：报警信息的类型，整数可以使用
12
种报警：开关量、负跳变、正跳变、位
==
、位
OFF-->ON
、位
ON-->OFF
、值
==
、值
<>
、值
>
、值
>=
、值
<
、值
<=
；浮点数可以使用
12
种报警：下下限、下限、上限、上上限、下偏差、上偏差、值
==
、值
<>
、值
>
、值
>=
、值
<
、值
<=
。
l
报警可用性：
0
表示不生效、
1
表示生效，其它值错误。
l
基准值：报警判断基准值，只能为数字。
l
触发误差：报警判断产生时相对于基准值的误差值，只能为数字。
l
解除误差：报警判断结束时相对于基准值的误差值，只能为数字。
l
报警分组：报警分组的序号，范围为
0-255
l
报警级别：设置报警的级别，范围为
0-100
l
多语言
ID
：指定是否使用多语言，
<-2
表示新建多语言项，
-1
表示不使用多语言，其它值表示修改对应的多语言项（如果有则修改，无则增加）。
l
多语言类型：表示多语言描述的多语言类别，需要整体保持一致。
l
报警描述：指定语言种类的报警描述，语言种类与导出时组态设置的当前选择的多语言种类有关，导入时此数据直接与多语言
ID
共同作用生成多语言数据项，如果多语言
ID
相同则最后一个多语言描述生效。
