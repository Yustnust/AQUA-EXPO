第十三章 多语言
本章主要从多语言的功能概述，多语言支持的模块，多语言组态的配置以及其他一些操作说明来阐述基于
Linux
的触摸屏多语言的使用方法。
13.1
功能概述
基于
Linux
的触摸屏使用多语言组态工程，有以下原因需要创建多语言工程：
l
在多个国家使用同一工程，项目使用多种语言创建；
l
将工程提供给工厂中使用不同语言的操作员使用，用多种语言创建项目
说明：
l
工程语言：在组态环境和运行环境下可以使用的语言，在多语言配置中可以选择并更改；
l
工程启动语言：在运行时语言选择窗口中选择，默认为
Chinese
，可以更改。其选择内容只能为工程已经选择语言。模拟运行或下载时，作为工程的初始运行语言；
l
基于
Linux
的触摸屏默认支持的语言有
Chinese
、
English
，用户可以根据实际情况添加自定义语言；
l
以前的旧工程，通过转换后所有文本内容都默认不支持多语言；
