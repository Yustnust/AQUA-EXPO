策略组成
策略条件：策略行中的条件部分和功能部分以独立的形式存在，策略行中的条件部分为策略条件。通过对策略条件部分的组态，用户可以控制在什么时候、什么条件下、什么状态下，对数据对象管理进行操作，对报警事件进行实时处理，打开或关闭指定的用户窗口，完成对系统运行流程的精确控制。
策略构件：策略行中的功能部分为策略构件。目前，
McgsPro
软件只支持脚本程序构件，脚本编辑的方法，请参考
第十一章
和
第十二章
内容。

如何使用运行策略密码：
（
1
）运行策略保护密码的意义
用户可为指定相关运行策略设置保护密码。防止其他没有权限的用户修改该运行策略，进而保护用户指定的运行策略不会受到不被允许的修改。
（
2
）运行策略保护密码的使用
l
打开指定的运行策略的属性设置对话框，输入密码确认即可。（密码支持十位字符串的输入，包含中英文和特殊符号。注意：中文密码的输入只支持非保密状态输入时。）
l
取消密码只需要打开运行策略的属性设置对话框，清除掉密码即可。
l
复制加密运行策略时，保密状态会跟随复制的运行策略。
l
删除加密运行策略时，必须先输入正确的该运行策略的保护密码。
l
不同运行策略可设置不同的保护密码，用户需要牢记自己设置的密码。
打开运行策略或运行策略属性设置对话框，都需要正确输入该运行策略的保护密码。

策略行条件属性
策略条件是运行策略用来控制运行流程的主要部件。在每一策略行内，只有当策略条件满足时，系统才会执行策略构件的逻辑。
在策略块，每个策略行都有如图
6.3-4
所示的表达式条件部分，用户在使用策略行时可以对策略行的条件进行设置（缺省时表达式的条件为真）。
注意：
策略块按照策略行的顺序，从上到下依次执行，也就是说，前一个策略行中修改的某个数据对象的值，在后一个策略行中是修改生效的
其操作有如下几种方法：
l
表达式：输入策略行条件表达式。
l
条件设置：用于设置策略行条件表达式的值成立的方式。
l
表达式的值非
0
时条件成立：当表达式的值非
0
时，条件成立，执行该策略。
l
表达式的值为
0
时条件成立：当表达式的值为
0
时，执行该策略。
l
表达式的值产生正跳变时条件成立一次：当表达式的值产生正跳变（值从
0
到
1
）时，执行一次该策略。
l
表达式的值产生负跳变时条件成立一次：当表达式的值产生负跳变（值从
1
到
0
）时，执行一次该策略。
