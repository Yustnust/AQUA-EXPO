9.3
脚本函数
运行环境的配方操作可以通过配方脚本函数的使用来进行，配方脚本函数需着重注意如下：
（
1
）
!RecipeLoad
函数的调用和配方构件的存在均可以使配方变为已加载状态，只有当配方组处于已加载时，其他配方函数才可以正确执行，并且不会修改配方组的状态。
（
2
）
!RecipeClose
函数可以使配方关闭，离开已加载状态，但是不会保存配方数据到磁盘文件。
（
3
）
!RecipeSave
函数功能为将当前配方组数据写入磁盘文件中保存，未保存配方掉电时，不会将配方数据保存到磁盘文件。

新配方组名称，字符串，需要新建的配方组名称
模版配方组名称，字符串，模版配方组的名称
新建模式，整数
BIT0
表示创建新配方组时，是否拷贝模版配方数据
BIT0 = 0
：不拷贝，新建配方数据为空
BIT0 = 1
：拷贝，新建配方组与模版配方组数据一致
BIT1
表示新建配方组已存在时的处理方式
BIT1 = 0
：不覆盖，返回失败
BIT1 = 1
：覆盖
返 回 值：
整数
0
：执行成功
-1
：执行失败
-14
：新建配方组名为空
-15
：模版配方未加载
-16
：新配方已存在，但是模式选择为不覆盖
实
例：
配方返回值
= !RecipeCreate(
“
我的面包
”
,
“
面包
”
,3)
注意事项：
需要模板配方组在已加载情况下才可以进行新建配方组。

参数说明：

返 回 值：
整数
0

-2

配方返回值
= !RecipeGroupDelete(
“
我的面包
”
)
注意事项：
使用此方法需要配方处于已加载状态。组态的配方组删除过后，依旧可以加载数据，此时数据为组态原始数据。脚本新建的配方组删除过后则不再能加载数据。
