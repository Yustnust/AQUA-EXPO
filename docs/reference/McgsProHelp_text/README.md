# McgsPro 3.3.6 官方帮助文档(纯文本版)

**来源**: McgsProHelp.chm(昆仑通态McgsPro 3.3.6.6354 SP1.3组态软件官方帮助文档)
**转换时间**: 2026-07-19
**转换方式**: archmage解压CHM → BeautifulSoup提取正文 → UTF-8纯文本
**文件数量**: 115个.txt文件,18章节
**总大小**: 约1MB
**编码**: UTF-8

## 转换工具

- `tools/parse_chm.py`: CHM二进制格式探测(标记定位)
- `tools/extract_chm_text.py`: 批量提取HTML章节为纯文本(BeautifulSoup)

转换流程:
```bash
# 1. 安装chm解压工具
apt-get install -y archmage chmlib

# 2. 解压chm到HTML目录(原gb2312编码)
archmage -x McgsProHelp.chm /tmp/chm_out

# 3. 转码gb2312→utf-8(用iconv或Python脚本)
# 4. 批量提取纯文本
python3 tools/extract_chm_text.py
```

## 使用建议

1. **AI助手检索**: 直接读取需要的.txt文件即可,无需再解压chm
2. **关键章节**: 优先查看"脚本程序/基本语句.txt"和"脚本函数/运行环境操作函数.txt",这两章决定了脚本能否编译通过
3. **错误排查**: 出现脚本错误时,先查"脚本程序/语言要素.txt"的命名规则和"组态查错.txt"
4. **构件属性**: 每个构件的属性配置详见"动画构件/"目录下对应文件
