EnableExitLogon
(n)
函数意义：
打开
/
关闭退出时的权限检查
返 回 值：
浮点数，任何情况下，都代表执行成功
参
数：
n
，浮点数
n = 0
，代表退出时不进行权限检查
n = 1
，代表退出时进行权限检查
n = 2
，代表当前登录用户超过登录时长设置自动注销时，弹出用户注销提示框
n = 3
，代表当前登录超时注销时，直接静默执行注销，无任何弹窗（未设置默认为此种行为）
实
例：
!EnableExitLogon(1)
，退出时进行权限检查
!EnableExitLogon(2)
，登录用户超过登录时长时，用户注销进行提示，选择否或关闭，重新开始计时

!SilentLogOn(strName,
strPassword, method, time)
函数意义：
静默登录，不弹出用户登录对话框
返 回 值：
整数
= 0
，登录用户操作成功
其他，登录用户操作失败，见第十章脚本函数返回值参考
参
数：
strName
：字符串，要登录的用户名称
strPassword
：字符串，要登录的用户密码
method
：注销方式。
0
：登录超时，用户保持登录状态超过设定时间后注销；
1
：自动注销，当触摸屏无人操作的持续时间超过设定时间后注销。
time
：超时时间，单位分钟。为
0
时表示永久。与注销方式配合使用。
实
例：
!SilentLogOn(
“
name
”
,
“
password
”
, 0,
0)
：登录名为“
name
”的用户，注销方式为登录超时，登录时间为永久。
注意事项：
如果已有登录用户，本次登录用户成功，会直接将已登录用户登出

!CopyUser(name, password, description, target)
函数意义：
复制一个用户，新用户与被复制的用户具有完全一致的用户组权限
返 回 值：
整数
= 0
，操作成功
= -1500
，用户名已存在
= -1508
，被复制的用户名不存在
= -1513
，参数不合法（例如新用户名或被复制用户名为空）
参
数：
name
：字符串，新用户的用户名
password
：字符串，新用户的密码
description
：字符串，新用户的用户描述
target
：字符串，被复制的用户名，新用户的组归属权限与该用户完全一致
实
例：
ret=!CopyUser("
新用户
","
新密码
","
新用户描述
","
老用户
")
注意事项：
（
1
）该函数调用时不受当前登录用户的权限限制，可对任何已存在用户进行复制。
（
2
）当被复制的用户为内置的超级用户“负责人”时，新用户的组归属关系仍然与其一致，但新用户不具有管理全部用户及用户组的超级权限。
