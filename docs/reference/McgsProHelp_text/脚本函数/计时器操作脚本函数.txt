12.10
计时器函数
可用的系统计时器范围为
0
到
127
，即系统内嵌
128
个系统计时器。用户可以随意使用其中的任意一个。
计时器返回时间值为浮点数，单位为秒，小数位最多可以表示到毫秒，默认情况下计时频率为
1
秒，达到计时器数值上限后停止计时，也可根据需要使用
!TimerSetLimit
脚本设置计时器运行模式。数值可精确到秒，因为采用浮点数表示计时器返回值，毫秒会略有误差。

!TimerWaitFor

计时器号
,
数值

函数意义：
等待计时器工作到“数值”指定的值后，脚本程序才向下执行
返 回 值：
浮点数
返回值
=  0
，调用成功
返回值
<> 0
，调用失败
参
数：
计时器号，
0-127
的整数变量
数值，整数，等待计时器工作到指定的值

例：
!TimerWaitFor(1,55)
’等计时器工作到

注意事项：
如果该函数在窗口调用，在计时器未启动时，如果设定的值大于该计时器的值会出现宕机的情况。
使用该函数时确认对应的计时器已启动。请确认在

计时器号
)
函数执行后再调用该函数
