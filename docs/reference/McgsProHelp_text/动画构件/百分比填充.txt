百分比填充
8.23.1
功能概述
图
8.23-1
百分比构件效果图
百分比填充构件提供了水平、垂直填充效果，填充区域会随着表达式值的变化而变化，同时在百分比填充构件的中间，可用数字来显示当前填充的百分比。

8.23.3
组态配置
在窗口中拖出一个百分比构件，鼠标双击该构件弹出属性设置对话框。本构件包括四个属性窗口页，即：基本属性页、刻度与标注属性页、操作属性页和可见度属性页。

8.23-3
基本属性页
l
构件颜色：设置和调整构件的背景颜色、填充颜色、字符颜色。
l
边界类型：用于设置百分比填充构件的边界形式。其中，“三维边框”是
Windows95
和
WindowsNT
下填充框的标准外形，可以使整个界面具备三维效果。
l
不显示百分比填充信息：选中此复选框，将不在构件中间显示百分比填充信息。

3
）操作属性页
操作属性页如图
8.23-5
所示
:

8.23-5
操作属性页
l
表达式：本项输入的表达式为百分比填充构件所对应的浮点数表达式，本构件把表达式的值转化成图形方式显示。
l
填充位置和表达式值的连接：设置没有填充和全部填充时所对应的表达式的值，运行时以此为依据，由表达式的值来计算对应的填充位置。
l
当表达式的值小于
0%
对应的值时，没有填充，填充信息显示为
0%
；当表达式的值大于
100%
对应的值时，填充区域被填满，填充信息显示为
100%
。
l
当
0%
对应的值大于
100%
对应的值时，填充方向是从左到右或从下到上，和正常情况无区别。
l
点击输入框右侧问号（“？”）按钮关联实时数据库中的数据变量。

8.23-6
可见度页
可见度是指输入框在系统运行中是否可见，是由指定的表达式的值决定。
l
表达式：本项中可以输入一个表达式，用表达式的值来控制构件的可见度。如不设置任何表达式，则运行时，构件始终处于可见状态。点击表达式输入框右侧问号（“？”）按钮关联实时数据库中的变量。
l
当表达式非零时：本项指定表达式的值与构件可见度相对应。
