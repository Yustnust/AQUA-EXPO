8.7
组合框
8.7.1
功能概述
用户对系统的操作中往往会遇到大量数据选择的情况，在个人计算机领域，微软公司提供的一个下拉列表构件给用户提供了方便操作，而应用在工控机领域的组态软件上，组合框构件也因此油然而生。
McgsPro
系列产品的组合框构件包括了
2
种类型（下拉列表框，下拉输入框），不同类型的组合框有不同的处理。如：
l
下拉输入框：提供用户编辑和选择功能；
l
下拉列表框：提供用户选择功能；
McgsPro
系列产品组合框构件本质上是一个特殊的输入型构件，最终目的是对构件的数据关联对象进行赋值操作，赋值方式有：点击下拉项赋值并显示、改变
ID
关联变量值赋值并显示、弹出输入键盘输入赋值并显示（下拉输入框）。
由于组合框构件的多样性，用户可以组合不同类型的组合框构件，完成大部分的手工输入工作，再结合组合框构件的属性和方法脚本以及和实时变量的无缝连接，整个系统功能得到了增强。
McgsPro
系列产品组合框构件由三个部分组成：组态环境组合框构件设计，运行环境组合框构件操作和运行环境组合框构件脚本函数。

）安全属性页
安全属性是指构件在系统运行中是否可操作，是由指定的表达式的值决定。
l
表达式：本项中可以输入一个表达式，用表达式的值来控制构件是否可操作（即使能状态）。如不设置任何表达式，则运行时，构件始终处于可操作状态。可使用右侧的问号（“？”）按钮查找并设置所需的表达式。
l
条件设置：本项指定表达式的值与构件使能状态相对应。
l
失效样式：指定构件不可操作时（构件失效）构件的外观状态。
l
弹框确认：弹框确认可实现组合框选项变化前，对操作进行确认，以达到安全操作目的。确认等待时间指定弹出确认对话框自动消失的时间间隔。

BeforeWrite
事件意义：
组合框（序号关联）、组合框（内容关联）修改后，输入的值写入被输入对象前触发。
AfterWrite
事件意义：
组合框（序号关联）、组合框（内容关联）修改后，在输入的值写入被输入对象后触发。
