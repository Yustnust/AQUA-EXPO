注意事项
Ø
联机失败可能原因及处理
1.
原因：触摸屏离线或网络不稳定
处理：确保屏端供电正常，
检查触摸屏
4G
或
WiFi
天线是否正常
安装
2.
原因：
SIM
卡不存在，或停机、流量耗尽
处理：确保
SIM
正常安装，且未停机（屏端自带
SIM
卡续费方式：关注微信公众号“智能物联网服务中心”，按月、按年充值加油包）
3.
原因：屏端系统时间异常
处理：请确保屏端系统时间与北京时间一致
4.
原因：屏端服务器端口号设置有误，或屏端服务器地址与客户端设置不一致
处理：检查屏端服务器端口号设置，以及保证屏端和客户端的服务器地址一致
5.
原因：屏端设置的用户名和密码，与客户端不一致
处理：保证屏端设置的用户名和密码，与客户端登陆时输入的用户名和密码一致
6.
原因：
PC
端
VPN
驱动安装异常
处理：重新安装
MCGS
调试助手
7.
原因：
Android
未安装
VPN
应用
处理：安装
VPN
应用，并允许“
OpenVPN for
Android
”关联启动
8.
原因：手机未允许
VPN
应用关联启动
处理：在手机权限设置中将“
OpenVPN for Android
”的启动权限设置为：“允许被其他应用唤醒”、“允许关联启动”、“允许后台活动”（不同品牌手机表述略有差异）
9.
原因：联机时弹出“本地组网失败，请检查重试
!
”
处理：检查触摸屏系统时间，需要设置为正确的北京时间，或重新安装
MCGS
调试助手
10.
原因：联机时弹出“设备组网失败，请检查重试
!
”
处理：检查触摸屏系统时间，需要设置为正确的北京时间
Ø
串口穿透失败处理方法
1.
检查串口穿透参数，确保串口穿透参数设置与
PLC
串口通讯参数一致
2.
检查触摸屏联机状态是否正常
3.
检查网络是否存在异常，
通过
PING
触摸屏的内网
IP
确认
4.
开启穿透时提示工程退出失败，可通过
VNC
浏览触摸屏运行环境，确认工程已退出，再重新开启穿透
5.
卸载虚拟串口后重新安装，安装完成后重新开启穿透
6.
穿透开启成功，但上传
/
下载
/
监控
PLC
程序失败，请检查串口参数是否与
PLC
参数一致，并重新开启穿透
Ø
其他异常情况处理
1.
现象：在触摸屏物联网参数设置页面，修改“用户名”失败
处理：检查“用户名”格式，用户名有效长度
6~32
个字节，仅字母有效，区分大小写，无用户名时不允许设备上线
2.
现象：在触摸屏物联网参数设置页面，修改用户密码失败
处理：检查密码格式，密码有效长度为
6~32
个字节，仅字母数字有效，区分大小写，无密码时不允许设备上线
3.
现象：触摸屏无法获取到
4G
网络的
IP
地址
处理：检查
SIM
卡流量是否用完或停机，检查
4G
信号强度，检查
SIM
卡是否正常安装
4.
现象：触摸屏无法获取
WiFi
网络的
IP
地址
处理：检查
WiFi
密码是否输入错误，检查
WiFi
信号强度，检查提供
WiFi
的路由器是否成功连接公网
5.
现象：触摸屏断电后，调试助手仍然显示该触摸屏状态为：在线
/
联机
/
占用
处理：
VPN
服务器超时时间为
2
分钟，设备直接断电后，需要等待
2
分钟才会更新设备状态
6.
现象：部分手机（如
vivo
和
oppo
）使用
VNC
浏览触摸屏画面时，偶发掉线
处理：此为安卓手机省电策略杀后台导致，请手动修改手机省电策略，修改方法如下：
（1）
vivo / IQOO
：设置 → 电池 → 后台高耗电，允许“调试助手”和“
OpenVPN
for Android
”在后台高耗电时继续运行
（2）
oppo
：设置 → 电池 → 关闭“智能耗电保护” → 自定义耗电保护，允许“调试助手”和“
OpenVPN for Android
”后台运行
（3）
其他品牌手机：按照类似方法查找电池省电策略，将“调试助手”和“
OpenVPN for Android
”加入白名单，或者禁用省电策略、允许后台运行、允许高耗电运行
