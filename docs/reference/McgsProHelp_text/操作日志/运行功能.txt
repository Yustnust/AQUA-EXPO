17.3
运行功能
运行环境中，当启用操作日志功能时，启用操作日志的构件被操作时会产生日志，并存储于磁盘。
（
1
）日志保存机制
操作日志每
60
秒自动存盘一次，也可使用脚本函数
!FreshDataSave()
主动存盘。最大存储约
1MB
的内容（约
10000
条），当存储内容超过此大小时，系统将自行清除
25%
的旧数据，无需用户手动清除。
（
2
）日志内容可视化
存储的日志内容类似存盘数据，用户可用存盘浏览构件和报表构件查看日志内容，日志内容的标准格式如表

（
3
）脚本函数
!OperationLogClear()
函数说明：
清除所有的操作日志
返 回 值：
整数，
0
：清除成功；其他：清除失败
!OperationLogEnable()
函数说明：
开启操作日志功能，最小执行间隔
3
秒，频繁调用无效。
返 回 值：
整数，
0
：开启成功；其他：开启失败
!OperationLogDisable()
函数说明：
关闭操作日志功能，最小执行间隔
3
秒，频繁调用无效。
返 回 值：
整数，
0
：关闭成功；其他：关闭失败
!ExportOperationLogToCsv(
文件名，开始时间，结束时间，导出模式
)
函数说明：
导出操作日志到
csv

参数说明：
文件名：字符型，导出文件的文件名
开始时间：整数，可由时间字符串
