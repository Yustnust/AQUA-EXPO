2.3.2 TCP/IP
下载
点击下载运行按钮或按下
F5
→ 下载配置窗口 → 选择联机 → 选择
TCP/IP
网络 → 输入
TPC
的
IP
→ 点击通讯测试 → 提示通讯正常后 → 点击工程下载可以下载工程到屏幕，如图
2.3-9
所示。
图
2.3-9 TCP/IP
下载
若
TPC
运行环境不兼容当前组态工程，则将提示“运行环境版本较低，是否先完成在线升级，再继续下载工程？”，如图

所示。若点击确定，则将升级运行环境，如图
