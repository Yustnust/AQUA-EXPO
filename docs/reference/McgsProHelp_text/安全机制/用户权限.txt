在通常情况下，退出
TPC

McgsPro

!EnableExitLogon(FLAG)
，这个函数的使用说明如下：
FLAG
= 1
，工程系统退出时需要用户登录成功后才能退出系统，否则拒绝用户退出的请求。
FLAG
= 0
，退出时不需要用户登录即可退出，此时不管系统是否设置了退出时需要用户登录，均不登录。
FLAG
= 2
，当前已登录用户超过登录时长时，弹出用户注销询问对话框，点击是才会执行用户注销操作，否则继续保持登录并重新开始计时。
FLAG
= 3
，当前已登录用户超过登录时长时，自动静默执行用户退出操作。
未设置默认为自动执行静默用户注销操作。
为了使上面函数有效，必须在组态时在脚本程序中加上这个函数，在工程运行时调用一次函数运行。
基于
Linux

McgsPro
