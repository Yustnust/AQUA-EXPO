第十章 安全机制
本章主要从组态工程，用户权限，系统权限，工程保护四个方面阐述基于
Linux
的触摸屏的安全机制。
10.1
功能概述
基于
Linux
的触摸屏提供了一套完善的安全机制：
（
1
）组态工程
工程密码设置功能，保护使用
McgsPro
组态软件开发成果
（
2
）用户权限
组态配置权限，为用户系统权限和操作权限提供支持
运行环境权限，为运行环境内重新分配用户权限提供便利
（
3
）系统权限
系统参数设置，防止其他人修改
TPC
系统设置
工程上传下载，防止其他人任意上传或下载
TPC
用户工程
（
4
）工程保护
组态设置，为工程文件保护提供支持
运行保护，为用户工程在指定触摸屏上使用提供支持
基于
Linux
的触摸屏的操作权限机制和
Windows NT
类似，采用用户组和用户的概念来进行操作权限的控制。在
McgsPro
组态软件中可以定义多个用户组，每个用户组中可以包含多个用户，同一个用户可以隶属于多个用户组。操作权限的分配是以用户组为单位来进行的，即某种功能的操作哪些用户组有权限，而某个用户能否对这个功能进行操作取决于该用户所在的用户组是否具备对应的操作权限。
基于
Linux
的触摸屏按用户组来分配操作权限的机制，使用户能方便地建立各种多层次的安全机制。如：实际应用中的安全机制一般要划分为操作员组、技术员组、负责人组。操作员组的成员一般只能进行简单的日常操作；技术员组负责工艺参数等功能的设置；负责人组能对重要的数据进行统计分析；各组的权限各自独立，但某用户可能因工作需要，能进行所有操作，则只需把该用户同时设为隶属于三个用户组即可。
