11.5
组态查错
脚本程序编制完成后，系统首先对程序代码进行检查，以确认脚本程序的编写是否正确。检查过程中，如果发现脚本程序有错误，则会返回相应的信息，以提示可能的出错原因，帮助用户查找和排除错误。常见的提示信息有：
l
未识别的标识符：该标识符不是局部变量和全局可访问的对象
l
未识别的类型：变量声明时没有输入正确的类型
l
未填入参数：函数调用（需要参数）没有填入参数
l
需要一个逻辑值：在条件语句和循环语句中的条件判断中的表达式的值，必须是字节型、整数、浮点数，而不能是字符串和数组
l
需要引用参数：函数的当前参数类型为引用
l
需要一个数据对象：函数的当前参数类型为数据对象
l
局部变量声明错误：局部变量声明的格式错误
l
局部数组变量声明错误：局部数组声明的格式错误
l
局部数组变量声明长度非法：局部数组声明的初始长度错误，须在
0-65535
之间
l
下标访问类型不匹配：访问数组的元素时，下标类型错误；必须是字节
/
整数
/
浮点，最好是整数
l
无副作用的表达式：除了函数调用，一般的表达式需要一个赋值语句来使用表达式的结果
l
类型不匹配：一般是表达式的操作类型不匹配，如整数
+
字符串
l
参数个数不匹配：函数的参数个数不匹配
l
参数类型不匹配：函数的参数类型不匹配
根据系统提供的错误信息，作出相应的改正，系统检查通过，就可以在运行环境中运行，达到简化组态过程、优化控制流程的目的。
