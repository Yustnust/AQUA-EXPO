11.2
编辑环境
11.2.1
功能概述
脚本编辑环境是用户书写脚本语句的地方。目前脚本编辑有两种模式，一种只有脚本编辑框，另外一种是带脚本编辑框的脚本编辑窗口。本章节主要介绍脚本编辑窗口，只有脚本编辑框的脚本编辑环境与脚本窗口中的脚本编辑框功能相似，只是少功能按钮、对象树相关内容和部分快捷键，在此就不多做介绍。脚本编辑窗口主要由脚本编辑框、功能按钮、右键菜单、对象树、对象树查找

11.2.2
脚本编辑框说明
脚本编辑框是用户进行脚本编写最主要的地方，所有脚本内容均显示在此处，其它部分功能均是为脚本编辑框中的内容进行服务的。脚本编辑框用于书写脚本程序和脚本注释，用户必须遵照
McgsPro
规定的语法结构和书写规范书写脚本程序，否则语法检查不能通过（参考后续章节）。目前，脚本编辑框除正常输入字符、行号显示、当前编辑行高亮外还支持自动完成、系统函数提示和快捷键功能。
脚本编辑框中正在编辑的行浅黄色高亮，数字常量红色显示，关键词蓝色显示。关键词有
MOD NOT OR AND XOR IF THEN ELSE ENDIF WHILE ENDWHILE BREAK EXIT DIM
AS BYTE INTEGER SINGLE FLOAT STRING
。

11.2.3
功能按钮说明
功能按钮提供了文本编辑的基本操作，用户使用这些操作可以方便操作和提高编辑速度。比如，在脚本程序编辑框中选定一个函数，然后按下帮助按钮，将自动打开关于这个函数的帮助说明，如果函数拼写错误，将列出与所提供的名字最接近函数的帮助说明。功能按钮只有在打开脚本编辑窗口时才有效。详细内容参照章节
11.2.7
。
11.2.4
右键菜单说明
脚本编辑框中点击鼠标右键弹出操作菜单，可以进行一些快捷操作，此部分功能主要是用于在只有脚本编辑框时进行一些语法或操作符的快捷输入。右键操作功能项基本上与功能按钮相似，详细功能和支持项详见章节
11.2.7.
11.2.5
对象树说明
对象树以树结构的形式，列出了工程中所有的窗口、策略、设备、变量、系统支持的各种方法、属性以及各种函数，用户可以在此快速找到自己想操作的变量、函数、对象、属性或方法，双击后即可进行快速输入。对象树只有在脚本编辑窗口中有效。
比如，可以在用户窗口树中，选定一个窗口：“窗口
0
”，打开窗口
0
下的“方法”，双击
Open
函数，则
McgsPro
自动在脚本程序编辑框中，添加一行语句：用户窗口
.
窗口
0.Open()
，通过这行语句，就可以完成窗口打开的工作。
