## 0. 追溯范围说明与图例

### 0.1 追溯范围说明

本文档建立"需求→Story→代码→变量→测试用例→状态"的完整双向追溯链，覆盖：

1. **需求侧**：从《PLC设计文档》v9.3 第1~12章提取的功能需求（共58条，REQ-001~REQ-058）
2. **Story侧**：项目已规划的7个Story（Story 1.1~1.7，对应AQEX-2~AQEX-11，AQEX-1为项目设计文档定稿）
3. **代码侧**：plc/stl/ 下20个FC源文件（OB1 + FC0/1/2/3/4 + FC10~19 + FC30/31/32 + FC40）
4. **变量侧**：依据《HMI-PLC变量地址表》v1.0，逐FC映射关键变量地址（V区/I区/Q区/DT区）
5. **测试侧**：《SAT_FAT验收测试用例》v1.0 的106条用例（TC-03-001~TC-11-005）

   │ 验收标准：VD82=开阀瞬间值；VD90=VD86−VD82；VD90≥目标进水量→关阀
   │ 优先级：高
   ↓

   ↓

   │   S    Q0.2, 1        ← 开阀A
   │ FC30 NETWORK 6（子状态3运行中）：
   │   MOVD VD86, AC0       ← 读当前累计值
   │   -D   VD82, AC0       ← 减快照值
   │   MOVD AC0, VD90       ← 写入VD_Current_InletVolume
   │   AR>= VD90, VD316     ← 比较≥目标进水量
   │   R    Q0.2, 1         ← 达标关阀A
   │   MOVD VD86, VD308     ← 快照关阀瞬间值（供内漏检测）
   ↓
【变量】
   │ VD82  = VD_FlowMeter_Snapshot（阀A开启瞬间快照，断电保持）
   │ VD86  = VD_FlowMeter_Current（流量计当前累计值，Modbus 0x0009映射）
   │ VD90  = VD_Current_InletVolume（本次进水量=VD86−VD82）
   │ VD308 = VD_FlowMeter_CloseSnapshot（关阀瞬间快照，供内漏检测）
