**项目背景一句话**: PLC代码Story 1.7已完成(20个FC的STL代码),经2轮完整性校验+静态分析,8个严重VD编址冲突已修复5个(剩余3个参数区步长冲突待专用迭代);HMI初步选型昆仑通态MCGS 12寸(供应商二轮确认中),采购未启动。
**版本**: v1.0
**编制日期**: 2026-07-18
**编制人**: 项目经理
**配套文档**: PLC代码静态分析报告v1.0、PLC代码完整性校验报告v1.0、FMEA失效模式分析v1.0、边界条件与异常场景清单v1.0、PLC程序版本管理规范v1.0、变更管理流程v1.0

## 一、技术债务分类与评级标准

### 1.1 债务分类

| 类别 | 说明 | 典型来源 |
|---|---|---|
| 代码债务 | STL代码缺陷/未实现逻辑/编址冲突/变量问题 | 静态分析报告、FMEA、边界条件清单 |
| 测试债务 | 未执行的测试/缺失的测试用例/未设计的验收场景 | 性能基准测试方案、SAT_FAT用例 |
| 文档债务 | 文档不一致/缺失/过时/注释错误 | 校验报告、版本管理规范、设计文档 |
| 设计债务 | 设计层面未实现的功能/缺失的诊断设计/硬件反馈缺失 | FMEA P2、边界条件清单 |
| 基础设施债务 | 版本管理工具/部署脚本/备份归档/版本号机制未建立 | 版本管理规范、变更管理流程 |

### 1.2 优先级评级

| 优先级 | 判定 | 处置要求 |
|---|---|---|
| **P0立即** | 安全功能缺陷/FMEA RPN≥150的P0项/阻塞发布 | 24小时内启动修复,v1.0发布前必修 |
| **P1高** | FMEA RPN≥150的P1项/静态分析严重项/影响验收 | v1.0发布前或release-1.1前修复 |
| **P2中** | 静态分析警告项/影响可维护性/需硬件改动 | 计划性修复,列入迭代backlog |
| **P3低** | 静态分析提示项/不影响功能/优化类 | 长期跟踪,择机整改 |

### 1.3 债务利息说明

技术债务若不及时偿还,将产生"利息":
- **代码债务利息**: 缺陷累积导致现场故障排查成本指数上升;编址冲突可能引发状态机误转移
- **测试债务利息**: 未测试项在SAT/FAT现场暴露,返工成本远高于内部测试
- **文档债务利息**: 文档不一致导致现场实施错误,重复沟通成本
- **设计债务利息**: 安全诊断缺失可能导致漫溢/实验数据失效等不可逆后果
- **基础设施债务利息**: 版本管理混乱导致8台PLC版本不一致,现场事故风险
